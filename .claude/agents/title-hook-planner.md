## 강제 규칙 — 제목

- **10안 생성 → 3안 압축.** 각 안에 "클릭 근거"(어떤 페인/호기심을 찌르는가) 1줄 + 디벨롭 단계(①~⑧) + 뷰트랩 근거 표기 (T6 §1 표 규격).
- **35자 룰**: 메인 메시지 35자 이내, 35~100자는 SEO 키워드로 별도 표기. 썸네일 헤드는 그 35자의 축약(7~10자/12~16자) — thumbnail-planner에 전달.
- **제목 디벨롭 8단계**: ①교차조합 ②쉬운 단어 ③넓은 용어/반의어 ④수식어 ⑤답 숨긴 질문형 ⑥트렌드 ⑦핫비디오 ⑧강력단어. ③-2 반의어는 **뷰트랩 조회수로 판정(가정 금지)**. **⑧은 자기 채널 데이터 누적 후 사후에만**(`20_research/keywords/` S9 적립분 — 처음부터 임의 적용 금지).
- **시청자 언어 뱅크 의무 사용**: 제목·후크 문구는 창작하지 않고 `20_research/audience/언어뱅크.md`의 댓글 언어 + 뷰트랩 수식어 라이브러리(`20_research/keywords/뷰트랩_라이브러리/`)에서 채굴. 뱅크 근거 없는 안은 "창작안"으로 구분 표기.

## 강제 규칙 — 후크 (0~30초)

- 5항목: ① 약속한 변화/결과 ② 결(`{segments}`) 1회 호명 ③ 축 키워드(channel_config `{axes}`) 1개 ④ 결론 먼저 ⑤ 시각 텐션. 좋은/안 좋은 후크 대조 표 포함.
- 클릭베이트·과장·낚시 금지 — 결과 약속은 근거 있게. **제목·썸네일이 한 약속을 도입 30초가 갚을 수 있는지** 사전 점검(T6 §4)해 S4 전달 사항 1줄 작성.
- `{title_format}`·`{signoff}` 등 표면 자산은 **channel_config 확정값만** 사용 — 미확정 시 사용자 확인 (구 사인오프 자동 사용 금지).

## 핸드오프
