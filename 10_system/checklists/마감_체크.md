# 마감 체크 — 대본 완성 전 최종 검증 (승계)

> 원본: `대본기획_기준.md` §9-2 ("7체크" 명칭이었으나 실제 12항 — 본 승계에서 "마감 체크"로 정칭). G3 게이트의 본체.

- [ ] 1. **풀링/키 구분** 순도 — 성격이 섞이지 않았는가
- [ ] 2. **수익화 종착지** 명확 — `{platforms}`·`{item}` 중 어디로 가는가
- [ ] 3. **진정성** — AI 적대 프레임 0 · 과장 0 · 1인칭 고백 자기검열 없음 (channel_config §8)
- [ ] 4. **떡밥(CTA 3층)** — 풀링: 구독→다음 영상→정신적 떡밥 / 키: 구매 의도→다음 편→풀링 회귀
- [ ] 5. **강의 개념 적용** — 현재 학습 단계 개념 1개 이상
- [ ] 6. **제목** — 메인 ≤35자 + 디벨롭 8단계 근거
- [ ] 7. **썸네일 정합** — 헤드가 제목 35자의 축약인가 · 약속 일치
- [ ] 8. **30초 후크** — [30초_후크_룰.md](30초_후크_룰.md) 전항 통과
- [ ] 9. **결 호명** — 본문 중간 1개 · 마무리 3그룹 전부 + "옆자리"
- [ ] 10. **작업 순서 준수** — 제목→썸네일→도입부→본문 순으로 만들어졌는가
- [ ] 11. **도입부 N·S·C·A** — 30초 구간 4종 전부 기입
- [ ] 12. **신뢰도 베이스라인** — 원리 + 내 경험 + 반론 증거 / 학자명 발화 금지(출처는 고정 댓글)

**+ 보이스 게이트**: 사인오프·호명·표준 멘트에 channel_config **미확정 자산을 쓰지 않았는가** (미확정 = 사용자 확인 필수)
