# 영상 유형별 체크리스트 (승계)

> 작업 도중 유형별 점검. 원본: `10_system/checklists/영상유형별_체크리스트.md` (무수정 승계 — 유형 중립)

## 풀링 (쇼츠/릴스)
- [ ] 후킹 첫 3초 안에 호기심 자극
- [ ] 핵심 메시지 1개로 좁혀졌는가 (2개 이상 X)
- [ ] CTA가 구체적인가 (단순 "구독" X)
- [ ] 종횡비 9:16 + 자막 안전구간
- [ ] 자막 한 줄 ≤12자
- [ ] BGM 볼륨이 내레이션을 방해하지 않는가
- [ ] `{no_expose}` 직접 노출 0회 *(v2 추가)*

## 키 (본 영상)
- [ ] 챕터 구조화 (리텐션 맵 정합)
- [ ] 각 챕터에 마이크로 CTA
- [ ] 챕터 인디케이터 자막
- [ ] 설명란 챕터 타임스탬프
- [ ] 자막 한 줄 ≤18자
- [ ] 인용·통계 출처 화면 표기

## 랜딩/세일즈
- [ ] 4단(Problem/Promise/Proof/CTA) 구조 명확
- [ ] 오버 프로미스 없음
- [ ] 증거(Proof) 구체적 (실 후기/숫자/스크린샷)
- [ ] 광고 표기 필요 여부 확인
- [ ] CTA 링크가 설명란 최상단
- [ ] 가격·조건이 영상↔랜딩 페이지 일치
