# 코워크 프롬프트 — 뷰트랩 추출 (S1·S2)

> 뷰트랩은 공개 API가 없는 유료 웹 도구 — **코워크(Claude in Chrome) 위임 작업**. 승계: `10_system/guides/뷰트랩_주제발굴_디벨롭_가이드.md`(상세 룰 원천)

## 전제 (실측 확인됨)
1. **구글 로그인은 자동화가 막힌다** → SOP 1단계는 항상 "사용자가 직접 로그인 완료 후 신호".
2. 이후 `app.viewtrap.com/video-search`에서 진행.

## 입력 (사용자 → 코워크)
- 키워드 1~N개 (또는 "주제뱅크 후보 검증: <주제 목록>")
- 목적: 주제 발굴(S1) / 제목 디벨롭 근거(S3) / 반의어·수식어 판정

## 추출 항목 (키워드별)
- 노출확률 · 추천 키워드(확장 아이디어) · 영상별 조회수·구독자·좋아요 · 성과도·기여도 · **조회수 급상승(떡상) 감지 영상**
- 썸네일 학습(S3 요청 시): 성과도·기여도 상위 영상 썸네일의 소재·문구 위치·색 구성 메모

## 저장 포맷
`20_research/keywords/YYYY-MM-DD_<키워드>.md`
```markdown
# 뷰트랩 — <키워드> (YYYY-MM-DD)
| 영상 | 채널 | 구독자 | 조회수 | 성과도 | 기여도 | 링크 |
|---|---|---|---|---|---|---|
## 발견 (3줄)
## 파생 주제 후보 (→ 주제뱅크 T1 카드로)
```

## 룰
- 수치는 화면에서 실추출만 — 기억 작성 금지.
- "구독자 대비 떡상" 영상 = 알고리즘 열림 신호로 별도 표기 (T2 스코어카드 '기회' 축 근거).
- 반의어·부정형 판정은 조회수 데이터로만 (긍정형 가정 금지).
