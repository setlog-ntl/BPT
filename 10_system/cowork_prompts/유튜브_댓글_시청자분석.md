## 0. 한 줄 정의 · 코워크 작동 방식

**코워크에서 사용자가 유튜브 링크(+분석 각도)를 지시 → Claude가 크롬으로 댓글을 직접 추출 → 「대표댓글 TOP 3(최상단) · 간략 정체성/추정연령 · 강화된 시청이유」 영상 페이지 1장 생성 → 누적 허브에 카드로 등록.**

```
[사용자] "이 링크 분석해줘 (+ 분석 각도)"
        │
        ▼
[Cowork] ① 크롬으로 영상 열기 → 인기순 댓글 직접 추출(InnerTube)
         ② 정체성/연령 신호·시청이유 집계 + 연령 추정
         ③ 템플릿 복사 → 영상 페이지 작성 (각도 반영)
         ④ 허브에 카드 추가 + 누적 현황 갱신
         ⑤ 검증 후 사용자에게 허브·페이지 공유
```

이 작업의 핵심은 **"직접 추출"** — 외부 서비스가 아니라 코워크가 Claude in Chrome으로 그 영상의 실제 댓글을 가져온다(§5).

## 1. 입력 모델 — "링크 + 분석 각도"

사용자 지시는 **유튜브 링크 1개 + (선택) 분석 각도** 형태다. 각도가 없으면 `기본`으로 처리한다.

### 1.1 분석 각도(기준) 메뉴

각도는 **고정 3단 구조(TOP3 → 정체성/연령 → 시청이유)는 그대로 두고**, 어떤 댓글을 끌어올리고 어디를 두텁게 쓸지를 바꾼다.

| 각도 | 사용자가 이렇게 말하면 | 출력에서 강조 |
|---|---|---|
| **기본** | "이 영상 분석해줘" | 표준 포맷(균형). 각도 메모 없음 |
| **경쟁·벤치마크** | "우리 관점에서 비교", "벤치마크로" | 시청이유를 우리 후크와 비교, 빈틈·차별점을 각 이유 옆에 1줄 |
| **후크 발굴** | "후크 뽑게", "제목 아이디어" | 시청이유 1~3위를 **풀링/키 후크 카피 후보**로 변환 표기 |
| **시청층 정밀** | "수험생 위주", "더 읽으려는 결 중심" | 정체성/연령 섹션 확대 + 해당 층 댓글 집중 인용 |
| **이북리더기 연계** | "이북리더기 관점" | 독서환경·휴대성·디바이스 관련 페인/댓글 집중(1차 아이템 연결) |
| **부정·반론** | "까는 댓글 위주", "리스크" | 비판·반론 섹션 확대 + 오해/리스크 정리 |
| **팬덤·재구매** | "팬덤 관점", "충성 시청자" | 반복 시청·감사·"N년째" 댓글 집중 |

> 각도는 복수 지정 가능(예: "후크 발굴 + 이북리더기"). 결 3그룹(읽으려는·읽고 있는·더 읽으려는)·풀링/키 퍼널 등 bizpt 용어로 지시해도 된다.

### 1.2 각도가 출력에 남는 위치

- 영상 페이지 **헤더 메타**에 `분석 각도 · <각도>` 표기.
- 각도가 `기본`이 아니면, 해당 섹션에 **각도 메모 1줄**(예: 후크 발굴 → 시청이유마다 "→ 후크 후보: …").
- 허브 카드에 작은 각도 태그(선택).

## 2. 산출물 구조 (고정)

영상별 페이지는 **이 순서를 반드시 지킨다**(사용자 확정).

| 순서 | 섹션 | 강도 | 내용 |
|---|---|---|---|
| **①** | **대표댓글 추천 많은 순 TOP 3** | **최상단·강조** | 좋아요 1·2·3위 댓글 + 좋아요 수 + 신호 태그 |
| ② | 정체성 · 추정 연령 | **간략** | 5밴드 연령 막대(추정) + 정체성 신호 칩 5개 + 한 줄 요약 |
| ③ | 시청 이유 | **강화(메인)** | 순위 · 비중% 막대 · **이유마다 근거 댓글 1개** (5~7개) |
| ④ | 더 보기 (선택) | 보조 | 그 외 대표 댓글 2~3개 (+ 각도 메모) |

작성은 `타채널참조/_템플릿_영상댓글분석.html` 복사 → `{{...}}` 치환. **정체성/연령은 짧게, 시청이유는 두텁게**가 이 포맷의 정체성.

## 4. 작업 순서 (코워크 체크리스트)

1. **[각도 확인]** 사용자 지시에서 링크 + 분석 각도 파싱(없으면 `기본`).
2. **[직접 추출]** Claude in Chrome로 영상 열기 → 영상 **일시정지**(무거운 watch 페이지는 렌더러가 멈춤) → 인기순 댓글 **약 600개** 추출(§5).
3. **[집계]** 페이지 내 JS로 정체성/연령·시청이유·인기순 정렬 집계(§6). URL/쿼리스트링은 **반드시 제거** 후 반환(콘텐츠 필터 차단 방지).
4. **[연령 추정]** §7 방법으로 5밴드(합 100%) 추정 + 주의문구.
5. **[작성]** 템플릿 복사 → `타채널참조/<카테고리>/<슬러그>.html`로 `{{...}}` 치환. 각도를 메타·메모에 반영(채널명은 카드 `.ch`에).
6. **[등록]** 허브 `<!-- VCARDS -->` 바로 아래 카드 1장 추가(최신순 맨 위) + 상단 누적 현황 숫자 갱신.
7. **[검증·공유]** §8 통과 → 허브·신규 페이지를 사용자에게 공유.

> 5개 이상 파일을 한 번에 만들거나 기존 결론을 바꿔야 하면 CLAUDE.md §7대로 사용자에게 먼저 확인.

## 5. 댓글 직접 추출 방법 (Claude in Chrome)

watch 페이지 DOM 스크롤은 렌더러 프리징·무한 스피너가 잦다. **유튜브 내부 InnerTube API**가 안정적.

1. 영상 진입 후 영상 일시정지(`document.querySelector('video').pause()`).
2. `ytcfg.get('INNERTUBE_API_KEY')`, `INNERTUBE_CONTEXT_CLIENT_VERSION`, `VISITOR_DATA` 추출.
3. `ytInitialData`에서 댓글 continuation 토큰:
   `contents.twoColumnWatchNextResults.results.results.contents[]` 중
   `itemSectionRenderer.sectionIdentifier === 'comment-item-section'` →
   `contents[0].continuationItemRenderer.continuationEndpoint.continuationCommand.token`.
4. `POST /youtubei/v1/next?key=<APIKEY>` (body: `{context:{client:{clientName:"WEB",clientVersion,hl:"ko",gl:"KR",visitorData}}, continuation:<token>}`) 로 페이지네이션.
   - **댓글 본문**: `frameworkUpdates.entityBatchUpdate.mutations[].payload.commentEntityPayload`
     → `.properties.content.content`(본문), `.properties.publishedTime`, `.author.displayName`, `.toolbar.likeCountNotliked`(좋아요), `.toolbar.replyCount`.
   - **다음 토큰**: `onResponseReceivedEndpoints[].(reloadContinuationItemsCommand|appendContinuationItemsAction).continuationItems[]` 중 `continuationItemRenderer`의 `continuationEndpoint.continuationCommand.token`.
5. 좋아요 문자열 파싱: `"1.2천"→1200`, `"1.1만"→11000`, 숫자는 그대로.
6. 약 600개(상위 인기) 모이면 종료. `hasMore=false`면 그대로 종료.
7. **fallback**: API가 막히면 페이지를 천천히 스크롤(`scrollBy` + 0.6초 대기)해 `ytd-comment-thread-renderer` 로딩. 빠른 대량 스크롤 금지(프리징).

> ⚠️ 도구로 반환 전 본문에서 `https?://\S+`, `www.\S+`, `?&=` 제거. 안 그러면 출력이 "Cookie/query string data"로 차단됨.

## 7. 추정 연령 산출 (반드시 "추정"으로 표기)

**유튜브 실제 시청자 연령 데이터는 채널 소유자(스튜디오)만 본다.** 따라서 연령은 **댓글 기반 추정**이며 페이지·허브·푸터에 항상 주의문구를 넣는다.

추정 근거 5가지를 종합해 10/20/30/40/50+ **5밴드(합 100%)** 배분:

1. **자기소개 신호 분포**(§6.1) — 가장 직접적.
2. **말투·호칭·이모티콘** — 존댓말+"교수님/선생님"+고전 이모티콘(☺️ ^.~ ㅠㅠ) → 성인 가중. 급식체·줄임말 → 10대 가중.
3. **영상 주제** — 학습/입시는 10대↑, 자기계발/노후/재테크는 30~50대↑.
4. **채널 성격** — 채널 전반 타깃.
5. **제목 후크** — "수능"·"공부" 등은 10대 추가 유입.

> 숫자는 반올림해 합 100, "약/추정" 표현. 정밀 통계로 단정 금지.

## 8. 검증 (공유 전 필수)

- [ ] 연령 5밴드 합 = **100** / 시청이유 비중 = 건수÷분석수 / 막대 폭 = 건수÷최다건수×100.
- [ ] 인용 댓글·좋아요 수는 **실제 추출 데이터** 기반(창작 금지, 발췌만, 왜곡 금지).
- [ ] 상단 TOP 3 = 실제 좋아요 1·2·3위(요약/메모가 상위면 그대로 싣되 신호 태그로 성격 표기).
- [ ] 분석 각도가 메타·메모에 반영됨(기본이면 생략 가능).
- [ ] 허브 카드 → 영상 페이지 도달 / 영상 페이지 `← 허브` → 허브 도달(깨진 링크 0).
- [ ] 허브 누적 현황 숫자(영상/채널/댓글) 갱신.
- [ ] HTML 파싱 정상·색 토큰 재정의 없음·연령 "추정" 주의문구 존재.

## 9. 허브 누적 절차 (영상 추가 시)

1. 영상 페이지 작성·저장(`타채널참조/<카테고리>/<슬러그>.html`).
2. `_댓글분석_허브.html`의 `<!-- VCARDS -->` **바로 아래**에 `.vcard` 1장 추가(최신이 맨 위). 카드: 채널 / 제목(2줄) / 조회·구독·게시·댓글수 / 핵심층 / 최다 이유 / TOP1 댓글 한 줄 / (선택)각도 태그 / 링크.
3. 카드 `topbar` 색은 최다 시청이유 계열(동기→growth, 페인→pain, 학습→value).
4. 상단 `#s-videos / #s-channels / #s-comments` 숫자 갱신. 빈 슬롯 `.empty`는 카드 충분 시 삭제.
5. 영상 3개↑부터 허브 하단 **누적 인사이트**에 교차 패턴(공통 페인·시청층·후크) 1~2줄 추가.

## 10. 안티 패턴 (하지 말 것)

- ❌ 연령을 **확정 통계처럼** 단정 (항상 "추정").
- ❌ 좋아요 수·댓글 문구 **창작/과장** (반드시 추출 데이터).
- ❌ 정체성/연령을 길게, 시청이유를 짧게 (포맷 역전 — 반대로).

- ❌ watch 페이지 대량 고속 스크롤 → 렌더러 프리징.
