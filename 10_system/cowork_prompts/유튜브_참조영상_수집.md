## 0. 한 줄 정의 · 코워크 작동 방식

**코워크에서 사용자가 인물·용어(+수집 각도)를 지시 → Claude가 크롬으로 유튜브를 검색해 누구나 아는 유명 영상을 한/영으로 수집 → 영상별로 「핵심 내용 · 핵심 발언/언급한 책 · 우리 채널 활용 포인트」를 붙인 컬렉션 페이지 1장 생성 → 누적 허브에 카드로 등록.**

```
[사용자] "<인물·용어> 영상 수집해줘 (+ 수집 각도)"
        │
        ▼
[Cowork] ① 크롬으로 유튜브 검색(한국어 + 영어 쿼리 여러 개)
         ② ytInitialData에서 실제 영상 메타 추출(제목·ID·채널·조회·게시·길이)
         ③ '유명/대표작' 기준으로 선별(§6) + 4그룹 분류
         ④ 대표 영상 1~3개는 watch 페이지에서 설명문 확인(상세 근거)
         ⑤ 템플릿 복사 → 컬렉션 페이지 작성(영상별 상세 + 활용 포인트)
         ⑥ 허브에 카드 추가 + 누적 현황 갱신
         ⑦ 검증 후 사용자에게 허브·페이지 공유
```

이 작업의 핵심은 **"실제 검증"** — 링크·조회수·길이를 기억이 아니라 크롬으로 그 영상에서 직접 가져온다(§5). **YouTube 영상 ID·URL을 절대 창작하지 않는다.**

## 1. 입력 모델 — "인물·주제 + 수집 각도"

사용자 지시는 **인물·용어 1개 + (선택) 수집 각도** 형태다. 각도가 없으면 사용자가 준 키워드를 그대로 주제로 삼는다.

### 1.1 수집 각도(기준) 메뉴

각도는 **검색 쿼리와 그룹 구성**을 바꾼다(어떤 영상을 끌어오고 어떻게 묶을지).

| 각도 | 사용자가 이렇게 말하면 | 수집·구성에서 강조 |
|---|---|---|
| **기본(인물 종합)** | "일론 머스크 영상 모아줘" | 대표 강연·인터뷰 + 주제별(공부/책/자기계발) 균형 |
| **독서·책 중심** | "○○의 책·독서 얘기만" | 추천도서·독서법·"책에서 배웠다" 서사 집중 |
| **공부·학습법 중심** | "○○ 공부법/학습법" | 제1원칙·메모·몰입 등 방법론 집중 |
| **자기계발·명언** | "동기부여/명언 위주" | 졸업연설·짧은 클립·자막 인용 카드용 |
| **후크 발굴** | "썸네일·제목 아이디어" | 제목 패턴(0.01%/후천적 천재 등)을 후크 후보로 표기 |
| **벤치마크(경쟁)** | "우리 채널 비교용" | 같은 주제를 다룬 한국 채널들의 구성·후크 비교 |
| **용어·개념** | "제1원칙", "문해력" 등 단어 | 인물 무관, 그 개념을 다룬 대표 영상 큐레이션 |

> 각도는 복수 지정 가능(예: "독서 중심 + 후크 발굴"). 결 3그룹·풀링/키 퍼널·6축 등 bizpt 용어로 지시해도 된다.

### 1.2 각도가 출력에 남는 위치
- 헤더 `h1`에 분석 각도 반영(예: "— 공부·책·자기계발").
- 그룹 구성(§2)을 각도에 맞게 조정. 종합 가이드 표의 '후크 아이디어'에 각도 메모.
- 허브 카드 태그에 각도 키워드.

## 2. 산출물 구조 (고정)

컬렉션 페이지는 **이 골격을 따른다**.

| 순서 | 섹션 | 내용 |
|---|---|---|
| ① | **헤더 + 4스탯** | 인물·주제, 한 줄 서사, 수집 영상수 / 한·영 / 합산조회 / 최고조회 |
| ② | **인트로 — "왜 bizpt 레퍼런스인가"** | 핵심 서사 + 결 그룹·관련 축 칩 |
| ③ | **그룹 A~D (주제별)** | 예: A 공부·학습 / B 책·독서 / C 자기계발·사고법 / D 강연·인터뷰. 각 그룹에 영상 카드 N개 |
| ④ | **영상 카드** | 썸네일(▶·길이) + 언어칩 + 제목(링크) + 메타 + 핵심 + (인용) + **📌 활용 포인트** |
| ⑤ | **종합 활용 가이드** | bizpt 6축 ↔ 영상 매핑 표 + **진정성 체크 노트** |

작성은 `참조영상모음/_템플릿_수집페이지.html` 복사 → `{{...}}` 치환, "영상 카드 복사 단위" 블록을 영상 수만큼 복제. **각 영상 카드는 반드시 「핵심 + 활용 포인트」를 포함**(단순 링크 나열 금지)이 이 포맷의 정체성.

## 4. 작업 순서 (코워크 체크리스트)

1. **[각도 확인]** 인물·용어 + 수집 각도 파싱(없으면 인물 종합).
2. **[검색]** Claude in Chrome로 유튜브 검색. **한국어 2~3개 + 영어 2~3개** 쿼리(§5.1). 예: `<인물> 독서 책`, `<인물> 공부법 학습`, `<인물> 명언 강연`, `<name> books learning`, `<name> interview advice`, `<name> commencement`.
3. **[추출]** 검색결과 페이지에서 ytInitialData를 JS로 파싱해 영상 메타 일괄 수집(§5.2).
4. **[선별]** §6 기준으로 '유명/대표작' 8~12개 선별. 한·영 균형. 4그룹 분류.
5. **[근거 보강]** 대표 1~3개는 watch 페이지 설명문 확인(§5.3)으로 핵심·인용 정확도 ↑. 길이 누락분은 player 메타로 보충(§5.4).
6. **[작성]** 템플릿 복사 → `참조영상모음/<인물·주제>/<슬러그>.html`. 영상별 「핵심·발언/언급책·활용 포인트」 작성(§7). 종합 가이드 표 채움.
7. **[등록]** 허브 `<!-- CCARDS -->` 바로 아래 카드 1장 추가(최신 맨 위) + 상단 숫자(인물·주제/영상/채널) 갱신.
8. **[검증·공유]** §8 통과 → 허브·신규 페이지를 사용자에게 공유.

> 5개 이상 파일을 한 번에 만들거나 기존 결론을 바꿔야 하면 CLAUDE.md §7대로 사용자에게 먼저 확인.

## 5. 영상 검색·메타 추출 방법 (Claude in Chrome)

기억으로 링크를 쓰면 **존재하지 않는 영상 ID를 만들 위험**이 크다. 반드시 크롬으로 실제 페이지에서 추출한다.

### 5.1 검색
`https://www.youtube.com/results?search_query=<쿼리>` 로 navigate(한글 쿼리는 그대로 URL에 넣어도 됨). 1.5초 대기 후 추출.

### 5.2 검색결과 메타 일괄 추출 (ytInitialData → videoRenderer)
```js
(function(){
  function walk(o,out){ if(!o||typeof o!=='object')return;

      const title=(v.title&&v.title.runs&&v.title.runs[0]&&v.title.runs[0].text)||'';
```

## 6. 수집·선별 기준 ("유명/대표작")

사용자 요구는 **"누구나 알 만한 유명 영상"**. 다음을 종합해 8~12개 선별:

1. **조회수**(절대 기준 아님) — 같은 주제군에서 상위. 단 조회수만으로 줄세우지 말 것.
2. **채널 권위** — 공식 채널(TED·USC·대학·언론), 대형 채널, 원본 인터뷰/팟캐스트 우선.
3. **대표성** — 그 인물/주제 하면 떠오르는 '정전(canon)' 영상(예: 머스크 = TED 2017, USC 졸업연설, 제1원칙 클립).
4. **주제 적합도** — 사용자 각도(공부·책·자기계발)에 직접 맞는가.
5. **한·영 균형** — "둘 다"가 기본. 한국 채널 해설본 + 영어 원본을 함께.
6. **포맷 다양성** — 강연/인터뷰/다큐/해설/짧은 클립을 섞어 활용처를 넓힘.

**제외**: 조회수 수백 대 무명 클립, 동일 영상 재업로드 중복, 주제와 무관한 가십·정치 영상, 출처 불명.

## 7. 영상별 상세 작성 기준

각 영상 카드는 **최소 「핵심 + 활용 포인트」**, 가능하면 「인용」「언급 책」을 포함한다.

- **핵심(필수)**: 영상이 무엇을 말하는가 1~2문장. (설명문·제목·일반 상식 기반, 과장·날조 금지)
- **인용(선택)**: 인상적 발언. 원문이 확인되면 따옴표로. 불확실하면 생략(지어내지 말 것).
- **언급 책(독서 주제 시)**: 영상에서 소개·추천한 책 제목.
- **📌 활용 포인트(필수)**: **bizpt 어느 축/후크/콘텐츠에 어떻게 쓰는가.** 결 3그룹·6축·풀링/키 용어로. 이 줄이 이 시스템의 존재 이유.
- **종합 가이드 표**: 6축 ↔ 영상 매핑 + 후크 아이디어. 마지막에 **진정성 체크 노트**(클릭베이트 경계, "그래서 당신이 읽을 책"으로 착지).

> 사실(메타·인용)과 해석(활용 포인트)을 섞지 말 것. 메타는 검증값, 활용은 우리 분석.

## 8. 검증 (공유 전 필수)

- [ ] **모든 VIDEO_ID·URL이 실제 검증됨**(기억·추정 금지). 썸네일이 정상 로드되는가.

## 10. 안티 패턴 (하지 말 것)
