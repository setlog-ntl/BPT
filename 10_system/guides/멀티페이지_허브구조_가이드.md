---

## 1. 언제 이 패턴을 쓰는가

다음 중 하나라도 해당되면 단일 파일을 쪼개고 본 가이드를 적용한다.

- 한 HTML 파일이 **1,500줄 이상** 또는 **40 KB 이상**
- 시청자/독자 단계가 **2개 이상으로 자연스럽게 분리**된다 (예: 페인 / 자기계발 / 가성비 = 5단계 사이클의 현상·욕구·계획)
- 하나의 시리즈에 **부속 가이드(녹음·촬영·편집·랜딩)**가 함께 존재해야 한다
- 향후 각 각도를 **독립적으로 고도화**할 가능성이 높다

단일 파일이 1,000줄 미만이고 단계 분리가 강제되지 않으면 굳이 쪼개지 않는다 (네비 인지 비용이 더 큼).

## 2. 파일 구성 표준

### 2.1 파일 종류 3가지

| 종류 | 역할 | 개수 |
|---|---|---|
| **허브 인덱스 (Hub)** | 마스터 컨셉·공통 자산·전체 운영표·체크리스트·원칙 등 모든 각도가 공유하는 전체 자산. 큰 진입 카드(Nav Card)로 각도/부속 가이드로 보냄. | 정확히 1개 |
| **각도 페이지 (Angle)** | 한 각도(앵글)의 콘텐츠 본체 — 시리즈라면 그 각도에 속한 편들의 타임라인·자산·자막·본문. | N개 (보통 2~4개) |
| **부속 가이드 (Auxiliary)** | 녹음·촬영·편집·랜딩처럼 각도와 직교하는 보조 자료. | M개 (0~N) |

### 2.2 파일명 규칙

```
docs/<영역>/<base>.html                       ← 허브 (기존 단일 파일을 그대로 허브로 전환)
docs/<영역>/<base>_01_<각도1>.html            ← 각도 1
docs/<영역>/<base>_02_<각도2>.html            ← 각도 2
docs/<영역>/<base>_03_<각도N>.html            ← 각도 N
docs/<영역>/recording_guide_<base핵심>.html   ← 부속 가이드 (예: 녹음)
docs/<영역>/edit_guide_<base핵심>.html        ← 부속 가이드 (예: 편집)
```

**규칙**:
- 허브는 **기존 파일명을 유지** (외부에서 들어오는 링크 보존)
- 각도는 `_01_`, `_02_`, `_03_` 두 자리 번호 + 한글 각도명 (alphabetic으로 정렬되도록)
- 각도명은 5단계 사이클이나 8대 페인 분류 등 **이미 합의된 카테고리** 사용
- 부속 가이드는 `<역할>_guide_<base>` 패턴 (영문 prefix로 한 폴더 안에서 시각적으로 구분)

### 2.3 첫 적용 예시 (이북리더기 판매대본)

```
docs/keycontent/
├─ video_plan_이북리더기_판매대본.html              ← 허브 (마스터·공통자산·운영표·체크리스트·원칙)
├─ video_plan_이북리더기_판매대본_01_페인.html      ← 각도 ① 페인포인트 (EP1+EP4)
├─ video_plan_이북리더기_판매대본_02_자기계발.html  ← 각도 ② 자기계발 (EP2+EP5)
├─ video_plan_이북리더기_판매대본_03_가성비.html    ← 각도 ③ 가성비 (EP3+EP6)
└─ recording_guide_이북리더기_판매대본.html         ← 부속 가이드 (녹음)
```

## 3. 모든 페이지 공통 — 상단 버튼 네비 (필수)

모든 파일(허브·각도·부속) **상단**에 동일한 네비 바를 배치한다. 이 바가 페이지 간 이동의 단일 출입구다.

### 3.1 HTML 스니펫 (복붙 후 active 위치만 변경)

```html
<nav class="angle-nav">
  <a class="abtn home" href="<base>.html">← 인덱스</a>
  <a class="abtn pain"   href="<base>_01_페인.html"><span class="num">①</span> 페인포인트</a>
  <a class="abtn growth" href="<base>_02_자기계발.html"><span class="num">②</span> 자기계발</a>
  <a class="abtn value"  href="<base>_03_가성비.html"><span class="num">③</span> 가성비</a>
  <span class="abtn sep">|</span>
  <a class="abtn rec" href="recording_guide_<base핵심>.html">🎙 녹음 가이드</a>
</nav>
```

각 페이지에서 자기 자신에 해당하는 버튼에 `active` 클래스를 추가:
- 허브: `<a class="qbtn active" href="<base>.html">🏠 인덱스 (허브)</a>`
- 페인: `<a class="abtn pain active" ...>`
- 자기계발: `<a class="abtn growth active" ...>`
- 가성비: `<a class="abtn value active" ...>`
- 녹음: `<a class="abtn rec active" ...>`

## 4. 허브 페이지 전용 — 큰 진입 카드 (Nav Cards)

허브에서는 상단 작은 네비 외에 **큰 진입 카드 그리드**를 별도로 둔다. 이게 허브의 핵심 UI.

```html
<section id="nav">
  <h2>📑 페이지 진입</h2>
  <div class="nav-grid">
    <a class="nav-card pain"   href="..._01_페인.html">…</a>
    <a class="nav-card growth" href="..._02_자기계발.html">…</a>
    <a class="nav-card value"  href="..._03_가성비.html">…</a>
    <a class="nav-card rec"    href="recording_guide_....html">…</a>
  </div>
</section>
```

각 카드는 `meta` (각도 번호) · `num-big` (큰 ①②③) · `ttl` (각도 이름) · `sub` (한 줄 설명 + 5단계 칩) 4구성. 호버 시 1px 위로 + 상단 4px 컬러 바.

CSS는 본 가이드 첫 적용 사례 `video_plan_이북리더기_판매대본.html` (허브)의 `.nav-grid` `.nav-card` 정의를 그대로 가져온다.

## 5. 각도 페이지 — 이전/다음 카드 (선택)

각도 페이지 마지막에는 시리즈 흐름을 따라 **다음 각도로 가는 큰 카드**를 둔다 (단방향 또는 이전+다음 양방향).

```html
<a class="next-card" href="<base>_02_자기계발.html">
  <div>
    <div class="label">Next Angle</div>
    <div class="title">② 자기계발 각도</div>
    <div class="sub">한 줄 설명</div>
  </div>
  <div class="arrow">→</div>
</a>
```

- 첫 각도: 다음 카드만
- 중간 각도: 이전 + 다음 (`.grid.cols-2`)
- 마지막 각도: 이전 카드만

## 6. 부속 가이드 — 후행 자산 추가 패턴

새 부속 가이드(예: 편집·랜딩페이지·썸네일·SEO)가 필요하면:

1. `<역할>_guide_<base>.html` 신규 파일 생성
2. **모든 기존 파일**(허브·각도 N개·기존 부속)의 `angle-nav`에 새 버튼 한 줄 추가
3. 허브의 `nav-grid`에도 카드 한 장 추가 (필요 시 `cols-4` → `cols-5` 자동)
4. 새 부속 색 토큰 1개 정의 (예: 편집=하늘색 `--edit:#7cd0e8`)
5. 가이드 본문은 부속 가이드의 6 섹션 스킬레톤 (공통 셋업 / 각도별 가이드 / 체크리스트 / 사전 / 컨트롤 시트 / 후반작업) 권장

기존 파일 일괄 수정은 다음 명령으로 처리:

```bash
# bash 기준 — angle-nav 직전·직후 패턴을 grep해서 일괄 Edit
rg -l "abtn rec" docs/keycontent/  # 기존 부속(녹음) 버튼이 있는 파일 목록
# → 각 파일에 새 부속 버튼 한 줄 Edit
```

## 7. 각도 분류 가이드라인

각도(앵글)는 **5단계 구매 사이클** 또는 **콘텐츠 8대 페인 분류**에서 가져온다.

### 7.1 5단계 사이클 기반 (영상 시리즈 기본값)

| 각도 | 단계 | 시청자 온도 | 색 토큰 |
|---|---|---|---|
| 페인포인트 | 현상 (Phenomenon) | Cold | `--pain` 코랄 |
| 자기계발 | 욕구 (Desire) | Cold/Warm | `--growth` 민트 |
| 가성비 | 계획 (Plan) | Warm/Hot | `--value` 노랑 |
| 행동 (옵션) | 행동 (Action) | Hot | `--action` 보라 |
| 보상 (옵션) | 보상 (Reward) | Returning | `--reward` 그린 |

### 7.2 8대 페인 기반 (제품 카테고리 시리즈)

8대 페인(신체/휴대성/디지털분산/공간/자투리시간/가성비/정체성/종이갈등) 중 시리즈에서 다룰 페인을 골라 1각도 = 1페인 (또는 묶음). 각도 색은 위 5단계 색 팔레트에서 의미가 가까운 걸 재사용.

## 8. 반복적 누적 관리 워크플로우

새 시리즈를 만들 때마다 다음 단계로 진행:

1. **스코프 확정**: 시리즈 한 줄 정의 + 각도 N개 + 부속 가이드 M개 결정
2. **파일 생성 순서**: 각도 1 → 각도 2 → ... → 각도 N → 부속 → **마지막에 허브** (허브 카드는 모든 파일이 만들어진 뒤 정확한 메타로 채움)
3. **버튼 네비 일관성**: §3 스니펫을 모든 파일 같은 위치(헤더 바로 아래)에 복붙. active만 다르게.
4. **CSS 토큰 재사용**: 색 팔레트는 §3.2를 그대로. 새 각도 색은 추가 토큰 정의 후 동일 CSS 패턴 한 줄씩.
5. **검증**: 허브의 모든 카드 링크 클릭 → 각도/부속 페이지 도달 → 각 페이지 상단 네비로 다른 페이지 모두 도달 → 깨진 링크 0건 확인.
6. **CLAUDE.md 등록**: 새 시리즈가 SPA(`index.html`)에서 참조되면 CLAUDE.md §4.1의 SPA 참조 보호 목록에 허브 파일 추가.

## 9. 안티 패턴 (하지 말 것)

- ❌ **버튼은 추가했는데 active 클래스 안 바꾼 채 복붙** → 사용자가 자기 위치 모름
- ❌ **각도별 색 토큰을 페이지마다 다르게 정의** → 보라색이 어떤 페이지에서는 페인 어떤 페이지에서는 자기계발이 됨
- ❌ **JS 탭 전환으로 처리** → 분할 효과 사라짐, 모바일 공유 시 특정 각도 직접 링크 불가
- ❌ **허브에 모든 콘텐츠를 그대로 두고 각도 파일은 빈 껍데기** → 분할 의미 없음, 허브가 여전히 무거움
- ❌ **부속 가이드 추가 후 기존 파일들의 angle-nav를 안 고침** → 일부 페이지에서만 새 부속 버튼이 보이는 비대칭 발생
