# 03 · 훅 · 문구뱅크

> ⚠️ **[승계 원본]** 본 문서의 채널 변수(채널명·사인오프·축·아이템)는 낡음 — **[`00_channel/channel_config.md`](../../../00_channel/channel_config.md)가 우선**한다. 구 사인오프·구 축 표기는 참고용이며 신규 영상에 자동 적용 금지. (2026-07-06 전면개편 PHASE 7)

> 카피를 뽑을 때 펴는 문서. 6축별 헤드라인 풀 + 결별 진입 문구 + 시그니처 라인 + 숫자 대비 + 금지 문구.
>
> **사용법**: ① §1에서 영상의 6축 풀 1~2개 선택 → ② §2 결별 진입 문구로 톤 조정 → ③ §3 시그니처 라인 1개 결합 → ④ §4 숫자 대비 패턴 적용 → ⑤ §5 금지 문구로 거른다.

> **제목 ↔ 썸네일 헤드 매핑 (5주차 반영)**: 영상 **제목은 35자가 메인**(유튜브에서 잘리지 않는 한계, 이후 100자까지 검색 키워드). **썸네일 헤드(7~10자 한 줄 / 12~16자 두 줄)는 그 35자 제목의 축약·변주** — 같은 맥락을 유지한다. 제목 자체를 8단계로 디벨롭하는 룰은 [`../../../대본/_기획기준/대본기획_기준.md §8.6`](../../../대본/_기획기준/대본기획_기준.md), 뷰트랩 코워크 실행은 [`../뷰트랩_주제발굴_디벨롭_가이드.md`](../뷰트랩_주제발굴_디벨롭_가이드.md).

> **결 표기**: ① = AI 안/못 쓰는 사람(입문) · ② = AI 쓰고 있는 사람(활용·단기 주력) · ③ = AI 더 잘 쓰려는 사람(심화).

## 2. 결별 진입 문구 (헤드 첫 단어 또는 부가 1줄)

> 결을 0.5초 안에 호명하는 단어 1개. 이 단어가 있으면 시청자는 "내 얘기"라고 인식한다.

### 2-1. 결 ① AI 안/못 쓰는 사람 (입문)

| 호명 단어 | 예시 부가 1줄 |
|---|---|
| "챗GPT 써봤는데" | "챗GPT 써봤는데 별로던 분께" |
| "AI가 어려운" | "AI가 아직 어려운 분께" |
| "안 써봤어도" | "한 번도 제대로 안 써봤어도" |
| "뭐부터" | "뭐부터 물어야 할지 막막한" |

### 2-2. 결 ② AI 쓰고 있는 사람 *(현재 단기 주력)*

| 호명 단어 | 예시 부가 1줄 |
|---|---|
| "매일 쓰는데" | "매일 쓰는데 평범한 답만" |
| "같은 챗GPT" | "같은 챗GPT, 다른 결과" |
| "프롬프트가" | "프롬프트가 안 먹히는 분께" |

| 호명 단어 | 예시 부가 1줄 |
|---|---|

## 3. 시그니처 라인 풀 (채널 자산)

> 채널 1년 운영 시 시청자가 **"아, 그 채널의 그 말"**로 기억하는 라인. 6축 어디서든 자연스럽게 등장.

| 라인 | 출처 / 사용처 | 톤 |
|---|---|---|
| **AI는 답을, 읽는 사람은 질문을** | 채널 사인오프·모토 | 정체성 |
| **읽는 사람이 (결국) 이긴다** | 풀링 — AI 대비 긍정 구도 | 정체성·긍정 |
| **미래의 나** | 키 시그니처 — 성장 각도 | 미래·도구·변화 |
| **정상이에요** | 풀링 면죄부 — "AI 못 써도 정상" | 면죄부·동반자 |
| **단 하나의 도구** | 키 — 환경·도구 메시지 | 단순화·전환 |
| **의지가 아니라 도구** | 키 쇼츠 — 성장 | 단일점·전환 |
| **환경을 바꾸면 습관이 따라온다** | 키 — 차분한 환경형 | 시스템·확장성 |
| **그 사람들 옆자리** | 풀링 결 호명 — "이 채널은 그분들 옆자리" | 정체성·커뮤니티 |

> **사용 규칙**: 한 썸네일에 시그니처 라인 **1개만**. 헤드 또는 부가 중 한 곳. 두 개 동시 NG.

## 4. 숫자 대비 패턴 (썸네일에서 가장 강력한 무기)

### 4-1. 0 / N 형 (변화의 폭)

| 패턴 | 예시 | 영상 종류 |
|---|---|---|
| `0 → 100` | 0권 → 100권 (1년) | 풀링 |
| `0 / 30` | 0권 / 30권 + FAILED | 키 (트래커형) |
| `0 / 50` | 빌 게이츠 50권 / 당신은? | 키 권위형 |
| `0% / 100%` | 진척률 게임 UI | 키 트래커형 |

### 4-2. 시간 압축 형

| 패턴 | 예시 | 영상 종류 |
|---|---|---|
| `5분 / 3시간` | 5분 독서 vs 3시간 SNS | 풀링·키 |
| `10초 / 1시간` | 프롬프트 10초 차이가 1시간을 가른다 | 풀링·키 (AI) |
| `평생 / 며칠` | 평생을 며칠 만에 | 풀링 |

### 4-3. 비교 형

| 패턴 | 예시 | 영상 종류 |
|---|---|---|
| `같은 AI / 다른 결과` | 같은 챗GPT, 다른 사람 | 풀링·키 (AI) |
| `10년 / 1년` | 10년 직장인 / 1년 독서가 | 풀링·키 |
| `30대 / 40대` | 30대 후반 / 40대에 시작해도 | 풀링 |

### 4-4. 숫자 사용 룰

1. **숫자는 헤드의 강조어와 분리** — 빨강(0/실패)·노랑·시안(목표) 명확히
2. **tabular-nums 폰트** — Pretendard에 내장. 0과 8 폭 동일
3. **소수점·퍼센트 신중** — `+243%` 같은 광고 톤 NG. 절대값 또는 0/N이 진정성
4. **단위 작게** — `30` 큰 글씨 + `권` 작게 (50% 크기)

### 5-3. 모호어 (재작성 대상)

| 모호어 | 사유 | 재작성 방향 |
|---|---|---|

| "추천 ○○" | 진정성 부족 | 변화·결과로 — "평범한 답에서 벗어나게 한 ○○" |
| "꿀팁·꿀템" | 톤 불일치 | 사용 금지 |
| "잘 쓰는 법" | 추상 | 구체화 — "같은 챗GPT인데 결과가 다를 때 쓰는 법" |

## 6. A/B 헤드라인 짝짓기 (실전)

> A/B는 **다른 톤끼리** 짝지어야 데이터가 의미 있다. 같은 톤의 미세 변형은 측정 가치 낮음.

| A안 (메인) | B안 (변형) | 측정 의도 |
|---|---|---|
| 대비형 (`같은 AI / 다른 결과`) | 비유형 ("좋은 프롬프트는 좋은 문장에서") | 숫자 vs 비유, 어느 게 결 ②를 더 부르나 |
| 고백형 ("챗GPT 써봤는데…") | 정체성형 ("AI는 답을, 읽는 사람은 질문을") | 진정성 직설 vs 시그니처 |
| 트래커형 (12개월 격자) | 권위형 (빌게이츠 50권) | 시각 자료 강도 vs 권위 무게 |
| 도구형 ("단 하나의 도구") | 환경형 ("환경을 바꾸면") | 단일점 vs 시스템 |

## 7. Claude로 헤드라인 30개 뽑기 (퀵 프롬프트)

> 자세한 표준 프롬프트는 [`04_제작워크플로우_AI프롬프트.md`](04_제작워크플로우_AI프롬프트.md) §2 참조. 여기는 한 줄 진입.

```
영상 제목: "<영상 제목>"
6축 주제: <독서 / 문해력 / 사고력 / AI / 바이브코딩 / 성장 중 1~2개>
주력 결: <① AI 안·못 쓰는 / ② 쓰고 있는 / ③ 더 잘 쓰려는>
영상 종류: <풀링 / 키>
판매 종착지: <이북리더기 / 책 관련 제품 / readtree>

위 영상의 썸네일 헤드라인 30개를 뽑아줘.
- 각 헤드는 7~10자 (한 줄형) 또는 12~16자 (두 줄형) 안
- §03 §5 금지 문구 자동 거르기 (AI 적대·치트키 과장 포함)
- 결 호명 단어 (§03 §2)를 헤드 또는 부가 1줄에 1개 포함
- 시그니처 라인 (§03 §3)은 30개 중 5~7개에만 사용
- 숫자 대비 패턴 (§03 §4) 활용한 안 10개 이상 포함
- 출력: 표 (번호 / 헤드 / 부가 / 톤 / 결 / 추천 템플릿)
```
