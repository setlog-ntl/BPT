# 캡컷 패키지 표준 스펙 (v1)

> 모든 영상 프로젝트는 `03_프로젝트/<영상>/03_캡컷_패키지/` 폴더에 다음 스펙을 만족하는 산출물을 둔다.
> 사용자는 이 폴더 전체를 캡컷에 import 하여 빠르게 마감 편집한다.

---

## 1. 폴더 구조 (필수)

```
03_캡컷_패키지/
├── 편집_가이드.md           # ★ 시간 순서대로 명령형 편집 지시
├── 자막.srt                # 표준 SRT 포맷 (UTF-8)
├── 사용자산.md              # 자산 라이브러리 ID 매칭표
├── 배경음악_지정.md              # 배경음악 ID + 페이드/볼륨 타이밍
└── 영상소스/                # 직접 촬영/AI 생성 클립
    ├── 001_<설명>.mp4
    ├── 002_<설명>.mp4
    └── ...
```

> 비롤, 인트로/아웃트로, 효과음, 배경음악은 **자산 라이브러리 ID로만 참조**. 파일 자체를 패키지에 복사하지 않는다.
> 캡컷 import 시 사용자가 자산 라이브러리 원본 경로에서 직접 import.

---

## 2. `편집_가이드.md` 표준 포맷

**모든 지시는 명령형, 시간 순서대로**. "적당히", "느낌 있게" 같은 모호한 표현 금지.

```markdown
# 편집 가이드 — <영상 제목>

## 메타
- 총 길이: 45초
- 종횡비: 9:16 (쇼츠)
- 적용 템플릿: 풀링_쇼츠_v1
- 사용 자산: 사용자산.md 참조

## 타임라인

### 0:00–0:03 (인트로)
- 자산: 인트로-001 (잔잔한_피아노_3초) 영상 트랙 1
- 자막 트랙 1: 후킹 카피 (자막.srt #1) — 자막스타일 ID `스타일-쇼츠-후킹`
- 효과음: 효과음-005 (스윕 인) at 0:00

### 0:03–0:15 (본론 1)
- 영상 트랙 1: 영상소스/001_데미안_표지샷.mp4 (0:03–0:09)
- 영상 트랙 1: 비롤-012 (책장넘김_2s) at 0:09–0:11
- 영상 트랙 1: 영상소스/002_본문구절.mp4 (0:11–0:15)
- 자막: 자막.srt #2~#4
- 배경음악: 배경음악-007 페이드 인 0.5s, 볼륨 -18dB

### 0:15–0:30 (본론 2)
...

### 0:42–0:45 (아웃트로 + CTA)
- 자산: 아웃트로-003 (구독_CTA_3초)
- 자막: "구독하고 책으로 다시 만나요"
- 효과음: 효과음-002 (팝)

## 컷 트랜지션 규칙
- 본론 내 컷-컷: 기본 직선 컷 (트랜지션 없음)
- 챕터 전환: 페이드 0.3s
- 인트로 → 본론: 슬라이드 좌→우 0.4s

## 자막 일괄 규칙
- 위치: 화면 하단 중앙 (Y=85%)
- 폰트: 산돌 격동고딕, 56pt
- 색: 흰색 + 검정 외곽선 4px
- 강조 단어는 노란색 (#FFD700)
- 한 줄 최대 12자, 2줄 초과 금지

## 캡컷 출력 설정
- 해상도: 1080x1920
- 프레임레이트: 30fps
- 비트레이트: 권장(자동)
- 워터마크 제거

## 마감 시 사용자 결정 사항
- [ ] 0:09 책장넘김 컷 길이 미세조정 (0.5s 이내)
- [ ] 배경음악 볼륨 영상 전체 청취 후 -3dB 단위 조정
```

## 3. `자막.srt` 표준

표준 SubRip 포맷 (UTF-8 BOM 없이).

```
1
00:00:00,000 --> 00:00:03,000
"넌 너 자신이 되는 게 두려운 거야"

2
00:00:03,500 --> 00:00:06,000
헤르만 헤세는 100년 전에 이미

3
00:00:06,000 --> 00:00:09,500
우리가 왜 가짜 자신으로 사는지 알았다
```

**규칙**:
- 자막 1줄 최대 12자(쇼츠) / 18자(키)
- 한 자막 표시 시간 1.5~4초
- 자막 간 간격 ≥ 0.2초
- 강조 단어는 별도 표기 X (캡컷에서 색 적용 — 편집 가이드에 지시)

## 4. `사용자산.md` 포맷

```markdown
# 사용 자산 매칭 — <영상 제목>

| 자산 ID | 카테고리 | 사용 위치 (시간) | 비고 |
|---|---|---|---|
| 인트로-001 | 인트로 | 0:00–0:03 | - |
| 배경음악-007 | 배경음악 | 0:03–0:42 | -18dB, 페이드 인/아웃 0.5s |
| 비롤-012 | 비롤 | 0:09–0:11 | 책장 넘김 |
| 효과음-002 | 효과음 | 0:43 | 팝 |
| 효과음-005 | 효과음 | 0:00 | 스윕 인 |
| 아웃트로-003 | 아웃트로 | 0:42–0:45 | 구독 CTA |
| 스타일-쇼츠-후킹 | 자막스타일 | 0:00–0:03 | 강조 자막 |

## 신규 등록 필요 자산
| 가제 | 카테고리 | 이유 |
|---|---|---|
| _(없음)_ | - | - |
```

**규칙**:
- 사용한 자산은 모두 표에 기록 (편집 가이드와 교차검증용)
- 만약 라이브러리에 없는 자산이 필요했다면 "신규 등록 필요" 표에 기록 → 영상 발행 후 자산 라이브러리에 정식 등록

## 6. `영상소스/` 폴더 규칙

- 파일명: `001_<짧은_설명>.<확장자>` — 3자리 번호로 정렬 보장
- 포맷: mp4 (H.264) 권장. 캡컷 호환성 최선
- 해상도: 출력 해상도 이상 (다운스케일이 업스케일보다 안전)
- 길이: 사용 길이 + 앞뒤 1초 여유 (편집 시 미세조정 마진)

## 7. import 시 사용자 동작 표준 시퀀스

캡컷에서 패키지 import 표준 절차:

1. 새 프로젝트 생성 → 종횡비 설정 (9:16 / 16:9)
2. `영상소스/` 전체 import → 미디어 빈에 정렬
3. 자산 라이브러리에서 사용자산.md 표 따라 필요 자산 import
4. 편집_가이드.md 펼쳐놓고 시간 순서대로 타임라인 배치
5. 자막.srt 일괄 import → 자막스타일 ID 따라 일괄 스타일 적용
6. 배경음악 트랙 추가 + 배경음악_지정.md 따라 페이드/볼륨 설정
7. 미리보기 → 마감 결정 사항 반영 → 출력
