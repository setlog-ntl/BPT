# 강의 노트 정리 (raw → 50_knowledge/lectures)

## 목적
비즈니스PT 강의의 원본 노트(필사·캡처·메모)를 **재사용 가능한 정리본**으로 변환해 `50_knowledge/lectures/<주차>/` 아래에 markdown으로 저장.

## 입력 (사용자가 제공)
- **원본 위치**: `raw/<날짜>_<주제>/` (예: `raw/2026-05-10_4주차-1강/`)
- **주차·강의번호**: 예) 4주차 1강 → 4-1강
- **주제**: 예) "풀링 콘텐츠의 정의와 역할"

## 사전 참조 (이 순서로 먼저 읽기)
1. `CLAUDE.md` (루트) — 하드 룰·톤
2. `프로젝트_방향성.md` §5 (3-Asset 모델), §6 (체크리스트), §8 (톤)
3. 같은 주차 또는 직전 주차의 정리본 (예: `50_knowledge/lectures/3주차_키콘텐츠_기획/`) — 용어·서식 일관성 참고
4. `50_knowledge/reference/01_용어집.md` — 강의 용어 표기 통일

## 작업 절차
1. **원본 자료 통독** — `raw/<해당 폴더>/`의 모든 파일을 읽고 무엇이 들어있는지 파악 (필사 노트·캡처·메모).
2. **슬라이드 그대로 옮기지 않음** — 개념만 추출해 사용자의 언어로 재구성 (README 원칙).
3. **다음 구조로 정리본 작성**:
   - YAML 프론트매터 (주제 / 원본 / 날짜)
   - 한 줄 핵심 메시지
   - 본문: 개념 정의 → 강사가 든 예시 → 우리 프로젝트(책·readingtree)에 어떻게 적용되는가
   - 다른 강의·문서와의 연결 (cross-reference)
4. **핵심 용어 추출** → 신규 용어가 있으면 `50_knowledge/reference/01_용어집.md`에 추가 항목 제안 (별도 PR성 변경).
5. **완료 후** `docs/README.md`의 강의 인덱스 표에 한 줄 추가.

## 산출물 형식 / 저장 위치
- **경로**: `50_knowledge/lectures/<주차>_<주제>/<강의번호>_<강의주제>.md`
  - 예: `50_knowledge/lectures/4주차_풀링콘텐츠_기획/4-1강_풀링콘텐츠_정의와_역할.md`
- **프론트매터 예시**:
  ```markdown
  ---
  주제: 풀링 콘텐츠의 정의와 역할
  강의: 4-1강
  주차: 4주차 (풀링 콘텐츠 기획)
  원본: raw/2026-05-10_4주차-1강/notes.md
  정리일: 2026-05-XX
  ---
  ```
