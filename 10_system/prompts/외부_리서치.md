# 외부 리서치

## 목적
프로젝트에 필요한 외부 정보(책·도구·시장·경쟁 채널)를 수집·정리해 의사결정에 사용할 수 있는 형태로 저장.

## 입력 (사용자가 제공)
- **리서치 주제**: 예) "킨들 페이퍼화이트 11세대 vs 크레마 카르타+", "독서 유튜브 채널 벤치마크 5개"
- **사용 목적**: 예) "키 콘텐츠 기획서의 비교 근거" / "풀링 콘텐츠의 후크 영감"
- **(선택) 시간 범위**: 예) "최근 1년 자료 위주"

## 사전 참조
1. `CLAUDE.md` (루트) — 톤·문서 스타일
2. `프로젝트_방향성.md` §5(3-Asset), §6.1
3. 리서치가 연결될 산출물의 위치 (예: `docs/item/` 또는 `docs/keycontent/`)

## 작업 절차
1. **리서치 주제를 3~5개 하위 질문으로 분해** (사용자에게 확인).
2. **자료 수집** (웹 검색·공식 문서·리뷰 등). 출처 URL을 반드시 보존.
3. **수집 자료 평가**:
   - 신뢰도 (공식/2차/SNS 등급화)
   - 시점 (최근/구버전)
   - 우리 프로젝트 적용 가능성
4. **요약·정리**:
   - 표·비교 매트릭스로 핵심을 압축
   - 모호한 정보는 "확인 필요" 표시
5. **프로젝트 적용 메모** — 이 정보가 어떤 콘텐츠/상품/기획에 어떻게 쓰이는지 1~3줄.

## 산출물 형식 / 저장 위치
- **경로**: `50_knowledge/reference/research_<주제slug>_<날짜>.md`
  - 예: `50_knowledge/reference/research_전자책단말기_비교_2026-05-XX.md`
- **프론트매터**:
  ```markdown
  ---
  유형: 외부 리서치
  주제: <주제>
  사용 목적: <어디에 쓸 것인가>
  수집일: 2026-XX-XX
  주요 출처: [URL1, URL2, ...]
  ---
  ```

## 산출물 본문 형식
```markdown
# <주제> 리서치 (2026-XX-XX)

## 핵심 결론 (TL;DR)
- ...

## 하위 질문별 정리
### Q1. ...
- 답: ...
- 근거: [출처](URL)
- 신뢰도: 공식/2차/SNS

## 비교 매트릭스 (있을 경우)
| 항목 | 옵션 A | 옵션 B | ... |
|---|---|---|---|

## 프로젝트 적용 메모
- 어디에 어떻게 쓸 것인가
- 후속 작업 제안

## 출처 전체
- ...
```

## 완료 체크리스트
- [ ] 모든 주장에 출처 URL이 붙었는가
- [ ] 신뢰도·시점이 평가됐는가
- [ ] 비교 가능한 자료는 표로 압축했는가
- [ ] 프로젝트 적용 메모가 구체적인가 (추상적 표현 금지)
- [ ] `docs/README.md` reference 섹션에 인덱스 한 줄 추가했는가
