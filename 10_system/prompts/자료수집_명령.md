# 자료수집 명령 (Prompt 1)

## 목적
주제 텍스트 1개를 받아 영상 제작에 필요한 자료(인용·통계·이미지 출처·참조 영상)를 한 폴더로 수집·정리.

## 입력 변수
- `주제`: (필수) 자료수집 대상 텍스트. 한 문장~한 단락.
- `책`: (선택) 중심 책 제목·저자. 책 기반 영상이면 필수.
- `출력폴더`: (필수) `03_프로젝트/<폴더>/02_자료수집/` 절대 경로
- `depth`: low / mid / **high** (기본: mid). low=후킹 1개+인용 3개, mid=인용 5개+통계 2개+이미지 5개, high=mid + 참조 영상 5개+반대 의견 2개

## 산출물

`출력폴더` 안에 다음 파일들 생성:

```
02_자료수집/
├── 인용.md          # 책·기사·인터뷰에서 직접 인용 가능한 문장 (출처 명시)
├── 통계.md          # 숫자·트렌드·시장 데이터 (출처·연도 명시)
├── 출처.md          # 모든 출처 URL 목록 (인용/통계 cross-reference)
├── 참조영상.md       # 유사 주제 다룬 영상 (URL·핵심 차별점 메모)
├── 반대의견.md       # high 모드 — 균형 잡기용
└── 이미지/           # 라이선스 OK인 이미지 (CC0 / 직접 촬영 / 공식 이미지)
```

## 작업 절차

1. WebSearch로 `주제` + `책`(있으면) 키워드로 1차 검색.
2. 검색 결과 상위 10개 중 신뢰도 높은 출처(공식 사이트·전문 매체·논문) 우선 선별.
3. 인용은 **반드시 출처 명시**. 출처 없으면 `인용.md`에 등록 X.
4. 이미지는 **라이선스 확인 가능한 것만** `이미지/` 폴더로 다운로드.
   - 라이선스 불명확 → URL만 `출처.md`에 기록, 다운로드 X
5. 통계는 **연도와 발표 기관** 함께 기록.
6. 참조 영상은 유튜브·블로그 영상 모두 가능. **핵심 차별점**(우리 영상은 어떻게 다를지) 메모 1줄 필수.
7. high 모드: `반대의견.md` 추가 — 같은 주제에 대한 반대·비판 의견 2~3개 정리.

## 체크리스트 (출력 전 자가검증)
- [ ] 모든 인용에 출처 있는가
- [ ] 통계에 연도·기관 있는가
- [ ] 이미지 라이선스 모두 확인되었는가
- [ ] 참조 영상에 차별점 메모 있는가
- [ ] 동일 출처가 인용/통계/이미지에 cross-reference 되어 있는가

## 출력 예시 (`인용.md`)

```markdown
# 인용 — 데미안의 자기 발견 3단계

## 1. 헤르만 헤세, 『데미안』 (1919)
> "새는 알을 깨고 나온다. 알은 세계다. 태어나려는 자는 한 세계를 깨뜨려야 한다."
- 출처: 데미안 본문 8장
- 사용 추천 위치: 영상 후킹 또는 결론

## 2. 카를 융, 『인격의 발달』 (1934)
> "자기 자신이 되는 것은 모든 인간의 가장 심오한 의무다."
- 출처: Collected Works Vol. 17, p. 154
- 영문 원문: "To become oneself..."
- 사용 추천 위치: 본론 — 자기 발견의 보편성 강조 시
```

## 사용법

```
@자동화편집/04_프롬프트/자료수집_명령.md 를 따라
- 주제: "데미안의 자기 발견 3단계"
- 책: "데미안 — 헤르만 헤세"
- 출력폴더: 자동화편집/03_프로젝트/2026-05-10_풀링_데미안_3분요약/02_자료수집/
- depth: mid
로 자료수집 실행해줘
```
