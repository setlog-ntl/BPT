# 캡컷 패키지 생성 (Prompt 4)

## 목적
기획서 + 스크립트 + 자료를 받아 캡컷 import 가능한 `03_캡컷_패키지/` 전체를 자동 생성.

## 입력 변수
- `기획서`: (필수) `00_기획서.md` 경로
- `스크립트`: (필수) `01_스크립트.md` 경로
- `자료폴더`: (선택) `02_자료수집/` 경로
- `출력폴더`: (필수) `03_프로젝트/<폴더>/03_캡컷_패키지/` 절대 경로
- `mode`: **short** / long / landing (기본 short — 풀링용)
- `자산우선순위`: (선택) "배경음악-007, 인트로-002 우선 적용해줘" 같은 사용자 지시

## 산출물

[`../guides/캡컷_패키지_스펙.md`](../guides/캡컷_패키지_스펙.md) 의 v1 스펙을 따라:

```
03_캡컷_패키지/
├── 편집_가이드.md
├── 자막.srt
├── 사용자산.md
├── 배경음악_지정.md
└── 영상소스/  (빈 폴더로 생성, 사용자가 직접 채움)
```

## 작업 절차

1. 스크립트의 시간코드 → SRT 변환:
   - 한 자막 단위는 호흡 단위(쉼표·문장 끝)로 분리
   - 쇼츠: 한 자막 ≤12자, 키: ≤18자
   - 자막 간 간격 ≥0.2초
2. 사용 자산 매칭:
   - 기획서 "사용 자산 후보" 섹션 우선
   - 자산 라이브러리 카탈로그 검색 → 분위기 태그 일치 자산 선별
   - 매칭 안 되면 → "신규 등록 필요" 표에 가제로 기재
3. 편집 가이드 작성:
   - mode=short: 0~60초, 5초 단위 섹션
   - mode=long: 챕터별 섹션
   - mode=landing: 4단(Problem/Promise/Proof/CTA) 섹션
   - 모든 지시는 명령형 (~한다, ~배치한다)
4. 배경음악_지정.md 작성:
   - mode=long은 챕터마다 다른 배경음악 가능
   - 페이드 인/아웃은 기본 0.5초, 볼륨 -18dB (사용자가 마감 시 조정)
5. 영상소스/ 빈 폴더 생성 + `README.md` 1개 추가:
   - "여기에 직접 촬영/AI 생성한 영상을 `001_<설명>.mp4` 형식으로 배치하세요" 안내

## 체크리스트 (출력 전 자가검증)
- [ ] SRT가 표준 포맷(UTF-8, 시간코드 형식 정확)인가
- [ ] 사용자산.md의 모든 ID가 카탈로그에 존재하거나 "신규 등록 필요" 표에 있는가
- [ ] 편집 가이드의 시간코드와 SRT 시간코드가 일치하는가
- [ ] 배경음악 페이드 타이밍이 인트로/아웃트로와 충돌 없는가
- [ ] 모호한 표현("느낌 있게", "적당히") 0건인가
- [ ] 마감 시 사용자 결정 사항이 체크박스로 정리되어 있는가

## 신규 자산 필요 시 처리

매칭 가능한 자산이 없을 때:
1. `사용자산.md`의 "신규 등록 필요" 표에 가제·카테고리·이유 기록
2. 영상 발행 후 사용자가 자산 라이브러리 카탈로그에 정식 ID로 등록
3. 그 후 본 영상 패키지의 사용자산.md를 ID로 업데이트

- 자료폴더: 자동화편집/03_프로젝트/2026-05-10_풀링_데미안_3분요약/02_자료수집/
