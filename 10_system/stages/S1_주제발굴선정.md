# S1 — 주제 발굴·선정

> **목적**: 감이 아니라 데이터로 "만들 가치"를 판정한다. 아이디어 깔때기의 입구.
> **왜**: 대형 채널은 10개를 발굴해 1개를 만든다. 주제 단계에서 조회수의 절반이 결정된다. **주제는 떠올리지 말고 뷰트랩에서 찾는다**(B-21·47).

## 입력
- 주제뱅크(`20_research/topics/`) · 뷰트랩 추출(`20_research/keywords/`) · YouTube API 검색(60_tools) · S9 환류 카드의 파생 주제 · 댓글에서 발견한 페인(S2 순환)

## 프로세스
1. **후보 수집 (주 단위)**: 뷰트랩 떡상 감지·추천 키워드 + API 인기 영상 + 댓글 페인 → 주제뱅크에 T1 주제카드 추가. 중복 각도 체크 — 기존 뱅크와 "행동 구체성·시점·페인"으로 각도 분리.
2. **스코어카드 평가** (T2 — 각 0~5, 가중 합산):

| 축 | 측정 근거 |
|---|---|
| 수요 | 뷰트랩 검색량·노출확률, API 검색 상위 조회수 — **뱅크 매핑만 = ≤3점, 실측 캡처/API 수치 = 4~5점** |
| 기회 | 경쟁 강도 대비 성과도 — "구독자 대비 떡상" 존재 = 알고리즘 열림 신호 |
| 채널적합 | `{axes}` 부합 + `{segments}` 중 명확한 1타깃 + 금지 프레임(channel_config §8) 무저촉 |
| 전환기여 | 풀링→키→랜딩 어느 자산이며 종착지(`{platforms}`·`{item}`)가 보이는가 |
| 제작용이 | 소스 확보·제작 난도 (역점수) |

3. 벤치마크 선정 룰: "개인·채널가치 낮은데도 잘된 콘텐츠"(순수 컨텐츠가치 = 에버그린 후보)를 참조(A-13). 반의어·부정형은 가정하지 말고 뷰트랩 조회수로 판정(B-25).
4. 커트라인 통과분만 주제 카드 확정 → `30_videos/NNN_슬러그/00_brief/` 생성 + `_index.md` 등록.

## 산출물
- T1 주제카드 + T2 스코어카드 (`00_brief/`) · 주제뱅크 갱신
