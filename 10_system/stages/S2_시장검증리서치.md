# S2 — 시장 검증·리서치

> **목적**: 시청자의 실제 언어·페인·연령·시청 이유를 확보해 패키징(S3)과 대본(S4)의 원료로 만든다.
> **왜**: 대형 채널은 자기 언어가 아니라 **댓글의 언어**로 제목과 후크를 쓴다. 제목·후크·썸네일 문구는 창작하지 않고 댓글에서 채굴한다.

## 입력
- G1 통과한 주제카드 · 경쟁·유사 영상 3~5편 (뷰트랩·API 선별)

## 프로세스
1. **댓글분석** (코워크 또는 API): 각도 7종(기본·경쟁·후크발굴·시청층·아이템 연계·부정·팬덤) 중 선택 → 4단 고정 구조(대표댓글 TOP3 → 정체성 간략 → **시청이유 메인** → 더보기) → 주제별 카테고리 허브 누적. 연령은 **항상 "추정" 표기**, 인용·ID·조회수 **기억 작성 절대 금지**(실추출만).
2. **경쟁영상 분해** (T4): 제목 공식·썸네일 구도·도입 30초 구조·챕터 흐름·조회수/구독자 비·배울 것/피할 것.
3. **본문 리서치 5단계** (B-18): 제목 다국어 번역 → 뷰트랩 검색 → 해외 반응 영상 선별(기여도·성과도·댓글수↑) → AI 맥락 해석 → 원고화 대기.
4. **시청자 언어 뱅크 적립**: 분석에서 나온 표현·페인을 `20_research/audience/언어뱅크.md`에 누적 (S3·S4 의무 반영 원료).
5. 외부 리서치 필요 시: 하위질문 3~5 분해(사용자 확인) → 출처 전건 보존 → 신뢰도 3등급(공식/2차/SNS) (D-15).
