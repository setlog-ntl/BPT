# S3 — 패키징 (제목·썸네일 먼저)

> **목적**: 대본보다 먼저 "클릭될 약속"을 확정한다. 채널 운영의 최중요 단계.
> **왜**: **패키징 퍼스트** — 제목·썸네일이 확정되지 않은 영상의 대본을 쓰지 않는다. CTR이 없으면 AVD는 존재할 기회조차 없다. 기존 룰북도 동일(B-13: 작업 순서 제목→썸네일→도입부→본문 강제).

## 입력
- G1 통과 주제카드 · S2 산출물(시청자 언어 뱅크·경쟁 분해) · 뷰트랩 수식어 라이브러리(`20_research/keywords/뷰트랩_라이브러리/`)

## 프로세스

### 1) 제목 — 10안 → 3안
- 시청자 언어 뱅크 + 뷰트랩 수식어로 **10안 생성 → 3안 압축**. 각 안에 "클릭 근거"(어떤 페인/호기심을 찌르는가) 1줄.
- **글자수 룰**(B-23): 메인 메시지 35자 이내, 35~100자는 SEO 키워드. 썸네일 헤드는 그 35자의 축약(7~10자/12~16자).
- **제목 디벨롭 8단계**(B-22): ①교차조합 ②쉬운 단어 ③넓은 용어/반의어 ④수식어 ⑤답 숨긴 질문형 ⑥트렌드 ⑦핫비디오 ⑧강력단어. ③-2 반의어는 뷰트랩 조회수로 판정(가정 금지). **⑧은 자기 채널 데이터 누적 후에만**(사후 룰 — S9 연동).

### 2) 썸네일 — 컨셉 3안 → 시안
- 컨셉 3안(구도·감정·헤드 1줄+부가 1줄 이하) → 썸네일지침 워크플로우 5단계(정합 점검→헤드 30안→5안 채점→시안→AB 발행) 적용 → AI 이미지 프롬프트(`40_assets/prompts/` 뱅크, 페이스리스 강제·실명 금지) → 발행 전 16항 체크.
- 핵심 상수(C 승계): 3요소 비중 이미지 45·문구 45·디자인 10 / 1초 인지(두께 700+·대비 4.5:1·글자 18%+) / 색 2색+화이트/다크 디폴트·4색 금지 / 안전영역 준수 / 이미지 강화 6단계(공감 요소는 좌상단).
- 결 호명 단어 1개 필수(`{segments}`) + 축 키워드(`{axes}`) + 진정성 6금지(숫자 과장·낚시·실사진·AI 정면·광고화·적대 톤).
- `{signature_lines}`·`{signoff}`는 **미확정 — 사용 전 사용자 확인** (구 사인오프 자동 사용 금지).

### 3) 조합 확정
- 제목×썸네일 매트릭스에서 **AB 후보 2조합** 확정. AB는 다른 톤끼리만(같은 톤 미세 변형 금지).
- 썸네일에서 한 약속을 **도입 30초가 갚을 수 있는지** 사전 점검 (S4 예고 정합).
