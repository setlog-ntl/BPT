# S4 — 구조·대본

> **목적**: 패키징이 만든 기대를 리텐션으로 갚는 대본.
> **왜**: 대본은 문학이 아니라 **리텐션 설계도** — 30초 후크로 잡고, 중간 re-hook으로 붙들고, 선언한 페이오프를 끝에서 지급한다.

## 입력
- **G2 통과한 패키징**(제목·썸네일 확정 — 없으면 착수 금지) · S2 시청자 언어 뱅크 · 신뢰도 보강 자료(S2 리서치)

## 프로세스
1. **리텐션 맵 먼저** (T7): 챕터 골격(HOOK→BODY→STORY→BODY→CTA, 1편=5~8챕터·pill 4종) 위에 분 단위 긴장 곡선·re-hook 지점·페이오프 위치 설계. 키는 pain→growth→value→rec 4단.
2. **대본 작성**:
   - 30초 후크 룰(B-04): 약속한 변화 + 결 호명 1회 + 축 키워드 + 결론 먼저 + 시각 텐션. 수미상관(약속만 하고 사라지면 클릭베이트).
   - 원고 4종 **N·S·C·A**(나레이션·지문·카메라·오디오) — 도입부 30초는 4종 전부 필수(B-17). 도입부 2패턴(과거 이력 나열형/결과 선공개형), 정성 기준 = "다음이 궁금해 어쩔 줄 모르는" 상태(B-14). 타분야 차용(같은 분야 베끼기 금지).
   - 톤: 구어체·결론 먼저·**본편 230자/분·쇼츠 250~270자/분**(±20%).
   - 본문 3요소(차용+출처 명시+내 경험 보강) + 신뢰도 6보강 베이스(원리+경험+반론 증거) 필수(B-19~20). 학자명 발화 금지 → 고정 댓글.
   - 결 호명(B-05): 본문 중간 1개, 마무리 3그룹 전부+"옆자리". CTA 3층(B-07): 풀링=구독→떡밥→정신적 떡밥 / 키=구매 의도→다음 편→풀링 회귀.
   - **채널 보이스는 channel_config 확정값만 사용** — `{signoff}`·`{call}`·표준 멘트 미확정 시 사용자 확인(구 멘트 자동 사용 금지). 시청자 언어 뱅크 표현 의무 반영.
   - 금지선: 풀링에서 `{no_expose}` 직접 노출 0회 / 키도 결 호명 없이 가격만 던지지 않기(B-08).
   - 쇼츠(B-38~46): 본편 1메시지의 "칼끝"(2개=실패) · 20~59초·9:16 · 본편 30초→0~3초 압축 · 첫 프레임=후크(로고 3초=즉사) · 3비트(훅/바디/CTA) · 풀자막 12~16자.
3. **검증**: 30초 후크 체크 + 마감 체크(12항) + script-empathy-editor 도입부 진단(공감 vs 정보 구분 — 7·8주차 기준).
