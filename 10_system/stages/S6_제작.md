# S6 — 제작

> **목적**: 녹음·촬영·조립에 바로 들어갈 수 있는 실행 패키지를 만든다.
> **왜**: 편집 앞 단계의 준비 완결성이 편집 시간을 결정한다. 캡컷 연동은 **수동 import + 자료 패키지 자동 생성**(.draft 직접 조작 금지 — 버전 의존 위험, E-02).

## 입력
- G3 최종 대본 · T9 소스 시트 · 40_assets 자산(ID 참조)

## 프로세스
1. **녹음용 대본 변환**: 호흡·강조 표기 추가 (원고 4종 중 N 트랙 기준).
2. **촬영/화면녹화 노트**: C(카메라)·S(지문) 트랙에서 추출.
3. **캡컷 패키지 생성** (T10 — [`guides/캡컷_패키지_스펙.md`](../guides/캡컷_패키지_스펙.md) 그대로):
   - 필수 5요소: `편집_가이드.md`(시간순·명령형·모호 표현 0건) · `자막.srt`(UTF-8, 쇼츠≤12자·키≤18자, 표시 1.5~4초) · `사용자산.md`(ID 매칭표+신규 등록 표) · `배경음악_지정.md`(볼륨 -18dB·페이드 0.5s 기본) · `영상소스/`(`001_<설명>.mp4`, H.264, 앞뒤 1초 여유)
   - 캡컷 import 사용자 7단계 시퀀스 첨부.
4. 페이스리스 제작 가이드 적용(해당 시). 쇼츠는 자동 파이프라인(`60_tools/shorts_pipeline/`: scenes→tts→srt→bgm→compose) 활용 가능.

## 산출물
- `05_production/` — 녹음 대본 · T10 캡컷 패키지 · 제작 체크

## 게이트
- **패키지 완결성**: 필수 5요소 존재 + 가이드↔사용자산 교차검증 + 모호 표현 0건.
