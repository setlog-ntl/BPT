# S8 — 업로드 패키지

> **목적**: 발행 순간에 결정되는 모든 메타데이터를 한 번에, 실수 없이.
> **왜**: 발행 직후 24~72시간이 알고리즘 초기 판정 구간 — 메타 누락·오타는 되돌릴 수 없는 초기 신호 손실이다.

## 입력
- 최종 출력 영상 · G2 확정 AB 조합 · S2 시청자 언어(설명란 첫 2줄 원료) · channel_config 확정 표면 자산(`{name}`·채널 키워드·`{platforms}` 링크)

## 프로세스
1. **T12 업로드 메타** 작성:
   - 최종 제목(AB 1안) · 설명(첫 2줄 후크 + 링크 + 챕터 타임스탬프) · 태그 5~10개 · 카드/최종화면 계획 · 고정댓글(CTA + 인용 출처) · 재생목록 · 공개 시각(타깃 시청 패턴 근거 1줄)
   - `{hashtags}`·`{title_format}` 미확정 시 사용자 확인(구 세트 자동 사용 금지).
2. **발행전 최종점검** ([체크리스트](../checklists/발행전_최종점검.md)) 전항 통과: 영상 본체(오타 0·자막 1.5~4초·길이 ±10%) / 메타(첫 3줄 CTA·썸네일 규격) / 자산·출처(ID 등록·출처 표기) / 진정성(후킹=본문 일치·과장 0건).
3. 유형별 체크 병행 ([체크리스트](../checklists/영상유형별_체크리스트.md)) — 풀링/키/랜딩 각 6항.
4. **유튜브 스튜디오 수동 업로드(사용자)** — 시스템은 패키지·체크리스트로 지원. YT Studio 썸네일 AB 테스트 설정(3안 동시).
5. 발행 직후 확인: 썸네일 렌더·챕터 인식·링크 동작.
