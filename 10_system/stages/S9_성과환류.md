# S9 — 성과 분석·환류

> **목적**: 발행이 끝이 아니라 **다음 기획의 입력**이 되게 한다. 데이터 루프의 완성.
> **왜**: 대형 채널과 그 외의 결정적 차이 — 그들은 모든 영상에서 "다음에 반복할 것 1개, 버릴 것 1개"를 추출한다. 루프가 닫혀야 복리가 생긴다. *(개편 전 저장소 최대 공백 스테이지 — 신설)*

## 입력
- 발행된 영상 · 스튜디오 지표(CTR·AVD·리텐션 그래프 — **사용자 제공 값/스크린샷**) · 공개 지표(YouTube API — `60_tools/`)

## 프로세스
1. **수집 시점: 24h / 72h / 7d / 28d** — 조회수·노출 CTR·평균 시청 지속시간(AVD)·리텐션 이탈점·유입 경로·구독 전환. T13 성과 리뷰에 시점별 기록.
2. **해석 — 원인 스테이지 지목**:

| 신호 | 원인 스테이지 | 환류처 |
|---|---|---|
| CTR 낮음 | 패키징 문제 | S3 룰·문구뱅크 갱신 (CTR -15% 점검 5단계, C-51) |
| 초반 이탈 | 후크 문제 | S4 후크 룰·패턴 뱅크 |
| 중반 이탈점 | 편집 문제 | S7 배열 룰 |
| CTR·AVD 좋은데 성장 없음 | 주제 시장 크기 | S1 스코어카드 가중치 |

- **지표 우선순위(C-49)**: ① AVD(하락 시 CTR 우세안도 폐기 = 낚시 신호) ② CTR(채널 평균 ±10%) ③ 저장·공유 ④ 댓글 톤. "CTR 함정" 경계.
- 썸네일 AB 판정: +24h 1차(CTR ±10%) → +7일 2차(CTR+지속률 동시) → +30일 회고(C-47).
3. **환류 카드 작성** (T14): `반복할 것 1 | 버릴 것 1 | 주제뱅크 추가 파생 주제 | 갱신할 룰(스테이지 문서 경로 지목)`.
   - 유지율 그래프 피크 = 다음 영상 후크 후보로 주제뱅크 적립(B-61).
   - 제목 "강력단어" 데이터 누적(B-24 — 사후 적용 원료).
4. **반영까지가 완료 조건**: 주제뱅크·해당 스테이지 문서에 실제 반영 + `30_videos/_index.md` 상태 갱신.
5. 회고 3층 운영(C-50): 1주(영상별) · 1개월(시즌 집계) · 분기(S0 channel_config 갱신 검토 + 가이드 자체 갱신).
