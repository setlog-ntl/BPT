# T1 주제카드 (S1)

> 주제뱅크·`00_brief/`에 1주제 1카드. 시청자 언어로 쓸 것 — 내 언어로 쓰면 이미 실패.

```markdown
## 주제카드 — <주제 한 줄 (시청자 언어)>
- 작성일:
- 타깃 결 (1그룹만): ① 입문 / ② 활용 / ③ 심화     ← channel_config {segments}
- 페인/호기심 (댓글·뷰트랩 근거 1줄):
- 자산 유형: 풀링 / 키 / 쇼츠 (섞이면 분리)
- 축 키워드 (1개+): ← channel_config {axes}
- 수익화 종착지: {platforms} / {item} 중 —
- 근거 링크: (뷰트랩 캡처 · API 결과 · 댓글분석 · 환류 카드)
- 중복 각도 체크: 기존 뱅크의 유사 주제 — / 각도 차이(행동 구체성·시점·페인) —
- 상태: 후보 / G1 통과 / 보류(반납) / 제작 중(NNN)
```
