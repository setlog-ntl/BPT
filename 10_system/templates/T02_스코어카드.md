# T2 스코어카드 (S1 — G1 게이트 판정지)

> 각 축 0~5점. 근거 없는 점수 금지 — 측정 근거 칸이 비면 그 축은 0점.

```markdown
## 스코어카드 — <주제>
| 축 | 점수(0~5) | 가중치 | 근거 |
|---|---|---|---|
| 수요 (뷰트랩 검색량·노출확률·API 상위 조회수) | | ×1.0 | |
| 기회 (구독자 대비 떡상 존재 = 알고리즘 열림) | | ×1.0 | |
| 채널적합 ({axes} 부합 + {segments} 1타깃 + 금지 프레임 무저촉) | | ×1.0 | |
| 전환기여 (풀링→키→랜딩 위치 + 종착지 가시성) | | ×1.0 | |
| 제작용이 (소스 확보·난도 — 역점수) | | ×0.5 | |
| **가중 합계** | /22.5 | | |

### 커트라인 판정
- 커트라인: 합계 60% (13.5) 이상 + 채널적합 3점 이상   ← 운영하며 S9 환류로 보정
- 판정: 통과 / 보류(뱅크 반납) / 킬

### 의사결정 5체크 (registry §4)
- [ ] 풀링/키 구분 명확  - [ ] 수익화 종착지  - [ ] AI↔문해력 연결  - [ ] READTREE·LINKMAP 여지  - [ ] 강의 개념 적용
- 1개 이상 모호 → 사용자 확인. ⑤ 강의 개념의 진도 기준 = `50_knowledge/lectures/` 최신 주차 — 판정 불가 시 "조건부 통과" 표기
```
