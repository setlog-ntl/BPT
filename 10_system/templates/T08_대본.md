# T8 대본 (S4 — 승계)

> **원천 데이터는 md, HTML은 뷰.** 승계 HTML 뷰 템플릿(변수화 복사본): [`template_풀링컨텐츠_기획서.html`](template_풀링컨텐츠_기획서.html) · [`template_키컨텐츠_기획서.html`](template_키컨텐츠_기획서.html) — 4섹션 구조(브리프 B1~B6 · 메시지팩 3카드 · 챕터 슬롯 · 검증) + 자수/시간 자동 계산 유지.

## md 대본 표준 골격
```markdown
# 대본 vN — NNN <제목>
- 유형: 풀링/키/쇼츠 · 리텐션 맵: [T7 링크] · 자수: —자 (—분)

## 챕터 <#> [pill] <챕터명> (m:ss~m:ss)
N: (나레이션 — 구어체·결론 먼저)
S: (지문 — 화면 지시)
C: (카메라/화면 소스)
A: (오디오 — BGM·효과음)
```
- 도입부 30초는 N·S·C·A **4종 전부** 채워야 통과.
- 보이스(사인오프·호명·표준 멘트)는 channel_config 확정값만 — **미확정 시 빈 슬롯 + 사용자 확인**.
- 시청자 언어 뱅크 표현 최소 2개 반영(출처 주석).
- 금지선: 풀링 = {no_expose} 직접 노출 0회.
```
