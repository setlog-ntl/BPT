# 운영매뉴얼 — 영상 1편의 일생 (1페이지)

> 사용자 관점: **무슨 명령을 치면 → 무엇이 나오고 → 어디서 승인하는가.** 상세 룰은 각 스테이지 문서(stages/)·게이트(checklists/).

## 영상 1편의 흐름

```
 사용자 명령                      시스템이 하는 일                          사용자가 하는 일
─────────────────────────────────────────────────────────────────────────────
 "새 영상 시작: S1 <주제>"   →  topic-scout: T1 주제카드+T2 스코어카드
                                → G1 판정 → 30_videos/NNN/ 생성            (모호 시 1회 확인)
                             →  S2: 댓글분석·경쟁 분해·언어뱅크 적립        코워크 실행 (뷰트랩·크롬 댓글
                                (코워크_요청.md 프롬프트 생성)               — cowork_prompts/ 붙여넣기)
                             →  S3: 제목 10→3안 + 썸네일 3안 + AB 조합     ★ G2 승인 (승인 전 대본 착수 금지)
                             →  S4: 리텐션 맵 → 대본(N·S·C·A) → G3        (도입부 톤 확인 권장)
                             →  S5: 소스 시트 (저작권 불명 0건)
                             →  S6: 캡컷 패키지 (가이드·SRT·자산ID·BGM)    캡컷 수동 import 7단계 → 편집
                             →  S7: 편집 기획서 (재미 내림차순 배열)
                             →  S8: T12 업로드 메타 + G4 체크              ★ 유튜브 스튜디오 수동 업로드
 "성과 리뷰 NNN"             →  S9: T13 지표(24h/72h/7d/28d)+T14 환류 카드  스튜디오 지표 값/스크린샷 제공
                                → 주제뱅크·룰 실반영(G5) → 다음 기획 입력
```

## 자주 쓰는 명령 (registry §2)

| 명령 | 결과 |
|---|---|
| `새 영상 시작: S1 <주제 후보>` | G1까지 자동 — 통과 시 `30_videos/NNN/` 생성 |
| `NNN 영상 S<K>부터 이어서` | README 상태 보드 읽고 해당 스테이지 재개 |
| `주제뱅크 갱신` | 후보 수집 루프 (뷰트랩 코워크 프롬프트 발급 포함) |
| `성과 리뷰 NNN` | S9 실행 — 지표 기록→환류 카드→뱅크/룰 반영 |
| `룰 갱신: <스테이지> <내용>` | stages/·guides 개정 + 이력 |

## 사용자 개입 지점 (이것만 기억)

1. **G2 패키징 승인** — 제목×썸네일 AB 조합 확정 (유일한 필수 승인 게이트)
2. **코워크 실행** — 뷰트랩·크롬 댓글 추출 (`10_system/cowork_prompts/` 프롬프트 복사 → Cowork에서 실행)
3. **업로드** — 유튜브 스튜디오 수동 (T12 메타 패키지 그대로)
4. **S9 지표 제공** — 스튜디오 전용 지표(CTR·AVD·리텐션)는 값 또는 스크린샷으로
5. **미확정 표면 자산** — 사인오프·호명 등을 시스템이 물으면 확정값 입력 (channel_config §6)

## 문서 지도 (역할 1줄씩)

- `registry.md` 라우팅 · `stages/S0~S9` 각 단계의 목적·프로세스·게이트 · `guides/` 상세 룰북(썸네일지침·편집기획·캡컷 스펙·뷰트랩) · `templates/T01~14` 산출물 양식 · `checklists/` 게이트 판정지 · `cowork_prompts/` 크롬 위임 3종
- 도구: `python 60_tools/check_links.py`(링크 검증) · `60_tools/youtube_api/`(검색·통계·댓글 — README 참조)
