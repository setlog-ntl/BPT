# 30초 후크 룰 체크리스트 (도입부분석 자체 기준)

> **목적**: 레퍼런스 영상 도입부(0~30초)를 **객관적으로 채점**하고, 우리 채널 「그럼에도 불구하고」 후크 기획에 차용할 포인트를 도출하기 위한 기준.
> **이 문서는 self-contained** 입니다 — 상위 폴더(`../../_기획기준/`)가 없어도 도입부 분석을 끝까지 수행할 수 있습니다.
> 분석 시 [`../실행_플레이북.md`](../실행_플레이북.md) Step 5에서 이 체크리스트를 `분석.md` §3에 대입합니다.

---

## 0. 사용법

1. 레퍼런스 영상의 `transcript.md` + `captures/`를 먼저 확보한다(플레이북 Step 1~3).
2. 아래 **§1 필수 5항목**을 ✅/⚠️/❌로 채점한다.
3. **§2 후크 유형**을 1개(주) + 보조로 분류한다.
4. **§3 피해야 할 패턴**에 걸리는지 점검한다.
5. **§4 채널 적합도 4축**으로 우리 채널과의 결 일치도를 본다.
6. 합산 점수와 한 줄 결론을 `분석.md` §1·§3에 옮긴다.

**판정 기호**: ✅ 충족 · ⚠️ 부분 충족 · ❌ 미충족 · — 해당없음(도입부 30초 밖)

## 1. 0~30초 필수 5항목 (핵심 채점표)

| # | 항목 | 정의 (무엇을 보는가) | 판정 | 근거(구간·발화·화면) | 배점 |
|---|---|---|---|---|---|
| 1 | **약속한 변화·결과** | 시청 후 얻을 변화/결과를 30초 안에 명시했는가 ("이 영상 보면 ~하게 된다") | | | 20 |
| 2 | **결(結) 호명 1회+** | 시청자의 결핍·욕구·상태("결")를 직접 불러냈는가 (§4-A 참조) | | | 20 |
| 3 | **8축 키워드 1개+** | 채널 8축 키워드 중 최소 1개가 발화/자막에 등장했는가 (§4-B 참조) | | | 20 |
| 4 | **결론 먼저** | 서론·자기소개 없이 결론/핵심 주장부터 진입했는가 | | | 20 |
| 5 | **시각적 텐션** | 첫 컷부터 시선을 잡는 시각 요소(충격 카드·B-roll·숫자·대비)가 있는가 | | | 20 |
|   | | | | **합계** | **/100** |

**해석 가이드**

| 점수 | 등급 | 의미 |
|---|---|---|
| 80~100 | A | 후크 정석 — 구조·문구·연출 모두 차용 가치 높음 |
| 60~79 | B | 일부 강점 — 강한 항목만 선별 차용 |
| 40~59 | C | 약한 후크 — 반면교사 위주, 차용 신중 |
| 0~39 | D | 후크 실패 — §3 피해야 할 패턴 사례로만 기록 |

## 2. 후크 유형 분류

도입부가 시청자를 붙잡는 **1차 메커니즘**을 분류한다. (주 1개 필수, 보조 복수 허용)

| 유형 | 정의 | 전형적 첫 컷 | 예시 신호 |
|---|---|---|---|
| **충격 카드형** | 강한 한 문장/이미지를 풀스크린 카드로 제시 | 검은 배경 + 큰 자막 | "당신은 책을 잘못 읽고 있다" |
| **변화 약속형** | 시청 전후의 변화를 약속 | before→after 대비 | "30일 뒤 당신은…" |
| **자기 고백형** | 화자의 실패·치부를 먼저 고백 | talking-head 클로즈업 | "사실 저는 1년에 1권도…" |
| **숫자 카드형** | 수치·통계로 호기심 자극 | 큰 숫자 풀스크린 | "독서 인구 0%대" |
| **질문형** | 답을 미루는 질문 제시 | 자막 질문 카드 | "왜 다 읽어야 한다고 믿죠?" |
| **클립 인용형** | 타 영상/뉴스/유명인 클립 인용 | 인용 화면 PIP | 뉴스 헤드라인 인서트 |
| **기타** | 위에 안 맞는 독자 패턴 | — | (서술) |

> 우리 채널 권장: **충격 카드형 / 변화 약속형 / 숫자 카드형**이 「그럼에도 불구하고」 톤과 잘 맞음(§4 참조).

## 3. 피해야 할 패턴 (안티 패턴)

하나라도 해당하면 도입부 차용 시 **반드시 각도 변환**한다.

| 안티 패턴 | 왜 나쁜가 | 해당? |
|---|---|---|
| ❌ 자기소개·인사로 시작 | "안녕하세요 ~채널" — 첫 5초 낭비, 이탈 유발 | |
| ❌ 30초 안에 전체 요약 | 본문 볼 이유 소멸 | |
| ❌ 본편 없는 약속·과장 | 후크가 본편과 불일치(클릭베이트) | |
| ❌ 8축·결 무관 잡지식 | 채널 정체성과 어긋남 | |
| ❌ 결론 없이 질문만 | 텐션만 주고 방향 없음 → 이탈 | |

## 4. 채널 적합도 4축 (「그럼에도 불구하고」 대비)

> 레퍼런스가 우리 채널과 얼마나 결이 맞는지 본다. **2개 이상 해당 = 결 맞음**(직접 차용 가능). **1개 이하 = 각도 변환 필요**.

| 축 | 질문 | 해당 | 우리 채널 적용 시 메모 |
|---|---|---|---|
| ① 좋아하는 책 | 책/독서/지식 콘텐츠인가 | Y/N | |
| ② 결(結) 3그룹 | 대상 시청자의 결핍·욕구가 우리 3그룹과 겹치는가 | Y/N | |
| ③ 8축 | 8축 주제 중 하나에 속하는가 | Y/N | |
| ④ 이북리더기·readtree | 디바이스/리딩툴/습관 솔루션과 연결되는가 | Y/N | |

### 4-A. "결(結)" 정의 슬롯

> 시청자의 결핍·상태를 부르는 호명 대상. **아래는 작업용 기본값(추정)이며, 상위 기획문서 `대본기획_기준.md`가 있으면 그 정의로 교체하세요.**

- (1그룹) 책을 사두고 못 읽는 사람 — "쌓아만 두는"
- (2그룹) 읽어도 남지 않는 사람 — "다 읽어도 기억이 안 나는"
- (3그룹) 시작 자체가 어려운 사람 — "첫 장을 못 넘기는"

### 4-B. "8축" 키워드 슬롯

> 채널 콘텐츠 8개 주제축. **아래는 작업용 자리표시자(추정)이며, 상위 기획문서가 있으면 정식 8축으로 교체하세요.**

| 축 | 키워드(작업용) |
|---|---|
| 1 | 독서법·읽기 기술 |
| 2 | 기억·체화 |
| 3 | 습관·지속 |
| 4 | 동기·태도 |
| 5 | 책 선택·큐레이션 |
| 6 | 디바이스·이북리더기 |
| 7 | 시간·환경 설계 |
| 8 | 자기계발 일반 |

> ⚠️ §4-A·§4-B는 **추정 기본값**입니다. 정식 정의가 상위 폴더에 있으면 이 슬롯만 덮어쓰면 됩니다 — 나머지 채점 구조는 그대로 유효합니다.
