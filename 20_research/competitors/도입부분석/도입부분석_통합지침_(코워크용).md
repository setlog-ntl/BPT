## ★ 최상위 원칙 — "스크립트 먼저" (SCRIPT-FIRST)

**모든 영상은 분석에 들어가기 전에, 유튜브 `스크립트 표시` 패널에서 실제 대본(스크립트)을 먼저 추출한다. 그 스크립트를 기준(원문)으로 📜 원문 / 📝 대본 타임라인을 만든 뒤에야 화면·점수·차용 작업을 진행한다.**

- 스크립트 없이 제목·추정으로 대본을 채우지 않는다. (과거 kw4/kw5에서 대본이 요약·추정으로 들어가 재작업한 실수가 있었음.)
- 스크립트가 확보되기 전에는 분석 작업을 **보류**한다. 추출 방법은 §5(검증된 절차).

## 0. 30초 요약 (이것만은 반드시)

1. **선정**: viewtrap '썸끝' 결과에서 **정답(=썸네일 판정)이 "좋음"인 영상만** 고른다. **"나쁨"은 절대 쓰지 않는다.** + 우리 **결**에 맞아야 한다.
2. **스크립트 먼저(1순위)**: 유튜브 `스크립트 표시` 패널에서 **실제 대본을 먼저 추출**한다. ✅ 작동 검증: 크롬 맨 앞(`open_application`) → 설명 펼치기 → '스크립트 표시' **버튼 실제 좌표 클릭** → 패널 세그먼트 DOM 추출(§5). 일부 영상은 패널이 안 차므로 그때만 사용자 붙여넣기. 제목 추정 금지.
3. **서식**: 영상 1편 = **3탭 분석.html**(📊 분석 리포트 / 📝 대본 타임라인 / 📜 원문). 기준 샘플 = 001·유시민·4-1(김교수).
4. **대본**: 📜 원문 탭은 **스크립트 원문 그대로**(오탈자 보존). 📝 대본 타임라인은 **내용을 최대한 그대로 유지**하며 **오타와 말이 안 맞는(비문) 부분만 수정**(윤문·요약 금지) → 맥락 단위 → 단위별 대본/화면/자막.
5. **화면/자막**: **크롬으로 실제 화면을 캡처**해 채운다(✔, 크롬이 맨 앞일 때만 됨). 못 보면 ◻ + 보완 예정. 추정으로 지어내지 않는다.
6. **마무리**: `_scripts/build_dashboard.py` **재실행**(대시보드 반영). 잘못된 자료는 삭제 대신 `_replaced_old`로 이동.
7. **로컬 스크립트**: 다른 생성 모듈을 **import하는 일괄 생성기 금지**. self-contained(import 0, 새 폴더만)·대시보드 생성기만 허용.

## 2. 절대 원칙 — MUST / NEVER

**MUST**
- **스크립트를 가장 먼저 추출**(§5 절차)하고, 그 스크립트를 기준으로 작업한다(SCRIPT-FIRST).
- 선정은 **썸끝 정답=좋음** + **결 맞음** 두 조건을 **모두** 만족.
- 분석은 **실제 스크립트·화면** 기반. 캡처는 **크롬으로 직접** 본 것만 ✔.
- 3탭 서식·점수·차용·적합도·출처를 빠짐없이 채운다.
- 자료 추가/수정 후 **대시보드 재생성**.

**NEVER**
- **스크립트 없이** 제목·추정만으로 대본/화면/자막을 **지어내지 않는다**(확보 전까지 작업 보류).
- 썸끝 **정답=나쁨** 영상을 쓰지 않는다.
- 📜 원문 탭을 **윤문/수정하지 않는다**(오탈자 보존).
- 자막 **직접 fetch(timedtext)·textTracks** 에 매달리지 않는다 — 토큰 차단으로 빈 값(§5). 스크립트는 **패널**에서 뽑는다.
- 다른 gen 모듈을 **import하는 일괄 생성기**를 쓰지 않는다.
- 이미 다른 키워드에 쓴 영상을 **중복 선정**하지 않는다.

## 3. 영상 선정 — 썸끝 "정답=좋음" + 결

### 3-1. 썸끝 결과 페이지 읽는 법
- 경로: `viewtrap.com/thumbnail-master` → 히스토리에서 키워드의 **확인하기** → `/thumbnail-master/result/<id>`.
- 결과 표 컬럼: **썸네일 | 제목 | 선택 | 정답 | 결과**. **정답**=도구 판정(실제 썸네일 품질, 좋음/나쁨) ← **이게 선정 기준**.
- 정렬 "썸네일 좋은 순" / "좋은 썸네일만 복습". **제목 클릭 → 해당 유튜브로 이동**.

### 3-2. 정답 판정 신뢰 추출 (DOM, 백그라운드 탭에서도 가능)
- 카드(행) 텍스트에 `좋음/나쁨`이 **2번** = **[선택][정답]**, **2번째가 정답**.
- 안전 파싱: 영상 링크에서 위로 올라가며 **`좋음|나쁨`이 정확히 2개**인 가장 작은 조상(=한 행)을 찾아 2번째를 정답으로. 결과는 최대 50편 → **스크롤로 전부 로드** 후 추출.

### 3-3. 선정 절차
1. **정답=좋음**만 후보. 2. 그중 **결 맞는** 제목만. 3. **중복 제외**. 4. 키워드당 보통 **5편**(부족하면 정답=좋음 풀 전체에서 더). 5. 제목 클릭 → 유튜브.
> ⚠️ "완독"처럼 정답=좋음+결 맞는 게 적은 키워드도 **정답=나쁨으로 채우지 말 것.**

## 5. ★ 스크립트 추출 — '스크립트 표시' 실제 클릭 (검증된 절차)

### 5-1. 작동 절차 (성공 검증됨 — 1086세그먼트 추출)
1. **`open_application("Google Chrome")`** 로 크롬을 화면 **맨 앞**으로 가져온다(`document.hidden=false` 확인).
2. 영상 페이지에서 **`#expand`(설명 더보기)** 클릭으로 설명을 펼친다.
3. '스크립트 표시' 버튼을 찾아 **rect(좌표)** 를 구하고(`getBoundingClientRect`, scrollIntoView 후), **Chrome MCP `computer left_click`(실제 좌표 클릭)** 으로 누른다. ⚠️ **합성(JS .click()) 클릭은 안 됨** — 반드시 실제 좌표 클릭.
4. **4~8초 대기**(패널 로딩).
5. `ytd-transcript-segment-renderer` 의 `.segment-timestamp`·`.segment-text` 를 DOM으로 수집(도입부 ~25세그먼트면 충분).

### 5-2. 영상별 편차 & 폴백
- 일부 영상은 패널이 **열려도(EXPANDED) 세그먼트가 안 채워짐**(로딩 점만, 토큰/캡션 이슈). → ① **재클릭 + 추가 대기**(10초+), ② 그래도 안 되면 **사용자에게 스크립트 복사·붙여넣기 요청**(사용자 로그인 브라우저 패널엔 복사 버튼 정상), ③ 화면에 자막이 박힌 영상은 **번인 자막 캡처**로 보완, ④ 전부 안 되면 "자막 미제공" 명시.
- **쓰지 말 것(빈 값 확인됨)**: 자막 직접 fetch(`timedtext` json3/srv3/vtt/xml 4종)·`video.textTracks` cue — 토큰 차단. **패널 DOM만** 유효.

### 5-3. 원문 vs 보정본
- **📜 원문** = 패널 원문 그대로(자동자막 오탈자 포함) · **절대 수정 안 함**.
- **📝 대본 타임라인** = 같은 스크립트의 **내용을 최대한 그대로 유지**하며 **오타와 '말이 안 맞는 부분'(자동자막 오인식으로 비문·뜻이 안 통하는 구간)만 최소 수정**(맥락·의미·말투 유지, 윤문·요약·재배열 금지), 누락 없이 → 맥락 단위로 묶고 단위별 대본/화면/자막.

## 9. 크롬 환경 제약 & 절차 (검증됨)

- **스크립트·스크린샷 모두 "크롬이 화면 맨 앞"일 때만** 동작. `open_application("Google Chrome")` 로 앞으로 가져오면 됨(검증). 비활성이면 스크린샷 백지/타임아웃, 스크립트 패널 0세그먼트.
- 스크립트 패널: **실제 좌표 클릭**으로 열어 DOM 추출(§5). 합성 클릭·fetch·textTracks는 안 됨.
- **정지프레임 갱신**: `currentTime` 이동 후 **잠깐 `play()`→`pause()`** 후 screenshot.
- **광고**: 합성 클릭 안 됨 → **실제 좌표 클릭**(스킵 버튼 rect) 또는 `video.currentTime=duration-0.1`. 비스킵 후원광고는 대기. (스크립트 DOM은 광고 중에도 추출 가능.)
- **이미지 파일 저장 불가** → 화면은 텍스트로 기록(✔/◻) + `captures/_수동캡처_가이드.md`에 `&t=` URL.
- **bash 마운트(도입부분석)**: 쓰기 후 끝부분 지연/잘림 가능 → Read 신뢰, 실패 시 끝부분 bash append / outputs(빠른 동기화)에서 실행.
- **DOM 추출(선정·메타데이터)은 백그라운드도 가능**.

## 14. 자주 한 실수 (안티패턴) — "엉뚱작업" 방지
1. ❌ 스크립트 없이 대본을 요약·추정 → ✅ '스크립트 표시' 패널에서 **실제 대본 먼저** 추출(§5).
2. ❌ '스크립트 표시'를 **합성(JS) 클릭** → ✅ **실제 좌표 클릭**(크롬 맨 앞 상태에서).
3. ❌ 자막 fetch/timedtext/textTracks 매달림(빈 값) → ✅ 패널 DOM, 안 되면 붙여넣기.
4. ❌ 정답=나쁨 영상 선정 → ✅ 정답=좋음 풀에서만.
5. ❌ 백그라운드 탭 스크린샷/패널(백지·0개) → ✅ open_application으로 크롬 맨 앞.
6. ❌ 제목으로 화면·자막 추정 기재 → ✅ 실제 캡처(✔)/보완 예정.
7. ❌ 📜 원문 윤문 / 📝 대본 타임라인 과도 수정·윤문 → ✅ 원문은 오탈자 보존, 대본 타임라인은 **내용 최대 유지·오타와 말이 안 맞는(비문) 부분만 최소 수정**.
8. ❌ import 일괄 생성기 → ✅ self-contained / 1편씩.
9. ❌ 자료 추가 후 대시보드 미갱신 / 잘못 선정본 하드삭제 / 중복 선정 → ✅ 재생성 / `_replaced_old` 이동 / 기존 사용 확인.
