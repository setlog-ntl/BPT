적용 순서 (제목 → 썸네일 → 도입부 → 원고)

  1. 8축(A) 1~2개 선택 → 채널 정체성 닻
  2. 결 호명(B) → "내 얘기" 인식 (0.5초)
  3. 페인(C) 또는 숫자(D) 결합 → 공감 / 시각적 텐션
  4. 강조·질문형(E) → 답을 숨겨 호기심(⑤)
  5. 시그니처(F) 1개 → 채널 톤 (한 썸네일에 1개만) — 여기까지 = 35자 메인 + 썸네일 헤드
  6. SEO(G)로 35자 이후~100자 검색 키워드 보강
  7. (키 영상만) 전환(H)으로 이북리더기·readtree 종착지 명시 — 풀링은 직접 노출 금지
  8. 금지 키워드로 거르고 → 30초 후크 룰(변화약속+결+8축) 통과 확인

색 = 카테고리

● A 8축 · F 시그니처 (정체성 닻)   ● B 결 3그룹 · H 전환(가치)   ● C 페인·공감

● D 숫자·대비   ● E 강조·질문형   ● G 검색·SEO
