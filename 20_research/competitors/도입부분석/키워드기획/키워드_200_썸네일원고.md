## 10. 적용 워크플로우 (제목→썸네일→도입부 순서)

> 근거: `대본기획_기준.md §8.5.1` 작업 순서 = **제목 → 썸네일 → 도입부 → 원고**.

```
1) 8축 1~2개 선택 (A)           → 채널 정체성 닻
2) 주력 결 호명어 선택 (B)       → "내 얘기" 인식
3) 페인(C) 또는 숫자(D) 결합     → 공감/텐션
4) 강조·질문형(E)로 호기심       → 답 숨기기(⑤)
5) 시그니처(F) 1개로 톤 박기     → 채널 자산
   └ 여기까지 = 35자 메인 제목 + 썸네일 헤드(7~10/12~16자)
6) G로 35자 이후~100자 검색 보강 → SEO
7) (키만) H로 종착지 명시        → 이북리더기/readtree
8) §9 금지 키워드로 거르기       → 톤 보호
9) 30초 후크 룰 통과 확인        → 변화약속+결+8축
```
