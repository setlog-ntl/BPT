# 문해력 - 뷰트랩 키워드 누적 데이터

이 폴더는 "문해력" 키워드에 대한 뷰트랩(Viewtrap) 검색 결과를 일자별로 누적 기록합니다.

## 폴더 구조

```
문해력/
├── README.md                      ← 본 문서 (누적 요약 인덱스)
├── 누적_데이터.csv                ← 일자별 핵심 지표 시계열 CSV
└── YYYY-MM-DD/                    ← 캡처 일자별 폴더
    ├── 필터통계.md                ← 필터 화면 전체 통계
    └── 상위영상목록.csv           ← 화면에 노출된 상위 영상 목록
```

## 캡처 이력

| 캡처일 | 총 영상 수 | 총 조회수 | 총 구독자 | 좋아요 합계 | 비고 |
|--------|-----------|-----------|-----------|-------------|------|
| 2026-05-16 | 319 | 4,796.6만 | 2.4억 | 74.2만 | 1차 캡처 (90개 추가) |

## 등급별 분포 추이

| 캡처일 | 기여도 G/G+ | 성과도 G/G+ |
|--------|-------------|-------------|
| 2026-05-16 | 42 / 0 (13.2%) | 30 / 1 (9.7%) |

> G/G+ = Good / Great 개수

## 핵심 인사이트 (최신 2026-05-16 기준)

- 누적 영상 319개 / 누적 조회수 4,796.6만
- 평균 조회수 15만, 중앙값 1.6만 → 일부 히트 콘텐츠가 평균을 끌어올림
- 평균 구독자 77.1만, 중앙값 3,038 → 채널 규모 극단적 양극화
- 기여도 Worst가 218개(68.3%)로 다수
- 성과도 Worst가 253개(79.3%)로 더욱 양극화
- 게시일 범위: 2021-03-17 ~ 2026-05-16 (약 5년)

## 데이터 활용 가이드

- **콘텐츠 기획**: 상위영상목록.csv에서 Good/Great 등급 영상의 패턴 분석
- **경쟁 분석**: 채널명 컬럼으로 강세 채널 추적 (EBSCulture, 문과언니, EBSi, 김주혜 국어 등)
- **시기 분석**: 누적_데이터.csv에서 시간에 따른 영상 수/조회수 변화 추적
- **타이틀 트렌드**: 상위 영상의 제목 패턴 분석으로 후크 도출
