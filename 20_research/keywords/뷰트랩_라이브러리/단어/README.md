# 뷰트랩 단어 조회수 누적 데이터

이 폴더는 [뷰트랩](https://app.viewtrap.com/video-search)에서 키워드별로 검색한 결과를 일자별로 누적 기록하는 자동화 데이터 저장소입니다.

## 🚀 빠른 시작

- **대시보드 보기**: `대시보드.html` 더블 클릭 (모든 키워드/캡처를 한눈에)
- **대시보드 갱신**: 새 데이터 추가 후 `python 대시보드_빌드.py` 실행
- **새 키워드 추가**: Claude/Cowork에게 "뷰트랩에서 ○○ 검색하고 대시보드 갱신해줘" 요청

## 폴더 구조

```
단어/
├── README.md                 ← 본 문서 (전체 키워드 인덱스)
├── 대시보드.html             ← 통합 대시보드 (자동 생성물)
├── 대시보드_템플릿.html      ← 대시보드 템플릿
├── 대시보드_빌드.py          ← 대시보드 빌드 스크립트
└── {카테고리}/{키워드}/      ← 카테고리별 키워드 폴더
    ├── README.md             ← 키워드 누적 요약
    ├── 누적_데이터.csv       ← 일자별 핵심 지표 시계열
    └── YYYY-MM-DD/           ← 캡처 일자별 폴더
        ├── 필터통계.md       ← 필터 화면 전체 통계
        └── 상위영상목록.csv  ← 화면에 노출된 상위 영상 목록
```

## 자동화 작업 흐름

1. Chrome 브라우저로 https://app.viewtrap.com/video-search 접속
2. 검색창에 대상 키워드 입력 → 검색 확인
3. 검색 완료까지 대기 (검색 진행률 표시 사라질 때까지)
4. 필터 버튼(슬라이더 아이콘) 클릭 → 필터 패널 오픈
5. 필터 패널 데이터 추출 (조회수/구독자/좋아요 통계, 게시일 범위, 기여도/성과도/노출확률 분포)
6. 비디오 리스트(화면에 보이는 상위 영상) 추출
7. 키워드 폴더 하위에 `YYYY-MM-DD/` 일자 폴더 생성
8. `필터통계.md`, `상위영상목록.csv` 저장
9. 키워드 폴더의 `누적_데이터.csv`에 한 줄 추가
10. 키워드 폴더의 `README.md` 캡처 이력 테이블 업데이트

## 주의사항

- 뷰트랩은 가상 스크롤 기반이라 한 번에 약 40개 영상만 DOM에 렌더링됩니다. 전체 영상 수는 필터 통계의 "총 영상 수"를 기준으로 봅니다.
- "검색 X회"는 같은 키워드에 대한 누적 검색 횟수입니다. 검색 시마다 새 영상이 추가될 수 있습니다.
- 캡처 일자는 한국 시간 기준으로 기록합니다.
