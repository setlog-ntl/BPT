# 뷰트랩 캡처 정밀 가이드 (단어_300 전용)

> 이 문서는 기존 `단어/` 폴더의 작업방식을 그대로 복제하여 단어_300 폴더에 적용하기 위한 캡처 작업 매뉴얼입니다.
> 대기 구간, 필터 조건, 노출확률 클릭 등 누락되기 쉬운 디테일을 모두 포함합니다.

## 0. 사전 확인

- **검색 URL**: https://app.viewtrap.com/video-search
- **로그인 상태**: 캡처 시작 전 로그인되어 있어야 합니다 (검색 기록 누적 영향)
- **검색 기록 영향**: 동일 키워드 재검색 시 누적 검색 횟수가 늘어나며 신규 영상이 추가될 수 있음
- **타임존**: 캡처 일자는 한국 시간(KST) 기준으로 기록

## 1. 키워드별 캡처 절차 (10단계)

### Step 1. 검색 실행

1. 검색창에 키워드 입력
2. **Enter 또는 검색 버튼 클릭**
3. URL이 `?q={키워드}` 형태로 변경되었는지 확인

### Step 2. 검색 완료 대기 ⏱️

- 화면 상단의 **검색 진행률 표시**(스피너 또는 진행 바)가 **완전히 사라질 때까지** 대기
- 최소 10초, 누적 검색이 많은 키워드는 30초 이상 걸릴 수 있음
- 영상 카운트(우상단 "총 X개")가 안정화되는 시점이 기준
- **주의**: 진행 중 다른 버튼을 누르면 통계 일부가 빈 값으로 캡처될 수 있음

### Step 3. 필터 패널 오픈

1. **필터 버튼(슬라이더 아이콘)** 클릭
2. 필터 패널이 슬라이드 인 되면 **1~2초 대기** (UI 안정화)

### Step 4. 노출확률 분석 클릭 🎯 (중요)

- 필터 패널 내 **노출확률** 섹션 또는 분석 트리거 버튼 클릭
- 영상별 노출확률 분석은 **자동 수행되지 않음** → 클릭으로 시작해야 결과가 채워짐
- 분석 결과 로딩 대기 (영상 수에 따라 5~20초)
- **노출확률 분석은 일부 영상에 대해서만 수행됨** → 합계가 모집단보다 작을 수 있음
- 완료 시점은 노출확률 등급별 카운트(Worst~Great)가 0이 아닌 값으로 표시되는 시점

### Step 5. 모집단 통계 수집 (필터 미적용 기준)

다음 항목을 **필터통계.md** 양식대로 기록:

#### 조회수 범위
- 합계 / 평균값 / 중앙값
- 필터 슬라이더 범위 (예: 0 ~ 1,000,000+)

#### 구독자 범위
- 합계 / 평균값 / 중앙값
- 필터 슬라이더 범위

#### 좋아요 범위
- 합계 / 평균값 / 중앙값
- 필터 슬라이더 범위

#### 영상 게시일 범위
- 최초 / 최근

#### 등급별 분포 (5단계: Worst / Bad / Normal / Good / Great)
- 기여도
- 성과도
- 노출 확률

### Step 6. 필터 적용

다음 4가지 조건을 **순서대로** 적용:

1. **조회수**: 50,000 이상 (필터 슬라이더 좌측 핸들 이동)
2. **기여도**: Good, Great 체크박스만 활성화
3. **성과도**: Good, Great 체크박스만 활성화
4. **Shorts**: 제거 옵션 활성화

각 필터 적용 후 결과 카운트가 갱신되기까지 **2~3초 대기**.

### Step 7. 필터 적용 후 통계 수집

- **최종 영상 수** (필터 통과 카운트)
- **필터 후 기여도/성과도/노출확률 분포** (모집단과 별도로 갱신됨)

### Step 8. 상위 영상 목록 캡처

화면에 노출된 상위 영상(약 40개, 가상 스크롤 한계)을 **필터적용_영상목록.csv**로 저장:

| 컬럼 | 설명 |
|------|------|
| 순번 | 1부터 시작 |
| 영상길이 | HH:MM:SS 또는 MM:SS |
| 제목 | 영상 제목 |
| 조회수 | 숫자 (쉼표 포함 가능) |
| 구독자 | 숫자 |
| 채널명 | 채널 이름 |
| 기여도 | Worst / Bad / Normal / Good / Great |
| 성과도 | 동일 |
| 노출확률 | Worst / Bad / Normal / Good / Great 또는 `-` (미분석) |
| 총영상수 | 채널 전체 영상 수 |
| 게시일 | YY.MM.DD 또는 YYYY-MM-DD |
| 썸네일URL | 가능하면 수집, 없으면 빈 값 |

### Step 9. 일자 폴더 생성 + 파일 저장

```
{키워드}/
└── YYYY-MM-DD/             ← 캡처 일자 (KST)
    ├── 필터통계.md         ← Step 5,7 통계
    └── 필터적용_영상목록.csv  ← Step 8 영상 목록
```

### Step 10. 누적 데이터 + README 갱신

#### `누적_데이터.csv`에 한 줄 추가 (30개 컬럼)

```csv
캡처일,총영상수,
조회수합계,조회수평균,조회수중앙값,
구독자합계,구독자평균,구독자중앙값,
좋아요합계,좋아요평균,좋아요중앙값,
기여도_Worst,기여도_Bad,기여도_Normal,기여도_Good,기여도_Great,
성과도_Worst,성과도_Bad,성과도_Normal,성과도_Good,성과도_Great,
노출확률_Worst,노출확률_Bad,노출확률_Normal,노출확률_Good,노출확률_Great,
필터통과수,게시일_최초,게시일_최근,비고
```

- 단위 변환: "4,796.6만" → `47966000`, "2.4억" → `240000000` (정수로 변환)
- 비고에는 차수와 특이사항 기록 (예: `1차_캡처_50K+_G/G+_NoShorts`)

#### 키워드 폴더 `README.md`의 캡처 이력 테이블에 한 줄 추가

| 캡처일 | 총 영상 수 | 총 조회수 | 총 구독자 | 좋아요 합계 | 필터 통과수 | 비고 |
|--------|-----------|-----------|-----------|-------------|-------------|------|
| YYYY-MM-DD | 숫자 | 한글요약(예: 2.7억) | 한글요약 | 한글요약 | 숫자 | 차수/특이사항 |

## 2. 가상 스크롤 한계

- 뷰트랩은 한 번에 약 **40개 영상**만 DOM에 렌더링됩니다
- 전체 영상 수는 항상 **필터 통계의 "총 영상 수"** 기준
- 필터 통과 영상이 40개를 넘으면 수집된 row 수 < 필터통과수 가 정상

## 3. 누적 검색 횟수 처리

- 동일 키워드를 여러 번 검색하면 "검색 X회"가 누적됨
- 누적 검색 시 신규 영상이 추가될 수 있음 → 캡처 시점의 총영상수가 이전보다 클 수 있음
- 비고에 차수와 누적 증가량 기록 (예: `2차_캡처_273개추가_누적527`)
