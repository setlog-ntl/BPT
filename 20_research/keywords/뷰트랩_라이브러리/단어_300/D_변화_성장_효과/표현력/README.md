# 표현력 - 뷰트랩 키워드 누적 데이터

- **카테고리**: D_변화_성장_효과
- **검색 URL**: https://app.viewtrap.com/video-search
- **검색어**: 표현력

> ⚠️ **중복 키워드**: 기존 `단어/B_인지_능력군/표현력/` 폴더에 동일 키워드 캡처 데이터가 존재합니다.
> 기존 데이터를 우선 참고하고, 본 폴더에는 추가 캡처가 필요할 때만 누적하세요.

## 캡처 이력

| 캡처일 | 총 영상 수 | 총 조회수 | 총 구독자 | 좋아요 합계 | 필터 통과수 | 비고 |
|--------|-----------|-----------|-----------|-------------|-------------|------|
| (캡처 전) | - | - | - | - | - | 캡처 대기 |

## 필터 조건 (기본값)

- **조회수**: 50,000 이상
- **기여도**: Good, Great만
- **성과도**: Good, Great만
- **Shorts**: 제거

## 캡처 절차 (요약)

1. 뷰트랩 video-search 페이지에서 `표현력` 검색
2. 검색 진행률(스피너) 사라질 때까지 대기 (보통 10~30초, 누적 검색시 더 길어질 수 있음)
3. 필터 패널(슬라이더 아이콘) 클릭 → 패널 오픈 후 1~2초 대기
4. **노출확률 분석 영역 클릭** → 분석 결과 로딩 대기 (영상 일부만 수행됨)
5. 모집단 통계(조회수/구독자/좋아요/게시일/기여도/성과도/노출확률) 수집
6. 필터 적용(조회수 50K+, 기여도 G/G, 성과도 G/G, Shorts 제거) → 결과 갱신 대기
7. 필터 적용 후 통계 + 상위 영상 목록 캡처
8. `YYYY-MM-DD/` 일자 폴더에 `필터통계.md`, `필터적용_영상목록.csv` 저장
9. `누적_데이터.csv`에 한 줄 추가, 본 README 캡처 이력 갱신

## 데이터 구조

```
표현력/
├── README.md             ← 본 문서
├── 누적_데이터.csv       ← 일자별 핵심 지표 시계열 (30개 컬럼)
└── YYYY-MM-DD/           ← 캡처 일자별 폴더
    ├── 필터통계.md       ← 모집단/필터 후 전체 통계
    └── 필터적용_영상목록.csv  ← 필터 통과 영상 목록 (12개 컬럼)
```
