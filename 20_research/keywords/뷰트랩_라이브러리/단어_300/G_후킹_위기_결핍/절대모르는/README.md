## 핵심 인사이트 (최신 2026-05-18 기준)

- 누적 영상 308개 / 누적 조회수 8,435.4만
- 평균 조회수 27.3만, 중앙값 4,160 → 후킹어 키워드 특유의 극단적 양극화 (Shorts 바이럴 영향)
- 평균 구독자 9.6만, 중앙값 1,448 → 채널 규모 양극화 심함
- 필터(조회수 50K+, Good/Great, No Shorts) 통과율 1.3% (4/308) → 문해력(2.2%)과 유사, 독서(16.1%)보다 훨씬 낮음
- 게시일 범위: 2021-11-12 ~ 2026-05-18 (약 4.5년)
- 상위 4개 중 2개가 동일 채널("1분만", 113만 구독)에 의존 → 채널 다양성 낮음
- 노출확률 분석은 자동 수행되지 않아 미분석 상태 (모든 영상 `-`)

## 필터 조건 (기본값)

- **조회수**: 50,000 이상
- **기여도**: Good, Great만
- **성과도**: Good, Great만
- **Shorts**: 제거

## 캡처 절차 (요약)

1. 뷰트랩 video-search 페이지에서 `절대모르는` 검색
2. 검색 진행률(스피너) 사라질 때까지 대기 (보통 10~30초, 누적 검색시 더 길어질 수 있음)
3. 필터 패널(슬라이더 아이콘) 클릭 → 패널 오픈 후 1~2초 대기
4. **노출확률 분석 영역 클릭** → 분석 결과 로딩 대기 (영상 일부만 수행됨)
5. 모집단 통계(조회수/구독자/좋아요/게시일/기여도/성과도/노출확률) 수집
6. 필터 적용(조회수 50K+, 기여도 G/G, 성과도 G/G, Shorts 제거) → 결과 갱신 대기
7. 필터 적용 후 통계 + 상위 영상 목록 캡처
8. `YYYY-MM-DD/` 일자 폴더에 `필터통계.md`, `필터적용_영상목록.csv` 저장
9. `누적_데이터.csv`에 한 줄 추가, 본 README 캡처 이력 갱신
