## 자동화 작업 흐름 (요약)

> 정밀 절차는 [`CAPTURE_GUIDE.md`](./CAPTURE_GUIDE.md) 참고. 핵심 디테일을 빠뜨리지 않도록 10단계 체크리스트로 정리됨.

1. Chrome으로 https://app.viewtrap.com/video-search 접속 (로그인 상태 확인)
2. 검색창에 키워드 입력 → 검색 실행
3. **검색 진행률(스피너) 완전 사라질 때까지 대기** (10~30초)
4. 필터 버튼(슬라이더 아이콘) 클릭 → 패널 오픈 후 1~2초 대기
5. **노출확률 분석 영역 클릭** → 분석 결과 로딩 대기 (영상 일부만 수행됨, 5~20초)
6. 모집단 통계 수집: 조회수/구독자/좋아요 합·평균·중앙값, 게시일 범위, 기여도·성과도·노출확률 분포
7. 필터 4가지 순차 적용: ① 조회수 50K+ ② 기여도 Good/Great ③ 성과도 Good/Great ④ Shorts 제거
8. 필터 적용 후 통계 + 상위 영상 목록(약 40개, 가상 스크롤 한계) 캡처
9. `{키워드}/YYYY-MM-DD/` 폴더 생성 후 `필터통계.md` + `필터적용_영상목록.csv` 저장
10. `누적_데이터.csv`에 30개 컬럼 row 추가 + 키워드 `README.md` 이력 갱신

### 핵심 주의사항

- **노출확률은 자동 분석되지 않음** → Step 5에서 반드시 클릭 트리거 필요
- **누적 검색 영향** → 같은 키워드 재검색시 총영상수가 늘어남 (비고에 차수/추가량 기록)
- **가상 스크롤** → 화면 상 약 40개만 DOM 렌더링, 전체 영상 수는 필터 통계 기준
- **단위 변환** → CSV 저장 시 "4,796.6만" → 47966000 같이 정수 변환
