## 🧩 핵심 개념

```
[수식어]  +  [핵심 명사]   →   후킹 제목
의외의   +  이유          →   망하는 "의외의" 이유
무섭게   +  오르는 종목    →   "무섭게" 오르는 종목의 공통점
```

- **수식어 = 앞에 붙이는 강조어** (이 폴더)
- **핵심 명사 = 이유·비밀·방법·충격…** (`단어_300/H_썸네일_강조어`)
- 둘을 조합해 제목·썸네일을 완성합니다.
