## 이게 뭔가요? (한 줄 정의)

`수식어`는 **명사(이유·비밀·방법…) 앞에 붙어 감정을 증폭시키는 말**입니다. 기존 `단어_300/H_썸네일_강조어`가 *명사(이유, 비밀, 충격…)* 풀이라면, 이 문서는 그 명사를 꾸미는 **앞단어 풀**입니다.

```
[수식어]  +  [핵심 명사]        →  완성된 후킹 제목
의외의    +  이유              →  부자가 망하는 "의외의" 이유
무섭게    +  오르는 (종목)      →  "무섭게" 오르는 종목들의 공통점
충격적인  +  근황              →  파산한 나라의 "충격적인" 근황   (실제 7위 영상)
```

## 제목 조합 공식

```
[지목/시점]  +  [정도/감정 수식어]  +  [핵심 명사]  +  [지목]

예) 요즘  +  무섭게 오르는  +  종목들의  +  공통점
예) 결국  +  충격적인  +  근황
예) 당신이  +  절대 하면 안 되는  +  습관  +  3가지
```

**실전 변환 템플릿 (Before → After)**

| Before (밋밋) | After (수식어 적용) |
|------|------|
| 부자가 망하는 이유 | 부자가 망하는 **의외의** 이유 / **충격적인** 이유 |
| 주가 오르는 종목의 공통점 | **무섭게** 오르는 종목들의 공통점 / **미친듯이** 오르는… |
| 보톡스 트렌드 | **완전히 달라진** 26년 보톡스 트렌드 |
| 다이소 꿀템 모음 | **역대급** 다이소 꿀템 38가지 / 보이면 **꼭** 사세요 |
| 잠자기 습관 | **절대** 하지 말아야 할 잠자기 습관 |
| 부업 하면 안되는 이유 | **요즘** 부업 하면 안되는 **진짜** 이유 |

## 사용 팁

1. **1제목 1~2개**만. 수식어를 3개 이상 떡칠하면 스팸처럼 보여 역효과.
2. **카테고리를 섞어라**: 시점(C) + 정도(D) + 명사 조합이 가장 자연스럽다. (예: *지금 당장 + 무조건 + 바꾸세요*)
3. **썸네일엔 짧은 것**(충격·반전·역대급·긴급), **제목엔 문장형**(절대 하지 말아야 할 / 모르면 큰일납니다).
4. `의외의`·`무섭게`처럼 빈도는 낮아도 신선한 수식어는 오히려 **차별화** 포인트가 된다.
