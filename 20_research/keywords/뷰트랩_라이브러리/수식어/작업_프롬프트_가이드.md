# 작업 프롬프트·절차 가이드 (수식어 수집)

> 사용자가 지시한 작업 내용을 다음에도 그대로 반복할 수 있도록 정리한 문서.
> 최초 작성: 2026-06-06 / 대상: 뷰트랩 핫 비디오 → 수식어 수집·정리

---

## 1. 작업 목적 (사용자 지시 원문 요약)

> "강조하는 수식어를 덧붙이기 위한 내용.
> (예: 부자가 망하는 이유 → 부자가 망하는 **의외의** 이유 / 주가 오르는 종목의 공통점 → **무섭게** 오르는 종목들의 공통점)
> 뷰트랩 **핫 비디오** 버튼을 클릭해 나오는 영상들(썸네일·제목)을 기준으로 **수식어 단어를 수집·정리**한다.
> 자료는 `C:\Dev\bizpt\뷰트랩 정리\수식어` 폴더에 정리하고, 이후 **썸네일과 제목 제작**에 활용한다.
> 수집된 단어는 **별도 문서화 + HTML 생성**하여 알맞게 구분해 정리한다."

**한 줄 요약**: 핫 비디오 인기 제목에서 "강조 수식어"를 뽑아 → 카테고리·빈도로 정리 → 문서(MD)+표(CSV)+HTML로 산출 → 썸네일/제목 제작에 재사용.

---

## 2. 수집 대상과 위치

- **사이트**: 뷰트랩 `https://app.viewtrap.com/video-search` (로그인 상태 필요)
- **진입**: 상단 빨간 **`🔥 핫 비디오`** 버튼 클릭 → 날짜 선택(예: 2026-06-05) → "핫 비디오 (NNN/800)" 목록 표시
- **수집 항목**: 제목(필수), 조회수, 채널, 기여도/성과도, 영상ID(=썸네일), 게시일
- **저장 위치**: `C:\Dev\bizpt\뷰트랩 정리\수식어\`

---

## 3. 표준 작업 절차 (10단계)

1. video-search 페이지 접속 → 로그인 확인
2. **핫 비디오** 버튼 클릭, 원하는 날짜로 설정
3. 목록 전체 로드 — 핫 비디오는 한 번에 ~40개씩 지연 로딩되므로 **끝까지 스크롤**해서 전량 로드
   - (기술 메모) 데이터는 페이지 JS의 `filteredVideoList` 배열에 전량 존재. 스크롤 대신 이 배열을 추출하면 한 번에 전 영상 확보 가능
4. 제목·메타데이터 전부 추출 → CSV로 저장 (`핫비디오_원본_영상목록_YYYY-MM-DD.csv`)
5. 제목에서 **강조 수식어** 후보 추출 (형용사/부사/수식구 — 명사 핵심어는 제외)
6. 수식어를 **8개 의미 카테고리**로 분류 + **빈도 집계** + 실제 예시 1~3개 첨부
7. `수식어_마스터.md` 작성/갱신
8. `수식어_대시보드.html` 생성/갱신 (카테고리·빈도 시각화)
9. `README.md` 요약 갱신
10. 검증: 수집 개수, 빈도 합계, 분류 오류 점검

---

## 4. 수식어 vs 핵심 명사 구분 기준 (중요)

| 구분 | 정의 | 예 | 저장 위치 |
|------|------|----|----------|
| **수식어 (이 폴더)** | 명사 앞에 붙어 감정·정도를 증폭하는 형용사·부사·수식구 | 의외의, 무섭게, 충격적, 절대, 미친듯이, 역대급, 꼭 | `수식어/` |
| **핵심 명사** | 제목의 뼈대가 되는 명사 | 이유, 비밀, 방법, 충격, 진실 | `단어_300/H_썸네일_강조어/` |

> 헷갈리면: **"___ 이유"의 빈칸에 들어가면 수식어**(의외의 이유, 충격적인 이유), **"이유" 자체는 핵심 명사.**

## 5. 8개 카테고리 정의 (분류 기준)

| 코드 | 카테고리 | 성격 | 대표어 |
|------|---------|------|--------|
| A | 충격·감정 폭발 | 감정 터뜨리기 | 충격, 소름, 난리, 경악 |
| B | 의외·반전 | 예상 뒤집기 | 의외의, 반전, 알고보니, 숨겨진 |
| C | 긴급·시점 | 긴박감 | 결국, 지금, 당장, 드디어, 속보 |
| D | 정도·강조 부사 | 강도 키우기 | 진짜, 절대, 무조건, 미친듯이, 무섭게 |
| E | 최상·극단 | 최고/극단 | 가장, 역대급, 최초, 끝판왕 |
| F | 경고·위기·부정 | 손실 회피 | 후회, 위기, 큰일, 망하는 |
| G | 호기심·지목 | 가리키기/호명 | 이것, 당신, 왜, 비법 |
| H | 명령·필수 시청 | 행동 지시 | 꼭, 필수, 반드시, 모르면 |

## 6. 다음에 쓸 재사용 프롬프트 (복사용)

```
뷰트랩 핫 비디오에서 수식어를 수집·정리해줘.
1. app.viewtrap.com/video-search 접속 → '핫 비디오' 버튼 클릭 → 날짜 [YYYY-MM-DD] 선택
2. 핫 비디오 목록(약 400+개) 제목을 전부 수집해서
   C:\Dev\bizpt\뷰트랩 정리\수식어\핫비디오_원본_영상목록_[YYYY-MM-DD].csv 로 저장
   (열: 순번,영상길이,제목,조회수,구독자,채널명,기여도,성과도,총영상수,게시일,영상ID,썸네일파일)
3. 제목에서 강조 수식어(형용사·부사·수식구)만 뽑아 8개 카테고리(A충격·B의외·C긴급·D정도·E최상·F경고·G호기심·H명령)로
   분류하고 빈도와 실제 예시를 붙여 수식어_마스터.md 에 정리(또는 누적)
4. 수식어_대시보드.html 갱신
규칙: 핵심 명사(이유·비밀·방법 등)는 제외, 앞에 붙이는 강조어만. 1제목당 예시 1~3개.
```
