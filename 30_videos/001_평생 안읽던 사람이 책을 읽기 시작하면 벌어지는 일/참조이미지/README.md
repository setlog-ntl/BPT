## 채널 시각 톤 (모든 프롬프트 공통 적용)

### 컬러 팔레트
- **딥블랙** `#0F1115` — 배경 기본, 어둠·내면·고요
- **골드** `#FFD166` — 강조·키워드 자막, 통찰의 빛
- **그린** `#06D6A0` — 성장·전환·CTA
- **레드** `#EF476F` — 경고·결정타·"그럼에도 불구하고" 시그니처

### 시각 원칙 (페이스리스 경향)
- 인물은 **얼굴 풀샷보단 손·뒷모습·실루엣·페이스리스 처리** 우선
- 인물 사례(페이커·코비·아놀드)는 **실명 검색용 자료 또는 상징적 컷**으로 처리(저작권 안전)
- **타이포 자막 카드 + B-roll 영상/이미지** 혼합 구조
- 사진을 쓸 땐 시네마틱·다큐멘터리 톤, 일러스트를 쓸 땐 미니멀·플랫
- 절대 클릭베이트·과장 시각 표현 금지 (채널 톤: 진정성)

### 권장 출력 사양
- 영상 본편: **16:9, 1920×1080** (4K 권장: 3840×2160)
- 자막 카드: **16:9, 1920×1080, 투명 PNG 또는 #0F1115 배경**
- 자막 폰트: Pretendard / Apple SD Gothic Neo / Noto Sans KR (Bold 800)

### 생성 도구 가정
프롬프트는 다음 AI 이미지 생성기에 모두 호환되도록 작성:
- Midjourney v6+ / Niji
- Stable Diffusion XL / Flux
- DALL·E 3
- Sora / Runway (영상 컷)
- Adobe Firefly

영상 컷은 정지 이미지 → AI 영상화(I2V) 또는 직접 T2V 모두 가능.

## 사용 워크플로우

1. 대본의 발화 구간을 보면서 해당 폴더의 `프롬프트.md` 열기
2. 컷 번호별 프롬프트 → 선호 AI 도구로 생성 (시드 고정 권장)
3. 결과 이미지를 같은 폴더에 `cut_XX_<설명>.png` 형식으로 저장
4. 자료가 부족하거나 AI 생성 부적합한 경우 → Pexels/Unsplash/Wikimedia Commons 직접 다운로드(저작권 확인)
5. 완성 후 자막 카드와 합쳐 영상 편집기에 임포트
