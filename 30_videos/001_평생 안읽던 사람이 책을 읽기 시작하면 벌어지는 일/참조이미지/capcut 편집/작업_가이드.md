## 2. CapCut에서 자막 수동 수정 절차

자동화 환경 제약(한글 IME 직접 입력 불가, 클립보드 권한 미승인)으로 인해 CapCut 자막은 사용자가 직접 수정하시는 것이 가장 빠릅니다.

### 권장 방법: 캡션 리스트 검색 활용
1. CapCut 우측 패널에서 **캡션** 탭 선택
2. 상단 **검색** 박스에 오타 문자열 입력 (예: `왜냐면`, `톡톡함`)
3. 검색된 캡션 항목을 **더블클릭** → 타임라인 자동 이동
4. **미리보기 화면의 자막을 더블클릭** 또는 우측 **텍스트** 탭에서 직접 수정

## 3. 이미지 편집 가이드

현재 환경에서 `참조이미지` 폴더의 이미지 파일에 직접 접근할 수 없어, 권장 편집 기준만 안내합니다.

### 영상 규격에 맞춘 이미지 편집 기준
- **해상도**: 1920×1080 (영상 비율 16:9 가정)
- **세이프존**: 상하좌우 5% 여백 확보, 자막 영역(하단 15%) 침범 금지
- **포맷**: PNG (투명도 필요시) 또는 JPG (배경 있을 때)
- **색감**: sRGB 색공간, 영상 전반 톤과 어울리는 채도/명도

### 폴더별 사용 시점 매핑 (대본 기준)
| 폴더 | 자막 줄 | 시점 |
|---|---|---|
| `00_후크_미리보기` | 1-9 | 인트로 |
| `01_출발점_현상` | 10-23 | 화자 소개 |
| `02_욕구점화_3축약속` | 24-36 | 핵심 메시지 |
| `03_시야_무지개와단어` | 37-55 | 뇌과학 설명 |
| `04_사고_프레임` | 56-77 | 두뇌 근육론 |
| `04사고_디테일_라인별` | 78-95 | 구체적 사례 |
| `05_성장_뇌근육_그럼에도` | 96-104 | 변화의 결과 |
| `06_결혼명` | 105-115 | 격려 |
| `07_CTA` | 116-124 | 구독 유도 |

### CapCut에 이미지 적용 방법
1. **미디어** 탭 → **가져오기** → 해당 챕터 폴더 선택
2. 자막 타이밍에 맞춰 이미지를 **상위 트랙**으로 드래그
3. **속성** 패널에서 크기/위치 조정 (Ctrl+드래그로 비율 유지)
4. **애니메이션** 탭에서 페이드인/아웃 0.3초 추천

## 4. 자동화 제약사항 요약

이번 세션에서 자동화로 처리 불가했던 항목과 사유:

| 작업 | 사유 | 해결 방법 |
|---|---|---|
| CapCut 한글 자막 직접 타이핑 | 한글 IME가 type 도구의 키 이벤트를 가로채지 못함 | 클립보드 권한 승인 또는 사용자 직접 입력 |
| 이미지 파일 일괄 편집 | 워크스페이스에 `참조이미지` 상위 폴더가 마운트되지 않음 | 상위 폴더를 작업 폴더로 재선택 |
| CapCut 자동화 다량 클릭 | 캡션 인라인 편집 모드 진입 동작 미확인 | UI 매크로 도구 또는 수동 작업 |

다음 세션에서 자동 편집을 원하시면:
1. 폴더 선택 시 `참조이미지` (상위 폴더)를 선택해 주세요
2. CapCut 실행 시 클립보드 권한 승인 다이얼로그를 미리 수락해 주세요
