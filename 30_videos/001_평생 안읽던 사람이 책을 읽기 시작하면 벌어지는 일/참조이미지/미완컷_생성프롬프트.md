1. **세션 첫 메시지**: 위 "공통 톤 가이드" 1회 입력
2. **Plus 업그레이드 후**: 우선순위 A → B → C → D 순서로 1컷씩 생성 요청
3. 각 컷 생성 시: "16:9, 1장만, 위 프롬프트 그대로" 명시
4. 생성된 이미지 우클릭 → 이미지 저장 → 위 "저장 위치" 폴더로 이동
5. 파일명 위 명시 그대로
