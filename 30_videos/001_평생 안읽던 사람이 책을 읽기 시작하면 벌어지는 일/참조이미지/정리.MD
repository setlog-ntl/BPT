## 4. 자동화 방식 (재사용 가능)

### 4.1 도구 스택
- **Playwright MCP** — 별도 브라우저 인스턴스에서 ChatGPT 자동 조작
- **JavaScript (browser_evaluate)** — DOM 쿼리, 이미지 fetch, base64 인코딩
- **Python (Bash)** — base64 디코딩 → PNG 파일 저장

### 4.2 1컷당 표준 사이클
```
1. (사전) 챕터 폴더의 프롬프트.md 읽어서 영문 프롬프트 추출
2. ChatGPT 입력창(div.ProseMirror)에 프롬프트 입력
   → "아래 영문 프롬프트로 이미지 1장 생성. 16:9. \n\n <영문 프롬프트>"
3. Enter 키 전송
4. 90~180초 대기 (생성 + "마지막 손질하는 중")
5. document.querySelectorAll('img') 으로 신규 이미지 ID 검출
   → naturalWidth > 800, alt 텍스트 변경 확인
6. 신규 이미지 URL을 fetch → ArrayBuffer → base64 → Playwright 결과 파일로 저장
7. Bash + Python으로 base64 디코딩 → 챕터 폴더에 PNG 저장
   → 파일명: cut_XX_YY_<영문설명>.png
8. 다음 컷으로
```

### 4.3 DOM 쿼리 패턴 (재사용 시 참고)
```javascript
// 신규 이미지 ID 검출
const seenIds = new Set([/* 이전 컷들의 file_id 목록 */]);
const newImages = [];
document.querySelectorAll('img').forEach(img => {
  if (img.naturalWidth > 800) {
    const id = img.src.split('id=')[1]?.split('&')[0];
    if (id && !seenIds.has(id)) {
      seenIds.add(id);
      newImages.push({ src: img.src, alt: img.alt });
    }
  }
});

// 생성 상태 확인
const generating = /(생성|손질|중)/.test(document.body.innerText.slice(-200));
```

### 4.4 자주 발생한 이슈와 대응
| 이슈 | 원인 | 대응 |
|---|---|---|
| `[data-message-author-role]` 쿼리로 assistant 메시지가 안 잡힘 | "메모리 가득 참" 팝업이 DOM을 가림 | 직접 `img` 태그 + `naturalWidth > 800` 으로 검출 |
| 1차 응답 대기 후 0개 이미지 | 생성에 평균 90~150초 소요 | 최초 120초 대기 → 30~60초 단위 폴링 |
| "마지막 손질하는 중" 단계에서 멈춤 | 정상 동작, 30~60초 추가 소요 | 추가 대기 후 재확인 |
| 다운로드 후 한글 파일명 깨짐 (콘솔 로그 상) | Bash + Windows 콘솔 인코딩 차이 | 실제 파일은 정상 저장됨 (utf-8) |
