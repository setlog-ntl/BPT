## 각 묶음 .md 파일 구조

모든 묶음 .md는 동일 양식을 따른다:

1. **헤더**: 캡션 라인 범위 / 타임코드 가이드 / 의미 단위 / 감정 코어
2. **사용 발화 (캡션 원문)**: `캡션기준 대본.md`에서 인용한 원문
3. **컷 컨셉**: 비주얼 메타포·카메라/구도·라이팅·자막 오버레이
4. **이미지 생성 프롬프트 (영문 메인)**: ChatGPT gpt-4o image gen용 — 컷별 2~4장
5. **한글 보조 설명**: 의도와 시각 패밀리 연결
6. **부정 프롬프트 / 주의사항**: 페이스리스·텍스트 노출 금지 등
7. **톤 필터 (채널 정체성)**: 색·해상도·렌즈·분위기
