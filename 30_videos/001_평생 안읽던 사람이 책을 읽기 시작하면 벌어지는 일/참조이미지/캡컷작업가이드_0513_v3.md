## 3. 캡컷 실제 작업 절차 (빠른 가이드)

### 사전 확인
- 캡컷 프로젝트 "0513 (1)" 열기
- V1: `0513_clean.mp4` (12:13)
- T 트랙: 자동 캡션 (459 블록)
- V2 트랙: `cut_00_01_hands_book_warm_light` 이미 0:00 위치

### 단계별 작업

1. **타임라인 확대**: 우측 하단 줌 슬라이더를 끝까지 오른쪽으로 → 1초 단위로 정밀 작업 가능

2. **각 이미지 배치 (위 표 순서대로)**:
   - 미디어 라이브러리에서 이미지를 V2 트랙으로 드래그
   - 또는 재생 헤드를 정확한 시간으로 이동 후 미디어에서 미리보기 viewer로 드래그하면 재생 헤드 위치에 자동 배치
   - 배치 후 클립의 우측 끝을 드래그하여 표의 "종료" 시간까지 길이 조정

3. **시간 정밀 입력 방법**:
   - 재생 헤드를 정확한 위치로 이동하려면: 키보드 ← → (1프레임), Shift+←→ (5프레임)
   - 또는 타임라인 룰러를 클릭한 후 캡컷 메뉴 → 편집 → "특정 시간으로 이동" (단축키 확인)
   - 시각적 정렬: 타임라인 룰러 눈금을 보면서 드래그

4. **자막 스타일 일괄 수정** (T 트랙):
   - 자막 트랙의 아무 클립이나 클릭 → 우측 패널 "기본" 탭
   - "모든 주요 캡션에 적용" 체크박스 활성화
   - 색상·글꼴·크기·정렬 변경 시 모든 자막에 일괄 적용
   - 또는 "편집효과" 탭에서 다양한 ART 프리셋 적용

5. **자막 배경 박스 추가**:
   - 자막 클립 선택 → 우측 패널 "말풍선" 탭
   - 원하는 박스/배경 스타일 선택

6. **각 이미지의 위치/크기 조정** (필요시):
   - 이미지 클립 선택 → 우측 패널 "기본" 탭에서 확대(100%)·위치 조정
   - 모든 이미지가 1920×1080이므로 기본 100%에서 화면을 꽉 채움
