## 핵심 규칙 (모든 프롬프트 공통)
- **문구 0**: 프롬프트 끝에 `no text, no letters, no words` 명시. 책 표지도 무지(blank cover).
- **페이스리스**: 손 · 뒷모습 · 실루엣 위주, 얼굴 노출 X.
- **책 제목 노출 X**: 명저(코스모스 등)는 '무지 벽돌책' 상징 + (편집 자막)으로 처리 — 저작권 안전.
- **수익화 직접 노출 0**: 이북리더기/readtree 직접 등장 X, 나무·가지·옆자리 메타포만(07-04).
- **출력**: 16:9, 4K 권장. 시네마틱·다큐 톤.

## 반복 모티프 (시리즈 통일감)
- **벽돌책**(두껍고 무거운 무지 하드커버) = 명저·실패. 00-09 / 01-01 / 03-01 / 06-06.
- **얇은 책**(가벼운 페이퍼백) = 해답·완독. 03-03 / 06-03 / 07-02.
- **수미상관**: 00-05(덮은책→절반) ↔ 06-06(같은 벽돌책 절반).
- **바벨/근육**: 02-04(바벨) ↔ 04-05(작은 손·큰 무게) ↔ 02-05·07-04(새싹·나무 성장).

## 워크플로우
1. 챕터 폴더의 `프롬프트.md` 영문 프롬프트를 `_자동화/ChatGPT_입력순서.md` 순서대로 ChatGPT(DALL·E)에 입력.
2. 생성 이미지를 다운로드.
3. `_자동화/_rename_move.ps1` 실행 → 다운로드 순서대로 각 챕터 폴더에 `cut_<챕터>-<컷>_<설명>.png`로 자동 정리.
4. 편집기에서 나레이션 타임코드에 맞춰 배치 + 자막은 별도 입力.
