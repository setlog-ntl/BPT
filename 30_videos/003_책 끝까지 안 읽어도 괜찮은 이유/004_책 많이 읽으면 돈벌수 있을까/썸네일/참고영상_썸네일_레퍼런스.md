### ★ 우리 004에 가장 가까운 3편

- **#2 「700권 읽고 마침내 깨달은 '진짜'」** = 우리 「**100권 읽어도 안 바뀐다**」 — 숫자 권위(많이 읽었다) + 본질(진짜) 패턴 직결. 단 우리는 "많이 읽는 게 정답"이 아님을 반론하는 **역방향** 활용.
- **#3 「한 번만 읽어도 다 기억」** = 우리 결 ③ "권수 말고 방식"의 반전 약속 구조. "적게 해도 결과"를 시각화하는 방법으로 학습.
- **#5 「일론 머스크도 배운」** = 거장 차용 패턴. 우리는 버핏·멍거·네이벌 — **실루엣·아이콘으로만**(사진 직접 사용 NG, 저작권 안전 오마주).

## 3. 문구 뱅크 — 004 적용 (위 패턴에서 도출)

> 6주차: 이미지 45 · **문구 45** · 디자인 10. 헤드 7~10자(한 줄)/12~16자(두 줄).
> 색: "100권·다독·권수"=`--pain #ef476f`, "3권·적용·복리"=`--growth #06d6a0`, 강조어=`--value #ffd166`, 배경=`bg-dark`.

| 유형 (참고 #) | 004 헤드 문구 후보 | 비고 |
|---|---|---|
| 숫자 반전 (#2) | **「100권 읽어도 안 바뀌는 이유」** | 숫자(100권) + 반전(안 바뀐다) ★1차 메인 |
| 반전 약속 (#3) | **「적게 읽고 더 버는 사람의 차이」** | 적게 해도 결과 — 권수 신화 역전 |
| 타깃 호명 (#7) | **「100권 읽어도 제자리인 분께」** | 결 ③ 정조준(허탈·조급 공감) |
| 부정 해소 (#4) | **「책 많이 읽어도 돈 못 버는 이유」** | A안 제목 직결(부정 프레임) |
| 본질·답숨김 (#6) | **「부자들의 독서와 당신 독서의 차이」** | 답 숨기고 궁금증 유발 |
| 거장 차용 (#5·#8) | **「버핏·네이벌이 권수를 안 세는 이유」** | 실루엣 오마주 + 반론 각도 |
| 대비 숫자 | **「100 vs 3」**(좌 빨강·우 초록) + 보조 "바뀐 건 오른쪽" | B안 시각 증거형 ★2차 |

**1차 채택**: 메인 「100권 읽어도 안 바뀌는 이유」(공감형) + 보조 「권수가 아니었어요」(A안 제목 정합). A/B로 「100 vs 3」 숫자 대비형(증거형).

## 4. 종합 학습 (구성 공통점)

- **이미지 소재**: 책 더미 클로즈업 + 텅 빈 메모 노트 / '100권 달성' 메모 클로즈업 / "100 vs 3" 숫자 대비(페이스리스·손·책 위주). 거장 등장 시 실루엣·아이콘만(정면 사진 NG).
- **문구**: 좌상단 큰 헤드(반전·타깃 호명·본질), 우하단 보조(숫자). 작은 화면 대비 크게. 헤드 9~12자.
- **공통 후킹**: 숫자 권위(#2 700권 → 우리 100권 역방향) / 반전 약속(#3) / 부정 해소(#4) / 거장 차용(#5·#8) / 본질·답숨김(#6) / 타깃 호명(#7) / 당위(#9).
- **색 배분**: 실패·권수어(`--pain` 빨강) ↔ 성장·적용어(`--growth` 초록) / 강조어 1단어(`--value` 노랑) / 배경 다크.
- **6단계 적용**: ①확대(책 더미+메모 클로즈업) ②증명(100 vs 3) ③궁금증(왜 100권도 안 바뀌나?) ④공감(좌상단 허탈 이미지) ⑤시청층(2030~40 자기개발·다독 경험층) ⑥뷰트랩(본 §1 성과도 Good 구성 학습).
