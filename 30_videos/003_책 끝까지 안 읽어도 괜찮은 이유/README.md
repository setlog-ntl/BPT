## 한 줄 정의

"책은 끝까지 읽어야 한다"는 믿음이 사람을 책에서 멀어지게 한다 — 완독 강박(매몰비용 오류)을 짚고, 거장들의 독서법으로 **"완독은 목표가 아니라 가끔의 결과"**임을 증명해 죄책감 없이 다시 책과 친해지게 하는 풀링 영상.

## 작업 순서 (7주차 §8.5.1)

1. **제목 → 썸네일 → 도입부**: `정리본/01_후크_미리보기.md` 확정(8단계·6단계·후크)
2. **본문**: `02 → 03 → 04 → 05` (매몰비용 → 유한성·거장 → 이동진·고백 → 해결·CTA)
3. **근거 보강**: `06`의 뷰트랩·레퍼런스로 차용·출처·보강 채우기
4. **통합 HTML**: `통합_끝까지_안읽어도.html` 브라우저 편집(자동 저장) → `.md` 내보내기
5. **검증**: `대본기획_기준.md §9-2` 마감 7체크리스트

> **HTML 허브 (8페이지, 상단 네비 동일)**: `통합_끝까지_안읽어도.html`(허브·기획·대본 편집) + 자료 7종 — 브리프 · ① 제목·썸네일·후크 · ② 매몰비용 · ③ 유한성·거장 · ④ 스토리 · ⑤ 해결·CTA · 뷰트랩·레퍼런스. 아무 페이지나 브라우저로 열면 상단 8버튼으로 서로 이동(자기 페이지 active, 챕터 페이지엔 prev/next도). `.md`(정리본)는 단일 진실 원천, HTML은 그 렌더·편집판. 룰북·진입점은 각 페이지 푸터.
