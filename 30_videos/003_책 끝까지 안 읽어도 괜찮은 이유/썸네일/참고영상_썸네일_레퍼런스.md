## 4. 종합 학습 (구성 공통점)

- **이미지 소재**: 인물 클로즈업(표정·손짓) 또는 책/메모 강조. 우리는 중간에 책갈피 꽂힌 채 덮인 책 / 안 읽은 책 더미(페이스리스).
- **문구**: 좌상단 큰 헤드(이득·반전·타깃 호명), 우하단 보조(숫자). 작은 화면 대비 크게.
- **공통 후킹**: 권위 스택(#2·#7) / 반전 약속(#3) / 부정 해소(#6) / 숫자(#4) / 유명인(#5) / 타깃 호명(#8) / 본질(#9).
- **색**: 부정·강박어 빨강, 안심·해결어 초록, 강조어 노랑, 배경 어둡게.
- **6단계 적용**: ①확대 ②증명(153/300) ③궁금증 ④공감(좌상단) ⑤시청층(2030~40 입문/실패층) ⑥뷰트랩(본 §1 성과도 Good 구성 학습).
