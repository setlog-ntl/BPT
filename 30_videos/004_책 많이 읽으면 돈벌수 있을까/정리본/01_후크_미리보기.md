## 1. 제목 디벨롭 (8단계)

> 기존(사용자 지정): **「책 많이 읽으면 돈 벌 수 있을까」** (18자). 글자수=공백 포함. ★=채택.

| 단계 | 제목 | 메모 |
|---|---|---|
| 기존 | 책 많이 읽으면 돈 벌 수 있을까 (18자) | 질문형·호기심 유발. "돈"이 강한 클릭 동기 |
| ② 쉬운 단어 | "다독" → "책 많이 읽기" / "수익" → "돈" 이미 일상어. "관계있다" → "상관있다" | 한자어 이미 최소. "돈" 유지 |
| ③-1 넓은 풀(뷰트랩 추정) | **독서**(1.7억) > **자기개발**(추정 5000만↑) > **책 읽기**(추정 3000만) > **다독**(추정 500만) | "독서"·"책 읽기"가 상위어 — 제목에 자연 노출 권장 |
| ③-2 반의어/부정 프레임 | **"책 많이 읽어도 돈 못 버는 이유"** / "책 읽으면 부자 된다는 거짓말" | 뷰트랩 실데이터: 부정어 풀이 더 클 가능성(살 찝니다 2.8억 사례). 부정 프레임 A/B 후보 |
| ④ 강조 수식어 | **"의외로 책 많이 읽는 사람이 돈 못 버는 이유"** / "실제로 부자들은 책을 이렇게 읽습니다" | 의외성·권위 조합 |
| ⑤ 답 숨겨 질문형 | **"책 읽는데 왜 내 삶은 안 바뀔까"** / "100권 읽고도 그대로인 사람의 공통점은?" | 혜택(왜 바뀌는가)를 숨기고 물음표 생성. 브리프 B5 캐치와 정합 |
| ⑥⑦ 트렌드·핫비디오 | (라이브 뷰트랩 — 자기개발·독서법 노출확률 normal↑ 확인 후) | 보류 |
| ⑧ 강력단어 | (보류 — 자기 채널 데이터 누적 후) | 철칙 |

### 채택안 (메인 ≤35자)

- ★ **A안(진정성·반론)**: 「책 많이 읽어도 돈 못 버는 이유」 (18자)
  - 안정형. 부정 프레임(③-2) + 원인 제공(⑤ 숨겨진 답). "왜 못 버는가" = 본편에서 전부 답함. 과장 없음.
- ★ **B안(질문·반전)**: 「1년에 100권 읽고도 그대로인 이유」 (20자)
  - CTR 실험. 숫자 카드(100권)로 구체성 확보 + "그대로인 이유"로 공감 극대화. 결 ③ 흡수력 최대.
- ★ **C안(통념 뒤집기)**: 「책 읽어서 돈 번다는 말의 함정」 (17자)
  - 통념 직접 타격. "함정"이라는 단어가 반론 앵글을 즉각 전달. 지적호기심 결 흡수 용이.

→ **1차 업로드 A안, 1주일 내 B/C로 A/B 교체**(6주차 3개 제작·교체 룰). A=안전(부정 반론), B=숫자 클릭실험(공감), C=통념 직접타격(지적호기심 결).

### SEO 보강 (35자 이후 ~ 100자)

`다독 독서법 자기개발 책추천 독서습관 부자독서 워런버핏독서법 책읽기효과 책읽으면좋은이유 독서효과 책읽는방법 성공한사람독서 독서량`

## 2. 썸네일 디벨롭 (6단계)

> 3요소 비중: 이미지 45 · 문구 45 · 디자인 10. 목표 = **클릭**, 핵심 = **공감**("100권 읽고도 제자리"인 허탈·조급).

| 단계 | 적용 | 구체 시안 |
|---|---|---|
| **① 확대** | 클릭 포인트만 남기고 확대 | **책 더미 위에 놓인 '2024 독서 100권 달성' 메모 클로즈업** — 권수 자랑이 실은 텅 빈 안도감임을 한 컷으로. 또는 책갈피 없이 완독된 책들이 쌓여 있는데 메모·형광펜 흔적 0인 컷 |
| **② 증명** | 후킹의 시각적 증거 | **'100권 vs 3권'** 숫자 대비 — 좌(빨강 `--pain`) "100권" + 우(초록 `--growth`) "3권" + 아래 보조 작게 "바뀐 건 오른쪽" 또는 "달라진 건 오른쪽". 권수가 아닌 적용이 결과를 만든다는 시각 증거 |
| **③ 궁금증** | 정답(권수가 아닌 이유) 숨김 | 해결책 대신 **"왜 100권 읽어도 그대로일까?"** 또는 **"이 차이는 어디서 올까?"** 만 노출 — 답은 영상 안에 |
| **④ 공감(좌상단)** | 예쁨 X, 겪는 상황 | 좌상단에 **쌓인 책 더미 + 허탈감 상징**(텅 빈 메모 노트·형광펜이 뚜껑 닫힌 채 옆에 방치) 이미지. 핵심 문구도 좌상단. 결 ③("권수 채웠는데 남은 게 없다") 정조준. 손·책·메모 위주(페이스리스 원칙) |
| **⑤ 시청층 선호** | 나이·성별 타겟 | 2030~40 자기계발 관심·독서 시작·다독 경험 층. 과한 연출 X — 현실적 책상·책 더미·손 클로즈업. 거장 실루엣(버핏·네이벌) 삽입 시 저작권 안전한 **실루엣·아이콘 오마주만**(사진 직접 사용 NG) |
| **⑥ 뷰트랩 학습** | 성과도 상위 구성 반영 | "다독·부자독서·자기개발" 맥락 핫 썸네일 구성 학습 → `../썸네일/참고영상_썸네일_레퍼런스.md`. 공통 패턴: 숫자 대비(100권 vs 3권) + 타깃 호명("100권 읽어도 제자리인 분") + 본질·답숨김("진짜 이유") |

**문구안(45%, 좌상단·큰 글씨)** — 제목과 정합:
- 메인 헤드(9~12자): **「100권 읽어도 안 바뀌는 이유」** / **「책 읽어도 돈 못 버는 이유」**
- 보조(작게): **「권수가 아니었어요」** (브리프 B5 캐치 직결)
- 색 토큰: "100권·다독·권수" = `--pain` `#ef476f`(빨강), "3권·적용·복리" = `--growth` `#06d6a0`(시안 초록), 강조어 1단어 = `--value` `#ffd166`(노랑). 배경 `bg-dark`.
- 진정성 라인: 검증 안 된 수익 숫자·낚시 과장("충격/경악") 금지. "100권"은 영상 내 근거·브리프 내 1인칭 고백과 연동. 거장 인물 = 실루엣·아이콘만(페이스리스 원칙).

**A/B 3개안**(1주일 내 교체):
1. **공감형(메인)**: 쌓인 책 더미 + 텅 빈 메모 노트 + 「100권 읽어도 안 바뀌는 이유」 — 결 ③ 정조준(허탈 공감)
2. **증거형(숫자 대비)**: 좌 `--pain` "100" ↔ 우 `--growth` "3" 숫자 클로즈업 + 보조 "바뀐 건 오른쪽" — "100 vs 3" 대비로 CTR 실험(브리프 B5 보조 캐치 시각화)
3. **반전형(통념 직격)**: 책 읽는 손 실루엣 + 거장 실루엣(버핏·네이벌 아이콘) + 「책 읽어서 돈 번다는 말의 함정」 — C안 제목과 정합, 결 ①(읽으려는 사람·효용 기대) 흡수

## 3. 30초 후크 — 도입부 N·S·C·A (0:00–0:30)

> 30초 내 필수: (a) 변화·결과 약속 (b) 결 호명 (c) 8축 키워드 1개 / 결론 먼저 / 후크-마무리 수미상관.
> 앵글 강제: 반론형(③-2 통념 뒤집기). 후크에 "자기개발" 8축 키워드 자연 노출. 수미상관 단서: "100권 읽고도 그대로인 나" → 마무리 "그 100권, 연결만 하면 자산" 회수.

| 코드 | 0:00–0:30 |
|---|---|
| **N 나레이션** | "1년에 100권 읽었어요. 근데 바뀐 게 없었어요. 책 읽으면 돈 번다길래 — 사실, 저 그 말 믿었거든요. 그런데 성공한 사람들 독서법을 들여다보니까, 돈과 연결되는 건 **권수가 아니었어요.** 오늘 이 영상 보시면, '얼마나 읽었나'보다 훨씬 중요한 한 가지가 보입니다. 책으로 **자기개발** 하고 싶은데 뭔가 계속 제자리인 것 같은 분이라면, 이게 답일 수 있어요." |
| **S 지문** | (책이 쌓인 책상 위에 '2024 독서 100권 달성' 메모가 붙어 있다 → 손으로 책 더미 위에 놓인 메모를 집어 들며 쓸쓸하게 내려다본다 → 카메라를 정면으로 바라보며 손 안의 메모를 내려놓는다) |
| **C 카메라** | [책 더미 + 메모 클로즈업 → 손이 메모 집는 미디엄 → 정면 미디엄으로 컷, 눈 맞춤 줌인] |
| **A 오디오** | (책 쌓이는 효과음 1회 → "근데 바뀐 게 없었어요" 직후 짧은 침묵 0.5초 → 잔잔한 BGM 페이드인 → "권수가 아니었어요" 강조에 한 톤 상승) |

> ✓ 변화 약속("'얼마나 읽었나'보다 중요한 한 가지가 보입니다") · ✓ 결 호명(③"제자리인 것 같은 분" + ①"책 읽으면 돈 번다길래") · ✓ 8축("자기개발" 직접 발화) · ✓ 결론 먼저("권수가 아니었어요" 15초 이내 제시) · ✓ 시각 텐션(책 더미+메모 B-roll) · ✓ 수미상관 단서("100권 읽었어요" = 마무리 "그 100권, 낭비 아님. 연결만 하면 자산"으로 회수).

### 미리보기 (0:20–0:30, 본편 3비트 떡밥)

"오늘 세 가지만 — ① 왜 책 많이 읽어도 삶이 안 바뀌는지(**다독 신화의 정체**), ② 버핏·네이벌 같은 사람들이 실제로 공유하는 독서의 패턴, ③ 그래서 **어떻게 읽어야** 권수 말고 진짜 복리가 쌓이는지."

### 좋은 후크 vs 안 좋은 후크 대조

| 항목 | 좋은 후크 (채택) | 안 좋은 후크 (금지) |
|---|---|---|
| 첫 문장 | "1년에 100권 읽었어요. 근데 바뀐 게 없었어요." — 1인칭 고백·결론 먼저 | "안녕하세요, 오늘은 독서와 돈의 관계에 대해 말씀드릴게요." — 자기소개 후 요약 |
| 결론 위치 | 15초 이내 "권수가 아니었어요" 명시 | 30초 다 쓰고 "그래서 오늘 알아볼게요" — 결론 없이 끌기 |
| 결 호명 | "자기개발 하고 싶은데 제자리인 것 같은 분" — 구체 상황 호명 | "독서에 관심 있으신 분들" — 막연한 범위 |
| 8축 키워드 | "자기개발" 직접 발화 (17초~) | 8축과 무관한 "유튜브 알고리즘상 오늘…" 등 |
| 약속 근거 | "성공한 사람들 독서법을 들여다보니" — 거장 근거 예고 | "책 읽으면 무조건 부자 됩니다" — 검증 안 된 과장 |
| 시각 텐션 | 책 더미 B-roll + '100권 달성' 메모 클로즈업 | 정적 talking-head만, 배경 벽 단색 |
| 진정성 가드 | "돈"은 후킹 입구, 본질은 사고력·복리로 착지 | "이 방법 쓰면 연봉 ○천 오릅니다" — 검증 안 된 수익 숫자 |
