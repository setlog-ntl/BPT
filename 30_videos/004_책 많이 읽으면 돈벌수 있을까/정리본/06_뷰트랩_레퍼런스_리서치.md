> 사용 형식(7주차 §8.5.3): **"[국가]의 [채널/매체]의 [인물]이 설명한 [내용]을…"** + "제가 해보니".

## §4. 본문 적용 요약 (차용 → 챕터 매핑)

```
후크(01)      1인칭 고백 "100권 읽고도 그대로" + "권수 아니었어요" 결론 먼저
본문①(02)     상관≠인과(통계 원칙) + 인풋 중독(생산적 지연) [Scribbr·Corr vs Caus]
본문②(03)     버핏(복리 방향) + 멍거(멘탈 모델 연결) + 네이벌(재독·사랑) + 콜리(88% 습관)
스토리(04)    내 1인칭 고백 — 권수에 취했다가 한 권 → 한 실행으로 전환
해결(05)      적용 독서①·재독 발췌②·연결 기록③ + 수미상관 "그 100권, 연결만 하면 자산"
```

> 발화엔 핵심 출처만(버핏·멍거·네이벌·콜리). 연도·URL·세부 인용은 **고정 댓글**(진정성 §6, 인지 비용↓).
