## 2. 신규 챕터 — ⑤ 행동버튼 (발화 확정안)

> 8-1강 §1.2.1: 행동버튼 = 정보를 행동으로 바꾸는 마지막 한 줄. **질문 환기 → 명령형 지시 → 도구·방법 제시**.
> 위치: ④ 결론 직후(6:30–7:10) → ⑥ 마무리 앞.

- **(질문 환기)** "자, 그럼 오늘부터 뭘 바꿔야 할까요?"
- **(명령형 지시)** "지금 당장, 다 못 읽고 쌓아둔 책 목록부터 닫으세요. 그리고 종이 한 장 꺼내서, '요즘 내 삶에서 진짜 풀고 싶은 문제' 딱 하나만 적어보세요. 일이든, 돈이든, 관계든."
- **(도구 제시)** "그 문제를 그대로 검색창에 넣어보세요 — **books.google.com**. 전 세계 책에서 그 문제를 다룬 부분을 바로 찾아줘요. 권수를 채우려고 읽지 말고, 그 한 문제의 답을 찾으려고 읽으세요."
- **(실행 마감)** "그렇게 찾은 책은, 손 닿는 곳에 두고 밑줄 긋고, 한 줄 메모하고, 이번 주에 딱 하나 실행까지. 그게 권수 100권을 이기는, 단 한 권의 독서예요."

### 진정성 가드 (불변)
- 이북리더기·readtree **직접 노출 0회**. "손 닿는 곳에 두고 바로 읽는 형태" = 다음 키 콘텐츠(발췌·메모 독서 도구)로 가는 **다리 메타포**만.
- `books.google.com`은 무료 도구 → 진정성 OK (8-1 §1.3 샘플 원고와 동일 논리). 콘텐츠=도구 추천 일관성.

## 3-B. 도입부 보완수정 (사용자 초안 반영, 2026-06-09)

> 기존 1인칭 고백형("1년에 100권 읽었어요")을 사용자 초안 기반 **서점·부자 통념형**으로 교체. 원본 초안은 `대본/도입부.md`에 보존.

- **흐름**: 부자책 통념 나열 → "저도 믿고 열심히 읽었다" → **"아직 부자 못 됐다"(솔직 선반박)** → "책이 쓸모없나? 아니다, 인생 최대 변화의 이유" → **"'어떻게 읽느냐'가 전부"** → **"대부분이 읽고 나서 가장 중요한 한 단계를 안 한다"** → 결 호명·8축 → 3비트 미리보기.
- **신규 떡밥 = 「그 한 단계」**: 도입부에서 심은 "빼먹는 한 단계"를 **⑤ 행동버튼**(읽은 걸 적용·books.google.com)에서 페이오프 → 도입부↔행동버튼 **2차 수미상관**.
- **⑥ 수미상관 호응**: "왜 누구는 수백 권 읽고도 그대로인지" 도입부 질문을 마무리에서 회수.
- **진정성**: "부자"는 후킹 입구일 뿐, "아직 부자 못 됐다"로 솔직 선반박 후 본질(어떻게 읽고 적용)로 착지. 검증 안 된 수익 숫자 금지.
- **타임코드**: ⓪ 0:00–0:40로 확장(통념 나열+선반박 분량).

## 3-C. 통합 HTML 「대본 전체 뷰」 탭 신설

- 통합 HTML 상단에 **인페이지 토글 탭** 추가: `📦 기획 뷰`(브리프·메시지팩·대본 편집·검증) ↔ `📜 대본 전체 뷰`(녹음용 풀스크립트, 읽기 전용).
- 대본 전체 뷰 = **기획 뷰의 대본을 실시간 렌더**(단일 진실 원천 1개 유지 — 중복 편집 없음). 챕터별로 `기획 의도 🎯 · info-tags · 🎙 나레이션(강조 연출 하이라이트) · 지문/카메라/오디오 · 연출·근거 메모`를 정리. 총 발화 자수·예상 시간 표시.
- 수정은 기획 뷰에서만 → 대본 전체 뷰는 자동 동기화. 인쇄/PDF 시 탭 UI 숨김.
