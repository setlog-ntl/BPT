# 01 · 후크 · 제목 8단계 · 썸네일 6단계 — AI 시대 살아남는 세 종류의 인간

> 작업 순서(7주차 §8.5.1): **제목 → 썸네일 → 도입부 → 본문**. 이 파일이 앞 단계(제목·썸네일)를 확정한다.
> 룰북: `대본기획_기준.md §8.6`(제목)·`§8.7`(썸네일) / 헤드 매핑 `../썸네일지침/03_훅_문구뱅크.md` / 금지문구 §5
> 성격: **풀링** (생존 불안 → 사고력·질문력 → 문해력·독서 → 독서 환경 = 키콘텐츠 진입)
> 6축: **AI**(입구) + **사고력** + **문해력/독서**(토대) + **성장** / 결: ②AI 쓰고 있는 사람(메인) + ①안·못 쓰는(불안 흡수) + ③더 잘 쓰려는

## 0. ⚠️ 진정성 가드 (이 주제의 최대 리스크 — 먼저 읽기)

이 주제는 **"생존 불안"을 입구로 쓰지만**, 채널 룰(§5.2 / CLAUDE.md §4.4)은 **"AI 적대·도태 공포" 프레임을 금지**한다.

| 금지 (도태 공포) | 채택 (긍정 선택) |
|---|---|
| "AI 시대 도태되는 사람" / "AI 모르면 망한다" | "AI 시대에 **더 비싸지는** 사람" / "AI가 **절대 못 대체하는** 사람" |
| 위협으로 클릭 → 본 적대 | 호기심·자기분류로 클릭 → "나는 어느 쪽?" |

**핵심 전환**: "살아남는다"를 *공포(밀려난다)*가 아니라 *분류·욕망(어느 쪽이 되고 싶나)*으로 쓴다. 시청자가 던지는 질문은 "나 망하나?"가 아니라 **"나는 살아남는 쪽일까? 어떻게 하면 그쪽이 되지?"**. 본편 착지도 "AI가 무섭다"가 아니라 **"읽는 사람이 AI를 더 잘 쓴다"**(채널 시그니처 "AI는 답을, 읽는 사람은 질문을").

## 1. 제목 디벨롭 (8단계)

> 기존(주제): **「AI 시대에 살아남을 세 가지 종류의 인간」** (19자). 글자수=공백 포함. ★=채택. ⑥⑦⑧은 라이브 뷰트랩·자기 채널 데이터 누적 후 적용(보류).

| 단계 | 제목 | 메모 |
|---|---|---|
| 기존 | AI 시대에 살아남을 세 가지 종류의 인간 (19자) | 분류 호기심("나는 어느 쪽?") + 생존 텐션. 강함 |
| ② 쉬운 단어 | "인간"→"사람", "세 가지 종류"→"세 종류" 압축 → **AI 시대에 살아남는 세 종류의 사람** (16자) | 중학생 일상어. "사람"이 "인간"보다 부드럽고 자기투영 쉬움 |
| ③-1 넓은 용어(뷰트랩 추정) | **AI**(거대) > 챗GPT(큼) > 인공지능. "살아남는"의 상위 욕망어 = **앞서가는·비싸지는·대체 안 되는** | ※ 라이브 뷰트랩 조회수 비교 필요. "AI"는 그대로 유지(최상위어) |
| ③-2 반의어/부정 프레임 | "AI가 절대 못 이기는 사람 / **밀려나는** 사람" — 부정어가 조회수 클 수 있음(살 찝니다 2.8억 사례). **단, §0 가드로 부정형은 보조 A/B만** | 부정 프레임은 톤 리스크 → 채택 시 "밀려나는"보다 "대체되는"이 중립적 |
| ④ 강조 수식어 | "결국", "끝까지", "딱" 부착 → **결국 살아남는 / 끝까지 살아남는 / 딱 세 종류** | "결국"·"끝까지"가 본질·필연 톤. 과장 아님(검증 가능) |
| ⑤ 답 숨겨 질문형 | 세 종류의 정체(=답)를 숨기고 물음표 → **"AI 시대, 끝까지 살아남는 사람은 누구일까"** / **"같은 챗GPT 쓰는데 왜 결과가 갈릴까"** | ⑤가 핵심. "세 종류가 뭔지" 안 알려주고 "나는 어느 쪽?"만 남김. 브리지(왜 결과 차이)와 직결 |
| ⑥⑦ 트렌드·핫비디오 | (라이브 뷰트랩 — "AI·생존·살아남는·챗GPT" 노출확률 normal↑ 확인 후 교체) | 보류 |
| ⑧ 강력 단어 | (보류 — 자기 채널 데이터 누적 후 사후만) | 철칙 |

### 채택안 (메인 ≤35자)

- ★ **A안 (분류·자기투영 — 메인 안전)**: 「AI 시대, 살아남는 사람은 딱 세 종류입니다」 (21자)
  - 기존 주제의 직계. "딱 세 종류"가 분류 호기심("나는?")을 즉발. 도태 공포 없이 텐션 확보. **1차 업로드 추천.**
- ★ **B안 (질문·브리지 직결 — CTR 실험)**: 「같은 챗GPT 쓰는데, 왜 누구만 살아남을까」 (21자)
  - 원고 브리지("같은 챗GPT를 써도 왜 결과 차이?")를 제목으로 끌어올림. 결 ②(쓰고 있는데 차이 못 느끼는 사람) 정조준. 가장 강한 공감 후보.
- ★ **C안 (긍정 욕망 — 채널 정체성)**: 「AI가 절대 못 대체하는 사람의 3가지 조건」 (22자)
  - §0 가드 완전 충족(공포 0, 욕망 100). "대체 못 한다"=긍정 선택. 채널 시그니처와 가장 정합. 진정성 점수 최상.

→ **1차 업로드 A안, 1주일 내 B/C로 A/B 교체**(6주차 3개 제작·교체 룰). A=분류 호기심(안전), B=숫자 없는 질문 공감(브리지), C=긍정 욕망(정체성).

- ★ **D안 (면죄부·질문형 — 참조 패턴 ⭐ 신규)**: 「아직도 챗GPT한테 "그냥 해줘"라고만 하세요?」 (24자)
  - 참조 카드 「아직도 AI한테 OO해줘라고 질문하고 계신가요?」(#aiguide, 댓글 65)의 **면죄부+질문형 패턴** 차용. "아직도 ~하세요?"가 시청자 자기점검("어, 나도 그런데")을 즉발. 살아남는 세 종류의 **첫 갈림 = 질문하는 사람**과 직결, 브리지("같은 챗GPT 왜 차이")로 가장 자연스럽게 연결. **결 ①②(쓰는데 평범한 답) 흡수력 최강.**

> **참조 카드 분석** — 「아직도 AI한테 OO해줘라고 질문하고 계신가요? \| AI가이드」(2026.05.28, 댓글 65, #aiguide #ai가이드).
> · 패턴: **"아직도 [대상]한테 [흔한 나쁜 습관]하고 계신가요?"** = 면죄부+질문형 뷰트랩. 흔한 습관을 전제로 깔아 자기투영 유도.
> · 썸네일 구성: `[카테고리 태그]` 좌상단 + 큰 문구(핵심어 "OO해줘"만 색강조) + 인물 + 시간 배지.
> · SEO 태그: 같은 키워드 3변형(#aiguide #ai가이드 #에이아이가이드)으로 검색 커버리지 확대 → 우리도 적용.
>
> 참조 스타일 메모 — 예시 「AI 꼭 여기서 공부하세요 / ○○진짜 폭발합니다」는 *명령형 + 강조 반전* 뷰트랩 펀치. 그대로 쓰면 클릭베이트(§5.1 "폭발/충격")로 톤이 깎임. **구조만 차용·단어는 채널화**: 「AI 시대, 이 세 사람만 살아남습니다」 / 「AI 잘 쓰는 사람, 사실 여기서 갈립니다」(보조 후보).

## 2. 썸네일 디벨롭 (6단계)

> 3요소 비중: 이미지 45 · 문구 45 · 디자인 10. 목표 = **클릭**, 핵심 = **공감**("나는 살아남는 쪽일까?"라는 자기분류 욕망). 헤드 7~10자(한 줄)/12~16자(두 줄) — 제목의 축약.

| 단계 | 적용 | 구체 시안 |
|---|---|---|
| **① 확대** | 클릭 포인트만 남기고 확대 | **갈림길에 선 사람 실루엣 한 컷** — 한쪽은 밝게(살아남는 쪽), 한쪽은 흐리게. 또는 같은 모니터(챗GPT 화면) 앞 **두 손**: 하나는 평범한 답, 하나는 날카로운 질문. "차이"를 한 컷으로 |
| **② 증명** | 후킹의 시각적 증거 | **"3"** 큰 숫자 카드(세 종류) + 화면 속 챗GPT 답변 두 개가 명백히 다른 품질. "분류"와 "결과 차이"를 동시 증명 |
| **③ 궁금증** | 정답(세 종류가 누구인지) 숨김 | 세 종류의 정체는 가리고 **"당신은 어느 쪽?"** / **"나는 살아남는 쪽일까?"** 만 노출 — 답은 영상 안에 |
| **④ 공감(좌상단)** | 예쁨 X, 겪는 상황 | 좌상단에 **챗GPT 앞에서 막막한 뒷모습/손**(결 ① 불안) + 핵심 문구. 페이스리스 원칙(정면 표정 인물 지양, 손·뒷모습·실루엣 위주). 결 ②("매일 쓰는데 평범한 답") 정조준 |
| **⑤ 시청층 선호** | 나이·성별 타겟 | 2030~40 직장인·AI 입문~활용층. 과한 SF 연출 X — 현실적 노트북·챗GPT 화면·손 클로즈업. AI 위협 이미지(로봇·해골 등) **금지**(§0 가드) |
| **⑥ 뷰트랩 학습** | 성과도 상위 구성 반영 | "AI·챗GPT·생존·미래직업" 맥락 핫 썸네일 구성 학습 후 반영(라이브). 공통 패턴 추정: 분류 숫자("3") + 자기투영 질문("당신은?") + 답 숨김 |

**문구안 (45%, 좌상단·큰 글씨) — 제목과 정합:**

- 메인 헤드(두 줄형 12~16자): **「살아남는 사람은 / 딱 세 종류」** / **「당신은 / 살아남는 쪽일까?」**
- 한 줄형(7~10자): **「당신은 어느 쪽?」** / **「AI가 못 이기는 사람」**
- 보조(작게): **「같은 챗GPT, 다른 결과」** (브리지 직결 / §03 문구뱅크 1-3 검증형)
- 색 토큰: "밀려나는·평범한 답" = `--pain` `#ef476f` / "살아남는·날카로운 질문" = `--growth` `#06d6a0` / 강조 1단어("3"·"질문") = `--value` `#ffd166` / AI 강조 보조 = 블루 `#6ea8fe`. 배경 `bg-dark`.
- 진정성 가드: "충격/폭발/도태/망한다" 금지(§5.1). 로봇·위협 이미지 금지. "3종류"는 본편에서 실제로 셋 다 설명(낚시 아님).

**A/B 3개안 (1주일 내 교체):**

1. **분류형(메인)**: "3" 큰 숫자 카드 + 「살아남는 사람은 딱 세 종류」 + 갈림길 실루엣 — A안 제목 정합, 자기분류 욕망(안전)
2. **대비형(브리지)**: 같은 챗GPT 화면 앞 두 손(평범한 답 `--pain` ↔ 날카로운 질문 `--growth`) + 「같은 챗GPT, 다른 결과」 — B안 제목 정합, 결 ② 정조준
3. **욕망형(정체성)**: 막막한 손 클로즈업 + 「AI가 못 이기는 사람」 + 보조 "당신은?" — C안 제목 정합, §0 가드 완전 충족(공포 0)

## 3. 키콘텐츠 문제인식 연결 (원고 드리블 체크)

> 이 풀링이 키콘텐츠로 흘러가는 다리. 제목·썸네일이 이 흐름의 입구인지 검증.

```
[썸네일·제목] 생존 불안 자극 → "나는 살아남는 쪽일까?"
   ↓ (전환) 살아남는 사람 = AI 사용법 많이 아는 사람 ❌ / 생각·질문·연결하는 사람 ⭕
   ↓ (문제인식 이동) "같은 챗GPT 써도 왜 결과 차이?"  ← B안 제목이 이 지점을 선점
   ↓ (브리지) 질문 수준 ← 사고력 ← 문해력 ← 독서
   ↓ 많은 사람이 독서 중요성 알면서도 실패 → 문제는 중요성이 아니라 "독서가 지속되는 환경"
   ↓
[키콘텐츠 진입] AI 시대 경쟁력을 만드는 독서 습관·환경 → 이북리더기
```

- ✅ 제목 B안이 브리지("같은 챗GPT 왜 차이")를 선점 → 본편 전환이 매끄럽다.
- ✅ 키콘텐츠 문제인식("AI 시대 살아남아야 한다는 불안")을 썸네일이 그대로 호명.
- ⚠️ 본편 마무리에서 **결 3그룹 모두 호명 + "그분들 옆자리"** + 시그니처 "AI는 답을, 읽는 사람은 질문을"로 착지(공포 아닌 긍정).
