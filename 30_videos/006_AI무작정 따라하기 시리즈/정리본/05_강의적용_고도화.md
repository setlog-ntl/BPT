## 1. 사용자 제공 원고 → 채널 정체성 고도화 (핵심 차이)

| 영역 | 사용자 원고(나레이션 초안) | 고도화본(이 폴더) |
|---|---|---|
| **구조** | 줄글 나레이션(섹션 구분 없음) | 8챕터 비트(HOOK·BODY×5·STORY·CTA) + N·S·C·A 지문 |
| **후크** | "요즘 AI 때문에 불안" 도입 | 콜드오픈 결과(반전) 선공개 — "수십 개 봤는데 만든 건 0?"(7주차) |
| **채널 연결** | 경험·실행 강조에서 멈춤 | **S6 문해력 브릿지** — 경험→자기 인식(읽기)→설명력=문해력 |
| **결 호명** | 없음 | 마무리에 **결 3그룹 + "옆자리"** |
| **수미상관** | 없음 | "순서가 거꾸로" → "경험이 먼저" 회수 |
| **사인오프** | 평이한 마무리 | + **"AI는 답을, 읽는 사람은 질문을"** |
| **떡밥** | "어떻게 만들고·배포·운영?" (원고 엔딩) | 그대로 회수 → **EP.02 진입 떡밥**으로 격상 |
| **진정성 가드** | 암묵적 | "공부 적대 금지(순서가 문제)"·과장 금지·수익 숫자 금지 명문화 |

> 한 줄: **"실행 우선 메시지를, 'AI보다 읽는 사람' 채널의 매니페스토 입구 영상으로 재정의했다."**

## 2. 강의 적용 체크

| 강의 | 적용 |
|---|---|
| 30초 후크 룰 | 콜드오픈 결과(반전) 선공개 + 결① 죄책감 해소 + 수미상관 (`01` §3) |
| 5주차 제목 8단계 | 제목 A/B/C, 35자+검색어, ⑧강력단어 보류, 답 숨김("진짜 이유") (`01` §1) |
| 6주차 썸네일 6단계 | EP.01 신규 시안 가이드(강의더미 vs 빈 폴더 대비)·궁금증·공감·도입부>썸네일 (`01` §2) |
| 7주차 도입부 | N·S·C·A 4종, 결과 선공개 패턴, 차용·출처·보강 3요소 (`01`·`02`) |
| 7주차 본문 신뢰도 | 베이스 라인 ①원리(순서 도식)+②경험("저도 그랬다")+⑤반론(순서가 진짜 원인) (`02` 하단) |
| 8주차 편집 요소 | 도입부 강도 최상위, "센 것을 앞에"(센 통찰=순서 전복을 ③에 조기 배치) |
| 9주차 편집 | 재미 내림차순 배열은 `편집/` 별도 관리(대본과 분리) |
