## 4단 구조 (대본 ② 흐름 그대로 시간 매핑)

### 1단. Problem — 0:00~1:30 (약 90초)

**핵심 메시지**: "성공자들의 공통점 = 독서. 그런데 우리는? 의지의 문제가 아니라 환경의 문제."

**구성**:
- 0:00~0:25 **후킹 (성공자 인용)**: 빌게이츠 50권 / 워런버핏 80% / 일론머스크 — 공통점 = 독서
- 0:25~0:50 **대비 충격**: "그런데 우리는?" 한국 성인 평균 3.9권 (12.8배 차이)
- 0:50~1:30 **문제 재정의**: "올해는 책 좀…" 다짐만 → 12월 한 권도 못 끝냄 → **의지 X 환경 O**
  - 종이책 = 무거움 / 스마트폰 = 알림 / 태블릿 = 결국 유튜브

**자료 인용**: 인용.md #1·#2·#3 / 통계.md A·B / 출처.md B1·B5·K1

### 2단. Promise — 1:30~3:00 (약 90초)

**핵심 메시지**: "진짜 독서 습관 = '독서만을 위한 도구' = 이북리더기 = 라이프스타일 전환점"

**구성**:
- 1:30~1:50 **약속 진술**: "독서만을 위한 도구가 필요하다 — 그게 이북리더기"
- 1:50~2:30 **자투리 시간 활용**: 출근 10분 + 점심 15분 + 자기 전 20분 = 한 달 2~3권
- 2:30~3:00 **카테고리 정의 전환**: "이북리더기 = 단순 전자기기 X = 라이프스타일 전환점"

**자료 인용**: 인용.md #4·#5·#7 / 통계.md C·D / 출처.md C1·D1

### 3단. Proof — 3:00~6:30 (약 210초 — 베네핏 5종)

**핵심 메시지**: "5가지 베네핏으로 약속을 입증."

**5개 베네핏 구간** (각 약 40~45초):

| # | 베네핏 | 핵심 자료 |
|---|---|---|
| B1 (3:00~3:45) | **미니멀리즘** — 책장 사라짐, 거실 깔끔, 이사·먼지 자유 | 본문 위주 (감정 호소) |
| B2 (3:45~4:30) | **세련된 라이프스타일 상징** — 카페에서 멋있어 보임 = 시간 사용의 상징 | 인용.md #8 (텍스트힙 / GQ Korea) |
| B3 (4:30~5:15) | **경제적 가치** — 종이책 대비 20~40% 저렴, 신간 즉시, 형광펜·메모 | 통계.md E |
| B4 (5:15~6:00) | **e-ink + 가벼움 + 배터리** — 200g, 한 달 배터리, 종이 질감 | 통계.md D |
| B5 (6:00~6:30) | **알림 차단** — 카톡·SNS·유튜브 X = 집중력의 피난처 | 본문 위주 |

**구성 원칙**: 각 베네핏 = "사실 + 사용자 일상 시나리오 + 한 줄 결론" 패턴 반복.

### 4단. CTA — 6:30~8:00 (약 90초)

**핵심 메시지**: "1년 뒤 자기 자신은 오늘 결정. 입문자 추천 모델로 지금 시작."

**구성**:
- 6:30~7:00 **결단 촉구**: "1년 뒤 어떤 사람이 되고 싶나요? 지금과 같은 사람? 아니면 책 30권을 읽은 자기 자신?"
- 7:00~7:30 **행동 지시**: "아래 링크에서 입문자에게 가장 추천하는 이북리더기 모델 확인"
- 7:30~7:50 **시간 압박 (부드럽게)**: "오늘 주문하시면 내일부터 자투리 시간이 성장의 시간으로"
- 7:50~8:00 **마무리 자막**: "**미래의 나에게 가장 확실한 선물, 지금 결정하세요.**"
