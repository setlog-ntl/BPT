# 이미지 — 사용 가이드

> 라이선스 불명확한 이미지는 다운로드 X — `../출처.md` 에 URL만 기록.

## 컬렉션 참조

본 프로젝트에서 쓸 책 관련 무료 이미지는 자산 라이브러리 컬렉션에서 매칭:

- [`../../../../40_assets/자산_라이브러리/썸네일프레임/책_무료이미지_컬렉션.md`](../../../../40_assets/자산_라이브러리/썸네일프레임/책_무료이미지_컬렉션.md)

권장 카테고리:
- **Problem 구간 배경**: B. 책장·도서관 (시네마틱·차분) — 책장이 가득한 도서관 와이드샷
- **Promise 구간 배경**: A. 책 일반 — 깔끔한 책 정물
- **Proof 구간**: 통계 자막 배경으로 미니멀한 책 클로즈업
- **CTA 구간**: C. 미적·감성 책 — 따뜻한 분위기 (행동 유도 친근감)

## 파일명 규칙

다운로드 시 다음 형식으로 저장:

```
P<구간>_<번호>_<짧은설명>.<확장자>

예시:
P1_01_도서관와이드.jpg
P2_02_책정물미니멀.jpg
P3_01_책페이지통계배경.jpg
P4_01_따뜻한책.jpg
```

P1=Problem, P2=Promise, P3=Proof, P4=CTA
