# 영상소스 — 사용자가 직접 채우는 폴더

> 본 영상은 비롤·이미지를 외부 무료 라이선스 사이트에서 가져오므로,
> **이 폴더에는 "본인 촬영 클립"과 "이북리더기 실물 촬영"만** 둡니다.

## 권장 본인 촬영 컷 (선택)

본인 출연·실물 촬영을 추가하면 신뢰감과 진정성이 크게 올라갑니다. 권장:

```
영상소스/
├── 001_본인_인사_2초.mp4              # 0:00 또는 6:30 CTA 도입
├── 002_이북리더기_실물_손에든_5초.mp4   # 1:30 또는 7:00 모델 등장
├── 003_본인_출근_지하철_이북_5초.mp4    # 1:50~2:08 자투리 시간 (옵션)
├── 004_본인_카페_이북리더기_5초.mp4     # 2:08~2:25 (옵션)
└── 005_본인_CTA_마무리_3초.mp4         # 7:50~8:00 마무리 (옵션)
```

## 파일명 규칙

- `001_<짧은_설명>.<확장자>` — 3자리 번호로 정렬 보장
- 한국어 가능, 단 띄어쓰기 X (언더스코어 사용)
- 포맷: mp4 (H.264) 권장
- 해상도: 1920x1080 이상

## 캡컷 import 시

1. 새 프로젝트 생성 (1920x1080, 30fps)
2. 본 폴더 전체 import → 미디어 빈 정렬
3. 외부 비롤·이미지는 자산 라이브러리 컬렉션 참조하여 다운로드 후 별도 import
4. 편집_가이드.md 따라 시간 순서대로 배치
