# 발행 체크리스트 — 1년 뒤 책 30권 (이북리더기)

> 캡컷 출력 직전·업로드 직전 점검. 기준: [`../../../10_system/checklists/발행전_최종점검.md`](../../../10_system/checklists/발행전_최종점검.md) + 본 영상 특화 항목.

---

## A. 영상 본체

- [ ] 시작·끝 마감 깨끗 (덜컥 시작/끝 X)
- [ ] 자막 오타 0건 (특히 인용·통계)
- [ ] 자막 표시 시간 1.5~4초
- [ ] 영상 트랙·자막·BGM·효과음 모두 의도대로
- [ ] 영상 길이 7~9분 ±10% (베네핏 4·5 결정에 따라 6:30~8:00)
- [ ] 화자 음성 레벨 / BGM 볼륨 충돌 없음 (BGM -18~-20dB, 음성 -6dB)
- [ ] 출력 해상도 1920x1080 / 30fps

## B. 메타데이터

- [ ] 제목 — [`제목_후보.md`](제목_후보.md) #1 사용 (또는 사용자 결정안)
- [ ] 설명란 첫 3줄에 핵심 + CTA 링크
- [ ] 챕터 타임스탬프 — 베네핏 4·5 포함 여부 반영
- [ ] 태그 15개 — [`태그.md`](태그.md) 그대로
- [ ] 썸네일 1280x720 — [`../04_썸네일/썸네일_v1.png`](../04_썸네일/) 1안 사용
- [ ] 종료 카드 / 카드 — 다음 영상 또는 채널 페이지 연결

## C. CTA 검증 (랜딩 영상 특화)

- [ ] 영상 설명란 첫 줄 CTA 링크 — 클릭 시 정상 동작
- [ ] 링크 → 입문자 추천 모델 페이지 (사용자가 의도한 곳)
- [ ] 광고/협찬 표시 — 제휴면 표기 의무 준수
- [ ] 가격·기능 — 영상 내용과 랜딩 페이지 일치 확인 (오버 프로미스 방지)

## D. 인용·통계 출처 확인

- [ ] 빌게이츠 50권 출처 — Penguin/CNBC/Blinkist 중 1개 (영상 + 설명란)
- [ ] 워런버핏 80% 출처 — fs.blog (영상 + 설명란)
- [ ] 한국 평균 3.9권 — 문화체육관광부 2023 (영상 + 설명란)
- [ ] 이북리더기 가격 비교 — 영상 내 "20~40%" 표기 vs 실제 차이 일치
- [ ] 빌게이츠/버핏 사진 사용 시 라이선스/초상권 검토

## E. 진정성 점검

- [ ] 후킹·썸네일과 본문 내용 일치 (클릭베이트 X)
- [ ] 책에 대한 진정성 살아있음
- [ ] 베네핏 5종 모두 근거 있음 (인용 또는 사실)
- [ ] 본인 사용 경험과 어긋남 없음 (사용자 검토)
