# 기획서 — 200g짜리 하나로 끝나는 3가지 문제

## 메타
- 유형: **키 (전환) — 9:16 쇼츠**
- 길이 목표: **60초 (00:00–01:00)**
- 종횡비: **1080×1920 (9:16)**
- 적용 템플릿: `풀링_쇼츠` 골격 + 키 컨버전 톤 (현재 stub — 본 영상으로 v1 검증)
- 비주얼 톤: **미니멀 텍스트 중심 (책 느낌)** — 종이 질감 / 차분한 베이지·먹·금 팔레트 / 큰 자막
- 입력 텍스트: 사용자 작성 60초 쇼츠 대본 (3-Block 구조)
- 본 프로젝트 연결: **본 영상의 종착지 = `2026-05-03_랜딩_책30권_확실한방법` 7~9분 랜딩 영상**

## 한 줄 요지

> **"종이책 무게 + 스마트폰 산만함 + 미루기 — 3가지가 한 손의 200g으로 끝난다."**

## 3-Asset 모델상 위치

| 단계 | 콘텐츠 | 본 영상 역할 |
|---|---|---|
| 풀링 (유입) | (예: 데미안 3분 요약 등 책 풀링 쇼츠) | 본 영상으로 트래픽 유입 |
| **키 (전환) ★** | **본 영상 (60초 쇼츠)** | **관심 시청자에게 "왜 이북리더기인가" 1분 압축 답** |
| 랜딩 (매출) | 1년 30권 7~9분 랜딩 영상 + 설명란 제휴 링크 | 본 영상에서 → 랜딩으로 클릭 유도 |

## 타깃
- 페르소나: **"책 좀 읽어야지" 다짐만 반복하는 20~40대.** 종이책은 무겁고, 스마트폰 잡으면 SNS·유튜브로 빠지는 자기 인식 있음.
- 시청 맥락:
  - 책·독서·자기계발 풀링 쇼츠 시청 직후
  - 알고리즘 추천으로 무관심 시청자에게 노출 — **0~1초 내 "내 얘기" 인지가 1순위 KPI**
- 시청 후 행동: 설명란 첫 줄 링크 클릭 → 랜딩 본 영상 또는 제휴 페이지

## 후킹 (Hook)

> **"종이책은 무겁고, 스마트폰은 산만하다면 — 정답은 200g짜리 하나입니다."**

- 통증 → 답 압축 1줄. 0~3초 안에 화면 위에 큰 자막으로 한 번에 노출.
- "당신의 통증을 알고 있습니다" 신호. 동시에 답을 짧게 던져 끝까지 남게 만듦.

## CTA

> **"지금 아래 링크에서 베스트 모델과 오늘만 적용되는 할인 코드 확인하세요. 망설이는 1분에도 독서 시간은 사라지고 있습니다."**

- 링크 위치: 영상 설명란 첫 줄 (Pinned 댓글 동시 게시 권장)
- "오늘만 적용되는 할인 코드"는 **실제 할인 코드가 있는 시점에만 사용**. 없을 시 "추천 모델 안내"로 교체.

## 3-Block 구조 (시간 매핑)

### Block 1. Hook — 0:00–0:10 (10초)
- 핵심 메시지: **"이게 내 얘기네"** 1초 만에 멈추게 함.
- 영상: 책상 위 무거운 종이책 → 스마트폰 알림 폭주 → 손바닥 위 200g 이북리더기 (3컷)
- 자막 #1~#4: 통증 2개 + 답 1개 (대본 기준)

### Block 2. Body — 0:10–0:50 (40초)
- 핵심 메시지: **"3가지 문제 → 3가지 해결"** 압축 입증.
- 베네핏 3종 (각 약 10~13초):
  - **B1. 한 달 가는 배터리** (충전 부담 ZERO)
  - **B2. 눈 시리지 않은 e-ink 화면** (LED 피로 ZERO)
  - **B3. 알림 없는 집중 환경** (산만함 ZERO)
- 종합 문장: **"수천 권을 손바닥 위에 들고 다니는 셈"** + **"매번 미루던 분이라면 이거 하나로 끝납니다"**

### Block 3. CTA — 0:50–1:00 (10초)
- 핵심 메시지: **지금 행동 + 시간 압박 (부드럽게)**.
- 화면: 화면 하단에 화살표·링크 아이콘 등장 → "DESCRIPTION" 강조.
- 마지막 자막: **"망설이는 1분에도 독서 시간은 사라지고 있어요"**

## 진정성 체크 (CLAUDE.md §4.4)

- 책과의 연결: **★★★** — 영상 본질이 "독서를 가로막는 환경" 진단.
- 클릭베이트 점검:
  - "3가지 문제" → 본문에서 정확히 3개 (무게·산만·미루기) 모두 답변 ✓
  - "끝나는" → 과장 표현 경계. 이북리더기가 만능은 아니므로, 자막에서는 "**훨씬 가벼워집니다**" / "**거의 끝납니다**" 톤도 백업으로 준비 (편집자 결정).
  - "오늘만 적용되는 할인 코드" → **실 코드 존재 시에만** 사용. 없으면 "오늘 추천 모델"로 교체. ✓
  - **오버 프로미스 없음** ✓
- 광고/협찬 표기: 제휴 링크 사용 시 영상 시작 1초 우측 상단 작은 자막 + 설명란 첫 줄 명시.
