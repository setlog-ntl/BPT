# 배경음악 지정 — 200g짜리 하나로 끝나는 3가지 문제

## 메인 트랙 (전체 60초)

| 항목 | 값 |
|---|---|
| 자산 ID | `차분_사색_라이트` |
| 분위기 | 미니멀, 종이/책 톤, 차분한 어쿠스틱 (피아노 + 가벼운 패드) |
| BPM | 80–95 권장 |
| 길이 | 60초 매칭 (또는 60초 컷팅) |

## 볼륨 / 페이드 타이밍

| 시간 | 액션 | 볼륨 |
|---|---|---|
| 0:00.0 | 페이드 인 0.5s | -∞ → -22dB |
| 0:00.5 ~ 0:42.9 | 유지 | **-22dB** |
| 0:43.0 | 강조 페이드 0.5s | -22dB → **-19dB** |
| 0:43.5 ~ 0:59.4 | 유지 | -19dB |
| 0:59.5 | 페이드 아웃 0.5s | -19dB → -∞ |

## 내레이션과의 믹스

- 내레이션 트랙: **-3dB ~ -1dB** (피크) 기준, BGM은 항상 **-19~-22dB**로 깔림.
- BGM 자체에 보컬·드럼 강한 비트가 들어간 곡은 사용 금지 (집중 방해).

## 효과음 우선순위 (BGM과 겹칠 때)

- `스윕_인`, `타이핑_탁`, `차임_경쾌`, `팝` 모두 BGM보다 **+3~+5dB** 위로 노출.
- 단, `차임_경쾌`(0:08, 0:14, 0:19)는 BGM에 살짝 묻혀도 OK — 베네핏 전환 표시용.

## 라이선스

- 본 영상은 **유튜브 쇼츠**로 발행. 사용 BGM은 **YouTube Audio Library** 또는 **CC0 / 라이선스 구매분**만 사용.
- 출처·라이선스 증빙은 [`../02_자료수집/출처.md`](../02_자료수집/출처.md)에 기록.

## 마감 시 사용자 결정

1. 트랙 후보 3개 가량 미리 들어보고 진정성·차분 톤이 가장 강한 것 선택.
2. 0:43 강조 페이드는 **본인 음성 톤이 약하면 -16dB까지** 더 끌어올려도 무방.
3. 마지막 0:59.5 페이드 아웃 대신 **하드 컷**으로 침묵 0.5s 두는 것도 가능 (시간 압박 강화 효과).
