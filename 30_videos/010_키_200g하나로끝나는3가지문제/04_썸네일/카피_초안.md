# 썸네일 카피 초안 (3안)

> 미니멀 텍스트 중심 (책 느낌). 베이지 배경 + 검정 텍스트 + 골드 포인트.

## 안 1 — 숫자 강조형
```
   200g
하나로 끝
3가지 문제
```
- 시각: 손바닥 위 이북리더기 정물 (왼쪽 1/3) + 텍스트 (오른쪽 2/3)
- 강조: `200g` 골드 #C9A961, 나머지 검정
- 톤: 차분, 호기심 자극 ("3가지가 뭐야?")

## 안 2 — 통증 직격형
```
종이책은 무거워
스마트폰은 산만해
이거면 끝.
```
- 시각: 책+스마트폰+이북리더기 3컷 비교 (위 1/3 작게) + 큰 텍스트
- 강조: "이거면 끝" 골드 + 굵게
- 톤: 직접 진단형

## 안 3 — 결단 유도형
```
1년 미루던 독서,
한 손으로 끝
```
- 시각: 새 책 비닐 그대로 vs 이북리더기 들고 있는 손
- 강조: "한 손으로 끝" 골드 + 굵게
- 톤: 자기 인식 + 결단

## 진정성 점검

- ✅ 클릭베이트 X — 모두 본문에서 입증되는 약속.
- ✅ 책 톤 — 종이·정물·자연광 베이지 일관.
- ⚠️ 안 3 "1년 미루던" → 본인 경험과 일치할 때만 사용. 거짓 진술이면 폐기.
