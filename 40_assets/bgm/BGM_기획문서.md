## 1. 왜 채널 전용 BGM이 필요한가 (결론 먼저)

- **소리도 채널 자산이다.** 채널 정체성 문서 §08-03이 이미 "3초 오디오 인트로(사운드 로고)"를 미확정 과제로 지정해 놨다. BGM은 그 사운드 로고를 영상 전체로 확장하는 작업이다.
- **"AI는 답을, 읽는 사람은 질문을"은 청각으로도 전달돼야 한다.** 빠른(AI) 시대의 **느린 자리(읽는 사람)** — 이 톤은 비주얼만으로 안 만들어진다. 음악이 0초부터 "여긴 호흡이 긴 채널"이라고 말해야 한다.
- **풀링·키·쇼츠는 목적이 다르다.** 신뢰 축적(풀링)·전환(키)·유입(쇼츠)이라는 서로 다른 기능을 한 곡으로 못 덮는다. 그래서 **3컨셉**으로 나눈다.

## 2. 사운드 정체성 — 모든 곡이 지켜야 할 공통 골격

| 축 | 기준 | 음악적 번역 |
|---|---|---|
| **북극성** | 정답이 흔해진 시대에 질문을 만드는 사람 | 답을 빨리 주는 소리(X) → 여백·여운을 남기는 소리(O) |
| **핵심 무드** | 빠른 시대의 느린 자리 | 80~95 BPM 기본, 과한 드롭·EDM 빌드업 금지 |
| **질감 모티브** | 책·종이·아날로그 | 종이 넘기는 폴리 사운드, 펠트 피아노, 따뜻한 어쿠스틱 |
| **진정성(3기둥 ②)** | 과장·클릭베이트 배제 | 자극적 신스 리드·트랩 하이햇 금지. 사람 손맛 있는 연주 |
| **AI ↔ 책 대비** | "AI는 답, 책은 질문" | 차가운 디지털 텍스처(절제)와 따뜻한 어쿠스틱의 공존·대화 |

### 색 토큰 ↔ 사운드 매핑 (시각 일관성을 청각으로)

| 색 토큰 | 의미 | 사운드 대응 |
|---|---|---|
| 딥블랙 `#0F1115` | 배경 | 저음역 패드·룸톤 — 곡의 바닥 |
| 골드 `#FFD166` | 강조("그럼에도") | 멜로디 훅·시그니처 모티브 (모든 곡에 공통으로 한 번 등장) |
| 그린 `#06D6A0` | 책/긍정 | 따뜻한 어쿠스틱(피아노·기타·핸드퍼커션) |
| 레드 `#EF476F` | AI/흐름 | 절제된 디지털 텍스처·아르페지오 (흐름 인정 구간) |

> **시그니처 모티브(골드):** 3~4음으로 된 짧은 상행 후 멈춤(질문하듯 끝나는 프레이즈). 세 컨셉 모두 이 모티브를 변주해서 넣으면 곡이 달라도 "같은 채널"로 들린다. Suno에는 가사·스타일로 직접 강제할 수 없으므로, 마음에 드는 1곡의 멜로디를 기준 삼아 나머지를 Cover/Remix로 파생하는 방식 권장(§6).

## 3. BGM 3컨셉 — 용도·무드·구조

### 컨셉 A — "느린 자리" (메인/풀링 테마) 🟢

| 항목 | 내용 |
|---|---|
| **용도** | 풀링 영상 배경 전체, 표준 인트로(0:00–0:30), 채널 기본 BGM |
| **무드** | 차분·따뜻·사색적. 옆자리에 앉은 듯한 친밀감 |
| **장르** | Lo-fi acoustic / warm ambient / felt piano |
| **BPM** | 80~88 |
| **악기** | 펠트 피아노, 어쿠스틱 기타, 따뜻한 패드, 종이 넘기는 폴리, 룸톤 |
| **구조** | 잔잔한 인트로 → 메인 루프(가사/멜로디 절제) → 끝까지 평탄 (말소리를 덮지 않음) |
| **퍼널 기능** | 신뢰·체류시간. 절대 튀지 않는다 (보이스오버 우선) |

### 컨셉 B — "그럼에도 불구하고" (키/감성·전환 테마) 🟡

| 항목 | 내용 |
|---|---|
| **용도** | 키 영상 후반(결론·추천), 랜딩 영상, 감정 고조 구간, 시즌 회고 |
| **무드** | 진정성 있게 차오르는 감동. 역접 후 다짐 — "그럼에도" 모먼트의 음악판 |
| **장르** | Cinematic acoustic / emotional post-rock(절제형) / indie folk |
| **BPM** | 88~95 |
| **악기** | 피아노 + 현악(첼로·바이올린) + 어쿠스틱 기타 + 부드러운 킥/스트링 스웰 |
| **구조** | 조용한 시작(흐름 인정) → 멈춤·여백(그럼에도) → 따뜻하게 차오르는 후반(우리의 선택) |
| **퍼널 기능** | 전환 직전 감정 정당화. CTA·랜딩 링크 구간에 깔림 |

### 컨셉 C — "질문이 시작되는 순간" (쇼츠/유입 테마) 🔴

| 항목 | 내용 |
|---|---|
| **용도** | 쇼츠 전체, 풀링 클립, 커뮤니티 영상, 빠른 인트로 훅 |
| **무드** | 가볍고 경쾌하되 채널 톤 유지. 호기심을 당기는 리듬 |
| **장르** | Upbeat lo-fi / chillhop / acoustic groove |
| **BPM** | 95~110 |
| **악기** | 통통 튀는 키보드/마림바, 가벼운 핑거스냅·핸드클랩, 부드러운 베이스, 종이 폴리 |
| **구조** | 즉시 시작되는 훅(0~2초) → 루프 → 깔끔한 종결 (45~60초에 맞춰 loop-friendly) |
| **퍼널 기능** | 3초 내 시선 고정. 알고리즘 유입. 단, 트랩·과자극 금지 |

> **각 컨셉을 가사 없는(instrumental) 버전과 가사 있는(vocal) 버전 두 가지로 제작** → 총 6트랙.
> instrumental = 보이스오버 영상 배경용(말소리 안 덮음) / vocal = 인트로·아웃트로·쇼츠 단독·시즌 회고처럼 말소리가 빠지는 구간용.

## 4. 가사 방향 (vocal 버전)

- **언어:** 한국어 중심. 후렴 핵심 구절만 짧게 — 자막 없이도 들리게.
- **금지(채널 안티 컨셉 그대로):** "책은 무조건 좋다"식 당위, "인생 바뀐다"식 과장, AI 적대 프레임.
- **반드시 담을 씨앗 문구(채널 자산과 일치):**
  - "AI는 답을, 읽는 사람은 질문을" — 모든 vocal 곡 후렴에 1회 이상 (채널 사인오프)
  - "AI는 답을 만든다, 읽는 사람은 질문을 만든다" 계열
  - 시그니처 "오늘도, AI보다 한 줄 더. 읽으세요" (B/C 곡에 변주)
- **톤:** 선언보다 독백·옆자리 말투. "~하자"보다 "~할게요/~있어요".

## 6. 제작 워크플로우 (무료 도구 기준 · 권장 순서)

> **도구:** 무료 본제작은 **Sonauto**(무제한·무료·한국어·instrumental/vocal). 도구 비교·선정 근거는 [`무료_음악생성_도구_비교.md`](무료_음악생성_도구_비교.md). 입력 방법은 [`Suno_프롬프트.md`](Suno_프롬프트.md) 상단 표.

1. **컨셉 A instrumental 먼저 제작**(Sonauto) → 채널의 "기준 사운드" 확정. 마음에 드는 1곡을 골든 마스터로 지정.
2. **vocal 버전:** 동일 STYLE 프롬프트 + 한국어 LYRICS로 재생성. Sonauto는 멜로디 컨디셔닝/Extend도 지원하므로 A 멜로디를 이어 만들면 통일성 ↑.
3. **B·C는 A와의 멜로디 통일성**을 위해 → style 프롬프트에 "variation of warm felt-piano motif" 류 표현 + 여러 번 생성 후 선택(완전 보장 안 됨).
4. 각 곡 **2~4회 생성 → 가장 채널 톤에 맞는 것 채택.** 후보는 곡명에 `_v1 _v2` 표기.
5. **사운드 로고(3초):** 컨셉 A 인트로 0~3초를 트리밍하거나, 별도 짧은 프롬프트([`Suno_프롬프트.md`](Suno_프롬프트.md) BONUS)로 생성.
6. Sonauto의 **무료 stem 분리**로 보컬/반주 분리 export → 영상에서 말소리 구간엔 반주만 깔기 가능.
7. 채택본은 `BGM/audio/<컨셉>_<버전>.mp3`로 저장(폴더는 다운로드 후 생성). **사용 도구·곡 ID·생성일·프롬프트 버전·라이선스 근거**를 §8 로그에 기록.

### 프롬프트 구조 메모 (도구 공통)
- **Style 프롬프트는 영어가 효과적** (장르·BPM·악기·무드·"no clickbait drop" 류 제외 표현 포함).
- **Lyrics는 한국어 가능.** `[Intro] [Verse] [Chorus] [Outro]` 구조 태그는 Sonauto/Suno에서 잘 먹힘(도구에 따라 무시 가능).
- instrumental: Sonauto는 **"No Lyrics" 버튼**, Suno는 Instrumental 토글.
- BPM·길이는 프롬프트에 적어도 정확히 안 맞을 수 있음 → 생성 후 선택으로 보정.

## 7. 라이선스·사용 주의 (발행 전 필수 확인) ⚠️

> 상세 비교·확인 절차는 [`무료_음악생성_도구_비교.md`](무료_음악생성_도구_비교.md) §1·§4.

- **무료 = 비상업인 도구 주의:** Suno 무료·Udio 무료·Stable Audio 무료는 **상업/유튜브 수익화 불가**. 톤 실험·연습까지만.
- **Sonauto 상업 약관 불명확:** 수익화 영상에 쓰기 전 **지원팀에 서면 확인 1회 필수**(질문·답변 캡처 보관 → §8).
- **MiniMax 2.6:** 상업 사용 명확 허용이나 **무료는 14일 베타 한정**(이후 유료). 라이선스가 깨끗해야 하는 발행 곡을 베타 기간에 몰아 제작 가능.
- 유튜브 **Content ID 충돌** 점검 — 동일 곡이 타인에게도 생성될 수 있으므로 핵심 곡은 stem/Extend로 변주해 고유성 확보.
- 곡 메타데이터(도구·생성일·프롬프트·라이선스 근거)를 §8에 남겨 추후 분쟁·재현에 대비.
