## 0. 결론 (먼저)

> **무료로 만들고 유튜브 채널에 쓰려면 → `Sonauto`를 1순위로 사용한다.**
> 완전 무제한·무료 + 한국어 보컬 + instrumental 모드 + 가사 자동/직접 입력을 모두 충족하는 유일한 도구.
> **단, 상업 라이선스 약관이 공식 문서화돼 있지 않다** → 수익화 영상에 쓰기 전 Sonauto 지원팀에 서면 확인 1회 필수(§4).

| 우선순위 | 도구 | 왜 |
|---|---|---|
| **1순위** | **Sonauto** | 영구 무료·무제한, 한국어 가사 OK, instrumental OK, stem 분리 무료 |
| 2순위(단기) | MiniMax Music 2.6 | 상업 라이선스가 **명확**. 단 무료는 14일 베타 한정(이후 유료) |
| 연습용 | Suno / Udio 무료 | 품질 좋지만 **무료 = 비상업(수익화 불가)**. 톤 테스트·프로토타입용 |

## 1. ⚠️ 무료 도구의 핵심 함정 — "무료 ≠ 상업적 사용 가능"

대부분의 인기 AI 음악 도구는 **무료 플랜으로 만든 곡을 유튜브 수익화·광고·클라이언트 작업에 쓰지 못한다.** 무료는 개인·비상업용 라이선스만 준다.

- **Suno 무료:** 하루 50크레딧(약 10곡)·attribution 의무 + **상업 사용 금지**. 상업 쓰려면 Pro($10/월)↑
- **Udio 무료:** 월 100크레딧 + 일 10·attribution 의무 + **상업 사용 금지**. 상업은 Standard($10/월)↑
- **Stable Audio 무료:** **개인·비상업 전용.** 상업은 Creator 라이선스(유료)

> 채널은 수익화가 전제(키→랜딩 퍼널). 따라서 위 셋의 **무료 플랜은 "톤 실험·연습"까지만** 쓰고, 실제 발행 곡엔 쓰지 않는다.

## 2. ✅ 무료 + 상업적 사용 가능한 도구

### Sonauto (1순위)
- **가격:** 완전 무료·**무제한**. 크레딧 시스템 없음, 카드 불필요, 일일 한도 없음.
- **곡:** 최대 ~4.5분 풀송. 텍스트→곡, 가사 직접 입력 / AI 자동 생성 / 멜로디 컨디셔닝.
- **instrumental:** **"No Lyrics" 버튼** 클릭 → 가사 없는 곡.
- **한국어:** 다국어 보컬 지원(프·스·이·중·일·**한**·아). 한국어 가사 노래 가능.
- **부가:** **stem 분리 무료**(보컬·드럼·베이스·기타 분리 export) — 영상 믹싱에 유리.
- **리스크:** 상업 라이선스 약관이 공식 문서화 안 됨(2026 기준). 일부 소스는 "상업권 기본 포함" 주장, 다른 소스는 "불명확". → **§4 확인 절차 필수.**

### MiniMax Music 2.6 (단기 대안)
- **가격:** 영구 무료 아님. 2026-04-10 시작 **14일 글로벌 베타** 동안만 하루 500곡 무료, 이후 유료 크레딧.
- **라이선스:** **royalty-free·상업 사용 명확 허용**(유튜브·광고·게임). 추가 라이선스 불필요.
- **instrumental:** 토글 1개로 무보컬 BGM.
- **한국어:** 문서상 미강조(중국어 강점). 다국어 지원은 함 → 한국어는 **테스트 후 판단**.
- **용도:** 라이선스가 깨끗해야 하는 곡을 **베타 기간에 몰아서** 만들 때.

## 4. Sonauto 상업 사용 확인 절차 (수익화 전 1회)

1. Sonauto 지원/약관 페이지에서 **"commercial use / monetization" 명시 조항 확인.**
2. 불명확하면 지원팀(이메일/디스코드)에 질문 → **서면 답변 캡처 보관.**
   - 질문 예: *"Can songs generated on the free plan be used in monetized YouTube videos commercially? Any attribution required?"*
3. 답변·캡처를 [`BGM_기획문서.md §8 제작 로그`]에 링크/첨부.
4. 만약 상업 불가/불명확으로 확인되면 → 발행 곡만 **MiniMax 베타** 또는 **Suno Pro 1개월**로 재제작(프롬프트 동일 재사용).

## 5. 권장 무료 워크플로우 (채널 적용)

```
[1단계 · 무료 톤 실험]
 Suno/Udio 무료 또는 Sonauto로 컨셉 A/B/C 여러 번 생성 → 채널 톤 후보 고르기
        │
[2단계 · 무료 본제작]   ← Sonauto (무제한·한국어·instrumental/vocal)
 채택 톤을 Sonauto로 본제작. instrumental은 "No Lyrics", vocal은 한국어 가사 입력
        │
[3단계 · 라이선스 확정]  ← §4 절차
 Sonauto 상업권 확인 OK → 그대로 사용
 불명확 → 발행 곡만 MiniMax 베타 / Suno Pro로 동일 프롬프트 재생성
        │
[4단계 · 저장·기록]
 채택본 BGM/audio/ 저장 + BGM_기획문서.md §8 로그에 도구·곡ID·라이선스 근거 기록
```
