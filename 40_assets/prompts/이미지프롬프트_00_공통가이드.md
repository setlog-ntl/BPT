## 1. 작업 원칙 3가지 (모든 자산 공통)

1. **텍스트(한글)는 AI로 생성하지 말 것.** Midjourney·DALL·E·SD 모두 **한글 글자를 깨뜨린다.** → **배경·그래픽만 AI로 생성**하고, **한글 텍스트는 Canva/Figma/PPT에서 직접 오버레이**한다. (영문 텍스트만 필요하면 Ideogram·DALL·E가 비교적 정확.)
2. **페이스리스 유지.** 인물 얼굴 정면 금지. 필요 시 **손·실루엣·뒷모습**까지만. (채널 톤 = 차분·진중·문학적.)
3. **컬러 토큰 고정.** 배경 딥블랙 `#0F1115` / 강조 골드 `#FFD166` / 책·긍정 그린 `#06D6A0` / (대비용) 레드 `#EF476F` / **AI 강조 블루 `#6EA8FE`(보조)**. 골드는 "빛/책의 온기", 블루는 "AI/디지털"로 자연스럽게 녹인다.
4. **모티브 = 책 + AI.** 펼친 책(따뜻한 빛)과 미세한 AI 요소(은은한 회로 라인·노드·칩)를 병치하되 과하지 않게. 핵심은 **"읽는 사람"** — 책이 토대, AI가 입구.

## 3. 네거티브 프롬프트 (SD/공통 — 넣을수록 깔끔)
```
text, letters, words, typography, watermark, signature, logo text, gibberish text,
human face, portrait, eyes, smiling person, crowd, hands deformed, extra fingers,
neon, oversaturated, rainbow colors, busy background, clutter, messy, low quality,
blurry, jpeg artifacts, cartoon, childish, clipart, stock-photo cheesy, 3d render plastic
```
> Midjourney는 `--no text, faces, watermark, neon, clutter` 형태로 축약 사용.

## 4. 도구별 사용 팁

| 도구 | 팁 |
|---|---|
| **Midjourney v6** | 프롬프트 그대로 + `--ar 1:1`(프로필)/`--ar 16:9`(배너·썸네일), `--style raw`로 사진톤 강화, `--s 250` 정도로 과한 스타일 억제. 변형은 `--seed` 고정 후 진행. |
| **DALL·E 3 / ChatGPT 이미지** | 영문 프롬프트를 자연어 문장으로 풀어 입력. "deep black #0F1115 background, warm golden #FFD166 light, no text, leave empty space for a title" 식으로 **여백 요청을 명시**. 한글 텍스트는 항상 후작업. |
| **Ideogram** | **영문 텍스트는 비교적 정확** — 영문 보조 카피가 필요하면 여기서. 한글은 여전히 불안정 → 한글은 Canva. |
| **Stable Diffusion** | §3 네거티브 프롬프트 필수. 사실적 톤 모델(예: Juggernaut/RealVis 계열) 권장. 16:9는 1344×768 등으로 생성 후 업스케일. |

## 5. 텍스트 오버레이 후작업 가이드 (Canva/Figma/PPT)

AI로 **배경만** 만든 뒤 글자를 직접 얹는다.

| 요소 | 값 |
|---|---|
| 메인 워드마크 | **AI보다 읽는 사람** (2줄: "AI보다" / "읽는 사람") |
| 배너 서브카피 | "책으로 생각하고, AI로 실행하다 — AI는 답을, 읽는 사람은 질문을." |
| 발행 안내 | "매주 수요일 · AI 한 줄에서 시작하는 한 가지 질문" |
| 강조어 색 | "AI" = 블루 `#6EA8FE` / "읽는 사람" = 골드 `#FFD166` / 나머지 흰색 `#E7E9EE` |
| 폰트(한글) | Pretendard / 본명조(Noto Serif KR — 문학적) / Gmarket Sans(굵은 워드마크용) 중 **1종 고정** (모든 자산 동일) |

## 7. 공통 발행 전 체크
- [ ] 컬러가 토큰(#0F1115 / #FFD166)과 일치하는가
- [ ] 얼굴·과장·네온·잡다한 요소가 없는가 (페이스리스·진중)
- [ ] 한글 텍스트는 AI 생성이 아니라 후작업으로 깨끗하게 들어갔는가
- [ ] 프로필·배너·썸네일이 **같은 모티브(책+AI/빛)·같은 폰트**로 통일됐는가
