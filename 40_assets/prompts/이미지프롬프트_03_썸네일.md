## 1. 썸네일 표준 레이아웃 (텍스트 오버레이 골격)
```
┌──────────────────────────────────────────────┐
│ [S1·EP04]  ← 좌상단 골드 라벨(작게)            │
│                                                │
│   ◀─ 좌 60% ─▶     │   ◀──── 우 40% ────▶      │
│   메타포/오브제 컷   │  (흐름 1줄, 회색·작게)    │
│   페이스리스         │   AI가 다 답해줘도        │
│   따뜻한 골드 빛     │  ┌──────────────────┐    │
│                     │  │ 읽는 사람 (골드강조)│    │  ← 헤드라인 2줄
│                     │  │ 이 이깁니다         │    │
│                     │  └──────────────────┘    │
└──────────────────────────────────────────────┘
```
> **배경(좌측 비주얼 + 우측 어두운 텍스트 공간)만 AI로 생성**하고, **라벨·헤드라인 한글 텍스트는 Canva/Figma에서 오버레이**한다.

## 2. 좌측 비주얼 배경 프롬프트 (결·주제별 4종)

> 공통: 우측 40%는 **텍스트용 어두운 여백**으로 비운다 → `keep the right 40% as dark empty space for text` 명시.

### ① 선택형 — 펼친 책 빛 + 미세 AI 노드 (풀링 기본, 1순위)
```
Left-side cinematic close-up of a single open book glowing with warm golden light (#FFD166)
in deep darkness (#0F1115), faceless, atmospheric night-reading mood, subtle paper texture,
shallow depth of field, keep the right 40% as dark empty negative space for text,
premium editorial thumbnail, no text --ar 16:9 --style raw --v 6
```

### ② 흐름 인정형 — 디지털/스크린 빛 (역접의 '앞부분')
```
Left-side close-up of a smartphone or screen emitting cool blue digital light in the dark,
scattered notification glow, cold and fast tech mood, deep black background (#0F1115),
faceless, keep the right 40% as dark empty space for text, cinematic, no text
--ar 16:9 --style raw --v 6
```

### ③ 역접 대비형 — 화면 vs 책 (한 컷 안에 흐름→선택)
```
Left-side composition: a cold blue glowing screen on one side gradually giving way to a warm
golden-lit open book on the other, contrast of cool digital vs warm reading light,
deep black background (#0F1115), faceless, cinematic, keep the right 40% darker for text overlay,
premium editorial, no text --ar 16:9 --v 6
```

### ④ 키컨텐츠/도구형 — 전자책 단말기·오브제 (전환 영상용)
```
Left-side product-style shot of an e-ink e-reader or a stack of books on a dark wooden desk,
one warm golden light source (#FFD166), deep black background (#0F1115), premium minimal,
faceless, subtle paper texture, keep the right 40% as dark empty space for text,
clean commercial editorial, no text --ar 16:9 --style raw --v 6
```

## 3. 헤드라인 문구 뱅크 (텍스트 오버레이용 — 강조어 1개 규칙)

| 흐름 1줄(회색·작게) | 헤드라인 2줄(굵게, 강조어=골드) |
|---|---|
| AI가 다 답해줘도 | 그런데 **읽는 사람**이 / 이깁니다 |
| 3분 요약이면 끝인데 | **왜?** / 원서를 펴는 사람 |
| 같은 챗GPT인데 | **왜?** / 결과가 다를까 |
| 스마트폰이면 충분한데 | 그런데 **전자책 단말기** / 를 사는 이유 |
| 코드 한 줄 몰라도 | **AI로** / 앱을 만든다 |

> 규칙: 강조어는 **"왜?" 또는 핵심어 1개만** 골드(`#FFD166`)로(AI 강조는 블루 `#6EA8FE`). 나머지는 흰색(`#E7E9EE`). 2줄 초과 금지.

## 4. 텍스트 오버레이 스펙

| 요소 | 값 |
|---|---|
| 시즌·번호 라벨 | 좌상단, `S1·EP##`, 골드 테두리 작은 칩 |
| 흐름 1줄 | 우측 상단, 회색 `#9AA3B2`, 작게 |
| 헤드라인 | 우측 중앙, 2줄, 굵게(900), 강조어 1개만 골드 |
| 폰트 | **1종 고정** — Gmarket Sans / Pretendard ExtraBold 중 채널 통일(배너·워드마크와 동일 계열) |
| 외곽선/그림자 | 가독 위해 텍스트에 미세한 어두운 그림자 1px |
| 안전 | 모바일(작게) 기준으로 헤드라인이 읽히는지 우선 |

---

## 5. 썸네일 전용 체크리스트
- [ ] 좌 60% 비주얼 / 우 40% 텍스트 그리드를 지켰는가
- [ ] 강조어가 **딱 1개**("왜?" 또는 핵심어)인가
- [ ] 헤드라인이 **2줄 이내**인가
- [ ] 좌상단 시즌·번호 라벨이 있는가
- [ ] 페이스리스·골드 톤(컬러 토큰)인가
- [ ] **모바일 미리보기 크기**에서 헤드라인이 읽히는가
- [ ] 시리즈 썸네일끼리 같은 폰트·라벨·그리드로 **통일**됐는가
