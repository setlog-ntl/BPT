# 02_자산_라이브러리

재사용 가능한 미디어 자산의 **카탈로그(메타데이터) 저장소**.

> ⚠️ **원본 미디어 파일은 여기에 두지 않는다.** git 저장소 비대화 방지.
> 카탈로그(`*.md` / `*.json`)만 두고, 실제 파일 경로는 메타데이터에 기록.

## 구조

| 폴더 | 자산 종류 | 일반적 길이/규격 |
|---|---|---|
| [`인트로/`](인트로/) | 영상 시작 인트로 클립 | 1~3초 |
| [`아웃트로/`](아웃트로/) | 영상 마무리 CTA 클립 | 3~7초 |
| [`비롤/`](비롤/) | 본문 사이 끼워 넣는 보조 영상 | 2~10초 단편 |
| [`효과음/`](효과음/) | 강조·전환 효과음 (스윕, 팝, 우-등) | <2초 |
| [`배경음악/`](배경음악/) | 배경 음악 | 30초~5분 |
| [`자막스타일/`](자막스타일/) | 캡컷 자막 프리셋 (폰트·색·애니메이션) | - |
| [`썸네일프레임/`](썸네일프레임/) | 썸네일 베이스 디자인 (PSD/PNG/Figma) | 1280x720 |

## 카탈로그 메타데이터 스키마

각 카테고리 폴더 안에 `카탈로그.md` 를 두고 다음 표를 유지:

```markdown
| ID | 이름 | 길이/규격 | 용도 | 분위기 태그 | 라이선스 | 원본 경로 | 등록일 |
|---|---|---|---|---|---|---|---|
| 인트로-001 | 잔잔한_피아노_3초 | 3.0s, 1080p | 키 본영상 | 차분, 사색 | CC0 | D:/media/intro/calm_piano.mp4 | 2026-05-03 |
```

**필수 필드**:
- `ID` — 카테고리 prefix + 3자리 (예: `배경음악-007`)
- `라이선스` — 상업적 사용 가능 여부 명시 (CC0 / CC-BY / Royalty-free / 자체제작)
- `원본 경로` — 실제 파일 위치 (로컬 절대 경로 또는 클라우드 링크)

## 자산 등록 절차

1. 새 자산 발견·제작 시 즉시 카탈로그에 등록 (나중에 한꺼번에 X)
2. 라이선스 확인 — 불명확하면 등록 보류
3. 분위기 태그는 일관되게 — [`태그_사전.md`](태그_사전.md) 단어만 사용
4. 영상 프로젝트에서 사용한 자산은 `03_프로젝트/<영상>/03_캡컷_패키지/사용자산.md` 에 ID로 기록
