# 책 관련 무료 영상 — 선큐레이션 컬렉션

> 책 콘텐츠 영상 편집에 자주 쓸 비롤 자료원 인덱스.
> 모두 **상업적 사용 가능 + 출처 표기 불필요** (Pexels / Pixabay / Coverr 라이선스).
> 실제로 다운로드해서 사용한 영상은 [`카탈로그.md`](카탈로그.md)에 정식 ID 부여하여 등록.
>
> 작성: 2026-05-03 · 출처 검증: 2026-05-03

---

## 사용 방법

```
1. 영상 기획 단계에서 분위기 태그 결정 (예: 차분, 사색)
2. 아래 표에서 태그 일치하는 카테고리 → 검색 페이지 열기
3. 영상 1편 골라 다운로드 → 02_자산_라이브러리/원본 저장 경로(외부)에 저장
4. 카탈로그.md 에 비롤-XXX ID 부여하여 등록
5. 영상 프로젝트의 사용자산.md 에 ID 기록
```

## 사용 시 체크리스트

영상 1개 다운로드 → 카탈로그 등록 전 점검:

- [ ] 라이선스 확인 — Pexels/Pixabay/Coverr 모두 "상업 사용 OK + 출처 표기 불필요" 기본이지만 개별 클립에 추가 제한 있을 수 있음 (페이지 하단 확인)
- [ ] 길이 측정 (초 단위)
- [ ] 분위기 태그는 [`../태그_사전.md`](../태그_사전.md) 단어만 사용
- [ ] 비슷한 영상 이미 카탈로그에 있는지 검색 (중복 방지)
- [ ] 원본 파일을 외부 저장소 경로(예: `D:/media/비롤/`)로 옮기고 카탈로그에 절대경로 기록
- [ ] 카탈로그.md 표에 한 줄 추가, 다음 사용 ID 갱신
