# 책 관련 무료 이미지 — 선큐레이션 컬렉션

> 책 콘텐츠 영상의 썸네일 베이스·인용 자막 배경·정물 컷 합성용 이미지 자료원 인덱스.
> 모두 **상업적 사용 가능 + 출처 표기 불필요** (Unsplash / Pexels / Pixabay 라이선스).
> 실제로 다운로드해 썸네일 베이스로 사용한 이미지는 [`카탈로그.md`](카탈로그.md)에 정식 ID 부여하여 등록.
>
> 작성: 2026-05-03 · 출처 검증: 2026-05-03

---

## 사용 방법

```
1. 영상 유형 결정 (썸네일/배경/정물)
2. 아래 표에서 적합 카테고리 → 컬렉션 페이지 열기
3. 이미지 다운로드 → 외부 저장소 경로(예: D:/media/이미지/)에 저장
4. 캡컷 또는 Figma/포토샵에서 썸네일 합성
5. 정식 썸네일이 완성되면 카탈로그.md 에 썸네일-XXX ID 부여 등록
```

## 사용 시 체크리스트

이미지 1장 다운로드 전 점검:

- [ ] 해상도 충분한가 — 썸네일은 최소 1280x720, 4K 영상 배경은 3840x2160 권장
- [ ] 라이선스 확인 — Unsplash·Pexels·Pixabay 모두 "상업 사용 OK + 출처 표기 불필요" 기본
- [ ] 사람 얼굴이 식별 가능하면 모델 릴리스 표시 있는지(Unsplash는 별도 표기) 확인
- [ ] 원본 파일을 외부 저장소(`D:/media/이미지/`)로 옮기고 카탈로그에 절대경로 기록
