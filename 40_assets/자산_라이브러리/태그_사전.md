# 자산 분위기 태그 사전 (v1)

> 카탈로그의 "분위기 태그" 컬럼은 반드시 이 사전 안의 단어만 사용.
> 새 태그가 필요하면 본 문서에 먼저 추가 후 사용.

## 분위기 (Mood)

| 태그 | 의미 | 자주 어울리는 영상 유형 |
|---|---|---|
| 차분 | 잔잔하고 사색적 | 키 본영상, 책 깊이 분석 |
| 사색 | 생각을 자극하는 | 키 본영상, 풀링 후킹 |
| 긴장 | 호기심·서스펜스 자극 | 풀링 후킹, 랜딩 문제 제시 |
| 경쾌 | 가볍고 빠른 | 풀링 본문, 정보성 |
| 따뜻 | 감정적 공감 | 키 마무리, 랜딩 약속 |
| 진지 | 무게감 있는 | 키 본영상, 랜딩 증거 |
| 희망 | 긍정적 결말 | 키·랜딩 마무리, CTA |

## 용도 (Use case)

| 태그 | 의미 |
|---|---|
| 후킹 | 첫 3초 주의 끌기 |
| 본문 | 메인 내레이션 구간 |
| 전환 | 챕터·구간 전환 |
| 강조 | 핵심 메시지 순간 |
| 마무리 | 영상 종료 부근 |
| CTA | 구독·클릭·구매 유도 |

## 톤 (Tone)

| 태그 | 의미 |
|---|---|
| 미니멀 | 단순하고 깔끔 |
| 아날로그 | 빈티지·필름 느낌 |
| 시네마틱 | 영화적, 색감 풍부 |
| 모던 | 디지털, 깔끔한 그래픽 |
| 친근 | 일상적, 부드러운 |

## 사용 예

```
| ID | 이름 | 분위기 태그 | ... |
|---|---|---|---|
| 배경음악-007 | 차분한_피아노_솔로 | 차분, 사색, 본문 | ... |
| 인트로-001 | 잔잔한_피아노_3초 | 차분, 후킹 | ... |
| 아웃트로-003 | 구독_CTA_3초 | 경쾌, CTA | ... |
```
