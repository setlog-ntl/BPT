# 1-4강 · 수익화 구조와 퍼널 역산

## 한 줄 요약
**기획은 수익화부터 거꾸로 설계하고, 제작은 풀링 콘텐츠부터 정방향으로 만든다.** 사람이 먼저 모여야 팔린다.

---

## 1. 수익화의 고객 단계 (피라미드)
| 단계 | 의미 |
|---|---|
| 잠재고객 | 아직 우리 콘텐츠를 모르는 사람 |
| 무료고객 | 풀링/키 콘텐츠를 본 사람 |
| 유료고객 | 랜딩에서 구매한 사람 |
| 재구매고객 | 다시 구매한 사람 (LTV 핵심) |

> 수익화는 결국 **유튜브**를 매개로 이루어진다. 유튜브 유입의 80% 이상이 홈화면(추천 알고리즘)에서 발생.

## 2. 콘텐츠 두 종류
| 구분 | 풀링 콘텐츠 | 키 콘텐츠 |
|---|---|---|
| 시청자 의도 | **없음** (탐색형) | **있음** (검색형) |
| 유입 채널 | 유튜브 홈 알고리즘 | 네이버·인스타·유튜브 검색 |
| 역할 | 사람을 모은다 | 사람을 거른다 → 구매 직전 단계로 이동 |

## 3. 두 가지 순서 — 방향이 정반대
| 단계 | 기획 (역방향 설계) | 제작 (정방향 실행) |
|---|---|---|
| 1 | ① 수익화 목표 | ③ 풀링 콘텐츠 |
| 2 | ② 키 콘텐츠 | ② 키 콘텐츠 |
| 3 | ③ 풀링 콘텐츠 | ① 수익화(랜딩) |

> **기획**: "뭘로 돈을 벌지" 정하고 역산해서 콘텐츠 설계.
> **제작**: 사람을 모으는 풀링부터 찍는다.

## 4. 매출 공식 + 퍼널 역산
- 매출 = **P (가격) × Q (수량)**
- 예: 3,000만원 = P(10만원) × Q(10개)
- 목표 매출 → 목표 Q → 깔때기 입구(조회수) 역산.

### 1-4강 깔때기 (개념 이해용 예시)
```
풀링 2,000회 ──10%──► 키 200회 ──10%──► 랜딩 20명 ──50%──► 구매 10개
```

| 단계 | 수치 | 전환율 |
|---|---:|---:|
| 풀링 콘텐츠 조회수 | 2,000 | — |
| → 키 콘텐츠 도달 | 200 | 10% |
| → 랜딩페이지 진입 | 20 | 10% |
| → 구매 전환 | 10 | 50% |

> 1-4강 수치는 **이해용 예시**. 실제 목표 전환율은 1-5강 (20/5/5) 참고.

## 5. 제작 파이프라인 (풀링 콘텐츠 기준)
```
썸네일/제목 → 원고 작성 → 촬영 → 편집 → 업로드
```
**썸네일·제목을 먼저 확정**해야 내용이 그 프레임 안에서 응축된다.

## 6. 한 장짜리 흐름도
```
[사람] (탐색) → 풀링 → 키 → 본편/랜딩 → 수익화
                                          ├ 잠재
                                          ├ 무료
                                          ├ 유료
                                          └ 재구매
```
