# 1-5강 · 정량 KPI와 트래픽 계산

## 한 줄 요약
**전체 맥락을 구분해서 구체적인 수량·숫자 목표로 바꾸고, 영상 단위 KPI까지 쪼갠다.**

---

## 1. 중요한 3가지
1. **정량적 목표 (KPI)**
2. **썸네일·제목부터 정하고 내용을 만든다** (1-4강 재강조)
3. **트래픽 계산하기**

## 2. 정량 KPI — 유튜브 영상 기준
| 지표 | 목표값 | 비고 |
|---|---:|---|
| 조회수 | **1,000 뷰** | 기본 트래픽 지표 |
| 클릭률 (CTR) | **10%** | 썸네일·제목 성과 |
| 시청 지속 (절대값) | **4분** (≈ 30%) | 전체 길이 대비 시청 비율 |
| 초반 30초 유지율 | **60%** | 도입부 훅 성과 |

> **정성 KPI (보조)**: 특정 주제에 대한 관심층 최소량 = 전체 파이.
> 사용자 주제: **AI / 책** 2가지.

> ※ 시청 지속 4분의 비율 기준은 1-5강 raw에서 35%로 적었다가, 2026-04-18 사용자 synthesis에서 **30%로 통일**.

## 3. 트래픽 계산 — 깔때기 목표 전환율
| 단계 | 라벨 | 목표 전환율 |
|---|---|---:|
| 풀링 → 키 | 키 콘텐츠 연계율 | **20%** |
| 키 → 랜딩 | 링크 클릭률 | **5%** |
| 랜딩 → 구매 | 유료 고객 전환율 | **5%** |

### 역산 흐름
```
[목표 매출] ÷ P (객단가) = Q (수량)
                            │ ÷ 5%  (유료 전환)
[랜딩페이지]                ◄┘
        │ ÷ 5%  (링크 클릭)
[키 콘텐츠]
        │ ÷ 20% (키 연계)
[풀링 콘텐츠]
```

### ⚠️ 1-4강 vs 1-5강 깔때기 수치 차이
| 단계 | 1-4강 (예시) | 1-5강 (목표) |
|---|---:|---:|
| 풀링 → 키 | 10% | **20%** |
| 키 → 랜딩 | 10% | **5%** |
| 랜딩 → 구매 | 50% | **5%** |

→ **1-4강은 개념 이해용 예시**, **1-5강은 실무 목표 전환율**.
→ SPA 트래픽 계산기는 **20/5/5 기본값** 사용. 사용자 임의 변경 가능.

## 4. 영상 단위 쪼개기 예시
- 월 풀링 조회수 **2,000회** 필요 시?
  - 영상 1개당 1,000 뷰 기준 → **최소 2개 필요**
  - 각 영상이 CTR 10% / 30초 유지 60% / 절대 4분을 동시에 충족해야 실현 가능.

## 5. 핵심 프레임
```
맥락(추상적 목표)
   └─ 구분
       └─ 구체적 수량·숫자
           └─ 영상 단위 KPI (쪼개기)
```
"열심히 올린다" 같은 정성적 선언이 아니라, **영상 1개마다 달성해야 할 수치 목록**으로 환원.
