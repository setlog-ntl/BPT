# 3-1강 · 키 콘텐츠 기본 개념

## 한 줄 요약
**키 콘텐츠는 제품 장점을 늘어놓는 게 아니라, "공감되는 문제"를 짚고 그 솔루션이 곧 내 제품임을 보여주는 콘텐츠다.**

---

## 1. 5단계 구매 사이클 (고객 머릿속)
```
현상(상황) → 욕구 → 계획 → 행동 → 보상
                                    ↻ (재구매)
```

| 단계 | 고객 내부에서 일어나는 일 | 콘텐츠가 해야 할 일 |
|---|---|---|
| **현상/상황** | 일상에서 문제 상황을 마주침 | "이런 상황 겪지 않으세요?" 공감 트리거 |
| **욕구** | 그 상황을 해결하고 싶은 욕구 발생 | 문제를 명료하게 정의 → 욕구 점화 |
| **계획** | 구매를 검토. **장점·기능**을 찾아본다 | 솔루션(=내 제품)의 장점·기능을 비교 가능하게 제시 |
| **행동** | 실제 구매·결제 | CTA·랜딩 링크 노출, 구매 마찰 제거 |
| **보상** | 사용 후 만족 → 재구매 | 사용 결과를 다음 콘텐츠의 증거로 재활용 |

> "장점·기능"을 찾는 곳은 **계획 단계 한 곳뿐**. 이 단계 전에 장점부터 늘어놓으면 욕구가 점화되지 않은 사람을 향해 외치는 셈 → 키 콘텐츠가 안 됨.

## 2. 키 콘텐츠 5원칙 (강의 슬라이드)
1. 제품의 장점을 늘어놓는 것은 키 콘텐츠가 아니다.
2. **제품으로 해결할 수 있는 문제에 대한 영상**을 만들어야 한다. *(강조)*
3. 그 문제는 **공감할 수 있는 문제**여야 한다.
   - 공감하는 사람의 수 = 잠재고객의 수.
4. 문제에 공감되었을 때 **솔루션에도 공감**할 수 있다.
5. 솔루션에 공감할 때 **구매**가 발생한다.

> 결론: **"키 콘텐츠는 문제를 공감한 사람들에게 솔루션을 주는 콘텐츠. 솔루션은 나의 제품이 되어야 한다."**

## 3. 두 프레임의 매핑
| 키 콘텐츠 5원칙 | 5단계 사이클 위치 |
|---|---|
| ① 장점 나열 X | (사이클 어디에도 들어가지 않음 — 잘못된 진입) |
| ② 문제 영상 | 현상/상황 진입 |
| ③ 공감 가능한 문제 | 욕구 점화 |
| ④ 솔루션 공감 | 계획 |
| ⑤ 솔루션 공감 → 구매 | 행동 |
| (다음 콘텐츠로 순환) | 보상 → 다음 키 콘텐츠의 증거 |

## 4. 실무 적용 — 키 콘텐츠 한 편 구조 템플릿
```
[훅: 상황]   "혹시 이런 적 있지 않으세요?" — 5초 안에 현상 환기
   ↓
[문제 정의]  공감 가능한 한 줄로 압축. 잠재고객 풀이 여기서 결정됨
   ↓
[솔루션 공감] "그래서 이걸 시도해 봤더니 …" — 솔루션의 논리·증거
   ↓
[제품 = 솔루션] 솔루션의 구체 형태가 내 제품임을 자연스럽게 연결
   ↓
[행동]      CTA — 랜딩 링크, 댓글 유도, 구독 등
   ↓
[보상 예고]  실제 사용 후 변화 — 다음 콘텐츠 떡밥
```

## 5. 1·2주차와 어떻게 연결되나
- **1-4·1-5강 (퍼널·KPI)**: 깔때기에서 "키 콘텐츠" 박스 안의 작동 원리가 곧 이 5원칙.
- **2-2강 (문제에 집중)**: "답을 팔지 말고 문제를 가진 사람을 모아라"가 슬라이드 5원칙으로 구체화.
- **2-4강 (본질→증거 4단계)**: 본질화 → 답변 → 현상화 → 증거 = 5단계 사이클의 구매·보상 구간을 콘텐츠 구성으로 옮긴 것.
- **2-5강 (재구매·LTV)**: 5단계의 마지막 "보상→재구매" 고리가 LTV의 출발점.

## 활용 체크리스트

### 콘텐츠 기획 전
- [ ] 이 콘텐츠가 다루는 **현상**을 한 문장으로 적었는가?
- [ ] 그 현상이 일으키는 **공감 가능한 문제**는?
- [ ] 그 문제에 공감할 사람의 규모(잠재고객 풀)는 충분한가?
- [ ] 솔루션은 내 제품과 자연스럽게 연결되는가? *(억지 연결이면 5원칙 위반)*

### 콘텐츠 구성 점검
- [ ] 도입 5초 안에 **현상 환기**가 있는가?
- [ ] 문제를 **한 줄**로 명료하게 정의했는가?
- [ ] 장점·기능 나열을 **계획 단계 이후**로 미뤘는가?
- [ ] 행동(CTA) 단계의 마찰(링크·결제·신뢰)이 최소화됐는가?

### 보상 → 재구매 고리
- [ ] 구매 후 **사용 결과를 수집**할 수단(리뷰·후기·데이터)이 있는가?
- [ ] 그 결과를 다음 키 콘텐츠의 **증거**로 쓸 계획이 있는가?

| 책 카테고리 | "필사하다 손목이 아프다 / 자세가 무너진다" | 눕서대 · 필사노트 · 독서등 번들 (단가 분석 참조) |

## 다음 강의와의 연결

- 4주차로 추정되는 랜딩페이지·전환 설계 강의로 이어질 것.
