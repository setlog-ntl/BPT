# 4주차 지시카드 — 풀링 콘텐츠 4가지 종류

## 1. 한 줄 정의

> **풀링 콘텐츠는 "그거 보면 살 거 같다고 답할 수 있는 후보군(잠재 소비자)"을 모으는 단계이며, *시간흐름 관심도 변화*(적다=에버그린 / 크다=시즌성)와 *투입시간·제작비용*(적다=데일리 / 크다=히어로)의 **두 독립 축**으로 4종을 분류한다. 강의자 권장은 두 축이 모두 "적다"인 *에버그린 × 데일리*다.**

---

## 2. 키 vs 풀링 (한 줄 구분)

```
키 콘텐츠  : 잠재 소비자 → 소비자   (계획·행동)  "그거 보면 살 거 같아?"
풀링 콘텐츠: 시청자 → 잠재 소비자   (현상·욕구)  "살 거 같다고 답할 후보군을 만드는가?"
```

- 풀링은 **기능·특징·장점에서 출발 → 일반화된 욕구·현상으로 확장**해 더 큰 모수를 끈다.
- 일반화 흐름: `[제품 기능] → [기능이 닿는 욕구·현상] → [더 넓은 관심사]` → **"내 컨셉에 모일 사람의 정의"(결 3그룹)**로 귀결.

---

## 3. 핵심 원칙 카드 (작업 지시 시 인용용)

### 원칙 1 · 4종은 2×2 교차표가 아니라 "두 독립 축"
- ①·② = *트래픽 패턴* 축(시간흐름 관심도), ③·④ = *제작 비용* 축.
- 한 콘텐츠는 두 축에서 **각각 어디 속하는지**를 따로 가진다 → "에버그린 + 데일리" 같은 **조합**으로 표기.

### 원칙 2 · 4종 정의 카드
| 코드 | 종류 | 축 · 값 | 한 줄 정의 | 주의 |
|---|---|---|---|---|
| ① | **에버그린** | 관심도 변화 적다 | 상록수처럼 꾸준한 트래픽 (예: "아이 열날 때") | 한 편 폭발력 낮음 — 양으로 적립 |
| ② | **시즌성** | 관심도 변화 크다 | 일정기간 폭발 후 급락 (예: "FOMC 예상") | **속도전** 필수, 시점 놓치면 무의미 |
| ③ | **데일리** | 제작비용 적다 | 가벼운 포맷 반복 (예: 인터뷰) | **포맷·템플릿** 잡혀야 적은 비용 유지 |
| ④ | **히어로/특집** | 제작비용 크다 | 대형 기획 (예: 웹드라마) | 에버그린·데일리 받쳐줄 때만 ROI |

### 원칙 3 · 강의자 권장 = "바로 에버그린 + 데일리"
- 두 축이 모두 "적다"인 사분면 = **번아웃 없이 자산이 쌓이는 유일한 영역**. 풀링의 출발점.
- ②·④(크다 축)는 **돈·시점을 한 번에 크게 베팅** → 풀 쌓이기 전 무리하면 ROI 음수.

### 원칙 4 · 운영 순서 (베이스 → 베팅)
```
①에버그린 + ③데일리 (즉시·베이스)
        ↓ 풀이 쌓인 뒤
②시즌성 (캘린더 잡힌 뒤) · ④히어로 (풀 충분할 때)
```

## 4. 4종 라인업 우선순위 카드

| 우선순위 | 종류 | 비유 | 진입 시점 |
|---|---|---|---|
| ★★★ | ① 에버그린 | 밭 — 매년 수확 | 즉시 |
| ★★★ | ③ 데일리 | 단골 식당 일일 메뉴 | 즉시 (포맷 잡힌 뒤) |
| ★★ | ② 시즌성 | 계절 한정 메뉴 | 시즌 캘린더 잡힌 뒤 |
| ★ | ④ 히어로 | 특별 행사 | 풀이 충분히 쌓인 뒤 |

## 5. 다른 작업에 지시할 때 쓰는 프롬프트 템플릿

### 5.1 풀링 콘텐츠 신규 기획 지시
```
주제: [주제]
8축 컨셉: [책 읽는 방법 / 이유 / 자기개발 / 습관 / 문해력 / 지적허영심 / 지적호기심 / 재미]
대상 결 그룹: [① 읽으려는 / ② 읽고 있는 / ③ 더 읽으려는]

4주차 지시카드(50_knowledge/lectures/4주차_풀링컨텐츠_기획/4주차_지시카드.md) 기준으로 풀링 한 편 기획:
- §3 원칙1: 두 축(관심도·제작비용) 각각에서 위치를 명시 → 조합으로 표기
- §3 원칙3: 강의자 권장 조합(에버그린 × 데일리)으로 갈 수 있는가? 아니라면 이유
- 이 풀링이 모은 사람이 어느 키 콘텐츠/판매(이북리더기·책 제품·readtree)로 흐르는지 한 줄
- 30초 후크 룰(대본/_기획기준/30초_후크_룰_체크리스트.md) 충족

산출물 경로: [경로]
```

### 5.2 기존 풀링 라인업 점검 지시
```
다음 채널 라인업을 4주차 지시카드 기준으로 점검:
- §3 원칙3: 에버그린 × 데일리 베이스 라인이 깔려 있는가? (없으면 최우선)
- §3 원칙2: 데일리 포맷이 번아웃 없이 유지 가능한 단순도인가?
- §4: 시즌성을 친다면 캘린더가 분기 단위로 잡혀 있는가? 히어로를 친다면 받쳐줄 풀이 충분한가?
- 풀링 → 키 전환 경로(고정 댓글·끝 화면·설명란)와 컨셉 결(2-3강) 정합

대상: [경로/채널]
```

### 5.3 8축 × 4종 매핑 지시
```
8축 컨셉 각각에 대해 4주차 4종(에버그린·시즌성·데일리·히어로) 중
가장 적합한 조합과 결 3그룹·연결 판매를 매핑한 표를 작성.
강의자 권장(에버그린 × 데일리)을 1순위로, 단계별 우선 기둥(단기 ②책 → 중기 ③readtree → 장기 ①시스템) 반영.
```
