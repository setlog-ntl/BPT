# 5주차(개정) 문제 해설·정답키 — 제목 디벨롭

> ⚠️ 객관식 보기 중 **썸네일 이미지로 제시된 문항**은 텍스트만으로 정답을 특정할 수 없어, **판단 기준(원칙)**으로 해설한다. 텍스트가 추출된 문항은 정답·근거를 명시. 실조회수 숫자는 PDF 원문 그대로.

## A. 핵심개념문제 (정답 + 근거)

### 핵심개념1
보기: ①핵심가치 ②개인가치 ③채널가치 ④원고 ⑤썸네일
문제: "유명하지 않기 때문에, 콘텐츠 가치 높은 풀링콘텐츠를 만들어서 **(A)**를 올립니다. 반복하며 콘텐츠 가치와 (A)가 누적됐을 때 **(B)**가 생깁니다."

- **A = 채널가치(③)**, **B = 개인가치(②)**
- 근거: 무명 제작자는 좋은 콘텐츠로 먼저 **채널**을 키운다(조회·구독이 채널에 붙는다). 콘텐츠가치+채널가치가 쌓이면 **개인**(제작자 브랜드)의 가치가 따라 생긴다. = 정리본 §1 "컨텐츠가치 먼저 → 개인·채널가치가 따라온다".
- *주의*: A/B 순서(채널↔개인)는 트레이너 정답 확인 권장. 핵심은 **둘 다 콘텐츠가치의 결과**라는 것.

### 핵심개념2
보기: ①핵심가치 ②개인가치 ③콘텐츠 가치 ④구매 가능성 ⑤채널가치
문제: "잘된 주제란 채널가치·개인가치 없어도 **(A)**만으로 히트한 주제. 좋은 주제란 **(B)** 있는 사람을 모을 수 있는 주제."

- **A = 콘텐츠 가치(③)**, **B = 구매 가능성(④)**
- 근거: 정리본 §1.2 "아이유 효과 배제 = 개인·채널가치 없이 **순수 콘텐츠가치**로 히트 = 에버그린 후보". 좋은 주제 = **구매 가능성** 있는 사람(풀링: "살 거 같다고 답할 후보군")을 모으는 주제.

### 핵심개념3
보기: ①썸네일 ②주제 ③클릭률 ④원고 ⑤제목
문제: "뷰트랩에서 찾고, 가장 먼저 디벨롭하는 것은 **(A)**. 바꾸기 가장 쉽고 시간 대비 **(B)**이 높아지는 효과가 크기 때문."

- **A = 제목(⑤)**, **B = 클릭률(③)**
- 근거: 작업 순서 "제목 → 썸네일 → 도입부 → 본문". **제목은 바꾸기 가장 쉽고 시간 대비 클릭률 상승 효과가 가장 크다** → 그래서 8단계의 출발이 제목. (정리본 §1에 보강 반영)

## B. 연습문제1 — 1단계(제목↔썸네일 교차 조합) 해설

> 1단계 룰: 다른 콘텐츠의 **썸네일 문구는 내 제목으로**, **좋은 제목은 내 썸네일 문구로** 조합. 동일 주제 2개를 섞는다. (연습1 지시: 뷰트랩에서 유사 주제 2개↑ 찾아 조합)

**객관식("적절하지 않은 것 2개 고르기")의 판단 기준**:
- 적절: 같은 주제·맥락이고, 썸네일↔제목으로 **교차 가능한** 쌍.
- 부적절: ① 주제가 다른 콘텐츠(섞으면 결이 깨짐) ② 썸네일과 제목이 **이미 동일**해 교차할 여지가 없는 것(=섞어도 변화 없음).

**BEFORE → AFTER 모범 디벨롭** (실제론 뷰트랩 2개 참조 후 조합):

| # | BEFORE | AFTER (모범) |
|---|---|---|
| 1-3 | [썸네일] 장사하면서 생기는 문제 이렇게 하면 해결됩니다 / [제목] 카페창업 후 경쟁업체가 생겨서 매출이 떨어질 때 문제 해결 방법 | [썸네일] **옆에 경쟁가게 생겼을 때** / [제목] **장사하다 경쟁업체 생기면 이렇게 하세요** |
| 1-6 | [썸네일] 30평대 아파트 인테리어 금액을 줄이는 방법 / [제목] 30평대 국민평형 아파트 리모델링 ｜ 가성비 인테리어 현장 소개 | [썸네일] **30평 인테리어, 이 금액 실화?** / [제목] **국민평형 아파트 가성비로 싹 바꾼 현장** |
| 1-9 | [썸네일] 키보드 고민되면 그냥 이거 사세요 / [제목] 사무용 키보드 고민되면 그냥 이거 사세요(로지텍 K580) | [썸네일] **사무용은 그냥 이거** / [제목] **키보드 고민 끝내준 로지텍 K580** |
| 1-12 | [썸네일] 영끌투자 빚 2억 / [제목] 영끌투자로 빚만 2억 신입사원, 빚 갚으며 부업 시작하게 된 이야기 | [썸네일] **신입사원 빚 2억** / [제목] **영끌로 빚 2억, 부업으로 갚기 시작했습니다** |
| 1-15 | [썸네일] 홍대 미대 수시 몇 등급부터 지원 가능할까? / [제목] 홍대 미대는 몇 등급부터 지원이 가능할까요? | [썸네일] **홍대 미대, 몇 등급부터?** / [제목] **미대 지망생이 가장 많이 묻는 한 가지** |

> 1-3·1-6은 썸네일/제목이 길고 설명적 → **짧고 후킹되는 문구를 썸네일로**, **구체 맥락을 제목으로** 분배. 1-15는 썸네일=제목(거의 동일)이라 1단계 **부적절 예시**(섞을 게 없음) → AFTER처럼 한쪽을 질문/후킹으로 비틀어야 함.

## C. 연습문제2 — 2단계(쉬운 단어/동의어) 해설

> 룰: 어려운 단어(한자어·영어·전문용어) → 더 쉬운 일상어(동의어). 중학생도 알 정도.

| # | 검색어 | BEFORE | AFTER (모범) |
|---|---|---|---|
| 2-8 | 리커버리 | 자유형 리커버리 입수지점 어깨통증 논란의 끝 | 자유형 **팔 넣는 위치** 어깨통증 논란의 끝 |
| 2-9 | 둔근운동 | 매트 위에서 손쉽게 하는 둔근운동, 힙익스텐션 | 매트에서 쉽게 하는 **엉덩이 운동**(힙익스텐션) |
| 2-10 | 안면비대칭 | 안면비대칭 바로알기2편 - 얼굴비대칭치료시기는? | **얼굴 비뚤어짐** 바로알기2편 - 교정 시기는? |

> "리커버리→팔 넣는 동작/위치", "둔근→엉덩이", "안면비대칭→얼굴 비뚤어짐/짝짝이". 객관식 2-1~2-7은 **둘 중 더 쉬운 일상어 쪽**이 정답.

## D. 연습문제3 — 3단계(넓은 단어/반의어, 실조회수) ★핵심 데이터

### 3-1) 상위어 (좁은 단어 → 넓은 단어)
| 좁은 단어 | 넓은 단어 | 넓은 단어 조회수 총합 |
|---|---|---|
| 피부노화 | **노화** | **3,143만** |
| 빌라 | **부동산** | **5,777만** |

→ 더 넓은 단어가 모수(조회수)가 크다 → 더 넓은 풀을 끌어온다.

### 3-7·3-8) 반의어/부정어 (조회수 비교) — ★통찰
| 표현 | 조회수 총합 |
|---|---|
| 비거리 늘어납니다 | 3,516만 |
| **비거리 늘어나지 않습니다** | **8,912만** |
| 살 빠집니다 | 1억 |
| 살 안 빠집니다 | 1.6억 |
| **살 찝니다** | **2.8억** |

> **핵심 통찰**: **부정어·반의어가 긍정형보다 검색량이 더 클 수 있다.** "안 빠진다/살 찐다"가 "빠진다"보다 크다 → 무조건 긍정형으로 가지 말고 **뷰트랩 조회수로 판정**한다. (정리본 §3.4에 반영)

### 3-6) 웍 (넓은 단어)
| BEFORE | AFTER (모범) |
|---|---|
| 새로 구매한 카본 스틸 웍 길들이기(시즈닝)+첫 요리 | **프라이팬** 길들이기, 처음이면 이대로만 (웍 시즈닝) |

> "웍"(좁음) → "프라이팬/팬"(넓음)으로 모수 확장. 객관식 3-1·3-4·3-5·3-9는 **더 넓은 단어를 쓴 제목**이 정답.

## E. 연습문제4 — 4단계(수식어, 핫비디오) 해설

> 룰: 영상찾기-핫비디오에서 **수식어**를 찾아 붙인다. "알맞지 않은 것 고르기"는 **과장·허위/주제와 안 맞는 수식어**가 답.

예시(4-3): "성적을 향상시키는 방법"에 수식어
- ① 꾸준히 / ② 짧은 시간 안에 / ③ 가장 빠르게 / ④ 초고속으로
- "초고속으로"는 과장·부자연 → **알맞지 않은 수식어 후보**. (자연스럽고 데이터로 검증된 수식어만)

> 수식어 풀: 의외의·무섭게·전설적인·알리지 말라던·인생 걸고… (`20_research/keywords/뷰트랩_라이브러리/수식어/`에 수집).

## F. 연습문제5 — 방법1~4 종합 디벨롭 (35자 이내)

| # | BEFORE | AFTER (모범, ≤35자) |
|---|---|---|
| 5-1 | 셀프 스타일링 필수템!! 이것들만 있으면 충분하지!! | **이것만 있으면 미용실 안 가도 되는 셀프템** |
| 5-2 | 요즘 사기 괜찮은 신발들을 가져와봤습니다 | **요즘 안 사면 손해라는 신발 골라봤습니다** |
| 5-3 | 스텐팬 절대 눌어붙지 않는 가장 정확한 방법 | **스텐팬 눌어붙는 사람만 모르는 한 가지** |

> 적용: ② 쉬운 단어 → ③ 넓은 단어/반의어 → ④ 수식어 → ⑤ 답 숨겨 질문/궁금형. 모두 35자 이내.

## G. 연습문제6 — 키콘텐츠 → 풀링 제목 디벨롭

> 키콘텐츠(구매 전환)를 기반으로 그 앞단 **풀링** 주제를 찾고 제목을 디벨롭.

| # | 키콘텐츠 | 풀링 제목 디벨롭 (모범) |
|---|---|---|
| 6-1 | 문틀철봉, 철봉바 안전하고 문틀 손상없는 찐 가성비 추천 | **집에서 턱걸이, 문틀 안 부서질까 걱정된다면** / **방문에 철봉 달았다가 후회하는 이유** |
| 6-2 | 우리집 최강의 밀폐용기, 당신의 선택은?(밀폐용기 추천) | **냉장고 정리 안 되는 사람 공통점** / **반찬 금방 상하는 집의 결정적 차이** |
| 6-3 | 그래서 어떤 나무 도마를 쓸까요? | **나무 도마 곰팡이, 이렇게 쓰면 생깁니다** / **도마 하나 잘못 골라 생기는 일** |

> 풀링은 제품(철봉·밀폐용기·도마)을 **욕구·문제(운동 시작·정리·위생)**로 일반화 → 더 큰 풀. (정리본 §2 일반화 흐름)

## H. 실행문제 (과제 — 기획 고도화 단계)

> "4주차에 정한 풀링콘텐츠 5개의 제목을 디벨롭하시오." — **사용자 데이터(4주차 풀링 5개)가 필요**하므로 여기선 **작성 틀**만 제시. 실제 채움은 다음 기획 고도화에서.

| 풀링 | 문제인식 | 문제해결 | 기존 제목 | 디벨롭 제목(≤35자) |
|---|---|---|---|---|
| 풀링1 | | | | (8단계 적용) |
| 풀링2 | | | | |
| … | | | | |

내 키콘텐츠 주제(문제인식/문제해결)를 먼저 적고 → 각 풀링의 기존 제목을 **8단계(특히 ②③④⑤)**로 35자 이내 디벨롭.

## 정답 요약표

| 문항 | 정답 |
|---|---|
| 핵심개념1 | A=채널가치(③) · B=개인가치(②) |
| 핵심개념2 | A=콘텐츠 가치(③) · B=구매 가능성(④) |
| 핵심개념3 | A=제목(⑤) · B=클릭률(③) |
| 연습1 객관식 | 주제 다르거나 썸네일=제목(교차 불가)인 2개가 "부적절" |
| 연습2 객관식 | 더 쉬운 일상어(동의어) 쪽 |
| 연습3 객관식 | 더 넓은 단어 쓴 제목 / 조회수 데이터는 D표 |
| 연습4 객관식 | 과장·부자연 수식어가 "알맞지 않음" |
