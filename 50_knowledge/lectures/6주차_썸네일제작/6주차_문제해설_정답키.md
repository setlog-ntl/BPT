# 6주차 문제 해설·정답키 — 썸네일 제작

> ⚠️ 연습1·2·3은 **썸네일 이미지 보기**로 푸는 문항이라 텍스트만으로 정답을 특정할 수 없다. **클릭 이유 → 강화 이미지 선택의 판단 기준(원칙)**으로 해설한다. 핵심개념은 정답·근거 명시.

---

## A. 핵심개념문제 (정답 + 근거)

### 핵심개념1
보기: ①썸네일 ②클릭 ③문제 ④공감 ⑤답
문제: "썸네일의 실제 목표는 **(A)**을 만드는 것. 시청자가 겪는 문제를 딱 짚으면 시청자는 **(B)**을 하고 **(A)**을 하게 된다. 어떤 사람이 모였는가에 따라 (A)하고 싶은 매력적 썸네일이 달라진다."

- **A = 클릭(②)**, **B = 공감(④)**
- 근거: 정리본 §1 "썸네일의 목표 = 클릭, 핵심 = 공감". 문제를 짚음 → **공감** → **클릭**. 모인 사람(결)에 따라 매력적 썸네일이 달라진다(§4).

### 핵심개념2
보기: ①원고 ②주제 ③문제 ④이미지 ⑤문구
문제: "클릭률을 구성하는 2가지 요소는 **(A)**와 **(B)**. 일반적으로 좋게 만들면 그렇고 그런 썸네일. 시청자가 왜 클릭했을까를 강화하면 클릭률↑."

- **A·B = 이미지(④) · 문구(⑤)**
- 근거: 정리본 §2 "클릭률 2요소 = 이미지·문구(각 45%)". 그냥 좋게 X → **클릭 이유를 강화**해야 클릭률↑.

---

## B. 연습문제1 — 이미지 vs 텍스트 (비중 판단)

> 문제: 제목을 보고, 시청자가 **클릭한 이유의 비중이 이미지인지 텍스트인지** 판단. (① 이미지 / ② 텍스트)
> 판단 기준: **그 썸네일에서 클릭을 만든 핵심이 "보여준 장면(이미지)"인가, "써 있는 문구(텍스트)"인가.**

| # | 제목 | 클릭 이유 핵심 | 비중(원칙) |
|---|---|---|---|
| 1-1 | 스마트폰 화면캡쳐 제일 쉬운 방법 | "90%가 모르는 1초만에" 카피의 충격 | **텍스트** 우세 |
| 1-2 | 운동 해야 하는 이유 / 근감소증 | "71세"인데 근육질인 **장면(증거)** | **이미지** 우세 |
| 1-3 | 고관절 통증 완벽 회복 5가지 | 통증 부위 빨갛게 표시한 인체 **이미지** | **이미지** 우세 |
| 1-4 | 탈모 극복하는 법 완결판 | 정수리 탈모 **클로즈업(증거)** | **이미지** 우세 |
| 1-5 | 승무원이 알려주는 좌석 무료 업그레이드 | "무료로 받기" 혜택 **문구** | **텍스트** 우세 |

> 핵심: 정답보다 **"왜 클릭했는지(이미지인지 텍스트인지)를 판단하는 훈련"**이 목적. 증거를 보여주는 건(②증명) 이미지 우세, 혜택·충격 카피는 텍스트 우세.

## C. 연습문제2 — 클릭 이유 강화 이미지 고르기

> 문제: 제목의 **클릭 이유를 파악**하고, 그 이유를 **강화시켜주는 이미지**를 보기 ①~④ 중 선택.
> 선택 기준: **제목이 약속한 것의 시각적 증거·공감(②증명/④공감)**에 가장 가까운 이미지. 예쁜 이미지·무관한 이미지는 오답.

| # | 제목 | 클릭 이유 | 강화 이미지 방향(정답 원칙) |
|---|---|---|---|
| 2-1 | 뚱뚱할수록 남자들이 좋아하는 이유 | 통념 반전 + 본인 공감 | 통통한 인물이 **당당/사랑받는 장면** (155cm·100kg 인물컷) |
| 2-2 | 한달만에 13kg 감량 | 결과 증명 | **BEFORE 59kg → AFTER 46kg 비교**컷 |
| 2-3 | 47평 올수리 2800만원 | 가성비 충격 + 결과 | **완공된 거실 풀샷**(반전 결과) |
| 2-4 | 얼굴 10배 작아보이는 앞머리 | 변화 증명 | **앞머리 전/후 얼굴 비교**컷 |
| 2-5 | 청소년 여드름 없애는 법 | 공감(내 상태) | **여드름 난 청소년 피부 클로즈업** |
| 2-6 | 갱년기증후군 증상과 치료 | 공감 + 권위 | **증상 호소/전문가** 가 함께 보이는 컷 |
| 2-7 | 식당서빙 부업으로 월 400만원 | 부러움 + 증거 | **돈/수익 인증** 또는 본인 인물컷 |
| 2-8 | 틀어진 골반 교정하는 방법 | 공감(통증) | **골반 틀어짐을 짚어주는** 설명 컷 |

> 공통 원칙: **제목의 후킹 = 클릭 이유** → 그 이유를 **증명하거나 공감시키는** 이미지가 정답. "예쁜 사진"은 오답.

## D. 연습문제3 — 클릭 이유 → 이미지 묘사 → 찾기

> 4개 제목(뱃살/청소템/중년 패션/여드름)에 대해 **① 클릭한 이유 → ② 이미지 묘사 → ③ 이미지 찾기**(트레이너 제출).

| 제목 | ① 클릭 이유 | ② 강화 이미지 묘사(모범) |
|---|---|---|
| 하루 10분, 뱃살이 사라진다고요? / 일주일 -3kg 복근루틴 | 짧은 시간 + 결과 의심·궁금 | 뱃살 잡은 손 → 납작 복부 **전/후**, "10분" 타이머 |
| 살림 고수들이 꼭 쓰는 청소템, 저도 써봤어요 | 검증된 추천 + 본인 후기 | 실제 사용 장면 + **반짝이는 결과**(전/후 오염→깨끗) |
| 중년 뱃살 커버 패션 TOP3 | 공감(체형 고민) | 중년 인물의 **커버 전/후 실루엣** 비교 |
| 집에서 홈케어로 한달동안 여드름 박멸 꿀팁 | 공감 + 결과 | 여드름 피부 → 깨끗한 피부 **클로즈업 전/후** |

> 묘사 핵심: **클릭 이유(이득/공감)를 증명하는 전/후·클로즈업** 중심으로 묘사.

## E. 실행문제 (과제 — 기획 고도화 단계)

> "5주차까지 찾은 풀링콘텐츠 **5개 중 1개**를 선택해 **썸네일 이미지를 디벨롭**한 뒤, **미드폼(1분 이상 3분 이내) 영상**으로 만드시오."

작성 틀(사용자 데이터 필요 — 다음 기획 고도화에서 채움):

| 항목 | 내용 |
|---|---|
| 내 키콘텐츠 주제 | 문제인식 / 문제해결 |
| 풀링1~5 | 기존 제목 → 제목 디벨롭(5주차 8단계) |
| 선택한 풀링(예: 풀링2) | **썸네일 이미지 디벨롭**(6단계) + **디벨롭된 제목** |
| 산출 | 미드폼 1~3분 영상 1편 |

→ 제목은 5주차 8단계, 썸네일은 6주차 6단계 적용. 코워크 절차는 `10_system/guides/뷰트랩_주제발굴_디벨롭_가이드.md`.
