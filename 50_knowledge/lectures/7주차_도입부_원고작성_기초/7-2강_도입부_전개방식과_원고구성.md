# 7-2강 · 도입부 전개 방식과 원고 구성

## 한 줄 요약
**도입부는 내 분야 안에서 베끼면 차별성이 없어 개인가치 상승 속도가 떨어진다. 핫비디오 같은 *타분야*의 도입부 전개 방식을 차용해 내 채널에서만 볼 수 있는 영상을 만들어야 구독전환율이 올라간다. 원고는 나레이션·지문·카메라 움직임·오디오 네 가지 구성요소로 작성한다.**

---

## 1. 핵심 원칙 — 도입부는 "타분야에서 가져온다"

### 1.1 원칙 정리표

| 구분 | 같은 분야(내 분야)에서 참고 | 타분야(핫비디오 등)에서 참고 |
|---|---|---|
| 적용 난이도 | 쉬움 | 약간의 번역 작업 필요 |
| 차별성 | **낮음** | **높음** |
| 오리지널리티 | 낮음 | 높음 |
| 개인가치 상승 속도 | **느림 / 떨어짐** | **빠름** |
| 구독전환율 | 상대적으로 낮음 | 상대적으로 높음 |
| 결론 | ❌ 별로 좋지 못함 | ✅ 권장 |

### 1.2 이유 (강의자 논리)
- 같은 주제의 도입부를 그대로 참고하면 **이 채널에서만 볼 수 있는 영상**이 안 됨.
- "이 채널에서만 볼 수 있는 영상"이라야 **개인가치가 상승**한다.
- 개인가치가 상승해야 **구독전환율**이 올라간다.

> 정리: *"내 분야 적용은 쉬워서 자꾸 손이 가지만, 그게 쉬워질수록 채널의 차별성은 사라진다."*

### 1.3 타분야의 예 — 핫비디오
- 강의자는 **핫비디오** 같은 다른 분야의 도입부 연출을 참고 대상으로 제시.
- 핫비디오의 도입 연출 방식(예: 결과 선공개, 시간순 나열, 강한 비주얼 후크 등)을 **책 분야로 번역**해 적용한다.

## 2. 도입부 전개 방식 — 강의 예시 2종

> 강의자가 든 두 가지 예시. 둘 다 **타분야 연출 방식을 책 콘텐츠로 번역**한 사례로 해석.

### 2.1 ① 과거 이력 나열형 — "시간을 거슬러 보여주기"
**구조**: 과거부터 현재까지 시간순으로 보여줌.

**책 콘텐츠 적용 예시 (강의 원문)**:
```
5년 전 읽은 책 → 4년 전 읽은 책 → 3년 전 읽은 책
→ 2년 전 읽은 책 → 1년 전 읽은 책 → 지금 읽는 책
```

**작동 원리(해석)**:
- 시간의 누적 = 변화·성장의 시각화.
- 시청자는 "그래서 지금은 어떻게 됐는데?" 라는 궁금증을 갖게 됨.
- 7-1강의 정성적 목표("이후가 궁금해서 어쩔 줄 모르겠는 느낌")와 직결.

### 2.2 ② 결과 선공개형 — "결과 먼저 → 실제 모습"
**구조**: 결과를 먼저 보여준 뒤, 실제 내가 하는 모습으로 이어짐.

**책 콘텐츠 적용 예시 (강의 원문)**:
1. 결과를 먼저 보여주는 도입부 (예: 변화한 결과·성취)
2. 실제 내 모습을 보여줌 — 읽고 있는 책, 쓰고 있는 글 등

**작동 원리(해석)**:
- "이 결과를 만든 방법이 뭔데?" → 시청자가 본문으로 끌려 들어옴.
- 결과 + 진짜 모습(과정의 일부) → 신뢰감 + 호기심 동시 자극.

### 2.3 두 패턴의 공통점
- 둘 다 **시점을 비틀어** 호기심을 만든다.
  - 과거 이력형: 과거 → 현재
  - 결과 선공개형: 결과(미래) → 과정(현재)
- 둘 다 **타분야(핫비디오 류)의 연출 문법**을 책 분야로 번역한 것.

## 3. 원고 구성요소 — 4가지 필수 요소

원고는 다음 네 가지 요소를 모두 의식하며 작성한다. (단순 대본 텍스트만 쓰면 안 됨)

| 구성요소 | 의미 | 예시 표기 |
|---|---|---|
| **① 나레이션** | 말로 전달되는 **대사** | `"평생 책 한 권 안 읽던 사람이…"` |
| **② 지문** | 출연자/촬영자의 **동작 지시** | `(책을 들어 올린다)` `(카메라를 본다)` |
| **③ 카메라 움직임** | **촬영 방식** — 앵글, 무빙, 줌, 컷 전환 | `[클로즈업]` `[줌인]` `[로우앵글 → 페이스]` |
| **④ 오디오** | **현장음 / BGM** | `(BGM: 잔잔한 피아노 페이드인)` `(현장음: 책장 넘기는 소리)` |

### 3.1 왜 4종을 다 적어야 하는가 (해석)
- 도입부의 감정(궁금증·호기심)은 **말로만** 만들어지지 않음.
- 같은 나레이션도 **카메라 움직임 + 오디오**가 다르면 완전히 다른 도입부가 됨.
- 4종을 명시해야 **편집·촬영 단계에서 도입부 의도가 보존**된다.

### 3.2 원고 작성 포맷 (가이드 — `대본/_기획기준/`와 정합)
```
[타임코드]
나레이션: ...
지문: (...)
카메라: [...]
오디오: (...)
```

## 4. 사용자 본인 채널에 적용

### 4.1 도입부 전개 방식 적용 시안 (이북리더기·풀링 라인업 기준)

| 적용 패턴 | 책 분야 번역 시안 | 결 그룹 |

| 과거 이력 나열형 | "5년 전 한 권도 못 읽던 나 → … → 지금은 한 달에 N권" | ② 읽고 있는 사람 / ① 읽으려는 사람 |
| 결과 선공개형 | "(결과) 나는 지금 이렇게 살고 있다 → (실제) 매일 읽는 책 공개" | ② 읽고 있는 사람 |
| 과거 이력형 (이북리더기 버전) | "5년 전 종이책 30권 → 4년 전 → … → 지금 이북리더기 한 대" | ② 읽고 있는 사람 → 이북리더기 키 |
| 결과 선공개형 (이북리더기 버전) | "(결과) 책장이 비었다 → (실제) 이북리더기 하나로 모든 책" | ② 읽고 있는 사람 → 이북리더기 키 |
