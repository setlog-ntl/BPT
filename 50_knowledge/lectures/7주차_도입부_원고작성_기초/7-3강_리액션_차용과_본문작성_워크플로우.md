# 7-3강 · 리액션 차용 + 본문작성 워크플로우

## 한 줄 요약
**해외 유튜브(유명인사 인터뷰 등)를 *리액션·해석 방식으로 차용*하여 내 관점으로 재해석한다. 본문 작성은 [제목 번역 → 뷰트랩 검색 → 해외 영상 확인 → AI 해석·분석 → 원고화]의 5단계 워크플로우를 따르되, 원고는 그대로 옮기지 않고 "출처 명시 + 내 직접 경험 보강"으로 추가 가치를 얹어야 한다.**

---

## 1. 본문 작성의 핵심 아이디어 — "리액션 방식으로 차용 + 내 방식으로 해석"

### 1.1 무엇을 차용하는가
- 해외 유튜브 영상
- 유명인사 인터뷰 (예: **일론 머스크** 등)
- 주제 예시: "책을 읽어야 하는 이유"

### 1.2 어떻게 변환하는가
| 원본 | 변환 결과 |
|---|---|
| 해외 영상의 발언·관점 | 내 채널에서의 **리뷰** |
| 인터뷰 속 주장 | 내 **관점으로 재해석한 설명** |

> 핵심: *해외 콘텐츠를 인용하되, **내 관점**이 무게 중심이 되도록 한다.*

---

## 2. 본문 작성 5단계 워크플로우

> 7-2강에서 잡은 도입부 다음, **본문**을 만들 때의 표준 절차.

```
① 제목을 일본어/영어로 번역
   ↓
② 번역한 내용을 복사해서 뷰트랩 검색
   ↓
③ 해외 반응 좋은 유튜브 영상 확인
   ↓
④ AI 활용 — 맥락 맞는지 해석·분석
   ↓
⑤ 스크립트 복사 → 원고 생성
```

### 2.1 단계별 상세

| 단계 | 행위 | 산출물 |
|---|---|---|
| ① 번역 | 관련 제목·키워드를 일본어/영어로 변경 | 검색용 다국어 키워드 |
| ② 검색 | 번역 키워드를 복사해 뷰트랩에서 검색 | 해외 영상 후보 리스트 |
| ③ 확인 | 해외에서 반응 좋은 유튜브 골라냄 | 차용 후보 영상(상위 N개) |
| ④ 해석 | AI 활용해 해당 내용의 맥락이 맞는지 해석·분석 | 영상 요약 + 맥락 분석 노트 |
| ⑤ 원고화 | 영상 스크립트 복사 → 원고로 생성 | 본문 초안 |

### 2.2 7-1강과의 정량 도구 정합
- 7-1강의 **뷰트랩 활용 기준**(기여도·성과도·댓글수 ↑ + 광고·스팸·무관 댓글 필터링)을 ②~③ 단계에 그대로 적용.
- 해외 영상도 동일 기준으로 선별.

---

## 3. **원칙 — 절대 그대로 가져오지 않는다**

> 강의자가 명시적으로 강조한 원칙.

### 3.1 금지 사항
- 해외 영상 원고를 **그대로 복사·번역**해서 쓰는 것 ❌

### 3.2 필수 사항 — "차용 + 출처 + 보강"
원고는 다음 3요소를 반드시 갖춰야 한다.

| 요소 | 내용 |
|---|---|
| ① **차용** | 해외 영상의 관점·발언을 인용 |
| ② **출처 명시** | 해외 채널·인물·영상 정보를 분명히 밝힘 |
| ③ **추가 가치(보강)** | 내 관점·해석·**직접 경험**을 얹음 |

### 3.3 출처 명시 화법 (강의 원문 예시)
```
"일본의 고레가와 채널의 진 씨가 설명한 XXX 내용을 …"
```
형식 일반화:
```
"[국가/언어]의 [채널명]의 [인물]이(가) 설명한 [내용]을(를) …"
```

### 3.4 보강 화법 (강의 원문 예시) — 직접 경험 결합
```
"제가 영상에서 봤는데, 제가 해보니 이렇습니다."
```
형식 일반화:
```
"[해외 영상]에서 [차용 내용]을 봤는데,
 제가 [실제로 해본 행동/실험/적용]을 해보니 [경험 결과]이었습니다."
```

→ 단순 리액션·번역 채널이 아니라 **타인 콘텐츠 + 내 실행·검증·관점**의 결합이 되도록 한다.

## 4. 본문 작성 흐름 정리 (5단계 워크플로우 + 원칙 결합)

```
[다국어 키워드 번역]
     ↓
[뷰트랩 검색 — 해외 영상 후보 선별]
     ↓
[해외 반응 좋은 영상 확인]
     ↓
[AI로 맥락 해석·분석]
     ↓
[스크립트 복사 → 원고 초안]
     ↓
┌──────────────────────────┐
│ 원칙 적용:                │
│  ① 차용 (그대로 X)         │
│  ② 출처 명시               │
│  ③ 내 직접 경험 보강       │
└──────────────────────────┘
     ↓
[최종 본문 원고]
```

## 5. 사용자 본인 채널에 적용

### 5.1 8축 컨셉별 다국어 검색 키워드 시안

| 8축 컨셉 | 영어 키워드 | 일본어 키워드 |
|---|---|---|
| 책을 읽어야 하는 이유 | why you should read books | なぜ本を読むべきか |
| 책 읽는 방법 | how to read books effectively | 本の読み方 |
| 자기개발 | self improvement through reading | 読書 自己啓発 |
| 책 읽는 습관 | reading habits | 読書習慣 |
| 문해력 | literacy / reading comprehension | 読解力 |
| 지적허영심 | intellectual snobbery / appearing well-read | 知的見栄 |
| 지적호기심 | intellectual curiosity | 知的好奇心 |
| 책 읽는 재미 | joy of reading | 読書の楽しさ |

→ 위 키워드들로 뷰트랩 검색 → 해외 반응 좋은 영상 풀 구축.

### 5.2 차용 우선 후보 인물·채널 (강의자 예시 + 확장)
- **일론 머스크** — 독서·학습 관점 인터뷰 (강의 원문 언급)
- 일본 독서 채널 (예: "고레가와 채널" 패턴) — 강의 원문에 등장한 형태
- 추가 후보(해석): 워런 버핏·찰리 멍거(독서 권유), 빌 게이츠(연간 독서 리스트), 나발 라비칸트, TED 강연 중 독서 관련 등.

### 5.3 출처+보강 화법 적용 시안

| 차용 출처 | 차용 내용 | 보강(내 경험) |
|---|---|---|
| 일론 머스크 인터뷰 | "나는 책으로 로켓 만드는 법을 배웠다" | 나는 ___ 분야 책으로 ___을 해봤더니 ___ |
| 일본 ◯◯ 채널 ◯씨 | 매일 30분 독서 루틴 | 나는 14일 동안 ___을 해보니 ___ |
| ◯◯ 인터뷰 | "지적호기심이 인생을 바꾼다" | 내가 ___ 책을 펴면서 실제로 바뀐 점 ___ |

### 5.4 현재 작업물에 즉시 반영할 항목
- `대본/풀링컨텐츠/평생 안읽던 사람이 책을 읽기 시작하면 벌어지는 일/` 본문에 **해외 차용 + 출처 + 내 경험 보강** 구조가 들어가는지 점검.
- 이북리더기 시리즈(`docs/keycontent/video_plan_이북리더기_판매대본*.html`)에도 동일 원칙 적용 가능 여부 검토.

## 활용 체크리스트

### 워크플로우 진행 시
- [ ] ① 다국어 번역 키워드를 **영어·일본어 둘 다** 준비했는가?
- [ ] ② 뷰트랩에서 7-1강 기준(기여도·성과도·댓글수)에 부합하는 영상을 골랐는가?
- [ ] ③ 해외 반응(조회수·댓글 분위기)이 실제로 좋은지 확인했는가?
- [ ] ④ AI 해석·분석 결과가 **내 영상 맥락**과 정합하는가?
- [ ] ⑤ 스크립트를 원고화할 때 **그대로 복사가 아니라 차용**으로 가공했는가?

### 원고 완성 직전 점검 (3요소)
- [ ] **출처가 명시**되어 있는가? (국가·채널·인물·영상)
- [ ] **내 직접 경험**(보강)이 들어가 있는가? "제가 해보니 이렇습니다" 화법 또는 동등한 표현?
- [ ] **추가 가치**가 한 줄로 요약 가능한가? — "이 영상이 (출처)에 없는 무엇을 더하는가?"

### 윤리·법적 점검 (해석 — 강의 외 보강)
- [ ] 인용 분량이 과도하지 않은가? (저작권 — 정당한 인용 범위)
- [ ] 출처 표기가 영상 자막·설명란에도 들어가는가?
