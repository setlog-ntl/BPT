# 7주차 지시카드 — 도입부·원고작성 기초

> 이 문서는 **압축 요약**이다. 풀버전은 각 강 정리본을, 원문은 raw를 참고할 것.
> 다른 작업에 적용 지시할 때는 **§3·§4·§5의 카드만** 복사해 붙여도 동작하게 설계됨.

---

## 1. 한 줄 정의

> **원고는 「제목 → 썸네일 → 도입부 → 원고」 순서로 짜고, 도입부는 *타분야 차용*으로 차별화하며, 본문은 *해외 영상 차용 + 출처 명시 + 내 직접 경험 보강*의 3요소를 갖춘 뒤, *신뢰도 6가지 보강*(원리·내경험·원본캡처·국내사례·반론증거·전문가)으로 무게를 얹는다.**

---

## 2. 작업 순서 (필수)

```
제목 → 썸네일 → 도입부 → 원고
```

- 이 순서는 **원고 드리블**(전 주차 흐름)에 그대로 적용.
- 본문(원고)이 도입부보다 먼저 작성되면 → 도입부가 본문에 끌려가서 약해짐. **금지**.

---

## 3. 핵심 원칙 카드 (작업 지시 시 인용용)

### 원칙 1 · 정성 > 정량
- **이번 주차에서 가장 중요한 목표는 정성적 목표**.
- 도입부가 만들어야 할 감정: *"이후 내용이 궁금해서 어쩔 줄 모르겠는 느낌"*.
- 정량(뷰트랩)은 정성 감각을 잡은 뒤 **검증·확장** 용도.

### 원칙 2 · 정성 목표 검증 질문
> "내가 끝까지 본 영상의 도입부는, 정확히 어디서 내 마음을 움직였는가?"

이 질문에 답을 못 적으면 **도입부 기획 시작 금지**.

### 원칙 3 · 정량 도구 = 뷰트랩 + 댓글 필터링
| 선별 기준 (AND 조건) | 필터링 (제거 대상) |
|---|---|
| 기여도 ↑ | 광고성 댓글 |
| 성과도 ↑ | 스팸 댓글 |
| 댓글수 ↑ | 영상과 무관한 댓글 |

### 원칙 4 · 도입부는 타분야에서 차용한다
- 같은 분야(책·독서) 도입부 베끼기 → 차별성·개인가치·구독전환율 **모두 떨어짐. 금지**.
- 타분야(핫비디오 등) 도입부 차용 → 차별성 ↑ → 개인가치 ↑ → **구독전환율 ↑**.
- 슬로건: *"이 채널에서만 볼 수 있는 영상을 만들어야 개인가치가 상승한다."*

### 원칙 5 · 본문은 차용·출처·보강 3요소
> 해외 영상 그대로 옮기는 것 **절대 금지**.

| 요소 | 필수 행위 |
|---|---|
| ① 차용 | 해외 영상·인터뷰의 관점·발언을 인용 |
| ② 출처 명시 | "[국가]의 [채널]의 [인물]이 설명한 [내용]을…" 화법 |
| ③ 보강 | "제가 영상에서 봤는데, 제가 해보니 이렇습니다" 식의 **내 직접 경험** |

### 원칙 6 · 신뢰도 6가지 보강 (7-4강)
> 원칙 5의 3요소 본문 위에 **신뢰의 무게**를 얹는다.

| 코드 | 방법 | 비용 | 임팩트 | 즉시 적용 |
|---|---|---|---|---|
| ① | 원리/주의점 설명 | 낮음 | 높음 | ✅ |
| ② | 내 경험 ("내가 해보니 이렇더라") | 낮음 | 높음 | ✅ |
| ③ | 원본 영상 캡처·삽입 | 중간 | 높음 | 차용본 결합 |
| ④ | 국내 사례로 치환 | 중간 | 높음 | 자료 수집 후 |
| ⑤ | 반론 증거 (4종 세부) | 중간 | 매우 높음 | ✅ 5-1·5-3 우선 |
| ⑥ | 전문가 인터뷰 (히어로) | 매우 높음 | 매우 높음 | 풀 누적 후 |

**베이스 라인 (모든 본문 필수)**: ① + ② + ⑤
**확장 라인**: ③ + ④
**점프 라인** (히어로): ⑥

#### 방법 ⑤ 반론 증거 4종 세부
- **5-1) 쇼츠 댓글 수집** — 같은 주제 쇼츠 댓글에서 진짜 의문 추출 (광고·스팸·무관 필터링)
- **5-2) 유사 주제 영상** — 다른 채널의 비슷한 주장 영상 + 그에 대한 반론
- **5-3) 자문형 반론** — "내 영상의 가장 약한 고리는?" 스스로 답하기
- **5-4) "XX 하지 마세요" 영상** — 같은 주제의 금기·실패담·역효과 콘텐츠 분석

## 4. 패턴·구성요소 카드

### 4.1 도입부 패턴 카드 (2종 기본 + 확장 자유)
| 패턴 | 구조 | 책 분야 번역 예시 |
|---|---|---|
| **① 과거 이력 나열형** | 과거 → 현재 시간순 | 5년 전 책 → 4년 전 → ... → 지금 읽는 책 |
| **② 결과 선공개형** | 결과 → 실제 모습 | "(결과) 변화 후의 나" → "(실제) 매일 읽는 책 공개" |

**공통점**: 시점을 비틀어 호기심 생성. 둘 다 타분야 연출 문법의 책 분야 번역.

### 4.2 원고 4종 구성요소 카드 (필수 표기)
| 코드 | 구성요소 | 의미 | 표기 예 |
|---|---|---|---|
| N | 나레이션 | 대사 | `나레이션: "평생 책 한 권 안 읽던..."` |
| S | 지문 | 동작 지시 | `지문: (책을 들어 올린다)` |
| C | 카메라 | 촬영 방식·앵글·무빙 | `카메라: [클로즈업 → 줌인]` |
| A | 오디오 | 현장음·BGM | `오디오: (BGM 페이드인)` |

→ 도입부 30초는 **4종이 모두 채워져야** 통과.

### 4.3 본문 작성 5단계 워크플로우 카드
```
① 제목을 일본어/영어로 번역
   ↓
② 번역 키워드 → 뷰트랩 검색
   ↓
③ 해외 반응 좋은 유튜브 선별
   ↓
④ AI로 맥락 해석·분석
   ↓
⑤ 스크립트 복사 → 원고 생성
   ↓
※ 원칙 5(차용·출처·보강) 강제 적용
```

### 4.4 출처+보강 화법 템플릿
```
[차용]: "[국가/언어]의 [채널명]의 [인물]이(가) 설명한 [내용]을(를) …"
[보강]: "제가 영상에서 봤는데, 제가 [실제 행동/실험/적용]을 해보니 [경험 결과]이었습니다."
```

- [ ] **핫비디오** — 원문에는 "핫비도아"로 표기됨. 실제 채널·플랫폼 이름 확정 필요.
