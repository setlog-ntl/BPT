# 비즈니스PT 용어집

## 사용자의 전체 관점 (synthesis)
> 유튜브라는 가장 큰 시장에서 기획을 통해 단계별로 유입부터 판매까지의 전체 로직을
> 세분화하여 구분하고, 구분된 기준에 따라 목표 금액을 기반으로 역산해 기획·수치화하여,
> 부족한 수치를 개선하며 수익화한다.

### 첫 번째 목표
- 각 단계별 단위를 쪼개고, 쪼갠 단위별로 **수치화된 데이터**를 만들어내는 것.

### 기획 vs 제작 (방향이 정반대)
- **기획**: 수익화를 위한 아이템 선정 → 키 콘텐츠 → 풀링 콘텐츠 (역순)
- **제작**: 풀링 콘텐츠 먼저 → 키 콘텐츠 → 수익화 (정방향)

---

## 핵심 용어
| 용어 | 정의 |
|---|---|
| **아이템** | 내가 판매할 것. 가격·품질·브랜드·정보를 기반으로 소비자가 필요로 하는 것 |
| **단가 (P)** | 판매 단가 |
| **수량 (Q)** | 판매 수량 |
| **풀링 콘텐츠** | 제품을 구매할 만한 잠재고객을 모으는 콘텐츠 (홈화면·탐색 유입) |
| **키 콘텐츠** | 모집된 고객이 구매를 선택하게 만드는 콘텐츠 (목적 검색 유입) |
| **검색 서비스** | 네이버, 유튜브, 인스타, 쓰레드 등 |
| **랜딩페이지** | 키 콘텐츠에서 유입된 최종 고객이 아이템을 구매하는 페이지 |
| **홈화면** | 유튜브 기본 화면. 풀링 콘텐츠가 유입되는 화면 |
| **전환율** | 각 프로세스 단계별 전환 비율 |
| **클릭률** | 썸네일에서 영상을 클릭하는 비율 |
| **썸네일** | 홈화면에 보여지는 화면 (제목·이미지) |
| **도입부 유지** | 썸네일 클릭 후 시청 지속 시간 (30초 KPI) |
| **본문/원고** | 유튜브 영상의 내용·원고 |

## KPI 정의
### 정량 KPI
| 지표 | 목표값 |
|---|---|
| 클릭률 | 10% |
| 도입부 유지 (30초) | 60% |
| 시청 지속 시간 | 4분 (전체 대비 30%) |
| 영상 1편 조회수 | 1,000 뷰 |

### 정성 KPI
- 해당 주제에 대한 관심층의 **최소량** = 전체 파이.
- 사용자 주제: **AI**, **책**.
