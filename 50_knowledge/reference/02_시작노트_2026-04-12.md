# 시작 노트 (2026-04-12)

## 콘텐츠 유형과 역할
- **풀링 콘텐츠** → 고객 모집
- **키 콘텐츠** → 판매 발생
  - 구성 요소: **썸네일 + 본문 + 링크**

## 차별화 포인트 (사용자 자기 인식)
- **AI + IT + 책**의 결합.
  - 좌측 축: `linkmap` (AI/IT)
  - 우측 축: `책` (필사·독서)
  - 세부: AI · 바이브코딩 · IT · 필사·책 소개·책 Item

## 역량 매트릭스 (self-assessment)
| 영역 | 자평 |
|---|---|
| 전문성 | 중상 |
| 서비스 | 상 |
| 글쓰기 | 중 |
| 말 | 하 |

## 콘텐츠 3요소 매핑 (영상 ↔ 외부)
| 영상 내 요소 | 대응되는 외부 형태 |
|---|---|
| 썸네일 | 배너 |
| 내용 | 상세 페이지 |
| 댓글 | 결제 링크 |

## 영상 KPI (한 줄)
- 클릭률 / 도입부 유지 (30초) / 시청 지속 (30%, 4분)

## 광고 유형
- **프리롤** — 썸네일 클릭 직후
- **미드롤** — 8분 이상에서 중간
- **엔드롤** — 마지막

## 기획 vs 제작
- **기획** → 페이퍼 · 아이디어
- **제작** → 실행 · 촬영 · 편집 · 업로드

## 주제 × 채널 그래프
- Y축: 주제, X축: 채널.
- 주제 기반으로 채널 구분 → 홍보 강화.
- 디테일 주제에서 홈 추천으로 노출.
