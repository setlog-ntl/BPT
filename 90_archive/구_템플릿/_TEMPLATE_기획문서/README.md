## 0. 30초 사용법 (복붙 → 5스텝)

```
① 이 폴더 복사 → "NNN_<주제 제목>"으로 이름 변경 (예: 004_시간 없는 사람이 책 읽는 법)
② 정리본/00~05 를 위에서부터 채운다 (작업 순서 = 제목→썸네일→도입부→본문)
③ 뷰트랩·웹으로 05_뷰트랩_레퍼런스 채우기 (차용·출처·보강 근거)
④ 통합_기획서_템플릿.html → "통합_<주제>.html"로 복사 후 브라우저로 열어 편집(자동 저장)
⑤ 대본기획_기준.md §9-2 마감 7체크리스트로 검증 → 풀링컨텐츠 기획문서/README.md 표에 1행 등록
```

> ⚠️ `통합_*.html`은 **파일명 안에 고유 저장키**를 박아 쓰는 게 안전하다. 003 사례처럼 `<script>window.__BIZPT_LS_KEY__='bizpt:script:v3:NNN_<슬러그>';</script>`를 본문 스크립트 위에 한 줄 추가하면, 파일을 옮겨도 입력이 보존된다.

## 1. 폴더 구조 (표준)

```
NNN_<주제 제목>/
├── README.md                  ← 영상 진입점(이 영상 1줄 정의·결정·구조). 003 README 참고해 작성
├── 정리본/                     ← 기획 단일 진실 원천 (MD)
│   ├── 00_브리프.md              B1~B6
│   ├── 01_후크_제목_썸네일.md     제목 8단계 + 썸네일 6단계 + 30초 후크 N·S·C·A
│   ├── 02_본문_챕터.md           body 비트(메타포·근거·차용·출처·보강)
│   ├── 03_스토리_진정성.md        1인칭 고백·감정 코어
│   ├── 04_해결_결호명_CTA.md      해결 + 결 3그룹 호명 + CTA
│   └── 05_뷰트랩_레퍼런스_리서치.md 뷰트랩 데이터 표 + 인물·영상 레퍼런스
├── 통합_<주제>.html             ← 통합_기획서_템플릿.html 복사본(편집·자동저장)
├── 대본/                       ← 통합 대본(N·S·C·A) 작성 위치
├── 썸네일/  └ 참고자료/          ← 썸네일 시안·참고
├── 참조이미지/                  ← 챕터별 컷 이미지(00 + 챕터별 + EXTRAS_브롤)
└── 자료/                       ← 데이터·도서·영상 참고
```

> 챕터 수·이름은 주제에 맞게 가감(기본 후크 + 본문 2~4 + 스토리 + CTA = 5~8챕터, `대본기획_기준.md §8`).
