# 참조이미지 — 챕터별 컷 매핑 (템플릿)

> 정리본 챕터 ↔ 이미지 폴더. 컷 생성 시 각 폴더에 `프롬프트.md`를 두고 `cut_XX_*.png` 저장.
> 챕터가 정해지면 아래 표를 채우고, 챕터명에 맞춰 하위 폴더(`01_<주제>` 등)를 만든다.

| 폴더 | 정리본 | 핵심 컷 |
|---|---|---|
| `00_후크_미리보기/` | 01 | 후크 핵심 비주얼·미리보기 카드 |
| `01_<본문비트1>/` | 02 |  |
| `02_<본문비트2>/` | 02 |  |
| `03_<스토리>/` | 03 | 1인칭 고백 비주얼(페이스리스 권장) |
| `04_<해결>/` | 04 | 해결 아이콘 카드 |
| `05_결호명_CTA/` | 04 | 결 3그룹 트립틱 + 옆자리 |
| `EXTRAS_브롤/` | 공통 | 책장·페이지 넘김 등 브롤 |

> 색 토큰: `--pain`(빨강) · `--growth`/`--rec`(초록) · `--value`(노랑). 페이스리스(손·옆모습) 우선.
