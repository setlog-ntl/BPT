# 풀링 콘텐츠 기획문서 — 진입점

> 풀링 = 무목적 탐색으로 들어온 시청자에게 **변화·결과·메타포**를 던져 구독·신뢰를 축적하는 영상.
> 종착지는 직접 판매가 아니라 **다음 영상·구독·정신적 떡밥**.
>
> 🗂 **레거시 안내(2026-06-13)**: 채널이 **"AI보다 읽는 사람"**으로 전환됨(정체성 SSOT = `docs/채널정채성/AI보다 읽는사람.MD`). 이 폴더의 **이미 완성된 개별 풀링 대본(001~004 등)은 구 채널명("그럼에도 한 페이지") 시기 제작물로 본문 원형 보존**한다. **신규 풀링부터** 새 정체성(결 호명 = AI 안/못 쓰는·쓰고 있는·더 잘 쓰려는 / 6축 / 사인오프 "AI는 답을, 읽는 사람은 질문을.")을 적용한다.

## 새 풀링 콘텐츠 시작하기 (권장: 폴더 템플릿 복사)

1. **룰북 일독** — [`../../_기획기준/대본기획_기준.md`](../../_기획기준/대본기획_기준.md)
   - 채널 정체성 카드, 풀링 vs 키 차이, 결 호명·CTA 룰, 챕터 구조 표준 확인
2. **폴더 템플릿 통째로 복사** — [`../_TEMPLATE_기획문서/`](../_TEMPLATE_기획문서/) → `NNN_<주제 제목>`으로 이름 변경
   - 정리본 MD 스켈레톤(00~05) + 통합 HTML 템플릿 + 표준 하위폴더(대본·썸네일·참조이미지·자료)가 들어 있음. 사용법은 그 폴더 `README.md` 참조.
3. **정리본 → 통합 HTML 순으로 채움** — 작업 순서(제목→썸네일→도입부→본문). 통합 HTML은 브라우저로 열면 자동 저장.
   - 첫 적용 예시: [`../003_책 끝까지 안 읽어도 괜찮은 이유/`](../003_책%20끝까지%20안%20읽어도%20괜찮은%20이유/)

> HTML만 빠르게 쓰려면 빈 템플릿 [`../../_기획기준/template_풀링컨텐츠_기획서.html`](../../_기획기준/template_풀링컨텐츠_기획서.html)을 `통합_<주제>.html`로 복사해도 된다.

## 진행 중 풀링 콘텐츠

| 폴더 | 주제 | 상태 |
|---|---|---|
| `001_평생 안읽던 사람이.../` | 시야·사고·성장 3축 | 통합 HTML 슬림 v3, 챕터 자동저장 편집 중 |
| `002_독서습관 실패한 99%.../` | 입문자 실수 3공통점 | 롱폼 v1 완성 + **미드폼 기획 완료**(정리본 07) ★미드폼 1순위 |
| `003_책 끝까지 안 읽어도 괜찮은 이유/` | 완독 강박 버리기(P01·책 읽는 방법) | **기획 완료** — 정리본 7종 + 통합 HTML + 뷰트랩·레퍼런스 리서치(2026-06-06) |
| `004_책 많이 읽으면 돈벌수 있을까/` | 다독 신화 깨기(반론형·자기개발/결③ 더읽으려는) | **기획 완료** — 정리본 7종 + 통합 HTML(허브+자료 7) + 썸네일 참고 + 뷰트랩·레퍼런스(2026-06-08) |

> 번호 주의: 뱅크 문서의 "003 시드 = 책 많이 읽으면 돈"은 **구 매핑**. 폴더 번호 `003_`은 사용자 지정으로 **완독 주제(P01)**에 배정됐고, `책 많이 읽으면…`은 **`004_`로 배번**됨(2026-06-08).
