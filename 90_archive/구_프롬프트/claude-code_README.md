# Claude Code 사용 가이드 (bizpt 프로젝트)

> 이 폴더는 **Claude Code(CLI)**를 이 프로젝트에서 일관되게 활용하기 위한 가이드와 재사용 프롬프트 모음.
> 진입점은 항상 루트의 [`CLAUDE.md`](../../CLAUDE.md) — 이 파일은 그 보조 자료.

---

## 폴더 구조

```
docs/claude-code/
├── README.md                  ← 이 문서 (사용 가이드 + 인덱스)
└── prompts/                   ← 재사용 프롬프트 (작업 유형별)
    ├── 강의노트_정리.md
    ├── 풀링콘텐츠_기획서_생성.md
    ├── 키콘텐츠_기획서_생성.md
    ├── 콘텐츠_기획_검증.md
    ├── 외부_리서치.md
    └── readingtree_인덱스_갱신.md
```

---

## 사용법 (3가지 패턴)

### 패턴 A — 프롬프트 파일을 그대로 컨텍스트에 주입
Claude Code에서:
```
@docs/claude-code/prompts/강의노트_정리.md

이번에 정리할 자료: raw/2026-05-XX_4주차-1강/notes.md
```
프롬프트 파일이 작업 절차·산출물 형식·체크리스트를 모두 정의하고 있으므로, 사용자는 변수만 채워넣으면 됨.

### 패턴 B — 프롬프트를 읽게 한 뒤 자유 대화
```
@docs/claude-code/prompts/풀링콘텐츠_기획서_생성.md 를 참고해서, 
"AI 시대에 종이책을 굳이 읽어야 하는 이유" 주제로 풀링 콘텐츠 기획서 만들어줘
```

### 패턴 C — 새 프롬프트 추가
새로운 반복 작업이 생기면:
1. `prompts/<작업명>.md` 신규 작성
2. 기존 프롬프트의 구조(목적 / 입력 / 절차 / 산출물 / 체크리스트) 따라가기
3. 이 README와 `CLAUDE.md` §6의 프롬프트 인덱스에 추가

## 프롬프트 작성 표준 형식

모든 프롬프트는 다음 6개 섹션을 가진다:

```markdown
# <작업명>

## 목적
이 프롬프트가 무엇을 만들어내는가 (한 줄)

## 입력 (사용자가 제공)
- 변수 1: ...
- 변수 2: ...

## 사전 참조 (Claude Code가 먼저 읽을 문서)
- 프로젝트_방향성.md
- (작업별 추가 reference)

## 작업 절차
1. ...
2. ...

## 산출물 형식 / 저장 위치
- 어떤 형식의 파일을 어디에 저장하는가

## 완료 체크리스트
- [ ] ...
- [ ] ...
```

이 표준을 지키면 Claude Code가 일관되게 동작한다.
