# 썸네일 카피 생성 (Prompt 5)

## 목적
영상 제목 + 핵심 메시지를 받아 썸네일 텍스트 후보 3안을 생성.

## 입력 변수
- `영상제목`: (필수) 유튜브 업로드용 제목 후보
- `핵심메시지`: (필수) 한 줄 요지 (기획서 "한 줄 요지" 그대로)
- `타깃`: (필수) 페르소나
- `유형`: 풀링 / **키** / 랜딩 (기본 키)
- `책`: (선택) 중심 책
- `출력파일`: (필수) `04_썸네일/카피_초안.md` 절대 경로

## 산출물

`출력파일` 1개. 후보 3안 + 비교표 + 추천.

## 작업 절차

1. 유형별 썸네일 카피 원칙 적용:
   - **풀링**: 1줄, 6~10자, 호기심·반전. 책 제목보다 메시지 우선.
   - **키**: 2줄 가능, 1줄당 6~12자. 책 제목 + 핵심 메시지 조합.
   - **랜딩**: 약속(Benefit) + 구체 결과 또는 가격
2. 3안의 결을 의도적으로 다르게:
   - 1안: 직설적 (질문/명령)
   - 2안: 호기심 자극 (반전/숨김)
   - 3안: 감정 (공감/감탄)
3. 진정성 점검: 클릭베이트(과장·왜곡) 없는지 자가검증.

## 산출물 표준 포맷

```markdown
# 썸네일 카피 초안 — <영상 제목>

## 메타
- 영상 제목: <입력 그대로>
- 핵심 메시지: <입력 그대로>
- 유형: 키
- 타깃: <입력 그대로>

## 후보 3안

### 1안 (직설적)
**카피**: "왜 우리는 / 가짜로 살까"
- 줄 구성: 2줄 (위 5자 / 아래 5자)
- 강조 단어: "가짜" — 노란색 (#FFD700)
- 시각 요소: 책 표지 우측, 인물 실루엣 좌측

### 2안 (호기심)
**카피**: "100년 전 / 헤세가 던진 질문"
- 줄 구성: 2줄
- 강조: "100년 전" — 빨간색
- 시각: 빈티지 종이 질감 배경

### 3안 (감정)
**카피**: "나는 누구인가, / 진짜로"
- 줄 구성: 2줄
- 강조: "진짜로" — 흰색 + 외곽선 굵게
- 시각: 거울에 비친 인물 (스톡 이미지)

## 비교표

| 안 | 결 | 강점 | 약점 | 클릭베이트? |
|---|---|---|---|---|
| 1안 | 직설 | 메시지 즉시 전달 | 단순할 수 있음 | ✗ |
| 2안 | 호기심 | 독서 관심층 강하게 자극 | 책 모르면 약함 | ✗ |
| 3안 | 감정 | 감정적 공감 | 구체성 부족 | ✗ |

## 추천
**2안** — 책+질문 구조라 키 영상 본문(헤세 분석)과 결이 맞고, 타깃이 책 검색하는 직장인이라 책 언급이 신뢰 형성에 유리.

```

## 체크리스트 (출력 전 자가검증)
- [ ] 3안의 결이 모두 다른가
- [ ] 카피 글자수가 유형 권장 범위 내인가
- [ ] 클릭베이트 점검 통과했는가
- [ ] 추천 안에 추천 이유가 1~2줄 명시되어 있는가
- [ ] 시각 요소가 자산 라이브러리에 있거나 신규 제작 가능한가
