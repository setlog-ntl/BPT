# 키 스크립트 생성 (Prompt 3)

## 목적
키(본 영상) 콘텐츠의 챕터 개요를 받아 시간코드 포함 최종 스크립트를 생성.

## 입력 변수
- `기획서`: (필수) `00_기획서.md` 경로 — 챕터 구조 포함되어 있어야 함
- `자료폴더`: (선택) `02_자료수집/` 경로
- `출력파일`: (필수) `01_스크립트.md` 절대 경로
- `목표길이`: (필수, 분 단위, 기본 10) 8~15분 권장
- `톤`: 차분 / **친근** / 분석적 / 강의형 (기본 친근)

## 산출물

`출력파일` 1개. 챕터별 분리, 각 줄에 시간코드.

## 작업 절차

1. 기획서의 챕터 4~6개 확인. 챕터마다 핵심 메시지 1줄·마이크로 CTA 1개 있는지 점검.
2. 챕터별 시간 배분: 인트로 30초 / 챕터(균등 또는 강조 챕터+30%) / 아웃트로 60초.
3. 각 챕터 작성 시:
   - 첫 5초: **챕터 후킹** (다음 챕터로 안 넘어가게)
   - 본문: 자료폴더 인용·통계 적극 활용 (인용 ID로 cross-reference)
   - 마지막 5~10초: **마이크로 CTA** (좋아요/댓글/다음 챕터 예고 중 1)
4. 톤 적용:
   - 친근: "~예요/~네요", 비유·일상 예시
   - 차분: "~입니다", 인용 위주, 여백 있는 호흡
   - 분석적: 숫자·구조 위주
   - 강의형: "오늘 배울 것은", "정리하면"
5. 시간코드는 **5~10초 단위**로 표기 (편집 시 위치 잡기 쉽게).

## 산출물 표준 포맷

```markdown
# 스크립트 — <영상 제목>

## 메타
- 총 길이 목표: 10분 (600초)
- 챕터: 5개
- 톤: 친근

## 0:00–0:30 인트로
[화면: 책 표지 + 타이틀 자막]
"안녕하세요, 오늘은 <주제>를 같이 풀어볼 거예요.
제가 이 책을 읽으면서 가장 충격이었던 게 뭐냐면…
[3초 멈춤 — 후킹]
바로 1장에서 나오는 이 한 문장이었어요."
[자막: 인용 1 (자료폴더/인용.md #1)]

## 0:30–2:30 챕터 1: <챕터 제목>
### 0:30–0:40 챕터 후킹
"먼저, 우리가 흔히 오해하는 게 하나 있어요…"
### 0:40–2:00 본문
...
### 2:00–2:30 마이크로 CTA
"여기까지 공감되셨다면 좋아요 한 번 눌러주시고,
다음 챕터에서는 <챕터 2 제목>을 볼게요."

## 2:30–4:30 챕터 2: ...
...

## 9:00–10:00 아웃트로
"오늘 정리해보면…
[3가지 핵심 자막]
이 책을 직접 읽어보고 싶으시면 댓글에 한 줄 남겨주세요.
다음 영상에서 <다음 주제> 다룰게요. 구독 부탁드립니다."

## 자료 인용 매핑
| 시간 | 자료 ID | 출처 |
|---|---|---|
| 0:25 | 인용 #1 | 데미안 본문 8장 |
| 1:15 | 통계 #2 | 한국출판마케팅연구소 2024 |
| ... | ... | ... |
```

## 체크리스트 (출력 전 자가검증)
- [ ] 챕터 수 4~6개인가
- [ ] 각 챕터에 후킹·본문·마이크로 CTA 모두 있는가
- [ ] 시간코드 합산이 목표 길이와 ±10% 이내인가
- [ ] 인용·통계가 자료폴더 ID로 추적 가능한가
- [ ] 톤이 처음부터 끝까지 일관된가
- [ ] 한 문장 길이가 너무 길지 않은가 (낭독 가능한 호흡)
