# 풀링 기획서 생성 (Prompt 2)

## 목적
주제·책·타깃 정보를 받아 풀링(쇼츠) 영상의 기획서(`00_기획서.md`)를 생성.

## 입력 변수
- `주제`: (필수) 영상 주제 한 줄
- `책`: (선택) 중심 책
- `타깃`: (필수) 페르소나 — "20~30대 자기성찰 키워드 검색하는 직장인" 같은 형식
- `출력폴더`: (필수) `03_프로젝트/<폴더>/` 절대 경로
- `자료폴더`: (선택) 사전에 자료수집된 `02_자료수집/` 경로 (있으면 활용)
- `템플릿`: (선택, 기본 `풀링_쇼츠_v1`) 적용할 템플릿 ID
- `길이`: 30 / **45** / 60 (초, 기본 45)

## 산출물

`출력폴더/00_기획서.md` 1개 파일.

## 작업 절차

1. `자료폴더`가 있으면 인용·통계 먼저 스캔 → 후킹 후보 3개 추출.
2. 풀링 표준 구조 적용:
   - **0~3초 후킹**: 의문문/충격 사실/반전 진술 중 1
   - **3~30초 본론**: 핵심 메시지 1개 (절대 2개 이상 금지)
   - **30~45초 CTA**: 다음 행동 명확하게 (구독/링크/다음 영상)
3. bizpt 의사결정 체크리스트 적용 (`../../00_방향성.md` §7):
   - 풀링/키/랜딩 구분: 풀링 ✓
   - 수익화 종착지 명확? — CTA에 명시
   - 책 진정성? — 후킹과 결론에 책 인용 1회 이상
   - readingtree 연결 여지? — 있으면 CTA에 부드럽게 녹임
4. 사용 템플릿 ID와 예상 자산 ID 후보 기재.

## 산출물 표준 포맷

```markdown
# 기획서 — <영상 제목>

## 메타
- 유형: 풀링 (쇼츠)
- 길이 목표: 45초
- 종횡비: 9:16
- 적용 템플릿: 풀링_쇼츠_v1
- bizpt 본 프로젝트 연결: (해당 docs/keycontent/ 기획서 링크 또는 N/A)

## 타깃
- 페르소나: <입력 그대로>
- 검색·시청 맥락: <어떤 상황에서 이 영상을 만나는가 1~2줄>

## 한 줄 요지
<영상 끝나고 시청자 머릿속에 남길 한 문장>

## 후킹 (0~3초)
- 후킹 카피: "<실제 첫 자막 텍스트>"
- 후킹 영상: 비롤 후보 ID 또는 직접 촬영 지시
- 효과음: 효과음-XXX (or 신규 필요)

## 본론 (3~30초)
- 핵심 메시지: <한 문장>
- 구성:
  - 3~10초: <소절 1>
  - 10~20초: <소절 2>
  - 20~30초: <소절 3>
- 주요 인용/통계: 02_자료수집/인용.md #1, 통계.md #2

## CTA (30~45초)
- 행동: <구독 / 링크 클릭 / 다음 영상>
- CTA 카피: "<실제 마지막 자막>"
- 자산: 아웃트로-XXX

## 사용 자산 후보
| 카테고리 | ID 후보 | 이유 |
|---|---|---|
| 배경음악 | 배경음악-XXX | 분위기 태그 매칭 |
| 인트로 | 인트로-XXX | - |
| 아웃트로 | 아웃트로-XXX | - |
| 효과음 | 효과음-XXX, 효과음-YYY | - |

## 진정성 체크
- 책과의 연결: <어떻게 진정성 살아있는지 1줄>
- 클릭베이트 점검: <과장 표현 없음 / 있다면 수정 필요 항목>

## 다음 단계
- [ ] 사용자 검토 (후킹/CTA 적절성)
- [ ] 검토 통과 시 → 04_프롬프트/캡컷_패키지_생성.md 진행
```

## 체크리스트 (출력 전 자가검증)
- [ ] 핵심 메시지 1개로 좁혀졌는가 (2개 이상이면 분리)
- [ ] 후킹 카피가 첫 3초 안에 호기심을 자극하는가
- [ ] CTA가 구체적인가 ("좋아요 눌러주세요" X, "댓글에 책 1권 남겨주세요" O)
- [ ] 사용 자산 후보가 카탈로그에 실제 존재하는가 (없으면 신규 등록 필요 표기)
- [ ] 진정성 체크 통과했는가

## 사용법

```
@자동화편집/04_프롬프트/풀링_기획서_생성.md 를 따라
- 주제: "데미안의 자기 발견 3단계"
- 책: "데미안 — 헤르만 헤세"
- 타깃: "20~30대 자기성찰 키워드 검색하는 직장인"
- 출력폴더: 자동화편집/03_프로젝트/2026-05-10_풀링_데미안_3분요약/
- 자료폴더: 자동화편집/03_프로젝트/2026-05-10_풀링_데미안_3분요약/02_자료수집/
- 길이: 45
로 기획서 생성해줘
```
