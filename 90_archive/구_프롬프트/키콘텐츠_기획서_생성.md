# 키 콘텐츠 기획서 생성

## 목적
**판매를 만드는** 목적 검색 유입형 콘텐츠 1편의 기획서를 작성. 풀링과 다르게 **상품/서비스로의 전환이 명시적**이어야 한다.

## 입력 (사용자가 제공)
- **타깃 상품/서비스** (필수): 예) "킨들 페이퍼화이트" / readingtree 프리미엄 / 큐레이션 책 패키지 등
- **유입 검색 키워드 가설** (1~5개): 예) "전자책 단말기 추천", "킨들 vs 크레마"
- **연결될 풀링 콘텐츠** (있다면): 어디서 흘러올 시청자인가

## 사전 참조 (이 순서로)
1. `CLAUDE.md` (루트)
2. `프로젝트_방향성.md` §3, §5(3-Asset), §6, §6.4
3. `docs/lectures/3주차_키콘텐츠_기획/` — 3주차 정리본
4. `docs/item/` 아이템 선정·시장성·단가 자료 — **반드시 참조** (어떤 상품을 키 콘텐츠로 다룰지의 근거)
5. `docs/keycontent/` 기존 키 콘텐츠 산출물 — 톤·형식 일관성
6. `docs/reference/readingtree_연계.md` — readingtree로의 전환 동선 가능성

## 작업 절차
1. **상품/서비스 평가** — `docs/item/`에서 해당 상품의 시장성·단가·선정 이유 확인. 데이터 없으면 사용자에게 보완 요청.
2. **검색 키워드 가설 검증**:
   - 키워드별로 시청자의 검색 의도 분류 (정보형 / 비교형 / 구매검토형)
   - 1편 콘텐츠가 다 커버할 수 없으면 **시리즈로 분할** 제안
3. **기획서 작성**:
   - **한 줄 정의** + **타깃 상품**
   - **타깃 시청자의 구매 여정 단계** (인지/검토/결정 중 어디인가)
   - **후크/제목 후보 5개** — 검색 키워드를 자연스럽게 포함
   - **핵심 비교/추천 포인트 3~5개**
   - **3-Act 구조** (문제 제기 → 옵션 비교 → 추천 + CTA)
   - **상품 노출 방식** (어떤 단계에서, 어느 강도로)
   - **CTA / 랜딩 동선** — 어느 페이지·링크로, 어떻게 전환을 측정할 것인가
   - **수익 가설** — 단가 × 예상 전환율 × 예상 트래픽 (역산 KPI 1주차 강의 적용)
   - **예상 길이·포맷·썸네일**
4. **3대 기둥 정렬 점검** — 특히 ② 책 진정성을 잃지 않는 추천인지 확인.
5. **저장**: `docs/keycontent/키_<상품slug>_<제목slug>.md`.

## 산출물 형식 / 저장 위치
- **경로 (markdown)**: `docs/keycontent/키_<상품slug>_<제목slug>.md`
- **경로 (HTML, SPA용)**: 필요 시 `.html` 추가
- **프론트매터**:
  ```markdown
  ---
  유형: 키 콘텐츠 기획서
  제목: <제목>
  타깃 상품/서비스: <상품명>
  검색 키워드: [키워드1, 키워드2, ...]
  연결 풀링: <있다면 풀링 파일 경로>
  랜딩: <랜딩 페이지 경로 또는 외부 URL>
  작성일: 2026-XX-XX
  ---
  ```

## 완료 체크리스트
- [ ] `docs/item/`의 상품 선정 근거(시장성·단가)와 일치하는가
- [ ] 시청자 구매 여정 단계가 명확히 정의되었는가
- [ ] 단순 추천이 아닌 **비교·맥락**이 있는가 (전문성 축)
- [ ] CTA가 단일 명확 동선인가 (CTA 분산 금지)
- [ ] 수익 가설(단가 × 전환율 × 트래픽) 역산이 들어갔는가
- [ ] 책에 대한 진정성·결이 살아있는가
- [ ] 풀링 콘텐츠 또는 검색에서 어떻게 도달할지 유입 경로가 그려졌는가
