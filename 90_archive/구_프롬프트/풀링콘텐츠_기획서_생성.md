# 풀링 콘텐츠 기획서 생성

## 목적
**고객을 모으는** 무목적 탐색 유입형 콘텐츠 1편의 기획서를 작성. 단발 영상이 아닌 **시리즈/풀의 한 조각**으로서 설계.

## 입력 (사용자가 제공)
- **주제 후보** (1~3개): 예) "AI 시대에 종이책을 읽어야 하는 이유"
- **연결될 키 콘텐츠 / 상품** (있다면): 예) "전자책 단말기 추천 시리즈" / readingtree
- **참고 책** (1~3권): 풀링 콘텐츠가 인용·녹여낼 책

## 사전 참조 (이 순서로)
1. `CLAUDE.md` (루트)
2. `프로젝트_방향성.md` §3(3대 기둥), §5(3-Asset), §6(체크리스트), §6.4(우선순위)
3. `docs/lectures/4주차_풀링콘텐츠_기획/` (해당 주차 정리본 — 학습 진도에 따라 추가)
4. `docs/keycontent/` 기존 산출물 — 톤·후크 일관성 참고
5. `docs/reference/readingtree_연계.md` — readingtree 후킹 가능 여부 점검

## 작업 절차
1. **위 후보 주제 평가** — 6.1 체크리스트 5개 적용, 가장 적합한 1개 선택 (사용자 확인).
2. **기획서 작성**:
   - **한 줄 정의**: 이 콘텐츠가 무엇이고 누구에게 무엇을 주는가
   - **타깃**: 누가 이 영상을 클릭하는가 (탐색 동기·페인 포인트)
   - **후크/제목 후보 5개**
   - **핵심 메시지** (시청 후 남는 한 문장)
   - **3-Act 구조** (도입·전개·마무리)
   - **삽입 책·인용** (어디서 어떻게)
   - **CTA / 다음 흐름** (어느 키 콘텐츠·랜딩으로 가는가)
   - **예상 길이·포맷** (롱폼/숏폼/카드뉴스 등)
   - **썸네일 컨셉 1줄**
   - **3-Asset 모델 내 위치**: 풀링 → 어떤 키 콘텐츠로 연결되는가
3. **3대 기둥 정렬 점검** — ① 강의 개념 적용 / ② 책 진정성 / ③ readingtree 연결 가능성.
4. **저장**: `docs/keycontent/풀링_<제목slug>.md` 또는 `.html` (HTML이 SPA에 들어갈 경우).

## 산출물 형식 / 저장 위치
- **경로 (markdown)**: `docs/keycontent/풀링_<제목slug>.md`
- **경로 (HTML, SPA용)**: `docs/keycontent/풀링_<제목slug>.html` — SPA에서 보여줄 경우만
- **프론트매터**:
  ```markdown
  ---
  유형: 풀링 콘텐츠 기획서
  제목: <제목>
  연결 키 콘텐츠: <있다면 해당 키 콘텐츠 파일 경로>
  연결 상품/서비스: <readingtree / 전자책 단말기 / 책 ...>
  작성일: 2026-XX-XX
  ---
  ```
