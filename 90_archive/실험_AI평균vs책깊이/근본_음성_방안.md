# 근본적으로 다른 음성 적용 방식 — 4가지 카테고리

지금까지 우리는 **카테고리 1 (오픈소스 무료 TTS)** 안에서 모델·파라미터·후처리만 바꿨습니다. 천장이 보입니다. 진짜 도약은 카테고리를 바꾸는 것.

## 카테고리 1 (지금까지 시도) — 오픈소스 무료 TTS

Edge TTS · XTTS-v2 · MeloTTS · rubberband 피치 처리 · ffmpeg 마스터링.

**천장**: 자연스러움 7~8/10. Edge는 낭독체 한계, XTTS는 한국어 발음 약함, MeloTTS는 한 화자뿐. 후처리로는 본질이 안 바뀜.

---

## 카테고리 A — 사람 목소리 (본인 또는 성우)

자연스러움 10/10 (그게 사람 목소리니까). 무료~소액.

### A1. 본인 녹음 + AI 후처리
- 스마트폰으로 10분 대본 녹음 (~10분 작업)
- **Adobe Enhance Speech (무료)**: 녹음을 스튜디오 품질로 변환. 2024년 출시한 Adobe 무료 도구. https://podcast.adobe.com/enhance
  - 노이즈 제거·EQ·컴프 자동 적용
  - 30분/월 무료
- 결과를 영상에 입힘
- **품질**: 9/10 보장. 본인 톤이 영상의 진정성 부여.

### A2. 크몽/숨고에서 성우 의뢰
- 한국어 성우 단가: 1000자당 1~3만원
- 우리 대본 ~2700자 = 3~8만원
- 24~48시간 납품
- **품질**: 9.5/10. 진짜 성우.

### A3. 무료 한국어 음성 라이브러리 검색
- AI Hub (정부 운영) 한국어 발화 데이터셋 활용 — 단, 짧은 문장 단위라 영상에 직접 못 씀
- 유튜브 크리에이터 커먼스 보이스 풀 — 일부 무료

---

## 카테고리 B — 한국어 특화 상용 TTS 무료 체험

자연스러움 9~9.5/10. 무료 체험 충분.

### B1. **NAVER Clova Voice / Dubbing** (★ 권장)
- https://clovadubbing.naver.com 또는 https://www.ncloud.com (Voice API)
- 무료 체험: **30일 + 매월 5분 무료**
- 보이스: "선중", "승호", "미진", "아라" 등 한국어 1위 자연스러움
- 우리 영상 7~10분 = 한 번 무료 체험 안에 가능
- API 키 → tts_gen_clova.py 만들면 우리 파이프라인 그대로 사용

### B2. **Typecast (한국 스타트업)**
- https://typecast.ai
- 무료 등급 매월 5분
- 캐릭터 + 감정 슬라이더 ("차분", "신뢰", "활기" 등)
- "지환", "한길" 같은 캐릭터 보이스
- 웹 UI에서 mp3 다운로드 → 우리 파이프라인 투입

### B3. **Vrew (Voyagerx, 한국)**
- https://vrew.voyagerx.com
- **완전 무료** (무료 등급 = 무제한 한국어 TTS)
- 동영상 편집기 안에 한국어 AI 보이스 내장
- 영상에 자막 + AI 음성 자동 입힘
- 우리 대본 텍스트 붙여넣기 → mp3 추출

### B4. **ElevenLabs Multilingual v3 (2025)**
- https://elevenlabs.io
- 무료 등급: 매월 10분 (우리 영상 한 번 가능)
- 한국어 v3는 강세·감정·강조 자동 추정 SOTA
- 음질 9.5~10/10

## 카테고리 C — AI 보이스 컨버전 (RVC / SoVITS)

기존 TTS 음성을 다른 사람 목소리로 변환. 자연스러움 8.5~9/10.

### C1. RVC (Retrieval-based Voice Conversion)
- 30초~1분 짜리 reference 음성으로 모델 학습
- 기존 Edge TTS 출력을 그 사람 목소리로 변환
- **장점**: 발음·발음규칙은 Edge TTS의 정확도 유지, 음색만 바뀜
- **단점**: GPU 권장(CPU 가능하지만 느림)·세팅 복잡

### C2. OpenVoice v2 (2024)
- 보이스 클로닝 + 감정 컨트롤
- pip 설치 가능, 모델 1GB 다운로드
- XTTS보다 한국어 잘 됨

---

## 카테고리 D — 신규 오픈소스 모델

### D1. GPT-SoVITS
- 2024년 후반 등장
- 5초 reference 오디오로 보이스 클로닝
- 한국어 fine-tune 모델 커뮤니티에 다수 존재
- 설치 복잡(GPU 권장)

### D2. F5-TTS
- 2024 Microsoft Research, 매우 자연스러움
- CPU 가능, 한국어 지원

### D3. NaturalSpeech 3 (Microsoft)
- 미공개 (논문만), 코드 일부 공개
