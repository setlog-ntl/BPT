# V7 — 한국어 발음 개선 기획서

## 진단: 왜 V6 (XTTS-v2) 발음이 어눌한가

XTTS-v2는 **다국어 모델**입니다. 16개 언어를 한 모델이 처리하느라:
- 한국어 음운 규칙(받침 연음, 경음화, ㅎ 약화) 미흡
- 한국어 어절 단위 자연스러운 운율 약함
- 영어 알파벳·외래어 발음에 영미식 억양 섞임 ("ChatGPT", "AI")

**한국어 전용 monolingual 모델**로 가야 진짜 자연스러운 발음.

## 권장: MeloTTS Korean

이유:
- **한국어 전용 학습** → 발음 정확도 압도적으로 좋음
- VITS 아키텍처 → 빠르고 자연스러움
- KSS 데이터셋 → 한국 여성 표준 발음
- CPU에서 빠름 (씬당 5초 이내)
- 라이선스 자유 (MIT)

## 구현

1. GitHub에서 MeloTTS 설치 (PyPI에 없음)
2. `melo` 모듈 사용 → `from melo.api import TTS; TTS(language='KR', device='cpu')`
3. 38씬 합성 (총 5분 이내)
4. 기존 슬라이드/이미지/마스터링 그대로 사용 (재생성 불필요)
5. 합성 → V7 영상

예상 시간: 5분 설치 + 5분 합성 + 5분 ffmpeg = **총 15분**.
