# 무료 한국어 음성 고도화 — 심화 기획서 v2

V4(InJoon + 마스터링)의 한계를 어디까지 끌어올릴 수 있는지, 무료 영역만으로 검토.

---

## 1. V4가 여전히 부자연스러운 본질적 이유

**문제의 뿌리**: Edge TTS의 한국어 모델은 "한 덩어리 텍스트를 균일한 prosody로 통째 읽는 낭독체"로 학습됨. 우리가 평문 1문단을 던지면, 그 안의 모든 문장이 **같은 음정 곡선·같은 속도·같은 강세 패턴**으로 재생됨.

진짜 사람은:
- 첫 문장 "솔직히, 요즘 책을 굳이 읽어야 하나 싶죠." → 살짝 위로 올라가는 톤 (생각 던지기)
- 다음 문장 "ChatGPT한테 한 줄이면 5분이면 끝나잖아요." → 평행 톤 (예시)
- 세 번째 "그런데..." → 톤 갑자기 살짝 낮아지면서 늘어짐 (반전 신호)
- 핵심 키워드 "독서" → 1.3배 길이로 늘이면서 살짝 큰 음량
- 문장 끝 "더 많이." → 강한 closure, 톤 하강

V4는 이 모든 변동을 0으로 깔고 균일하게 재생함. **씬 단위로 한 번에 합성하는 한 이 한계는 깰 수 없음.**

## 3. 옵션별 상세 설계

### T1. 문장 단위 분리 합성 + 컨텍스트 prosody (★★★★★)

**아이디어**: 씬당 1 mp3를 → 씬당 N개 문장 mp3로 분해. 각 문장에 다른 rate/pitch 적용. 적절한 호흡으로 이어붙임.

**규칙 매트릭스** (자동 적용):

| 문장 유형 | 조건 | rate | pitch | 후속 호흡 |
|---|---|---|---|---|
| 의문문 | 끝이 `?` | -8% | 끝부분 +5Hz 효과 (별도) | 600ms |
| 짧은 임팩트 | <20자 평서문 | -10% | +0Hz | 500ms |
| 일반 평서문 | 20~40자 | -3% | +0Hz | 350ms |
| 긴 설명 | 40자+ | +0% | +0Hz | 400ms |
| 새 챕터 첫 문장 | 씬의 1번째 문장 | -5% | +3Hz | 350ms |
| 정리·결론 문장 | "정리하면", "결국" 시작 | -8% | -2Hz | 700ms |
| 핵심 문구 | scene.big1/big2 포함 | -12% | +0Hz | 500ms (앞 멈춤 +200ms) |

**구현 단계**:
1. `tts_gen.py` 재설계: 씬 단위 → 문장 단위 + 룰 적용
2. 각 문장 mp3를 `audio/scene_XX_S01.mp3`, `S02.mp3`... 로 저장
3. compose 단계에서 씬당 mp3들을 순차 concat (적절 호흡 silence 삽입)
4. 결과적으로 씬 1개 → mp3 N개 → 합쳐서 단일 씬 mp3

**예상 합성 시간**: 38 씬 × 평균 2.5 문장 = 95개 호출. Edge TTS 호출당 2~3초. 총 **약 5분**.

**잠재 부작용**: 문장 사이 톤 매칭이 살짝 어색할 수 있음. → T5의 boundary smoothing으로 완화.

---

### T5. 음성 휴먼화 후처리 (★★★)

**아이디어**: AI 티의 핵심은 "너무 깨끗함". 사람 녹음에는 미세 노이즈·피치 jitter·호흡이 있음. 의도적으로 그걸 부여.

**구체 처리** (ffmpeg + sox 필터 체인):

1. **피치 jitter**: 문장마다 ±5 cents 랜덤 변동 (0.5% 미만, 귀로는 못 잡지만 무의식 효과)
2. **볼륨 jitter**: 문장마다 -0.5 ~ +0.5dB
3. **노이즈 플로어**: -55dB 핑크 노이즈 항상 깔기 (무음이 너무 무음 아니게)
4. **숨소리 삽입**: 700ms+ 호흡 시작 부분에 "들숨" 합성 노이즈 (filter: `aevalsrc=...:duration=0.2`)
5. **마이크룸 톤**: 매우 약한 short reverb 7% wet (방 안에서 녹음한 느낌)
6. **문장 경계 crossfade**: 50ms acrossfade로 클릭 제거

이건 T1과 함께 적용해야 효과 누적.

---

### T6. 사용자 보이스 부분 녹음 + Edge TTS 혼합 (★★★★)

**아이디어**: 영상에서 진짜 중요한 5~6개 핵심 문장(메인 메시지·CTA·첫 줄)만 사용자가 자기 목소리로 녹음. 나머지는 Edge TTS. 합치면 청취자는 "어, 이 사람 진짜 사람이네" 인상이 강해짐.

**필요 핵심 문장** (5개):
1. (Scene 5) "오늘 영상의 핵심을 한 문장으로 요약하면 이겁니다. AI는 평균을 주고, 책은 깊이를 준다."
2. (Scene 14) "정리하면, AI는 평균을 주고 책은 깊이를 줍니다."
3. (Scene 36) "AI는 평균을 줍니다. 책은 깊이를 줍니다. 평균에서 깊이로 가는 사람만, AI를 도구로 쓸 수 있어요."
4. (Scene 37) "AI는 점점 더 똑똑해질 겁니다. 그건 막을 수 없어요."
5. (Scene 38) "오늘 댓글에 한 가지만 적어주세요. 요즘 읽고 있는 책 한 권."

**필요한 것**: 스마트폰 녹음 약 90초 분량. WAV/MP3 어떤 포맷이든.

**구현**: 사용자가 5개 mp3 파일을 `pipeline/audio_human/scene_05.mp3` 같은 식으로 두면, tts_gen.py가 해당 씬은 사용자 녹음 사용, 나머지는 Edge TTS.

이걸 T1과 결합하면 무료에서 끝판왕 수준 가능 (실제 9/10).

---

### T3. Coqui XTTS-v2 보이스 클로닝 (★★)

**아이디어**: 6초 reference 오디오 → 그 목소리로 한국어 모든 문장 생성. 사용자 본인 목소리 클로닝 가능.

**필요 환경**:
- Python + PyTorch (CPU도 됨, GPU 권장)
- HuggingFace에서 XTTS-v2 모델 다운로드 (~2GB)
- 사용자 6초 녹음 1개

**효과**: V4 대비 +2점. 진짜 그 사람 목소리.

**리스크**: 
- 모델 다운로드 시간 (10~30분)
- CPU에서는 합성도 느림 (씬당 30초~1분)
- 한국어 발음이 가끔 어색 (영문 알파벳 섞이면 영어 발음)
- 비전공자에게 세팅 부담

**현실적 평가**: 사용자가 명백히 원하지 않는 한 권장 안 함.

---

### T4. Bark TTS (★★)

**효과**: 자연스러운 호흡·웃음·강세 자동. 실제 들으면 사람 같음.

**문제**: CPU에서 매우 느림 (10초 텍스트 → 60~120초 합성). 38 씬 약 2700자 → **6~8시간 합성** 예상.

**현실적 평가**: 시간 여유 있으면 한 번 시도 가치. 우리 프로젝트에는 부적합.

---

### T7. MeloTTS 한국어 (★★)

**아이디어**: 오픈소스 다국어 TTS. 한국어 모델 포함. PyPI 설치 가능 (이미 시도했었음).

**한계**: KSS 데이터셋 학습이라 화자 1명 톤 고정. Edge TTS InJoon 대비 큰 차이 없음.

### tts_gen.py v5 설계

```
def split_sentences(narration):
    """한국어 문장 분리: 다/요/까/네/라+. 또는 ?·!"""
    # 정규식으로 문장 끝 토큰 + 구두점에서 split
    
def classify_sentence(text, scene, position):
    """문장 종류 판정 → rate, pitch, post_pause"""
    if text.endswith('?'): return -8%, +5Hz, 600ms
    if len(text) < 20:    return -10%, +0Hz, 500ms
    if scene.contains_key_phrase(text): return -12%, +0Hz, 500ms (pre 200ms pause)
    if position == 0:     return -5%, +3Hz, 350ms
    ...
    
async def synthesize_scene_v5(scene):
    sentences = split_sentences(scene.narration)
    sentence_audio = []
    for i, sent in enumerate(sentences):
        rate, pitch, gap = classify_sentence(sent, scene, i)
        mp3 = await edge_tts.synthesize(sent, rate=rate, pitch=pitch)
        sentence_audio.append((mp3, gap))
    return concat_with_gaps(sentence_audio)
```

## 6. 결정 포인트 (사용자께)

1. **Step 1만 갈까, Step 2까지 갈까?**
   - Step 1: 자동 합성. 사용자 작업 0.
   - Step 2: 90초 녹음 필요 (영상 임팩트 +0.5점).

2. **T5 후처리 강도**:
   - 보수적 (jitter ±0.3%, breath 5%만)
   - 적극 (jitter ±0.5%, breath 15%) — 더 사람같지만 과하면 어색

3. **호흡 길이 사용자 검수**:
   - 자동 룰만으로 (현재 권장) — 100% 자동
   - 38 씬 호흡 사용자가 직접 검수 — 정밀 가능
