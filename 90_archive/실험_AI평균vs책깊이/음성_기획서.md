# 자연스러운 한국어 내레이션 — 기획서

> AI 시대 왜 책을 읽어야 할까 영상의 음성을 "AI 같은 TTS"에서 "사람이 읽는 듯한 내레이션"으로 끌어올리기 위한 분석·기획.

---

## 1. 현재 음성이 부자연스러운 이유 (진단)

현재: `Edge TTS · ko-KR-HyunsuMultilingualNeural` + 씬 단위 mp3 + 무음 0.25s padding + 페이드인/아웃

들으면 거슬리는 8가지 패턴:

| 증상 | 원인 |
|---|---|
| 모든 문장이 같은 억양 곡선으로 끝난다 | 문맥별 prosody 변화가 없음. 평서문도 의문문도 단조. |
| 핵심 키워드("평균", "깊이")가 묻힌다 | 강조(emphasis) 신호가 없음. 음량·길이·피치 변화 0. |
| 씬과 씬 사이 호흡이 인위적 | 무조건 0.25s 무음. 문장 의미와 무관한 일률 간격. |
| 한 씬 안에서 속도가 일정 | 사람은 핵심에서 느려지고 예시에서 빨라짐. TTS는 변동 없음. |
| 숨소리·미세한 입소리가 전혀 없음 | 청자가 "녹음실 사람이 읽는다"는 신호를 못 받음. |
| 문장 끝 음정이 평탄 | 한국어 평서문은 미세 하강·문말 약화가 자연스러움. |
| 같은 주제 안에서 흐름 단절감 | 씬 단위로 잘라서 합성 → 문장 간 톤 매칭 안 됨. |
| BGM 위에서 음성이 떠 있는 느낌 | 마스터링 부재 (de-ess, 컴프, EQ 안 됨). |

**한 줄 요약:** 지금은 "기계가 한 문장씩 읽고 무음 붙이고 다음 문장으로 넘어간다." 사람의 자연스러움은 "한 단락을 통째로 호흡하면서 강세·속도·피치를 끊임없이 미세 변화시킨다"에서 나옴.

## 2. 레퍼런스 — 자연스러운 한국어 에세이 내레이션은 어떤가

### 2-1. 톤이 잘 잡힌 한국 유튜브 에세이/인사이트 채널 패턴

**공통 특징** (실제로 자주 들리는 패턴):

- **속도 변동**: 인사이트 한 줄을 던질 때 → 평균 대비 70~80% 속도. 예시·부연 설명 → 110~120% 속도. 한 문장 안에서도 핵심어에서 살짝 늘림.
- **피치 변동**: 새 단락 시작은 살짝 높게(주의 환기), 단락 끝은 살짝 낮게(closure). 의문문은 끝 음정 5~10% 상승.
- **호흡(pause)의 의미적 사용**:
  - 문장 끝 일반: 250~400ms
  - 콜론·점 다음 (예: "그건 책입니다.") : 600~900ms
  - 단락·챕터 전환: 1.0~1.5s + 살짝 톤 변화
  - 강조 직전 ("그런데... [pause] 더 중요한 건"): 400~600ms
- **강조어 처리**: 핵심 단어를 약 1.2~1.5배 길이로 늘리고, 음량 +2~3dB, 피치 +3~5%.
- **숨소리·입소리**: 매 8~12초마다 들숨 사운드 살짝, 문장 시작 직전 순간 입소리.
- **마스터링**: 약한 컴프(2~3:1, 5~8dB GR), 80Hz 하이패스, 6kHz 부근 -2dB de-ess, BGM에 듣기 좋은 -18dB ducking.

### 2-2. 비교 가능한 보이스 레퍼런스 (한국 시장 기준)

| 채널·서비스 | 핵심 특징 | 우리에게 시사점 |
|---|---|---|
| **NAVER Clova Voice "Ara"·"Mijin"·"Nara"** | 한국 시장 1위 TTS. 자연스러운 prosody 학습됨. | 유료지만 가장 자연스러움. API 키 필요. |
| **NAVER 클로바 더빙 "선중"·"승호"** | 유튜브 더빙 강자. 강세·호흡 학습됨. | 같은 NAVER 라인. 무료 체험 가능. |
| **TYPECAST(타입캐스트) 셀럽 톤 캐릭터** | "지환", "한길" 같은 캐릭터 보이스. 감정 옵션 제공. | 한국어 감정 컨트롤 가장 직관적. |
| **ElevenLabs "Antoni"·"Bella" (multilingual)** | 영어 1위, 한국어 v2 모델은 자연스러움 매우 좋음. | 핵심어 강세를 자동으로 잡아줌. |
| **OpenAI TTS-1-HD "alloy"·"echo"·"onyx"** | 다국어 모델. 한국어 점점 자연스러워짐. | 가격 합리, API 안정. |
| **Edge TTS HyunsuMultilingual** (현재) | 무료, API 안정. 단조로운 prosody. | 후처리·SSML로 끌어올려야 함. |
| **Edge TTS InJoon / SeoHyeon** | 차분/낭독체. Hyunsu보다 자연스럽다는 평. | 보이스만 바꿔도 개선 가능. |

### 2-3. 같은 대본을 사람이 어떻게 읽는지의 골격

대본 원본:
> "AI는 평균을 줍니다. 책은 깊이를 줍니다. 평균에서 깊이로 가는 사람만, AI를 도구로 쓸 수 있어요."

자연스러운 사람 읽기 (정성 분석):

```
"AI는 [살짝강조] 평균을 [짧은 늘임] 줍니다. [600ms 호흡]
 책은 [짧은 멈춤] 깊이를 [짧은 늘임] 줍니다. [800ms 호흡, 톤 살짝 낮춤]
 평균에서 [정상] 깊이로 가는 사람만, [짧은 멈춤 350ms]
 AI를 [정상] 도구로 [강조, 1.3배 늘임] 쓸 수 있어요." [문말 살짝 하강]
```

지금 우리 TTS는 위 모든 변동을 0으로 깔고 한 문장으로 통과시킴.

## 3. 솔루션 옵션 — 5가지 길

각 옵션의 [기대 자연스러움 / 구현 난이도 / 비용]을 함께 표기.

### 옵션 A. **현재 Edge TTS + SSML prosody 정밀 적용**
> 보이스는 그대로, 대본을 SSML로 풍부하게 마크업

- 핵심 작업:
  1. 38개 씬의 narration을 SSML로 재작성:
     - `<break time="500ms"/>` 의미 단위 호흡
     - `<prosody rate="0.92">…</prosody>` 인사이트 부분 살짝 느리게
     - `<prosody pitch="+3%">…</prosody>` 새 챕터 시작 약간 높게
     - `<emphasis level="strong">평균</emphasis>` 핵심어 강조
     - 문장 끝마다 `<break time="350ms"/>`
  2. tts_gen.py 변경: 평문 → SSML.
  3. 씬 사이 무음을 `0.25s` 고정 → 의미 기반 가변(0.4~1.2s)으로.
- **기대**: 6/10 → 7~7.5/10. "사람 같다" 까지는 안 가도 "기계 티가 덜 난다" 수준.
- **난이도**: 중. 코드 수정만, 외부 의존성 없음.
- **비용**: 0원. 시간 ~30분.
- **리스크**: Edge TTS의 SSML 한국어 emphasis가 종종 무시됨. 일부 마크업이 효과 없을 수 있음.

### 옵션 B. **Edge TTS 보이스 변경 + 옵션 A**
> SunHi(여) / SeoHyeon(여, 새) / InJoon(남, 차분) 등으로 비교 후 선택

- 핵심 작업:
  1. 5~6개 한국어 보이스에 같은 한 문단을 합성 → 사용자가 들어보고 고르기.
  2. 선택된 보이스로 옵션 A 그대로 적용.
- **기대**: 보이스에 따라 +0.5~1.0점.
- **난이도**: 하. 보이스 이름만 바꿈.
- **비용**: 0원. 시간 ~15분 비교 + ~30분 합성.

### 옵션 C. **TTS 후처리 마스터링 (옵션 A·B 위에 얹는 보조)**
> 합성된 음성에 컴프·EQ·de-ess·미세 reverb 적용해 "녹음실 톤" 부여

- 핵심 작업:
  1. ffmpeg `acompressor`, `equalizer`, `aphaser`, `aecho` 필터 체인 설계.
  2. compose_ffmpeg.py에 마스터링 단계 삽입.
  3. BGM에 sidechain ducking 추가 (음성 시 BGM -8dB).
- **기대**: 추가 +0.5~1.0점. "라디오 같은 따뜻함" 부여.
- **난이도**: 중. 필터 파라미터 튜닝 필요.
- **비용**: 0원. 시간 ~1시간.
- **단점**: TTS 자체의 단조로움은 가려주지만 본질은 안 바뀜.

### 옵션 D. **NAVER Clova Voice / Clova 더빙 사용 (사용자 PC 네트워크)**
> 한국 1위 TTS로 교체. 유료지만 가장 자연스러움.

- 핵심 작업:
  1. 사용자가 NAVER Clova API 키 발급 (NAVER Cloud Platform).
  2. tts_gen.py를 Clova HTTP API로 교체.
  3. 보이스 선택 (선중·승호·미진·아라 등).
- **기대**: 9/10. 한국어 톤 자연스러움 압도적.
- **난이도**: 중. API 키 + 코드 교체.
- **비용**: 약 1,000자당 4원 → 우리 대본 2,700자 × 1회 ≈ 11원. 매우 저렴.
- **선결 조건**: NAVER Cloud Platform 가입 + API 키 + 결제 카드 등록 (월 5만원 이내 무료).

### 옵션 E. **ElevenLabs Multilingual v2 (사용자 PC 네트워크)**
> 영미권 1위. 한국어 v2 모델 자연스러움 최상급. 강세 자동 추정.

- 핵심 작업:
  1. ElevenLabs API 키 발급 (월 무료 10분 음성 제공, 우리 영상 7.5분).
  2. tts_gen.py를 ElevenLabs API로 교체.
- **기대**: 9.5/10. 강세·호흡까지 자동.
- **난이도**: 중. API 키 + 라이브러리 설치.
- **비용**: 무료 등급으로 첫 영상 가능. 이후 한 번 합성에 약 $0.30 (= 약 400원).

### 옵션 F. **TypeCast 캐릭터 보이스 (사용자 PC 네트워크, 한국어 특화)**
> 한국 스타트업. 캐릭터 보이스 + 감정 컨트롤이 직관적.

- 핵심 작업:
  1. TypeCast 가입 + 캐릭터 선택 ("지환", "한길" 등).
  2. 대본 입력 → mp3 다운로드 → 우리 파이프라인에 투입.
- **기대**: 8.5~9/10. 감정 슬라이더로 "차분·인사이트형" 톤 잡기 쉬움.
- **난이도**: 중하. 웹 UI에서 다운로드 → 자동화는 약간 번거로움.
- **비용**: 무료 등급 매월 5분, 영상 7.5분이라 한 번은 유료 ($10/월) 필요.

## 4. 권장 접근 — 단계별 추천

### 권장 1순위: **옵션 D (NAVER Clova) — 한국어 1등 자연스러움 + 가장 저렴**
이유:
- 한국 시장에 최적화된 prosody. 한국어 화자가 자연스럽다고 느끼는 1순위.
- 비용이 1회 11원 수준. 부담이 거의 없음.
- API가 안정되어 있고 사용자 PC에서 인터넷 접근 가능.
- 우리 파이프라인 구조 그대로 두고 tts_gen.py만 교체.

### 권장 2순위: **옵션 E (ElevenLabs Multilingual v2) — 강세 자동 추정 최강**
이유:
- 한국어 v2 모델은 영어권 화자보다 한국 사람이 들어도 "사람 같다"는 평가가 많음.
- 강조어를 코드로 직접 마크업 안 해도 모델이 알아서 잡아줌.
- 무료 등급 안에서 첫 영상 합성 가능.
- 단점: 한국어 발음에 가끔 영미 억양이 섞일 수 있음 (v2에서 많이 개선됨).

### 권장 3순위 (만약 D·E 둘 다 안 되는 경우): **옵션 A + B + C 조합**
- 보이스를 SeoHyeon으로 교체 + SSML prosody 정밀 적용 + ffmpeg 마스터링.
- 무료지만 천장 수준은 7.5/10.

### 절대 안 하는 것
- 옵션 C 단독: 후처리만으로는 본질이 안 변함. 옵션 A·B·D·E와 항상 같이 가야 함.

## 5. 사용자께 결정이 필요한 항목

1. **API 키 발급 의사** — NAVER Clova(추천)·ElevenLabs·TypeCast 중 하나라도 가입해서 키를 발급해주실 수 있는지.
   - 어렵다 → 옵션 A+B+C 무료 조합으로 끌어올림.
   - 가능하다 → 가장 빠른 자연스러움 도약.

2. **보이스 성별·톤 취향** — 차분한 남성 / 부드러운 여성 / 신뢰감 있는 중저음 등.
   - 옵션 D 가는 경우 NAVER 보이스 카탈로그에서 한 번에 결정.

3. **마스터링 강도** — "라디오 톤"으로 따뜻하게 / "팟캐스트 톤"으로 정직하게 / 후처리 최소.

4. **씬별 호흡 길이 컨트롤 의지** — 의미 단위 호흡(권장)을 코드로 자동 할지, 38씬을 직접 검수해서 호흡을 손으로 정해줄지.

## 6. 다음 단계 (사용자 결정 후)

선택지 D 가는 경우 (가장 빠름):

1. NAVER Cloud Platform 가입 → Clova Voice 활성화 → API 키 발급 (5분).
2. 사용자가 키를 알려주시면 (메모장에 적어 주시면) `tts_gen_clova.py` 모듈 작성.
3. RUN_CLOVA.bat 더블클릭 → 38씬 재합성 → 30초 안에 완료.
4. 음성 페이드 + 마스터링(옵션 C 일부) 적용.
5. ffmpeg 합성 → 새 MP4 (V4).
6. 1차 청취 → 호흡·강세 미세 조정 → 최종.

**예상 소요 시간**: 사용자 키 발급 5분 + 합성 1분 + 마스터링·합성 5분 = **약 10분 안에 V4 완성**.

## 부록 — 무료(옵션 A+B+C) 만으로 했을 때의 한계

Edge TTS의 한국어 보이스는 본질적으로 "낭독체 학습 모델"이라 강세·감정 변동이 약합니다. SSML로 호흡과 속도는 어느 정도 잡을 수 있지만, **한국어 화자 귀가 "사람 같다"고 느끼는 임계선까지 가려면 결국 더 자연스러운 모델 (NAVER·ElevenLabs)이 필요**합니다. 무료 조합으로는 7.5/10이 천장이라고 보수적으로 잡고, 그 이상이 필요하면 D 또는 E로 가는 것이 효율적입니다.
