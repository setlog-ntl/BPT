# _AI생성 — OpenAI(gpt-image-1) 사진풍 이미지

> 🗂 **레거시(구 채널명 시기)**: 이 폴더의 시안은 구 채널명 **"그럼에도 한 페이지"** 시기 생성물이다. 채널은 2026-06-13 **"AI보다 읽는 사람"**으로 전환됐다. 새 정체성 비주얼 = [`../../docs/채널정채성/AI보다 읽는사람.png`](../../docs/채널정채성/AI보다%20읽는사람.png), 갱신된 프롬프트 기준 = [`../이미지프롬프트_00_공통가이드.md`](../이미지프롬프트_00_공통가이드.md).

채널(구 "그럼에도 한 페이지") 이미지 자산을 **OpenAI 이미지 API**로 생성한 **사진풍 결과물**.
코드 기반 타이포 시안은 별도 폴더 [`../_시안/`](../_시안/) 참조.

## ⚠️ 보안 (반드시 확인)
- API 키는 **이 폴더/문서/코드에 평문 저장하지 않는다.** 프로젝트 루트 **`.env`의 `OPENAI_API_KEY`** 에만 보관(`.gitignore`로 커밋 차단됨).
- **키가 외부(채팅 등)에 한 번이라도 노출됐다면 즉시 재발급(rotate)** 하세요 → https://platform.openai.com/api-keys
- 새 키 발급 후 루트 `.env`의 값만 교체하면 스크립트는 그대로 동작.

### 밝은(라이트) 버전 — `generate_light.py`
다크 대신 **따뜻한 크림/아이보리 + 자연광 + 골드 액센트**. 채널 정체성(책·한 페이지·진정성) 유지.

| 파일 | 생성 규격 | 내용 |
|---|---|---|
| `01_로고_밝은_AI.png` | 1024×1024 | 크림 배경 위 펼친 책 + 따뜻한 자연광, 미니멀 |
| `02_배너_밝은_AI.png` | 1536×1024 | 창가 독서 코너·책상 위 책·화분, **우측 넓은 텍스트 여백** |

> 재생성: `python generate_light.py` (밝은 톤 프롬프트는 스크립트 `LIGHT`/`JOBS`에서 조정).

- 썸네일: 우측에 `S1·EP##` 라벨 + 흐름 1줄 + 헤드라인(강조어 골드)

## 재실행 / 추가 생성
```
# 프로젝트 루트 .env 에 OPENAI_API_KEY 가 있어야 함
python generate.py
```
- 프롬프트·파일명·장수를 바꾸려면 `generate.py`의 `JOBS` 리스트 수정.
- 예: 썸네일을 EP별로 여러 장 만들려면 ③ 프롬프트를 복제하고 파일명만 변경.
- 비용: 호출당 과금(gpt-image-1 high 품질 기준). 대량 생성 전 장수 확인.
