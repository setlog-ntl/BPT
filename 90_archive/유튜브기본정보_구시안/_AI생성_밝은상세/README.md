# _AI생성_밝은상세 — 밝은 톤 · 디테일 프롬프트 세트

> 🗂 **레거시(구 채널명 시기)**: 구 채널명 **"그럼에도 한 페이지"** 시기 생성물. 채널은 2026-06-13 **"AI보다 읽는 사람"**으로 전환됨. 새 정체성 비주얼 = [`../../docs/채널정채성/AI보다 읽는사람.png`](../../docs/채널정채성/AI보다%20읽는사람.png), 갱신 프롬프트 = [`../이미지프롬프트_00_공통가이드.md`](../이미지프롬프트_00_공통가이드.md).

채널(구 "그럼에도 한 페이지") 이미지 자산을 **밝은(라이트) 톤 + 디테일 프롬프트**로 생성한 세트.
사진풍 결과는 OpenAI `gpt-image-1`. 한글 텍스트는 후처리 오버레이.

## 프롬프트 문서 (이미지별 · 디테일)
| 이미지 | 프롬프트 문서 | 규격 |
|---|---|---|
| `01_로고_밝은.png` | [`프롬프트_01_로고.md`](프롬프트_01_로고.md) | 1024×1024 |
| `02_배너_밝은.png` | [`프롬프트_02_배너.md`](프롬프트_02_배너.md) | 1536×1024 |
| `03_썸네일_밝은.png` | [`프롬프트_03_썸네일.md`](프롬프트_03_썸네일.md) | 1536×1024 |

각 프롬프트 문서 = **최종 프롬프트(복붙) + 구성요소 분해(Subject/Composition/Lighting/Color/Texture/Mood/Camera) + 네거티브 + 메모.**

## 톤 / 컨셉
- 밝은 크림·웜베이지 `#F5EFE2` + 골드 액센트 `#FFD166`, 아침 자연광, 페이스리스, 진정성.
- 로고=펼친 책 미니멀 / 배너=창가 독서 코너(우측 여백) / 썸네일=책 클로즈업(우측 여백).

## 후처리 (텍스트 오버레이)
- 로고: "그럼에도 / 한 페이지" 워드마크
- 배너: 우측 여백에 워드마크 + 서브카피 + "매주 수요일…"
- 썸네일: `S1·EP##` + 흐름 1줄 + 헤드라인 — 밝은 배경이라 **딥블랙 텍스트 + 골드 강조** 권장
- 규격 후처리: 로고 800×800 / 배너 2560×1440 / 썸네일 1280×720

## 재생성
```
python generate.py     # 루트 .env 의 OPENAI_API_KEY 사용
```
프롬프트 수정은 `generate.py`의 `LOGO`/`BANNER`/`THUMB` 또는 위 프롬프트 문서를 함께 갱신.
