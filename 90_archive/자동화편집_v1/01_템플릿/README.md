# 01_템플릿

영상 유형별 **반복 사용 가능한 구조** — 자막 스타일, 인트로/아웃트로 형식, 타임라인 패턴, 트랜지션 규칙.

## 구조

| 폴더 | 영상 유형 | 평균 길이 | 핵심 패턴 |
|---|---|---|---|
| [`풀링_쇼츠/`](풀링_쇼츠/) | 유입용 쇼츠/릴스 | 30~60초 | 후킹(0~3초) → 본론 → CTA |
| [`키_본영상/`](키_본영상/) | 전환용 본 영상 | 8~15분 | 챕터 4~6개 + 챕터마다 마이크로 CTA |
| [`랜딩_세일즈/`](랜딩_세일즈/) | 상품·서비스 전환 영상 | 2~5분 | 문제→약속→증거→CTA |

## 템플릿 1개의 표준 구성

각 템플릿 폴더에는 다음 파일을 둔다:

```
<유형>_템플릿/
├── README.md              # 이 템플릿이 언제 적용되는지
├── 타임라인_구조.md        # 초 단위 타임라인 패턴
├── 자막스타일.md           # 폰트·크기·색·위치 규칙
├── 인트로_아웃트로.md      # 어떤 자산을 쓰는지 (자산 라이브러리 참조)
└── 캡컷_편집_가이드_초안.md # 03_프로젝트/에서 이걸 복사해서 쓰는 base
```

## 템플릿 신규 추가 절차

1. `00_방향성.md` 의사결정 체크리스트 통과했는지 확인
2. 새 폴더 생성: `01_템플릿/<유형명>/`
3. 위 5개 파일 작성
4. `00_워크플로우.md` 와 본 README 표 갱신
5. 첫 영상으로 검증한 뒤 `01_템플릿/<유형명>/README.md` 에 "검증완료" 기록
