# 03_프로젝트

영상 1편 = 1폴더. 기획부터 캡컷 패키지까지 모든 산출물이 여기에 모인다.

## 폴더명 규칙

```
YYYY-MM-DD_<유형약자>_<제목요약>/
```

- 유형약자: `풀링` / `키` / `랜딩`
- 예시: `2026-05-10_풀링_데미안_3분요약/`

## 영상 1편당 표준 구조

```
2026-05-10_풀링_데미안_3분요약/
├── 00_기획서.md            # 입력 텍스트, 타깃, 후킹, CTA, 사용 템플릿 ID
├── 01_스크립트.md           # 시간코드 포함 최종 내레이션
├── 02_자료수집/             # Claude가 수집한 인용·통계·이미지 출처·참조 영상
│   ├── 인용.md
│   ├── 출처.md
│   └── 이미지/             # 로컬 캐시한 이미지 (라이선스 OK인 것만)
├── 03_캡컷_패키지/          # ★ 캡컷에 import할 핵심 산출물
│   ├── 편집_가이드.md       # 시간 순서대로 명령형으로 작성된 편집 지시
│   ├── 자막.srt            # SRT 포맷 자막
│   ├── 사용자산.md          # 02_자산_라이브러리/에서 어떤 ID를 쓰는지
│   ├── 배경음악_지정.md          # 배경음악 ID + 페이드인/아웃 타이밍
│   └── 영상소스/            # 직접 촬영/생성한 컷 (비롤은 자산 라이브러리 참조)
├── 04_썸네일/
│   ├── 카피_초안.md         # 썸네일 텍스트 후보 3개
│   └── 썸네일_v1.png
└── 05_메타데이터/
    ├── 제목_후보.md         # 제목 A/B 후보
    ├── 설명.md              # 유튜브 설명란 텍스트
    ├── 태그.md
    └── 발행체크리스트.md     # 05_체크리스트/ 복사본
```

## 새 프로젝트 시작 시

1. 폴더명 규칙에 맞게 폴더 생성
2. [`../04_프롬프트/풀링_기획서_생성.md`](../04_프롬프트/) 같은 표준 프롬프트 실행
3. 기획서 → 자료수집 → 스크립트 → 캡컷 패키지 순서로 채워나감
4. 발행 후 폴더는 보존 (자동화 패턴 학습용)
