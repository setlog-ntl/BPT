# 04_프롬프트

자동화 표준 프롬프트 5종. Claude에게 작업 지시할 때 이 프롬프트를 그대로 복사·변수만 바꿔 사용.

## 인덱스

| # | 프롬프트 | 입력 | 출력 |
|---|---|---|---|
| 1 | [`자료수집_명령.md`](자료수집_명령.md) | 주제 텍스트 | `02_자료수집/` 폴더 채움 (인용·통계·이미지·참조영상) |
| 2 | [`풀링_기획서_생성.md`](풀링_기획서_생성.md) | 주제 + 책 + 타깃 | `00_기획서.md` (후킹·구성·CTA·사용 템플릿 ID) |
| 3 | [`키_스크립트_생성.md`](키_스크립트_생성.md) | 키워드 + 챕터 개요 | `01_스크립트.md` (시간코드 포함) |
| 4 | [`캡컷_패키지_생성.md`](캡컷_패키지_생성.md) | 기획서 + 스크립트 + 자료 | `03_캡컷_패키지/` 폴더 전체 |
| 5 | [`썸네일_카피_생성.md`](썸네일_카피_생성.md) | 영상 제목 + 핵심 메시지 | `04_썸네일/카피_초안.md` (3안) |

## 사용법

```
Claude에게:
@자동화편집/04_프롬프트/풀링_기획서_생성.md 를 읽고
- 주제: [데미안의 자기 발견 3단계]
- 책: [데미안 — 헤르만 헤세]
- 타깃: [20~30대 자기성찰 키워드 검색하는 직장인]
으로 03_프로젝트/2026-05-10_풀링_데미안_3분요약/ 에 산출물 생성해줘
```

## 프롬프트 작성 원칙

각 프롬프트 파일은 다음 구조를 따른다:

```markdown
# <프롬프트 이름>

## 목적
한 줄로

## 입력 변수
- 변수명: 설명

## 산출물
- 파일 경로 + 형식

## 작업 절차
1. ...
2. ...

## 체크리스트 (출력 전 자가검증)
- [ ] ...

## 출력 예시
실제 예시 텍스트
```
