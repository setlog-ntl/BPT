# 영상 유형별 체크리스트

> 작업 도중 유형별로 빠뜨리기 쉬운 항목 점검.

## 풀링 (쇼츠/릴스)
- [ ] 후킹 첫 3초 안에 호기심 자극되는가
- [ ] 핵심 메시지 1개로 좁혀졌는가 (2개 이상 X)
- [ ] CTA가 구체적인가 (단순 "구독" X)
- [ ] 종횡비 9:16 + 자막 위치 안전구간 안에 있는가
- [ ] 자막 한 줄 ≤12자 지켜졌는가
- [ ] 배경음악 볼륨이 내레이션을 방해하지 않는가

## 키 (본 영상)
- [ ] 챕터 4~6개로 구조화되었는가
- [ ] 각 챕터에 마이크로 CTA 있는가
- [ ] 챕터 인디케이터 자막(예: "Chapter 2/5")이 화면에 있는가
- [ ] 영상 설명란에 챕터 타임스탬프가 있는가
- [ ] 자막 한 줄 ≤18자 지켜졌는가
- [ ] 인용·통계의 출처가 화면에 함께 표기되었는가

## 랜딩/세일즈
- [ ] 4단(Problem/Promise/Proof/CTA) 구조 명확한가
- [ ] 오버 프로미스(과도한 약속) 없는가
- [ ] 증거(Proof)가 구체적인가 (실 후기/숫자/스크린샷)
- [ ] 광고 표기가 필요한가 (필요하면 표시)
- [ ] CTA 링크가 영상 설명란 최상단에 있는가
- [ ] 가격·조건이 영상과 랜딩 페이지 간 일치하는가
