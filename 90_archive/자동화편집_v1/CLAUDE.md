## 1. 한 줄 정의

bizpt 콘텐츠(풀링·키·랜딩) 영상을 **템플릿·자산·자동화** 3축 체계로 제작하여, 점진적으로 캡컷 편집 부담을 줄이는 워크스페이스.

## 2. 시작 전 반드시 읽을 문서

1. [`00_방향성.md`](00_방향성.md) — 본 폴더 모든 작업의 단일 진실 원천
2. [`00_워크플로우.md`](00_워크플로우.md) — 풀링/키/랜딩 표준 제작 프로세스
3. [`README.md`](README.md) — 폴더 구조 빠른 인덱스
4. [`01_템플릿/캡컷_패키지_스펙.md`](01_템플릿/캡컷_패키지_스펙.md) — 캡컷 패키지 표준 스펙

## 3. 하드 룰

### 3.1 본 프로젝트와의 경계
- **콘텐츠 전략·기획·학습 정리는 여기서 하지 않는다.** 본 프로젝트(`../`)에서 진행.
- 본 프로젝트의 기획서를 **입력**으로 받아, 영상 제작에 필요한 **실행 산출물**만 여기서 생성.

### 3.2 폴더 구조 룰
- 새 영상 = 새 폴더: `03_프로젝트/YYYY-MM-DD_<유형>_<제목>/`
- 자산 카탈로그는 본 폴더(`02_자산_라이브러리/`), **원본 미디어 파일은 외부 경로 참조**.
- 새 자산 분위기 태그는 [`02_자산_라이브러리/태그_사전.md`](02_자산_라이브러리/태그_사전.md) 단어만 사용.

### 3.3 캡컷 패키지 룰
- [`01_템플릿/캡컷_패키지_스펙.md`](01_템플릿/캡컷_패키지_스펙.md) v1 스펙 100% 준수.
- 편집 가이드는 **명령형, 시간 순서대로**. "느낌 있게", "적당히" 같은 모호한 표현 금지.
- 자막은 SRT(UTF-8). 쇼츠 ≤12자, 키 ≤18자.

### 3.4 자료수집 룰
- 인용은 **반드시 출처 명시**. 출처 없으면 등록 X.
- 이미지는 **라이선스 확인된 것만** 다운로드.

### 3.5 진정성 룰
- 본 프로젝트 CLAUDE.md §4.4 그대로 적용 — **"좋아하는 책에 대한 진정성"** 우선.
- 클릭베이트(과장·왜곡) 카피 금지. 썸네일 카피는 자가 점검 후 사용.

## 4. 의사결정 체크리스트

새 영상/템플릿/자산 작업 전:

1. 풀링/키/랜딩 중 어디에 속하는가?
2. 기존 템플릿·자산으로 70% 이상 커버되는가?
3. 본 프로젝트의 기획서가 입력으로 존재하는가?
4. 결과물이 재사용 자산으로 추출될 여지가 있는가?
5. 캡컷 편집 가이드가 다음 사람도 따라 할 수 있게 작성되었는가?

→ 1개 이상 "아니오/모호" → 사용자에게 확인.

## 6. 사용자에게 확인이 필요한 상황

- 새 템플릿(`01_템플릿/`) 추가
- 5개 이상 자산 일괄 등록·삭제
- 발행된 영상 프로젝트 폴더 수정
- 의사결정 체크리스트(§4) 모호 항목 발생
- 본 프로젝트의 콘텐츠 결정에 영향을 주는 기획 변경

## 7. 톤 / 문서 스타일

- 한국어 기본
- 강의 용어 그대로: 풀링, 키, 랜딩, 후킹, CTA, 마이크로 CTA, 챕터
- **결론 먼저 → 근거 뒤에**
- 표·체크리스트 적극 활용
- 모호 표현 금지 ("적당히", "느낌 있게" 등) — 캡컷 가이드 작성 시 특히 엄격
