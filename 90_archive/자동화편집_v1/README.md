## 30초 사용 안내

```
1. 새 영상을 만들고 싶다
   → 03_프로젝트/YYYY-MM-DD_<제목>/ 폴더 생성
   → 04_프롬프트/풀링_기획서_생성.md 같은 표준 프롬프트로 시작

2. 자주 쓰는 배경음악/인트로/효과음을 정리하고 싶다
   → 02_자산_라이브러리/<카테고리>/카탈로그.md 에 등록

3. 새 영상 유형을 시스템에 추가하고 싶다
   → 01_템플릿/<유형>/ 폴더 추가 + 00_워크플로우.md 갱신
```
