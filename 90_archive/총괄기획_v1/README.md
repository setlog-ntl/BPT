# 총괄기획 — bizpt 운영 사령탑 (Operations Command Center)

> 이 폴더는 프로젝트 **전체를 한눈에 내려다보고 유기적으로 지휘**하는 운영 허브다.
> 전략("왜")은 [`../프로젝트_방향성.md`](../프로젝트_방향성.md)가 단일 진실 원천(SSOT)이고,
> **운영("무엇을·어떻게·누가")** 은 이 폴더가 SSOT다. 둘은 중복하지 않고 서로 링크한다.
>
> 작성: 2026-05-30

---

## 이 폴더가 하는 일

비즈니스PT 교육을 기반으로 **유튜브 전체 기획·제작 → 내 서비스·상품 판매**로 이어지는 프로젝트에서,
강의가 진행될수록 ① 강의 내용을 정리·보강하고 ② 이후 강의와 연계해 ③ 영상 제작의 여러 카테고리
(강의·지표·썸네일·제목·풀링·키·쇼츠·원고…)로 전파하는 흐름을 **한 기준 문서로 묶어 관리**한다.

이 폴더가 곧 **메인 BPT 총괄기획 에이전트(`bpt-master-planner`)의 두뇌**다.
사용자가 총괄기획에 지시하면, 에이전트는 이 폴더를 읽고 → 어느 카테고리·항목인지 판별 → 적절한
카테고리 에이전트로 라우팅하거나 그 에이전트의 맥락·내용을 직접 수정·관리한다.

## 사용법

### 사람이 쓸 때
1. `BPT_총괄기획.html`을 더블클릭 → 전체 현황·카테고리 맵·에이전트 맵을 한눈에 본다.
2. 깊은 내용·규칙은 `BPT_총괄기획.md`에서 읽는다.

### 에이전트를 지휘할 때
- Claude Code에서 **`bpt-master-planner`** 에이전트에게 자유형 지시 1개를 준다.
  - 예) `"3주차 키컨텐츠 개념을 썸네일 기준에 반영해줘"`
  - 예) `"쇼츠 기준 문서가 없으니 만들어줘"`
  - 예) `"4주차 강의 정리됐으니 풀링 카테고리에 전파해줘"`
- 에이전트가 카테고리를 판별하고, 적절한 카테고리 에이전트를 호출하거나 직접 갱신한 뒤 보고한다.

## 갱신 규칙 (중요)

- **카테고리가 늘거나 담당 에이전트가 바뀌면 → `카테고리_레지스트리.md`를 먼저 고친다.**
  그다음 `BPT_총괄기획.md`·`BPT_총괄기획.html`을 같은 내용으로 동기화한다. (3파일 정합 유지)
- **전략·정체성(채널명·3대 기둥·6축·결 3그룹·단계별 우선 기둥)이 바뀌면 → `../프로젝트_방향성.md`를 고친다.**
  여기서는 복제하지 않고 링크만 한다.
- 모든 갱신은 `bpt-master-planner`가 수행하는 것을 기본으로 하되, 사람이 직접 고쳐도 된다.
