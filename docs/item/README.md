# item/ — 아이템 선정·카테고리 산출물

비즈니스PT 2주차(아이템·단가 결정) 학습을 거쳐 사용자가 도출한 **아이템 후보·카테고리·단가** 산출물 보관소.

> **판매 라인업 정체성** (`프로젝트_방향성.md §1.1`):
> - **1차 판매 = 이북리더기** (`../keycontent/`에 키 콘텐츠 시리즈 진행 중)
> - 이후: 책 관련 제품들(필사노트·눕서대·독서등 등 본 폴더 카테고리 산출물) → readtree 서비스
> - 모이는 사람의 결: 책을 ① 읽으려는 / ② 읽고 있는 / ③ 더 읽으려는 사람

## 파일 인덱스

### SPA(`index.html`)가 직접 링크하는 파일 ⚠️
이름·위치 변경 시 `index.html`의 참조도 함께 수정해야 함 (참조 위치는 `docs/README.md` 참조).

| 파일 | 용도 |
|---|---|
| `아이템선정_워크시트.html` | 셀 직접 수정 → 변경사항 저장 다운로드 가능한 편집형 워크시트 |
| `최종선정10개.md` | 8개 카테고리 + 대표 아이템 요약 |
| `bizpt-item-categories-2026-04-28.json` | 8 카테고리·15 아이템 단가 JSON 스냅샷 (SPA 편집 데이터) |
| `bizpt-lecture-notes-2026-04-26.md` | 2주차(2-1~2-5강) IndexedDB 원본 내보내기 |

## 활용 흐름
1. **카테고리·단가 시야 잡기** → `최종선정10개.md` → `카테고리_단가분석_2026-04-28.md`
2. **시장성 3축 비교** → `아이템선정_시장성분석.html`
3. **워크시트 편집** → `아이템선정_워크시트.html` (셀 수정 → 저장 → 다운로드)
4. **데이터 동기화** → `bizpt-item-categories-2026-04-28.json` (SPA 편집 후 내보내기 결과)
5. **개인 자산 확장 검토** → `habitree_사업확장_우선순위.html` (별도 트랙)
