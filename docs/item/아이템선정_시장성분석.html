핵심 인사이트 ① — 카테고리 시너지: 3개 아이템은 모두 "몰입 독서를 돕는 도구"라는 단일 페르소나를 공유. 단품 판매가 아닌 독서 환경 큐레이션 패키지(이북리더기 + 독서등 + 클립북라이트)로 구성하면 객단가 상승 + 브랜드 콘셉트 강화 가능.

핵심 인사이트 ② — 진입 전략:
  • 저진입 시작 (아이템 2): 북라이트 OEM으로 빠른 PMF 검증 → 마진 확보
  • 중간 확장 (아이템 3): 자체 디자인 독서등으로 브랜드 형성 (프리즘 벤치마크)
  • 장기 자산 (아이템 1): 이북리더기는 직접 제조 대신 총판/리셀러 구조로 카테고리 라인업 완성

핵심 인사이트 ③ — 리스크: 이북리더기는 R&D 진입장벽이 압도적으로 높고 마진율이 낮음 → 단독 진입은 비추천. 북라이트는 무명 SKU 경쟁이 치열해 브랜딩·패키징·UX로만 차별화 가능.

다음 단계 제안

  1. 각 상품의 실제 가격·리뷰 수·평점 추가 확인 → 시장 반응 정량화
  2. 경쟁 SKU 5~10개씩 가격대별 매핑 → 포지셔닝 맵 작성
  3. 아이템 추가 선정 시 동일 양식으로 누적 → 비교 풀 확장
  4. 최종 1~2개 선정 후 사업계획서·MVP 단계로 진입
