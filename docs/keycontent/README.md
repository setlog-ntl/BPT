# keycontent/ — 키컨텐츠 기획·영상 자료

비즈니스PT 3주차(키컨텐츠 기획) 학습을 실제 키컨텐츠 자산 — **전자책 단말기** — 에 적용한 기획서·영상 대본 보관소.

> **메모**: 키컨텐츠 영상은 전자책 "단말기(전자제품)" 판매를 위한 별도 트랙. Linkmap·Appatree 같은 다른 자산은 `item/habitree_사업확장_우선순위.html` 참조.

## 활용 흐름
1. **키컨텐츠 기획 잡기** → `전자책단말기_키컨텐츠_기획.html` (8대 카테고리·신체적 불편 등 문제 매핑)
2. **개별 영상 기획** → `video_plan_AI시대_왜_책을_읽어야_할까.html` (컨셉 → 썸네일 → 10분 구성)
3. **대본 작성** → `scripts_AI시대_왜_책을_읽어야_할까.html` (버전 비교표로 톤·길이 선택)
4. **판매구조 시리즈 운영** → `scripts_판매구조_10편_시리즈.html` (Cold 4/Warm 4/Hot 2 1세트, 발행 운영표 포함)
