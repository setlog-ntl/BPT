# 3-3강 · 사이클 단계별 콘텐츠 전략

## 한 줄 요약
**5단계 사이클 뒷단으로 갈수록 인원은 줄지만 행동에 가까워 가치가 높다. 다만 계획 단계 모수가 비어 있으면 윗단(현상·욕구)으로 올라가 풀부터 채워야 한다.**

---

## 1. 사이클 위에 깔때기를 얹는다 (3-1강 위에 추가되는 그림)

3-1강은 **고객 머릿속의 5단계** 자체를 정의했고, 본 강의는 그 위에 **인원수·행동거리** 두 축을 더한다.

```
현상 ─────► 욕구 ─────► 계획 ─────► 행동 ─────► 보상
(많음)                              (적음, 행동에 가장 가까움)

   ◀────── 인원수 감소 ──────▶
   ◀────── 행동까지 거리 감소 ──▶
```

| 단계 | 인원수 | 행동까지 거리 | 콘텐츠 한 편의 ROI 특성 |
|---|---|---|---|
| **현상/상황** | 가장 많음 | 멀다 | 도달은 크지만 전환은 작음. 인지·공감용. |
| **욕구** | 많음 | 멂 | 문제 정의로 욕구 점화. 잠재고객 풀 형성. |
| **계획** | 줄어듦 | 가깝다 | 비교·검토. 장점·기능 콘텐츠가 작동하는 유일한 칸 (3-1강). |
| **행동** | 적음 | 가장 가까움 | CTA·랜딩·후기. 적은 도달로 직접 매출. |
| **보상** | 가장 적음 | (구매 후) | 사용 결과 → 다음 콘텐츠의 증거로 재활용. |

> **핵심 명제 ①**: 뒷단계로 갈수록 모수는 작아지지만, **실제 구매에 가까운 사람**이므로 적은 도달로도 콘텐츠 한 편의 가치가 더 클 수 있다. "수가 적더라도 좋다"의 의미.

---

## 2. 의사결정 룰 — 어느 단계 콘텐츠를 만들 것인가

키 콘텐츠 한 편을 기획할 때 **현재 내 깔때기에서 어느 칸이 가장 비어 있는지**가 단계 선택을 결정한다.

| 진단 | 병목 위치 | 만들어야 할 콘텐츠 | 이유 |
|---|---|---|---|
| 인지·도달 자체가 적다 | **현상·욕구가 비어 있음** | 공감 가능한 문제 환기·시장 확대 콘텐츠 | 윗단 풀이 없으면 아래로 흘릴 사람이 없다 |
| 도달은 있는데 비교·검토하는 사람이 적다 | **계획이 얇음** | 장점·기능·비교·솔루션 공감 콘텐츠 | 욕구는 점화됐지만 내 제품이 후보로 안 들어옴 |
| 비교까지는 오는데 구매가 안 일어남 | **행동이 새는 곳** | CTA·랜딩·신뢰·결제 마찰 제거 콘텐츠 | 행동 단계 마찰이 곧 전환율 손실 |
| 구매는 있는데 다음 사이클이 없다 | **보상→재구매 끊김** | 사용 결과·후기·LTV 콘텐츠 (2-5강) | 보상 고리 없이는 1회성 매출에서 멈춤 |

> **핵심 명제 ②**: "**계획하는 사람이 적다면 현상·욕구로 올라가 사람들을 모아라**" — 단계 선택은 절대적 우열이 아니라 **병목 진단의 함수**다.

---

## 3. 두 명제의 관계 — 단순화 도식

```
           [수익 효율 큼]
                ▲
                │  계획·행동 단계 콘텐츠
                │  (모수 충분할 때)
                │
   [현재 깔때기] ─┼──── 어느 칸이 비어 있나? ────► 콘텐츠 단계 선택
                │
                │  현상·욕구 단계 콘텐츠
                │  (윗단 풀 부족할 때)
                ▼
           [도달·인지 큼]
```

- **명제 ①** 만 보면 "항상 뒤쪽 단계 콘텐츠가 효율적"으로 잘못 해석할 수 있다.
- **명제 ②** 가 그 해석을 잡아준다 — 윗단이 마르면 뒤쪽 단계 콘텐츠는 모수 부족으로 작동하지 않는다.

---

## 4. 1·2주차와의 연결

- **1-4·1-5강 (퍼널·KPI 역산)**: 단계별 잔존율(예: 20% / 5% / 5%)이 본 강의의 "수가 적더라도"를 정량화한다. 행동 단계 1명을 뽑기 위해 위쪽에 몇 명이 필요한지 계산식으로 곧장 잇는다.
- **2-2강 (문제에 집중·시장 크기)**: "계획하는 사람이 적다"는 곧 **잠재고객 풀이 작다**. 본 강의의 "현상·욕구로 올라가라"는 2-2강의 시장 확대 전략과 동일한 처방.
- **3-1강 (키 콘텐츠 5원칙)**: 사이클의 **위치 정의**까지가 3-1강. 본 강의는 그 위에서 **단계 선택의 의사결정 룰**을 추가한다.

## 5. 활용 체크리스트

### 콘텐츠 기획 전 — 병목 진단
- [ ] 현재 내 깔때기에서 가장 비어 있는 칸은 어디인가? (현상·욕구 / 계획 / 행동 / 보상)
- [ ] 그 진단의 근거는 정량 데이터인가, 직감인가? (유입·전환·구매 수치 확인)
- [ ] 같은 단계 콘텐츠를 이미 여러 편 만들었는데도 효과가 없다면 — 다른 단계 병목 가능성을 의심했는가?

### 콘텐츠 단계 선택
- [ ] 윗단(현상·욕구) 콘텐츠를 만들기로 했다면 — 공감 가능 인구 규모(2-2강)는 추정했는가?
- [ ] 아랫단(계획·행동) 콘텐츠를 만들기로 했다면 — 윗단에서 흘러올 모수가 충분한가?
- [ ] "수가 적어도 좋다"를 핑계로 모수 부족을 무시하고 있지는 않은가?

### 사용 후 검증
- [ ] 콘텐츠 발행 후 **어느 단계의 인원이 늘었는지** 측정 지표가 정해져 있는가?
  (현상·욕구 = 도달·노출 / 계획 = 클릭·체류 / 행동 = 구매·CTA 클릭 / 보상 = 리뷰·재구매)

## 6. 사용자 본인 아이템에 적용 (시드 메모)

| 아이템 | 현재 추정되는 병목 | 우선 만들 콘텐츠 단계 | 이유 |
|---|---|---|---|
| readtree (메인) | 윗단 — "책이 머리에 안 남는다"는 문제 환기가 충분히 안 됨 | **현상·욕구** 콘텐츠 | 잠재고객 풀 자체를 키워야 계획 단계 비교가 발생 |
| linkmap (연계) | 윗단 — AI 도구 과잉 문제는 환기됐지만 readtree 문맥 안 결합이 미흡 | **현상·욕구** + **계획**(비교) 병행 | 이미 욕구 점화된 군이 있으므로 비교 콘텐츠가 일부 작동 |
| 책 카테고리 (필사 번들) | 아랫단 — 손목·자세 문제는 공감대 큼, 비교·후기가 부족 | **계획·행동** 콘텐츠 | 이미 욕구 점화된 시장 → 적은 도달로 직접 매출 가능 |
| 러닝 카테고리 | 아랫단 — 손목·관절 문제 공감대 형성됨 (2-5강) | **계획·행동** 콘텐츠 | 같은 이유, 카본화·아대 비교 후기로 직접 전환 노릴 수 있음 |

→ 메인 아이템(readtree·linkmap)은 **윗단부터** 채우고, 카테고리 번들은 **아랫단 콘텐츠**로 빠른 매출을 노리는 두 트랙 전략이 본 강의의 룰과 정합.

## 다음 강의와의 연결
- 3-2강 (미정리) 의 위치는 본 강의 정리 후 보강.
- 단계별 콘텐츠를 **검색 노출**(네이버·인스타·유튜브 키워드 매칭) 과 어떻게 연결할지가 다음 흐름.
- 단계별 콘텐츠가 **랜딩페이지 전환율 5%** (1-5강 목표)로 수렴하기 위한 CTA·링크 디자인 — 4주차로 이어질 것으로 추정.
