5주차강의는 풀링컨텐츠의 제작과 기초로
썸네일과 제목을 만들고 풀링컨텐츠의 기초를 설명한다


컨텐츠가치와 개인가치 채널가치가 3가지 가치가있다
컨텐츠가치는 시간과 수량이 누적되어야 가치가 올라갈수잇고 컨텐츠가치가 올라가면서 
개인가치가 올라갈수잇고 채널가치가 올라갈수잇는 영향을준다
컨텐츠가치란 특정한 내용자체가 가지고 있는 가치
컨텐츠가치가 높다면 누가이야기해도 어떤채널에서 이야기해도 잘된다 

개인가치와 채널가치는 특정개인이 유명해지고 채널이 유명해지면서 발생하는가치이기에
먼저 나의 컨텐츠가치를 만들어가며 내 개인가치와 채널가치를 키워가야한다

그렇기에 참고할만한 썸네일은 개인가치와 채널가치가 높지않고 
잘되는 썸네일과 제목들을 참고해야한다 
예를들어 아이유가 무언가를 한다면 컨텐츠가치와 관계없이 잘될수있기때문이다

만일 개인가치와 채널가치가 없지만 잘되는 썸네일이 있다면 뷰트랩을 통해서 찾아서
해당 컨텐츠는 좋은컨텐츠이며 에버그린컨텐츠로 이런컨텐츠를 찾는것이 핵심이다
이런컨텐츠를 잘찾고 만들어가면 나의 컨텐츠가치를 높일수있고 그러인해 개인가치와 채널가치를 늘려갈수있다

좋은주제를 떠오르는게 아니고 좋은주제츨 찾는것이중요하다
컨텐츠가치가 높은 풀링컨텐츠의 세가지요소는
좋은주제 : 많은사람들이 재밌게 들을수있는주제
출연자의 능력 : 좋은주제에대해 좋은관점을 풀어낼수있는 능력
제작자의 능력 : 이것들을 만들어가는 능력

뷰트랩에서 좋은주제이지만 썸네일이 별로인 항목을 디벨롭해서 좋게 만들어낸다
더높은 클릭율과 원작자와 다툼을 피하기위한 방법으로 나만의 아이덴티티로 디벨롭해야한다
디벨롭방법은 8가지이 단계별로 있으며 아래와 같다.  
풀링컨텐츠를 찾고 해당 제목을 디벨롭하여 강화하는 방법은 아래와 같다. 

1. 다른컨텐츠의 썸네일을 나의 제목으로 만든다 / 다른컨텐츠의 제목을 나의 썸네일로 만든다 
   2개의 동일주제 컨텐츠를 가지고 섞어서 만들어낸다
2. 쉬운단어로 변경한다(한자어를 일상어, 외래어나 전문용어를 일상용어로 중학생도 이해할수있을정도로 쉽게)
   예를들면 수익화 -> 돈번다, 노화 -> 늙는다 , 독서 -> 책읽기, 창업 -> 차리기 
3-1. 뷰트랩에서 조회수 검색기준 숫자를 비교하여 더 넓은 용어로 바꾼다, 상위어,동의어,일상어  
     (독서 -> 책읽기, 창업 -> 장사 , 스마트한 -> 똑똑한 )
3-2. 반의어를 찾는다 
   (이렇게하면 부자된다, 이렇게하면 가난해진다에서 부자와 가난을 뷰트랩에서 검색하여 더많은 검색량을 활용한다 가난보다 부자가 조회가 많으니 부자를 사용한다)
4. 강조하는 수식어를 덧붙인다 
   (부자가망하는이유 -> 부자가망하는 의외의 이유, 주가 오르는 종목의 공통점 -> 무섭게 오르는 종목들의 공통점)
   (해당내용들도 썸네일의 핫비디오를 통해서 검색해서 찾아내 수집한다 썸네일과 제목)
   (전설적인, 알리지말라던, 인생걸고 등등...)
5. 제목에 답이나와있다면 질문이 생기는 제목으로변경하여 궁굼하게 만든다 제목의 정답을 숨겨준다
   제목이 곧내용이면 안된다, 머리속에 물음표를 띄워라, 중요한 정보를 누락시킨다 누가 언제어디서 무엇을 어떻게 왜 이정보중 사람들이 혜택을 얻게되는것을 감춘다 시청자의 욕구를 기반으로 하라

   (아이폰 살때 화면불량을 확인해야 합니다 -> 아이폰 사고 후회하는 결정적 이유)
   (예를들면 가정주부가 외벽청소로 월 천만원을 버는 이유 라고했을때 무엇을 궁굼해할지 하나씩 제거해가며 확인해본다 
    가정주부를 뺏을때? 천만원을 뺏을때? 외벽청소를 뺏을때? 라고하면 무엇인지가 궁굼한것처럼 해당내용을 깊게고민해서 
    시청자들이 궁굼해할만한 항목을 제거해서 궁굼함을 유발하게한다) 
6. 조회수성장이 멈춘제목 -> 현재홈화면에 노출되고 있는 영상의 제목을 벤치마킹 
   (뷰트랩의 노출확률분석의 nomal 이상의 영상으로 변경한다 예를들면 특정카테고리 주제로 검색했을때 기여도와 성과도가 좋은 영상중에 노출확률이 좋은영상의 기준으로 변경 현재 트랜드를 찾아낸다) 

제목의 글자수는 35자를 메인으로한다 유튜브에서 잘리지않는 글자수가35글자이며 이후글들은 검색이되는 문구들을 넣는다 해당 주제에 맞는 검색에 걸릴만한 단어들로 채워 100자를 맞춘다 

7. 핫비디오를 활용하여 영상찾기로 찾은 주제를 핫비디오에 나온 좋은 제목에 맞도록 수정한다
8. 강력한단어로 변경한다 단, 클릭율이 높은 표현을 사후에 알수있기에 처음부터 적용하면 안된다 
   나의 생각을 기반으로하면 안되고 데이터를 기반으로하여야 하기에 임의대로 적용하면안된다 나의 컨텐츠의 경험적으로 적용해야하며 사후에 적용해야한다 그렇기에 함부로 적용하면안되고 컨텐츠가 많아지고 경험적으로 적용해야한다 
   그렇기에 1~7단계까지 적용하고 8단계를 적용해야한다 데이터가 쌓이고난뒤에는 적용하면 의미가 생긴다
