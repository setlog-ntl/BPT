# 5-1강 · 풀링 콘텐츠 제목 디벨롭 8단계

## 한 줄 요약
**좋은 주제는 "떠올리는" 게 아니라 뷰트랩에서 "찾는" 것이다. 컨텐츠가치를 먼저 쌓으면 개인가치·채널가치는 따라온다. 그래서 개인·채널가치가 낮은데도 잘된 썸네일·제목(=에버그린 후보)을 찾아, 제목을 8단계로 디벨롭해 내 아이덴티티로 강화한다. 제목은 35자가 메인(유튜브에서 안 잘리는 한계), 이후는 검색에 걸리는 키워드로 100자까지 채운다.**

5주차는 풀링 콘텐츠의 **제작 기초 = 제목과 썸네일 만들기**를 다룬다. 4주차가 "풀링 콘텐츠 4종류(무엇을 만들까)"였다면, 5주차는 "그 풀링을 **어떤 제목·썸네일로 포장할까**"다.

---

## 1. 3가지 가치 — 컨텐츠가치·개인가치·채널가치

콘텐츠가 잘되는 이유는 세 가지 가치가 섞여 있다. **우리가 통제할 수 있고, 먼저 쌓아야 하는 것은 컨텐츠가치뿐**이다.

| 가치 | 정의 | 어떻게 오르나 | 우리의 통제력 |
|---|---|---|---|
| **컨텐츠가치** | 특정 내용 **자체가 가진 가치** | 좋은 내용이 시간·수량으로 **누적** | **높음 (먼저 만든다)** |
| **개인가치** | 특정 **개인이 유명**해지며 생기는 가치 | 컨텐츠가치가 쌓인 결과로 **따라옴** | 낮음 (결과) |
| **채널가치** | 특정 **채널이 유명**해지며 생기는 가치 | 컨텐츠가치가 쌓인 결과로 **따라옴** | 낮음 (결과) |

### 1.1 인과: 컨텐츠가치 먼저 → 개인·채널가치가 따라온다
- 컨텐츠가치가 높으면 **누가 이야기해도, 어떤 채널에서 이야기해도 잘된다.**
- 그래서 신생 채널은 **내 컨텐츠가치부터 만들어가며** 개인가치·채널가치를 키워야 한다.
- 컨텐츠가치를 잘 찾고 만들면 → 개인가치·채널가치가 자연히 상승하는 **선순환**.

### 1.2 적용 룰 — "아이유 효과"를 배제하고 참고하라
- 아이유가 무언가를 하면 컨텐츠가치와 **무관하게** 잘된다(= 개인·채널가치가 끌어올림). 이런 건 참고 대상이 **아니다.**
- 참고해야 할 것은 **개인가치·채널가치가 높지 않은데도 잘된 썸네일·제목.** 그건 순수하게 **컨텐츠가치로 잘된 것** = **에버그린 콘텐츠 후보**.
- 이런 항목을 **뷰트랩에서 찾아내는 것**이 핵심이다(→ §2, 뷰트랩 활용은 [`뷰트랩_주제발굴_디벨롭_가이드.md`](../../../대본/_기획기준/뷰트랩_주제발굴_디벨롭_가이드.md)).

## 2. 좋은 주제는 '떠올리는' 게 아니라 '찾는' 것

### 2.1 컨텐츠가치 높은 풀링 콘텐츠의 3요소
| 요소 | 정의 |
|---|---|
| **좋은 주제** | 많은 사람이 **재밌게 들을 수 있는** 주제 |
| **출연자의 능력** | 좋은 주제에 대해 **좋은 관점**을 풀어낼 수 있는 능력 |
| **제작자의 능력** | 이것들을 **콘텐츠로 만들어가는** 능력 |

> 세 요소 중 **좋은 주제는 발명이 아니라 발견**이다. 머리로 짜내지 말고, 이미 시장에서 검증된 주제를 뷰트랩에서 찾는다.

### 2.2 디벨롭의 원리 — "주제는 좋은데 썸네일이 약한" 항목을 노린다
- 뷰트랩에서 **좋은 주제이지만 썸네일·제목이 별로인 항목**을 찾아 **디벨롭**해 더 좋게 만든다.
- 더 높은 클릭률 + **원작자와의 다툼 회피**를 위해 → **나만의 아이덴티티로 디벨롭**한다(그대로 베끼지 않는다).
- 풀링을 찾고 그 제목을 강화하는 표준 절차가 아래 **8단계**다.

## 3. 제목 디벨롭 8단계

> ⚠️ **순서가 곧 룰이다.** 1~7단계를 먼저 적용하고, **8단계는 데이터가 쌓인 뒤 사후에만** 적용한다(§3.8).

| 단계 | 방법 | 한 줄 |
|---|---|---|
| **1** | 제목↔썸네일 교차 조합 | 동일 주제 2개 콘텐츠를 섞어 만든다 |
| **2** | 쉬운 단어로 변경 | 한자어·전문어 → 중학생 일상어 |
| **3-1** | 더 넓은 용어로 (뷰트랩) | 조회수 비교 → 상위어·동의어·일상어 |
| **3-2** | 반의어 검색 (뷰트랩) | 검색량 많은 쪽을 채택 |
| **4** | 강조 수식어 덧붙이기 | 의외의·무섭게·전설적인 (핫비디오 수집) |
| **5** | 답을 숨겨 질문형으로 | 제목=내용 금지, 머릿속에 물음표 |
| **6** | 현재 트렌드 벤치마킹 | 홈 노출·노출확률 normal↑ 영상 기준 |
| **7** | 핫비디오 제목에 맞춰 수정 | 검증된 좋은 제목 형태로 |
| **8** | 강력한 단어로 (사후) | 데이터 누적 뒤에만 |

### 3.1 ① 다른 콘텐츠의 제목·썸네일 교차 조합
다른 콘텐츠의 **썸네일을 내 제목으로**, 다른 콘텐츠의 **제목을 내 썸네일로** 만든다. 2개의 동일 주제 콘텐츠를 가져와 **섞어서** 새 조합을 만들어낸다.

### 3.2 ② 쉬운 단어로 변경
한자어를 일상어로, 외래어·전문용어를 일상용어로 — **중학생도 이해할 수 있을 정도**로.
- 수익화 → **돈 번다** / 노화 → **늙는다** / 독서 → **책 읽기** / 창업 → **차리기**

### 3.3 ③-1 더 넓은 용어로 (뷰트랩 조회수 비교)
뷰트랩에서 조회수 검색 기준 숫자를 비교해, 더 **넓은 용어**(상위어·동의어·일상어)로 바꾼다.
- 독서 → **책 읽기** / 창업 → **장사** / 스마트한 → **똑똑한**

### 3.4 ③-2 반의어를 찾는다
같은 메시지를 반대로도 표현할 수 있다. 양쪽을 뷰트랩에서 검색해 **검색량이 많은 쪽**을 쓴다.
- "이렇게 하면 **부자** 된다" vs "이렇게 하면 **가난**해진다" → 부자가 조회가 많으니 **부자**를 채택.

### 3.5 ④ 강조하는 수식어를 덧붙인다
- 부자가 망하는 이유 → 부자가 망하는 **의외의** 이유
- 주가 오르는 종목의 공통점 → **무섭게 오르는** 종목들의 공통점
- 수식어 풀: **전설적인 · 알리지 말라던 · 인생 걸고 · 의외의 · 무섭게** …
- → 이런 수식어·제목은 **핫비디오로 검색해 수집**한다(썸네일·제목 함께). 수집물은 [`뷰트랩 정리/수식어/`](../../../뷰트랩%20정리/수식어)에 적립.

### 3.6 ⑤ 답을 숨겨 질문형으로 (※ png 슬라이드 핵심)
제목에 **답이 나와 있으면** 클릭할 이유가 사라진다. **제목이 곧 내용이면 안 된다.**
- 원칙: **머릿속에 물음표를 띄워라.** 중요한 정보(누가·언제·어디서·무엇을·어떻게·왜 중 **시청자가 혜택을 얻는 항목**)를 **누락**시킨다. 시청자의 **욕구를 기반**으로 감춘다.
- 예: "아이폰 살 때 화면 불량을 확인해야 합니다" → "**아이폰 사고 후회하는 결정적 이유**"
- **제거 테스트**: "가정주부가 외벽청소로 월 천만원을 버는 이유"에서 한 항목씩 빼본다.
  - *가정주부*를 빼면? / *천만원*을 빼면? / *외벽청소*를 빼면? → 무엇인지 **궁금해지는** 지점을 찾아 그 항목을 감춘다.

### 3.7 ⑥ 현재 트렌드 벤치마킹 (성장 멈춘 제목 구제)
조회수 성장이 멈춘 제목은 → **현재 홈 화면에 노출되고 있는 영상의 제목**을 벤치마킹한다.
- 기준: 뷰트랩 **노출확률 분석에서 normal 이상**인 영상. 특정 카테고리로 검색했을 때 **기여도·성과도가 좋고 노출확률이 좋은** 영상을 기준으로 바꿔 **현재 트렌드**를 찾아낸다.

### 3.8 ⑦ 핫비디오 제목에 맞춰 수정
핫비디오의 '영상 찾기'로 찾은 주제를, 핫비디오에 나온 **좋은 제목 형태에 맞도록** 수정한다.

### 3.9 ⑧ 강력한 단어로 변경 — 반드시 사후에
- 예: "이런 자세로 있으면 무릎 다칩니다" → "이런 자세 하는 사람은 무릎 **작살납니다**"
- **주의**: 클릭률 높은 표현은 **사후에야 알 수 있다.** 내 생각이 아니라 **데이터를 기반**으로 해야 하므로 **임의로 처음부터 적용하면 안 된다.**
- → **1~7단계를 먼저 적용**하고, 콘텐츠가 쌓여 경험·데이터가 생긴 **뒤에** 8단계를 적용해야 의미가 생긴다.

## 4. 제목 글자수 — 35자가 메인

| 구간 | 역할 |
|---|---|
| **앞 35자** | **메인 메시지** — 유튜브에서 **잘리지 않는** 글자수 한계 |
| 35자 이후 ~ 100자 | **검색에 걸리는 문구** — 주제에 맞는 검색 키워드로 채운다 |

> 즉, 핵심은 35자 안에 다 담되, 뒤는 SEO용 키워드로 100자까지 보강한다. (35자↔썸네일 헤드 7~10자/12~16자 매핑은 [`썸네일지침/03_훅_문구뱅크.md`](../../../대본/썸네일지침/03_훅_문구뱅크.md) 참조.)

## 5. 본인 채널 적용 (이북리더기 1차 → 책 관련 제품 → readtree)

> 정체성 카드(`프로젝트_방향성.md §1.1`): 결 3그룹(읽으려는·읽고 있는·더 읽으려는) × 8축(책 읽는 방법·이유·자기개발·습관·문해력·지적허영심·지적호기심·재미) × 1차 판매 이북리더기.

### 5.1 8단계를 책 분야 제목에 꽂는 예시

**예시 A — "책 읽는 습관"(8축) × 결 ②(읽고 있는 사람)**
- 원형(약함): "독서 습관을 만드는 방법" — 제목=내용(⑤ 위반), 한자어(②), 답 노출.
- ② 쉬운 단어: 독서 → 책 읽기 → "책 읽는 습관 만드는 방법"
- ③-1 넓은 용어(뷰트랩): "습관" 검색량 확인 후 유지/치환
- ④ 강조 수식어: "**3일이면 끝나는** 책 읽는 습관"
- ⑤ 질문형(답 숨김): "**왜 책 읽는 습관은 3일이면 무너질까**" — 혜택(해법)을 감춤
- 35자 체크: 17자 → 통과. 뒤에 "독서습관 책읽기 루틴 작심삼일" 검색 키워드 보강.

**예시 B — "책을 읽어야 하는 이유"(8축) × 결 ①(읽으려는 사람), 1차 판매 연결**
- ⑤ 질문형 + ④ 수식어: "**교과서도 안 읽던 사람이 1년에 100권 읽은 의외의 계기**"
- (개인·채널가치 무관하게 잘되는 에버그린형 — §1.2 참고 대상과 같은 결)
- 풀링 → 키(이북리더기 판매대본) 전환 경로 확보.

### 5.2 8단계 ↔ 뷰트랩 코워크
8단계 중 ③-1·③-2·⑥은 **뷰트랩 데이터가 있어야** 실행된다. "클로드 + 뷰트랩"으로 주제를 찾고 8단계를 자동 변주하는 절차는 별도 가이드 → [`대본/_기획기준/뷰트랩_주제발굴_디벨롭_가이드.md`](../../../대본/_기획기준/뷰트랩_주제발굴_디벨롭_가이드.md).
