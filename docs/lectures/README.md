# lectures/ — 강의별 정리본

각 강의별 markdown은 다음 템플릿으로 작성한다.

## 템플릿
```markdown
---
강의: N주차 N강
주제: <한 줄 주제>
강의일: YYYY-MM-DD
원본: <raw 또는 docs 원본 경로>
---

# N-N강 · <주제>

## 한 줄 요약
**...**

## (본문 섹션들)

## 활용 체크리스트
- [ ] ...

## 다음 강의와의 연결
- ...
```

## 작성 원칙
- **활용 가능한 형태**가 목적. 원본 그대로 옮기지 않고 **체크리스트·표·도식**으로 재구성.
- 사용자 본인 사례(readtree·linkmap·habitree·appatree, 8 카테고리·15 아이템)는 **2주차 4강·5강**에서 강의 내용과 함께 통합.
- 강의 간 모순(예: 깔때기 수치 1-4강 vs 1-5강, 시청 지속 비율 30% vs 35%)은 **표로 명시**하고 통일 기준을 적어둔다.
