## 1. 채널 정체성 1장 카드

| 항목 | 값 |
|---|---|
| **북극성** | 좋아하는 책을 축으로, 책 관련 사업을 비즈니스적으로 키우는 유튜브 채널 |
| **1차 판매** | **이북리더기** (현재 키 콘텐츠 시리즈 = 1차 판매 대본) |
| **이후 판매** | 책 관련 제품들 → **readtree** 서비스 |
| **모이는 결 3그룹** | ① 책을 **읽으려는** 사람 / ② 책을 **읽고 있는** 사람 / ③ 책을 **더 읽으려는** 사람 |
| **컨셉 8축** | 책 읽는 방법 · 책을 읽어야 하는 이유 · 자기개발 · 책 읽는 습관 · 문해력 · 지적허영심 · 지적호기심 · 책 읽는 재미 |
| **단계별 우선 기둥** | 단기 ② 책 / 중기 ③ readtree / 장기 ① 시스템 — *"책으로 시작해서, 시스템으로 끝낸다"* |

이 카드와 결이 맞지 않는 주제는 채널에 들이지 않는다.

## 2. 풀링 vs 키 — 대본 작성 관점의 차이

| 구분 | **풀링** | **키** |
|---|---|---|
| 시청자의 유입 동기 | 무목적 탐색 (알고리즘) | 목적 검색 (이북리더기 추천/비교 등) |
| 대본의 종착지 | 구독·신뢰 축적 | 구매 의도 캡처 |
| 후크 톤 | 변화·결과 약속·호기심 | 페인 진단·구체 비교·가성비 |
| 본문 톤 | 메타포·이야기·1인칭 변화 | 구조 분해·근거 표·체크리스트 |
| 상품 노출 | **직접 노출 X** — 정신적 떡밥만 | **직접 노출 O** — 가격·페인 해소 명시 |
| CTA | 다음 영상 / 구독 / "그분들 옆자리" | 클릭·비교·구매 의도 / 다음 시리즈 |
| 길이 | 메시지 충분히 전달되면 자유 | 페인→가치→추천 흐름이 끊기지 않을 만큼 |

**판별 1줄 룰**: "검색해서 들어왔는가, 알고리즘이 데려왔는가" — 검색 = 키, 알고리즘 = 풀링.

## 3. 30초 후크 룰 (요약)

상세 체크리스트는 [`30초_후크_룰_체크리스트.md`](30초_후크_룰_체크리스트.md).

- **0~30초**에 (a) 영상이 약속하는 변화·결과 / (b) 결 호명 / (c) 8축 키워드 1개 이상이 모두 자연 등장
- 첫 문장은 **결론 먼저** — 궁금증 트리거 또는 충격 카드
- 후크에서 약속한 것은 본편에 **모두 등장** (클릭베이트 회피)
- 후크와 마무리는 **수미상관** — 끝에서 후크의 키워드를 한 번 더 호명

## 4. 결 호명 룰

3그룹은 마무리 챕터에 **반드시 모두 호명**한다 — "읽으려는 분 · 읽고 계신 분 · 더 읽고 싶은 분".
표준 멘트 패턴: **"… 그분들 옆자리에 계신 분들"** — 이미 그 결에 속해 있는 시청자에게 자기 정체성을 확인시킴.

본문 중간(예: 미리보기 직후, 챕터 전환점)에는 **결 1개만** 자연스럽게 호명. 풀링은 ① 결, 키는 ②③ 결을 우선 호명.

## 5. CTA 룰

| 콘텐츠 | 1차 CTA | 2차 CTA | 3차 CTA |
|---|---|---|---|
| **풀링** | 구독 + 결 3그룹 호명 | 다음 영상 떡밥 (시리즈 다음 편) | 정신적 떡밥 — readtree 단어/프레임/성장 트리 같은 메타포만 |
| **키** | 클릭·비교·구매 의도 행동 유도 | 같은 시리즈 다음 편 (페인 → 가성비 → 추천 등) | 풀링으로 회귀 (신뢰 강화) |

**금지선:** 풀링에서 이북리더기·readtree **직접 노출 0회**. 키에서도 결 호명 없이 가격만 던지지 않음.

## 6. 진정성 점검

- "**좋아하는 책**"이라는 진정성이 문장에 살아 있는지 모든 챕터에서 점검
- 1인칭 변화 기록·자기 고백을 자기검열 없이 — 마흔 밑바닥 같은 결정적 순간은 그대로
- 학자명·논문명·연도를 발화에 욱여넣지 않음 (시청 인지 비용↑) — 출처는 **고정 댓글**로
- 단순 클릭베이트·과장 표현 금지

## 8. 챕터 구조 표준

영상 1편 = 챕터 5~8개. 각 챕터는 다음 4종 중 하나의 라벨을 갖는다.

| pill | 의미 | 위치 |
|---|---|---|
| `hook` | 후크·미리보기·결·8축 키워드 | 0~30초 |
| `body` | 본문 비트·메타포·근거 | 30초~마무리 직전 |
| `story` | 1인칭 변화·결정적 순간·감정 코어 | body 중간 1~3지점 |
| `cta` | 결 호명·다음 영상·구독·구매 의도 | 마지막 챕터 |

키 콘텐츠는 추가로 4단계 pill 사용 (`docs/keycontent/video_plan_*.html` 토큰 그대로):
- `pain` (문제 진단) → `growth` (성장 약속) → `value` (가치 비교) → `rec` (추천·구매)

## 8.5 도입부·본문 작성 룰 (7주차 반영)

> 출처: `docs/lectures/7주차_도입부_원고작성_기초/` (지시카드 + 7-1~7-4강).
> 전체·프롬프트는 [`7주차_지시카드.md`](../../docs/lectures/7주차_도입부_원고작성_기초/7주차_지시카드.md) 참조. 여기엔 대본 작성에 직접 강제할 룰만 압축.

### 8.5.1 작업 순서 (필수)
```
제목 → 썸네일 → 도입부 → 원고(본문)
```
- 본문을 도입부보다 먼저 쓰면 도입부가 본문에 끌려가 약해진다. **금지**.
- 0:00–0:10 후크 + 0:10–0:30 미리보기(§3 30초 후크 룰)가 이 "도입부" 단계에서 결정된다.

### 8.5.2 도입부 룰
- **정성 우선**: 도입부 끝에서 "다음이 궁금해서 어쩔 줄 모르겠는" 상태가 되는가? (정량=뷰트랩은 검증·확장용)
- **타분야 차용**: 같은 분야(책·독서) 도입부 베끼기 금지 → 차별성·개인가치·구독전환율 하락. 핫비디오 등 **타분야 연출을 책 분야로 번역**.
- **도입부 2패턴(기본)**: ① 과거 이력 나열형(과거→현재) ② 결과 선공개형(결과→실제 모습). 둘 다 시점을 비틀어 호기심 생성.
- **원고 4종 표기(N·S·C·A 필수)**: 도입부 30초는 4종이 모두 채워져야 통과.

| 코드 | 구성요소 | 표기 예 |
|---|---|---|
| N | 나레이션(대사) | `나레이션: "평생 책 한 권 안 읽던…"` |
| S | 지문(동작) | `지문: (책을 들어 올린다)` |
| C | 카메라(앵글·무빙) | `카메라: [클로즈업 → 줌인]` |
| A | 오디오(현장음·BGM) | `오디오: (BGM 페이드인)` |

### 8.5.3 본문 작성 — 차용·출처·보강 3요소 (그대로 옮기기 금지)
- **5단계 워크플로우**: ① 제목 다국어 번역 → ② 뷰트랩 검색 → ③ 해외 반응 좋은 영상 선별 → ④ AI 맥락 해석 → ⑤ 스크립트 → 원고화. (②③은 §3 30초 후크 룰이 아니라 7-1강 뷰트랩 기준 = 기여도·성과도·댓글수 ↑ + 광고·스팸·무관 댓글 필터링)
- **3요소 필수**: ① 차용(관점·발언 인용) ② 출처 명시("[국가]의 [채널]의 [인물]이 설명한 [내용]을…") ③ 보강("제가 해보니 이렇습니다" — 내 직접 경험).

### 8.5.4 본문 신뢰도 6가지 보강 (7-4강)
3요소 본문 위에 신뢰의 무게를 얹는다. ① 원리/주의점 · ② 내 경험 · ③ 원본 영상 캡처 · ④ 국내 사례 치환 · ⑤ 반론 증거(4종: 쇼츠 댓글·유사 주제·자문형·"XX 하지 마세요") · ⑥ 전문가 인터뷰.
- **베이스 라인(모든 본문 필수)**: ① + ② + ⑤
- **확장 라인**: ③ + ④  /  **점프 라인(히어로)**: ⑥

## 8.6 제목 기획·디벨롭 프레임 (5주차 반영)

> 출처: `docs/lectures/5주차_풀링컨텐츠_제목썸네일_기초/5-1강_제목_디벨롭_8단계.md`.
> 코워크 실행(뷰트랩+클로드)은 [`뷰트랩_주제발굴_디벨롭_가이드.md`](뷰트랩_주제발굴_디벨롭_가이드.md). 여기엔 대본 작성에 직접 강제할 룰만 압축.

### 8.6.1 전제 — 3가지 가치
- **컨텐츠가치**(내용 자체의 가치) > 개인가치·채널가치. **컨텐츠가치를 먼저 쌓으면 개인·채널가치는 따라온다.**
- 참고할 썸네일·제목은 **개인·채널가치가 낮은데도 잘된 것**(= "아이유 효과" 배제 = 순수 컨텐츠가치 = 에버그린 후보). 좋은 주제는 **떠올리는 게 아니라 뷰트랩에서 찾는다.**

### 8.6.2 제목 디벨롭 8단계 (순서가 곧 룰)

| 단계 | 방법 | 핵심 |
|---|---|---|
| ① | 제목↔썸네일 교차 조합 | 동일 주제 2개를 섞는다 |
| ② | 쉬운 단어로 | 한자어·전문어 → 중학생 일상어 (수익화→돈번다, 독서→책읽기) |
| ③-1 | 더 넓은 용어 (뷰트랩) | 조회수 비교 → 상위어·동의어·일상어 |
| ③-2 | 반의어 (뷰트랩) | 검색량 많은 쪽 채택 (부자 vs 가난 → 부자) |
| ④ | 강조 수식어 | 의외의·무섭게·전설적인 (핫비디오 수집) |
| ⑤ | **답 숨겨 질문형** | 제목=내용 금지, 머릿속 물음표, 6하원칙 중 혜택 항목 누락 |
| ⑥ | 트렌드 벤치마킹 | 노출확률 normal↑ + 기여도·성과도 상위 영상 기준 |
| ⑦ | 핫비디오 제목 맞춤 | 검증된 좋은 제목 형태로 |
| ⑧ | 강력 단어 (**사후만**) | 데이터 누적 후에만 — 1~7 먼저, 임의 적용 금지 |

### 8.6.3 글자수 룰
- **메인 메시지 35자 이내**(유튜브에서 잘리지 않는 한계). **35자 이후 ~ 100자**는 검색 키워드(SEO)로 채운다.
- 제목 35자 ↔ 썸네일 헤드(7~10자/12~16자)는 그 제목의 축약·변주 → [`../썸네일지침/03_훅_문구뱅크.md`](../썸네일지침/03_훅_문구뱅크.md).

### 8.6.4 강제선
- ⑧ 강력 단어는 **데이터 누적 후 사후 적용**(처음부터 임의 적용 금지).
- 작업 순서(§8.5.1) "제목 → 썸네일 → 도입부 → 본문"에서 **제목 단계의 실행 매뉴얼**이 본 §8.6.
