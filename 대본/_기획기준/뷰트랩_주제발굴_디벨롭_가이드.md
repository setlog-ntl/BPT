## §0. 한 줄 원칙

**좋은 주제는 떠올리는 게 아니라 뷰트랩에서 찾는 것, 제목은 8단계로 디벨롭하는 것.**
클로드는 뷰트랩 데이터(`뷰트랩 정리/`)를 읽고 8단계를 자동 변주하며, 사람은 뷰트랩에서 데이터를 캡처하고 진정성·결을 판정한다.

핵심 전제(5-1강 §1):
- **컨텐츠가치를 먼저 쌓으면 개인가치·채널가치가 따라온다.**
- 그래서 참고 대상은 **개인·채널가치가 낮은데도 잘된 썸네일·제목**(= "아이유 효과" 배제 = 순수 컨텐츠가치 = 에버그린 후보).

## §1. 뷰트랩 자산 맵 (이미 운영 중)

| 위치 | 내용 | 용도 |
|---|---|---|
| `뷰트랩 정리/단어/` | A~H 8군 100키워드, `README.md`(인덱스)·`대시보드.html`·`대시보드_빌드.py` | 키워드별 조회수·기여도·성과도·노출확률 **시계열** |
| `뷰트랩 정리/단어/{군}/{키워드}/` | `README.md` + `누적_데이터.csv` + `YYYY-MM-DD/`(필터통계.md·상위영상목록.csv) | 8단계 ③(넓은 용어/반의어)·⑥(트렌드)의 **근거 데이터** |
| `뷰트랩 정리/단어_300/` | 300개 세분화 단어 풀 | 후보 주제·키워드 확장 |
| `뷰트랩 정리/수식어/` | (현재 비어 있음) | 8단계 ④ 강조 수식어 뱅크 — **채워야 할 TODO** |

> 키워드 군 요약: A 독서_직접(30) · B 인지_능력(10) · C 자기계발(10) · D 학습_교육(10) · E 시간_습관(10) · F 감정_심리(10) · G 뇌신경_과학(10) · H 전자책_플랫폼(10).

### 뷰트랩 캡처 자동화 (기존 흐름, `단어/README.md` §자동화 작업 흐름)
1. Chrome → https://app.viewtrap.com/video-search 접속 → 키워드 검색
2. 필터 패널에서 조회수·구독자·기여도·성과도·노출확률 분포 추출
3. `{군}/{키워드}/YYYY-MM-DD/`에 `필터통계.md`·`상위영상목록.csv` 저장
4. `누적_데이터.csv` 한 줄 추가 + 키워드 `README.md` 갱신
5. `python 대시보드_빌드.py`로 대시보드 갱신

## §2. 코워크 루프 (5스텝)

```
① 후보 주제 제안(클로드)  →  ② 뷰트랩 캡처(사람)  →  ③ 데이터 적재(클로드/사람)
        →  ④ 제목 8단계 디벨롭(클로드)  →  ⑤ 후크·진정성·결 검증(클로드+사람)  ↺
```

| 스텝 | 누가 | 무엇을 |
|---|---|---|
| **①** | 클로드 | 8축 × 결 3그룹 후보 주제 N개 제안 (정체성 카드 정합 — 아래 §정합) |
| **②** | 사람 | 뷰트랩에서 후보 키워드 검색 → 조회수·기여도·성과도·노출확률 캡처 (§1 자동화 흐름) |
| **③** | 클로드/사람 | 캡처를 `뷰트랩 정리/단어*/`에 적재 + 대시보드 갱신 |
| **④** | 클로드 | 적재된 데이터로 **제목 디벨롭 8단계**(§3) 실행 → 제목 N개(35자 이내) |
| **⑤** | 클로드+사람 | 30초 후크 룰·진정성·결 3그룹 정합으로 거름 → 최종 후보 확정 |

**정합 게이트(모든 루프 통과 필수, `대본기획_기준.md §1` 정체성 카드)**: 1차 판매 = 이북리더기 / 결 3그룹(읽으려는·읽고 있는·더 읽으려는) / 8축 중 1개 이상 / 진정성(좋아하는 책) 살아 있을 것.

## §3. 제목 디벨롭 8단계 — 클로드 실행 표

> 5-1강 §3·`대본기획_기준.md §8.6`과 동일. 여기선 **"클로드에게 시키는 형태"**(입력→뷰트랩 조회→출력)로 재서술.

| 단계 | 입력 | 뷰트랩 조회 항목 | 출력 |
|---|---|---|---|
| **① 교차 조합** | 동일 주제 2개 콘텐츠 | 상위영상목록.csv (좋은 제목·썸네일) | 썸네일↔제목 섞은 신규 조합 |
| **② 쉬운 단어** | 1단계 제목 | — (사전 치환) | 한자어·전문어→중학생 일상어 |
| **③-1 넓은 용어** | 후보 단어들 | 단어별 **조회수** 비교 | 상위어·동의어·일상어로 치환 |
| **③-2 반의어** | 대립쌍(부자/가난 등) | 양쪽 **검색량** 비교 | 검색량 많은 쪽 채택 |
| **④ 강조 수식어** | 3단계 제목 | (핫비디오 수집분 `수식어/`) | 의외의·무섭게·전설적인 부착 |
| **⑤ 질문형(답 숨김)** | 4단계 제목 | — (제거 테스트) | 6하원칙 중 혜택 항목 누락 → 물음표 |
| **⑥ 트렌드 벤치마킹** | 성장 멈춘 제목 | **노출확률 normal↑** + 기여도·성과도 상위 | 현재 홈 노출형으로 교체 |
| **⑦ 핫비디오 맞춤** | 6단계 제목 | 핫비디오 '영상 찾기' | 검증된 제목 형태로 수정 |
| **⑧ 강력 단어 (사후)** | 1~7 완료 제목 | **자기 채널 누적 데이터** | 강력 표현 — *데이터 쌓인 뒤에만* |

**철칙**: ⑧은 1~7을 모두 거친 뒤, 자기 콘텐츠 데이터가 쌓인 **사후에만**. 처음부터 임의 적용 금지(5-1강 §3.9).
**글자수**: 메인 메시지 **35자 이내**, 이후 검색 키워드로 100자까지(§4 / 5-1강 §4).

## §4. 클로드 표준 지시 템플릿 (복붙용)

### A. 주제 발굴 (루프 ①)
```
@대본/_기획기준/뷰트랩_주제발굴_디벨롭_가이드.md @대본/_기획기준/대본기획_기준.md
8축 중 "[책 읽는 습관]"과 결 [②(읽고 있는 사람)]에 맞는 풀링 주제 후보 10개를 제안해줘.
개인·채널가치 무관하게 잘될 에버그린 후보 위주로. 정체성 카드 정합 게이트 통과한 것만.
```

### B. 제목 8단계 디벨롭 (루프 ④)
```
@뷰트랩 정리/단어/A_독서_직접군 의 조회수 데이터를 근거로,
주제 "[___]"의 제목을 8단계로 디벨롭해줘.
- ②쉬운단어 → ③뷰트랩 상위어/반의어 → ④수식어(@뷰트랩 정리/수식어) → ⑤질문형(답 숨김, 제거 테스트)
- 각 제목 35자 이내, 뒤에 검색 키워드 보강안 별도 표기
- ⑥은 노출확률 normal↑ 기준으로, ⑧ 강력단어는 보류
결과를 8단계 변화 과정이 보이는 표로.
```

### C. 검증 (루프 ⑤)
```
위 제목 후보를 @대본/_기획기준/30초_후크_룰_체크리스트.md 와
진정성·결 3그룹 정합으로 걸러서 상위 3개만 남기고, 탈락 사유도 적어줘.
```

### D. 뷰트랩 캡처 갱신 (루프 ②③)
```
뷰트랩에서 "[키워드]" 검색하고 대시보드 갱신해줘.
(→ 뷰트랩 정리/단어/README.md §자동화 작업 흐름 1~10 수행)
```
