## 1. 컬러 토큰 (절대 변경 금지)

### 1-1. 핵심 4색 (의미가 묶여 있다)

| 토큰 | HEX | 의미 | 어디에 쓰나 |
|---|---|---|---|
| `--pain` | `#ef476f` | 페인·과거·실패·0의 상태 | "0권", "FAILED", 빨간 사선·취소선, 좌측 BEFORE |
| `--growth` | `#06d6a0` | 성장·미래·도구·결과 | "30권", "100권", 시안 액센트 라인, 우측 AFTER |
| `--value` | `#ffd166` | 가치·강조어·"미래의 나"·노랑 강조 | 헤드 강조어 1단어, 시안 2 따뜻한 톤, EP 라벨 |
| `--info` | `#5cc4e0` | 정체성·시리즈·인용 | 시안 3 정체성형, "EP01", 인용 톤 |

> **법칙**: 한 썸네일에 4색 모두 쓰지 않는다. **2색 + 화이트/다크 배경**이 디폴트. 3색은 트래커형(키)에서만 예외 허용.

### 1-2. 다크 배경 그라디언트 (5종)

| 토큰 | 그라디언트 | 매칭 톤 |
|---|---|---|
| `bg-dark` | `linear-gradient(135deg, #1c1f29 0%, #0c0e13 100%)` | 기본 (대비형·고백형) |
| `bg-blue` | `radial-gradient(circle at 30% 30%, #2d6cdf 0%, #0c0e13 70%)` | 미래의 나·키 시안 B (`thumb-2`) |
| `bg-green` | `linear-gradient(135deg, #0c2a1c 0%, #0c0e13 100%)` | 차분한 환경·키 시안 C (`thumb-3`) |
| `bg-warm` | `radial-gradient(circle at 30% 30%, #3a2d18 0%, #0c0e13 70%)` | 풀링 고백형 (`thumb-2` 풀링) |
| `bg-amber` | `linear-gradient(135deg, #2a1c0f 0%, #0c0e13 100%)` | 풀링 비유형·근육 (`thumb-4` 풀링) |

> **다크 모드 우선** — 2026 유튜브 시청자 다수가 다크 모드. 화이트 배경은 BEFORE/AFTER split의 한쪽으로만 쓴다.

### 1-3. 대비 검증

| 검증 | 기준 |
|---|---|
| 헤드 텍스트 vs 배경 | **WCAG 4.5:1 이상** — 모바일 축소판에서 깨지지 않게 |
| `--pain` vs `--growth` 동시 노출 | 직접 인접 금지 — 사이에 화이트/다크 또는 화살표 1개 끼움 |
| `--value`(노랑) | 최대 1단어만 — 면적 8% 이하 (눈이 아프다) |

## 3. 해상도 · 안전 영역

### 3-1. 출력 사이즈

| 형식 | 사이즈 | 용도 |
|---|---|---|
| **롱폼 16:9** | **1920×1080** (또는 1280×720, sRGB) | 메인 채널 영상 |
| **쇼츠 9:16** | **1080×1920** | 쇼츠·릴스·틱톡 동시 | 
| 미리보기 4:3 | 1440×1080 | 모바일 검색 결과 (자동 크롭 — 가운데 75% 안에 핵심 배치) |

### 3-2. 안전 영역 (절대 침범 금지)

```
┌──────────────────────────── 1920px ───────────────────────────┐
│ ▒▒▒▒▒  상단 60px : 채널 배지·숫자 노출 영역 (피하기) ▒▒▒▒▒  │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │                                                         │ │
│ │              ★ 핵심 영역 (1680×900)                     │ │
│ │              헤드·숫자·메인 비주얼 다 여기                │ │
│ │                                                         │ │
│ └─────────────────────────────────────────────────────────┘ │
│ ▒▒▒▒▒  하단 우측 200×60px : 영상 길이 표시 가림 영역 ▒▒▒▒▒ │
└────────────────────────────────────────────────────────────────┘
```

| 영역 | 규칙 |
|---|---|
| 상단 60px | 모바일 알림 배지가 덮음 — 헤드 NG |
| 하단 우측 200×60px | 영상 길이 표시(`9:23`)가 덮음 — 글자 NG |
| 좌·우 가장자리 60px | 모바일 모서리 라운드 — 핵심 NG |
| 중앙 75% 박스 | 4:3 자동 크롭 시 살아남는 영역 — 헤드·숫자 모두 여기 안에 |

## 4. 템플릿 카탈로그 6종

> 각 템플릿은 **풀링 또는 키 둘 중 어느 쪽에 강한지** 표시. A/B 테스트는 다른 템플릿 2개를 짝짓는다 (같은 템플릿 색 변형은 의미 없음).

### 4-1. 대비형 (Contrast) — 풀링·키 양쪽 권장 메인

```
┌──────────────────────────────────┐
│   0          →          100      │  ← 큰 숫자 좌(빨강) → 우(노랑/시안)
│  (--pain)              (--value) │
│                                  │
│   교과서도 안 읽던 사람의 변화      │  ← 부가 1줄 (14자)
└──────────────────────────────────┘
```
- 배경: `bg-dark`
- 폰트: Pretendard 900, 숫자 200px / 부가 36px
- 강함: 풀링 권장 메인 (안 1) / 키 트래커형의 단순화 버전
- 적용 예: 풀링 "0 → 100", 키 "0권 → 30권"

### 4-2. 고백형 (Confession) — 풀링 전용

```
┌──────────────────────────────────┐
│         30대 후반,                │
│   처음 책을 다시 잡았다            │  ← 헤드 2줄 (Pretendard 130px)
│                                  │
│   ──── (노랑 라인 5px×80) ────    │
│                                  │
│   — 한 페이지가 너무 어려웠다       │  ← 부가 1줄
└──────────────────────────────────┘
```
- 배경: `bg-warm` (따뜻한 갈색)
- 톤: 차분 · 진정성 · 면죄부
- 강함: 풀링 — 결 ① 읽으려는 사람 흡인
- 절대 키에 쓰지 않음 (키는 결과·도구를 보여야 함)

### 4-3. 정체성/시리즈형 (Identity) — 풀링·키 양쪽 시리즈 시즌

```
┌──────────────────────────────────┐
│                                  │
│   그럼에도                         │
│   불구하고,                        │  ← Pretendard 110px
│   읽기로 했다  (시안 강조)          │
│                                  │
│                          EP 01   │  ← 우측 하단 (시안 18px)
└──────────────────────────────────┘
```
- 배경: `bg-dark` 또는 `bg-blue`
- 강함: 시즌 1 시리즈 통째로 — 채널 정체성 자산화
- EP 번호 필수, 시즌 단위 운영 (시즌1 = 풀링 8개, 시즌2 = 키 등)

### 4-4. 비유형 (Metaphor) — 풀링 강함

```
┌──────────────────────────────────┐
│                                  │
│      🏋️    =    📚                │  ← 큰 이모지/일러스트
│   (운동)    (독서)                 │
│                                  │
│      독서도 근육입니다             │  ← 헤드 (노랑)
│  한 번도 안 든 사람이 100kg를…     │  ← 부가
└──────────────────────────────────┘
```
- 배경: `bg-amber`
- 강함: 풀링 — 호기심 + 면죄부 동시 제공
- 주의: 이모지는 **1쌍만** (등호·화살표 포함). 4개 이상은 산만

### 4-5. 트래커형 (Tracker) — 키 강함 (이북리더기 시그니처)

```
┌──────────────────────────────────┐
│  1년 내내 0권 → 진짜 30권 읽은 미래의 나 │  ← 상단 헤드
├────────┬─────────────────────────┤
│ BEFORE │ AFTER                    │
│        │                          │
│  📕    │      ▲ 1 YEAR LATER       │
│ 0 권   │      30권                 │
│        │                          │
│ ┌─트래커 박스 (12개월 빈 격자)──┐ │
│ │ JAN 0  FEB 0  MAR 0 …       │ │
│ │ STATUS: ✗  [FAILED 도장]     │ │
│ └─────────────────────────────┘ │
└──────────────────────────────────┘
```
- 5변형 (이미 구현됨, `대본/key/이북리더기_자기계발/titles_thumbnails_*.html` 참조):
  - 3A: 12개월 격자
  - 3B: 30권 책 체크리스트
  - 3C: Goal vs Actual 바차트
  - 3D: 365일 일별 격자 (GitHub 잔디)
  - 3E: 진척률 0% 게임 UI
- 강함: 키 — 결 ②·③ 모두 (목표·도구 메시지 직격)
- A/B 풀: 5변형 중 2~3개 선정해 24h 비교

### 4-6. 권위형 (Authority) — 키 강함

```
┌──────────────────────────────────┐
│                                  │
│   [실루엣] 빌 게이츠               │  ← 일러스트·실루엣 (사진 NG)
│                                  │
│       50권 / 1년                  │  ← 큰 숫자
│                                  │
│       당신은 ?  권                 │  ← 빈칸 챌린지
└──────────────────────────────────┘
```
- 배경: `bg-dark` + 미세 spotlight
- 강함: 키 — 결 ③ 더 읽으려는 사람 (지적허영심·문해력 축)
- **저작권 안전**: 절대 실제 사진 사용 금지. AI 일러스트·실루엣·아이콘 오마주만.
- 인물 풀: 빌 게이츠 / 워런 버핏 / 일론 머스크 / 오프라 윈프리 / 무라카미 하루키 — 검증된 독서가만

## 6. 2026 트렌드 부록 (참고용)

| 트렌드 | 본 채널 적용 |

| **Proof of Human** (AI 폴리시 < 진정성) | 우리 채널의 본질과 정확히 일치 — silhouette/뒷모습/손만, AI 인물 정면 NG |

| **Blue = 신뢰·교육** | 본 채널의 시안(`#5cc4e0`)이 신뢰 톤 — 키 권위형에서 적극 활용 |

## 7. 자주 하는 실수 5

1. **헤드 글자가 너무 많다** — 14자 넘으면 모바일에서 안 읽힘. 잘라낼 단어 1개를 찾아서 자른다.
2. **색을 4개 이상 쓴다** — 한 썸네일에 2색 + 화이트/다크가 디폴트.
3. **인물 정면 사진** — 페이스리스 원칙 위반. silhouette·뒷모습·손만.
4. **EP·시안# 라벨 안 떼고 발행** — 발행 전 체크리스트(§05 §1) 1번 항목.
5. **풀링에 단말기·상품 노출** — 풀링은 광고 0%. 단말기는 키에서만.
