# 03 · 훅 · 문구뱅크

> 카피를 뽑을 때 펴는 문서. 8축별 헤드라인 풀 + 결별 진입 문구 + 시그니처 라인 + 숫자 대비 + 금지 문구.
>
> **사용법**: ① §1에서 영상의 8축 풀 1~2개 선택 → ② §2 결별 진입 문구로 톤 조정 → ③ §3 시그니처 라인 1개 결합 → ④ §4 숫자 대비 패턴 적용 → ⑤ §5 금지 문구로 거른다.

> **제목 ↔ 썸네일 헤드 매핑 (5주차 반영)**: 영상 **제목은 35자가 메인**(유튜브에서 잘리지 않는 한계, 이후 100자까지 검색 키워드). **썸네일 헤드(7~10자 한 줄 / 12~16자 두 줄)는 그 35자 제목의 축약·변주** — 같은 맥락을 유지한다. 제목 자체를 8단계로 디벨롭하는 룰은 [`../_기획기준/대본기획_기준.md §8.6`](../_기획기준/대본기획_기준.md), 뷰트랩 코워크 실행은 [`../_기획기준/뷰트랩_주제발굴_디벨롭_가이드.md`](../_기획기준/뷰트랩_주제발굴_디벨롭_가이드.md).

## 3. 시그니처 라인 풀 (채널 자산)

> 채널 1년 운영 시 시청자가 **"아, 그 채널의 그 말"**로 기억하는 라인. 8축 어디서든 자연스럽게 등장.

| 라인 | 출처 / 사용처 | 톤 |
|---|---|---|
| **그럼에도 불구하고** | 풀링 EP01 시그니처 — 채널명·시즌1 모토 | 정체성·면죄부 |
| **미래의 나** | 키 시그니처 — 자기계발 각도 | 미래·도구·변화 |
| **정상이에요** | 풀링 면죄부 — "안 읽혀도 정상" | 면죄부·동반자 |
| **단 하나의 도구** | 키 — 환경·도구 메시지 | 단순화·전환 |
| **의지가 아니라 도구** | 키 쇼츠 — 자기계발 | 단일점·전환 |
| **환경을 바꾸면 습관이 따라온다** | 키 — 차분한 환경형 | 시스템·확장성 |
| **독서도 근육입니다** | 풀링 비유형 NEW | 면죄부·재미 |
| **첫 책 / 다시 잡은 책** | 풀링 CTA | 동반자·커뮤니티 |
| **그 사람들 옆자리** | 풀링 결 호명 — "이 채널은 그분들 옆자리" | 정체성 |

> **사용 규칙**: 한 썸네일에 시그니처 라인 **1개만**. 헤드 또는 부가 중 한 곳. 두 개 동시 NG.

## 4. 숫자 대비 패턴 (썸네일에서 가장 강력한 무기)

### 4-1. 0 / N 형 (변화의 폭)

| 패턴 | 예시 | 영상 종류 |
|---|---|---|
| `0 → 100` | 0권 → 100권 (1년) | 풀링 |
| `0 / 30` | 0권 / 30권 + FAILED | 키 (트래커형) |
| `0 / 50` | 빌 게이츠 50권 / 당신은? | 키 권위형 |
| `0% / 100%` | 진척률 게임 UI | 키 트래커형 |

### 4-2. 시간 압축 형

| 패턴 | 예시 | 영상 종류 |
|---|---|---|
| `5분 / 3시간` | 5분 독서 vs 3시간 SNS | 풀링·키 |
| `7분 × 365일` | 자투리 7분 × 1년 = 12권 | 키 |
| `평생 / 며칠` | 평생을 며칠 만에 | 풀링 (4가지 이유 中) |

### 4-3. 비교 형

| 패턴 | 예시 | 영상 종류 |
|---|---|---|
| `10년 / 1년` | 10년 직장인 / 1년 독서가 | 풀링·키 |
| `30대 / 40대` | 30대 후반 / 40대에 시작해도 | 풀링 |
| `2,000원 / ?` | 책 한 권 2,000원 / 강의 50만원 | 풀링 (지적호기심) |

### 4-4. 숫자 사용 룰

1. **숫자는 헤드의 강조어와 분리** — 빨강(0/실패)·노랑·시안(목표) 명확히
2. **tabular-nums 폰트** — Pretendard에 내장. 0과 8 폭 동일
3. **소수점·퍼센트 신중** — `+243%` 같은 광고 톤 NG. 절대값 또는 0/N이 진정성
4. **단위 작게** — `30` 큰 글씨 + `권` 작게 (50% 크기)

## 6. A/B 헤드라인 짝짓기 (실전)

> A/B는 **다른 톤끼리** 짝지어야 데이터가 의미 있다. 같은 톤의 미세 변형은 측정 가치 낮음.

| A안 (메인) | B안 (변형) | 측정 의도 |
|---|---|---|
| 대비형 (`0 → 100`) | 비유형 ("독서도 근육") | 숫자 vs 비유, 어느 게 결 ①을 더 부르나 |
| 고백형 ("30대 후반…") | 정체성형 ("그럼에도 불구하고") | 진정성 직설 vs 시그니처 |
| 트래커형 (12개월 격자) | 권위형 (빌게이츠 50권) | 시각 자료 강도 vs 권위 무게 |
| 도구형 ("단 하나의 도구") | 환경형 ("환경을 바꾸면") | 단일점 vs 시스템 |

## 7. Claude로 헤드라인 30개 뽑기 (퀵 프롬프트)

> 자세한 표준 프롬프트는 [`04_제작워크플로우_AI프롬프트.md`](04_제작워크플로우_AI프롬프트.md) §2 참조. 여기는 한 줄 진입.

```
영상 제목: "<영상 제목>"
8축 주제: <8축 중 1~2개>
주력 결: <① / ② / ③>
영상 종류: <풀링 / 키>
판매 종착지: <이북리더기 / 책 관련 제품 / readtree>

위 영상의 썸네일 헤드라인 30개를 뽑아줘.
- 각 헤드는 7~10자 (한 줄형) 또는 12~16자 (두 줄형) 안
- §03 §5 금지 문구 자동 거르기
- 결 호명 단어 (§03 §2)를 헤드 또는 부가 1줄에 1개 포함
- 시그니처 라인 (§03 §3)은 30개 중 5~7개에만 사용
- 숫자 대비 패턴 (§03 §4) 활용한 안 10개 이상 포함
- 출력: 표 (번호 / 헤드 / 부가 / 톤 / 결 / 추천 템플릿)
```
