## 1. 발행 전 체크리스트 (16항목 · 5분)

## 2. A/B 테스트 운영안

### 2-1. 표준 절차 (YouTube Studio 썸네일 테스트, Q4 2025 출시 도구 기준)

```
[발행 시점]
  ↓
시안 A (메인) + B (변형) + C (실험) 3안 등록
  ↓
[+24시간] : 1차 점검
  - CTR 차이 ±10% 이상 → 우세안 채택
  - 차이 미미 → 7일 추가 테스트
  ↓
[+7일] : 2차 점검
  - CTR + 평균 시청 지속률 동시 평가
  - 평균 시청 지속률이 떨어지면 CTR 우세안이라도 폐기 (낚시 신호)
  ↓
[+30일] : 회고
  - 어떤 톤이 우리 채널에서 우세한지 누적 (§3 회고)
```

### 2-2. A/B 짝짓기 룰

| 룰 | 내용 |
|---|---|
| **다른 톤끼리** | 대비형 vs 비유형 / 고백형 vs 정체성형 / 트래커형 vs 권위형 (같은 톤 미세 변형 NG) |
| **3안 동시** | A(메인) + B(변형) + C(실험) — 2안만으론 통계적 의미 약함 |
| **같은 시점 발행** | 시안 등록 시 모두 동일 발행 시각 — 시간차 노출 NG |
| **단어 1개만 변형 NG** | "30대 후반" vs "30대 중반" 같은 미세 변경은 측정 가치 낮음 |

### 2-3. 측정 지표 우선순위

| 우선순위 | 지표 | 임계값 |
|---|---|---|
| 1 | **평균 시청 지속률** | 떨어지면 우세 CTR이라도 NG (낚시 신호) |
| 2 | **CTR (노출 클릭율)** | 채널 평균 ±10% — 그 이상이 우세안 |
| 3 | **저장·공유 비율** | 결 ②·③(읽고/더 읽으려는 사람) 결집 신호 |
| 4 | 댓글 톤 | 면죄부·동질감 댓글이 늘면 결 ① 흡인 신호 |

> **CTR 함정**: CTR만 보면 자극적 헤드가 항상 이긴다. 평균 시청 지속률을 동시에 보지 않으면 채널 톤이 망가진다.

## 4. CTR 떨어졌을 때 점검 흐름

> 채널 평균 CTR이 직전 분기 대비 -15% 이상 떨어지면 다음 순서로 점검.

```
[1단계] 영상 vs 썸네일 정합
  └ 헤드와 영상 본문이 어긋났나? (낚시?)
     YES → 본 가이드 [§01 §5 진정성 라인](01_프로젝트정합_원칙.md) 위반 — 톤 회복

[2단계] 시리즈 일관성
  └ 직전 5개 썸네일이 다른 채널처럼 보이나?
     YES → [§02 §1 컬러 토큰](02_디자인시스템_템플릿.md), §2 폰트 통일 회귀

[3단계] 결 호명
  └ 헤드/부가에 결 호명 단어가 빠졌나?
     YES → [§03 §2 결별 진입 문구](03_훅_문구뱅크.md) 강제 1개 적용

[4단계] 모바일 가독성
  └ 모바일 축소판에서 헤드 읽히나?
     NO → §02 §2 폰트 크기 + §02 §3 안전영역 재점검

[5단계] 톤 단조
  └ 같은 톤만 반복했나? (예: 대비형 5연속)
     YES → A/B 짝에 다른 템플릿 강제 투입
```

## 5. 시즌 색·시그니처 잠금 (선언)

> 시즌 단위로 채널 자산을 묶기 위해, 한 시즌이 시작될 때 **이 표 하나를 채워 GitHub/노션에 박아 둔다.** 시즌 종료까지 변경 NG.

```
─────────────────────────────────────────

기간:                  2026-05-09 ~ 2026-_____
주력 결:               ② 책을 읽고 있는 사람
시즌 시그니처 라인:    "그럼에도 불구하고"
시즌 색 (3색 잠금):    --pain #ef476f / --growth #06d6a0 / --value #ffd166
시즌 폰트:             Pretendard 800/900
시즌 메인 템플릿:      대비형 + 트래커형
시즌 EP 표기 위치:     우측 하단 (`EP 01`, 18px, --info)
시즌 끝 회고 일정:     2026-_____
─────────────────────────────────────────
```
