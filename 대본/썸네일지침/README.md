# 썸네일 지침 — 허브

> **이 폴더의 목적**
> bizpt 채널(좋아하는 책 → 1차 판매 = 이북리더기 → 이후 = 책 관련 제품 + readtree)의 **모든 영상 썸네일을 설계·제작·검증**할 때 첫 줄에서 펴는 단일 진실 원천(SSOT).
> 풀링 콘텐츠와 키 콘텐츠의 썸네일은 **목적·톤·색·문구 패턴이 전부 다르다.** 이 폴더가 그 차이를 못 박고, 8축 컨셉·결 3그룹·1차 판매 이북리더기까지 한 번에 정합시킨다.

## 0. 한 줄 원칙

**썸네일은 영상의 8.5분이 아니라, 영상의 "첫 1초"다.** 그 1초 안에 *결(누구를 부르는지)* + *축(8축 중 어느 결에 호소하는지)* + *판매 종착지(이북리더기/책 제품/readtree)*가 동시에 보이게 만든다. 그 외는 다 잘라낸다.

> 한 줄 더: **"좋아하는 책에 대한 진정성"이 빠진 썸네일은, 클릭이 잘 나와도 채널 자산이 깎인다.** 클릭만 노린 후크는 §3 §5의 금지 라인에 걸린다.

## 2. 빠른 시작 (작업 5분 체크리스트)

새 영상의 썸네일을 만들기 전, **이 6개 답을 먼저 적는다.** 한 줄도 비우지 않는다.

```
[1] 영상 종류:        풀링 / 키 / 랜딩 — 어느 것?
[2] 8축 중 어느 축:    책 읽는 방법 · 책을 읽어야 하는 이유 · 자기개발 · 책 읽는 습관
                       · 문해력 · 지적허영심 · 지적호기심 · 책 읽는 재미
[3] 결 (모이는 사람):  ① 읽으려는 / ② 읽고 있는 / ③ 더 읽으려는  중 주력은?
[4] 판매 종착지:       이북리더기(1차) / 책 관련 제품 / readtree  중 어느 것으로 가나?
[5] 핵심 한 줄(헤드):  영상 본질을 7~10자 안에. (예: "1년 뒤 30권 읽은 미래의 나")
[6] 감정 코어:         페인 / 면죄부 / 변화 / 권위 / 호기심  중 무엇을 흔드는가?
```

> 6개 중 1개라도 모호하면 **썸네일을 그리지 말고 영상 기획서로 돌아간다.** 썸네일이 흔들리는 건 거의 항상 영상 기획이 흔들리는 거다.

## 3. 4개 강령 (Do · Don't)

| ✅ Do | ❌ Don't |
|---|---|
| **한 가지 메시지** — 한 썸네일에 한 메시지. 헤드 한 줄 + 부가 한 줄 이하. | 헤드/부가/스티커/리스트 동시 노출 — 1초 안에 못 읽는다. |
| **1초 인지** — 모바일 썸네일(축소판)에서도 헤드가 읽혀야 한다. | 폰트 두께 700 이하 / 색 대비 4.5:1 미만 / 글자 18% 미만 점유. |
| **결 호명** — 시청자가 "어, 나 얘기네"를 0.5초 안에 느끼게. | "○○하는 법" 같은 공허한 일반화 — 누구를 부르는지 안 보임. |
| **진정성 우선** — 좋아하는 책·실제 경험·면죄부 톤. | 과장 숫자·낚시 후크·"충격" "경악" "절대" 류 시리얼 단어. |

## 4. 풀링 vs 키 — 30초 요약

| 축 | 풀링 썸네일 | 키 썸네일 |
|---|---|---|
| **목적** | **유입·구독**. 무목적 탐색자에게 "내 얘기네"를 만든다 | **전환**. 검색·재방문자에게 "이 도구다"를 만든다 |
| **감정 코어** | 면죄부·고백·공감 ("그럼에도 불구하고") | 권위·미래·도구 ("미래의 나" / 빌게이츠·워런버핏) |
| **숫자** | 0 vs 100 (변화의 폭) | 0권 vs 30권 + 트래커·FAILED 도장 (목표 vs 현재) |
| **메인 색** | --value(노랑·따뜻함) + --pain(과거의 0) | --growth(시안·미래) + --pain(현재의 실패) + --value(액센트) |
| **얼굴** | 본인 얼굴 또는 페이스리스 silhouette — 진정성 | 페이스리스 + 제품/도구 클로즈업 — 객관성 |
| **CTA 신호** | 없음 (구독·시청 자체가 CTA) | 명확함 (단말기·화살표·구매) |
| **기존 시안 참조** | `대본/풀링/책을.../video_plan_*.html` 4안 (대비/고백/시리즈/비유) | `대본/key/이북리더기_자기계발/titles_thumbnails_*.html` 5안 (트래커형) + `video_plan_*02_자기계발.html` 3안 |

세부는 [`02_디자인시스템_템플릿.md`](02_디자인시스템_템플릿.md) §3·§4 참조.
