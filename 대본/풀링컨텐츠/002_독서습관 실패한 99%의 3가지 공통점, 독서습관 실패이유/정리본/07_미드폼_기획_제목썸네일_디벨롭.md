## 2. 썸네일 디벨롭 (6단계 결과)

> 3요소 비중: 이미지 45 · 문구 45 · 디자인 10. 목표=클릭, 핵심=공감. 기존 시안 `../썸네일/1.png`·`2-이미지교체.png`·`썸네일추천_독서습관실패99.html` 대비 6단계로 강화.

| 단계 | 적용 | 구체 시안 |
|---|---|---|
| **① 확대** | 클릭 포인트만 남기고 확대 | **덮인 채 쌓인 안 읽은 책 더미** 위에 X 표시 / 또는 책 덮으며 한숨짓는 인물 상반신 (페이스리스: 손·옆모습) |
| **② 증명** | 후킹의 시각적 증거 | 달력에 **빨간 X 3개**(=3일) + 작게 "99%" 도장 |
| **③ 궁금증** | 정답(쉬운 책) 숨김 | 해결책은 안 보이고 "**왜 3일이면 덮을까?**" 만 |
| **④ 공감** | 예쁨 X, 겪는 상황, **왼쪽 위** | 좌상단에 **방치된 책 + 먼지**(공감 이미지) / 핵심 문구도 좌상단 |
| **⑤ 시청층 선호** | 나이·성별 타겟 | 2030~40 독서 입문층 톤(과한 연출 X, 현실적 책상) |
| **⑥ 뷰트랩 학습** | 성과도 높은 구성 반영 | "작심삼일·독서습관" 맥락 핫 썸네일 구성 학습 → `뷰트랩 정리/단어/E_시간_습관군/작심삼일` |

**문구 배치(45%)** — 제목과 정합, 큰 글씨:
- 메인 헤드(좌상단, 9~12자): **「3일 만에 덮는 이유」** 또는 **「99%가 3일이면 포기」**
- 색 토큰(`02_디자인시스템`): "3일/99%/실패" = `--pain`(빨강), "공통점" = `--value`(노랑 강조어). 배경 `bg-dark`.
- 진정성 라인 준수: 숫자 과장·낚시·AI 인물 금지(99%·3일은 영상 내 근거 있음).

**A/B 3개안**(6주차 기본원칙: 3개 제작·1주일 내 교체):
1. **공감형**: 방치된 책 더미 + "3일 만에 덮는 이유"
2. **증거형**: 달력 X 3개 + "99%가 3일이면 포기"
3. **고백형**: 덮은 책↔절반 펼친 책 split + "5년 전의 나"

## 3. 미드폼 1~3분 영상 기획 (목표 ~2:30)

### 3.1 도입부 N·S·C·A (0:00–0:30) — 후크
| 코드 | 0:00–0:30 |
|---|---|
| **N 나레이션** | "책 읽으면 좋다는 얘긴 지겹게 들으셨죠. 근데 속으론 '아는데… 못 읽겠는데 어쩌라고.' 성인 10명 중 6명이 1년에 책 0권. **시간·의지 문제가 아니라 '시작하는 방법'에 함정**이 있어서예요. 새해마다 결심하고 3일이면 덮는 99%, 거기엔 **딱 3가지 공통점**이 있어요. 못 읽는 건, 당신 잘못이 아닙니다." |
| **S 지문** | (쌓인 안 읽은 책 더미 앞 한숨 → 손으로 '57%' 자막 가리킴 → 손가락 1·2·3) |
