## 3. 풀링별 제목 8단계 디벨롭 (35자 이내)

> 단계: ② 쉬운 단어 → ③-1 넓은 용어(뷰트랩) / ③-2 반의어 → ④ 강조 수식어 → ⑤ 답 숨겨 질문형 → (⑥⑦ 트렌드/핫비디오는 라이브 뷰트랩) / ⑧ 강력단어 **보류**.
> ★ = 채택 후보(메인). 글자수 = 공백 포함.

### 풀링1 · 평생 안 읽던 사람의 변화 (결①·책 읽는 이유)
| 단계 | 제목 |
|---|---|
| 기존 | 평생 안읽던 사람이 책을 읽기 시작하면 벌어지는 일 (24자) |
| ② 쉬운 | 평생 책 안 보던 사람이 책을 읽으면 생기는 일 |
| ④ 수식어 | 평생 책 안 보던 사람에게 **진짜로** 벌어지는 일 |
| ⑤ 질문형(답 숨김) | ★ **평생 책 안 읽던 사람, 1년 뒤 뭐가 달라졌을까** (24자) |
| 보강(SEO 100자) | …독서효과 독서변화 인생책 책읽는법 자기계발 |

→ 결①(읽으려는)에 "변화 약속" + 답을 숨겨 호기심. 8축: 책 읽어야 하는 이유.

### 풀링2 · 독서습관 실패 99% (습관·결②) ★미드폼 후보
| 단계 | 제목 |
|---|---|
| 기존 | 독서습관 실패한 99%의 3가지 공통점 (20자) |
| ② 쉬운 | 책 읽는 습관 실패하는 99%의 3가지 공통점 |
| ③-1 넓은 풀 | "독서습관"(1459만) → **"작심삼일"(5450만)** 결합 |
| ④ 수식어 | 책 읽기 **작심삼일** 하는 99%의 결정적 공통점 |
| ⑤ 질문형 | ★ **책 읽기 3일 만에 포기하는 사람들의 공통점** (24자) |
| 대안(반의어/부정) | 책 읽는 습관, 왜 99%가 3일 만에 무너질까 |
| 보강(SEO) | …독서습관 작심삼일 독서실패 책읽기 독서초보 책추천 |

→ "실패/포기"(부정 프레임) + "작심삼일"(큰 풀) + "3일"(구체 숫자). 결: 습관 안 된 사람 + ② 읽고 있는 사람. 키(이북리더기=가볍게 시작하는 습관 도구)와 직결.

### 풀링3 · 책 많이 읽으면 돈 벌까 (자기계발·결③)
| 단계 | 제목 |
|---|---|
| 기존 | 책 많이 읽으면 돈 벌 수 있을까 (16자) |
| ③-2 반의어 | 책 많이 읽어도 돈 못 버는 이유 *(부정 프레임 — 반의어 통찰)* |
| ④ 수식어 | 책 많이 읽어도 **부자 못 되는** 사람들의 공통점 |
| ⑤ 질문형 | ★ **책 많이 읽는데 왜 돈은 안 모일까** (17자) |
| 보강(SEO) | …독서수익 자기계발 부의비밀 다독 책읽기 독서법 |

→ 반의어/부정 프레임(읽어도 돈 못 번다)이 호기심·반전. 결③(더 읽으려는)·8축 자기계발.

### 풀링4 · 읽어도 머리에 안 남는 이유 (문해력·효과 없던 사람)
| 단계 | 제목 |
|---|---|
| 기존 | 책 읽어도 머리에 안 남는 이유 (16자) |
| ③-1 넓은 풀 | "문해력"(4796만) 결합 |
| ④ 수식어 | 책 읽어도 **하나도** 기억 안 나는 결정적 이유 |
| ⑤ 질문형 | ★ **책 읽어도 다음 날 까먹는 사람, 뭐가 문제일까** (25자) |
| 보강(SEO) | …문해력 독서법 기억력 완독 독서노트 책읽는법 |

→ 결: "읽어도 효과 없던 사람"(6주차 결 확장) 정조준. 8축 문해력.

### 풀링5 · 벽돌책 완독의 비밀 (책 읽는 재미·결③)
| 단계 | 제목 |
|---|---|
| 기존 | 벽돌책 처음 끝까지 읽는 법 (14자) |
| ③-1 넓은 풀 | "완독"(6294만)·"다독"(7243만) 결합 |
| ④ 수식어 | **죽어도** 안 넘어가던 벽돌책 끝까지 읽은 법 |
| ⑤ 질문형 | ★ **벽돌책 100페이지도 못 넘던 내가 완독한 비결** (25자) |
| 보강(SEO) | …완독 다독 벽돌책 독서법 코스모스 책추천 |

→ 결③(더 읽으려는)·8축 책 읽는 재미. 1인칭 변화(진정성).

→ 5개 중 **클릭률·판매 직결·제작 속도·진정성** 모두 최상. **풀링2를 미드폼으로 확정 추천.**
