# 편집/ — 편집 기획 영역 (대본기획과 별도 관리)

> 영상 **편집(컷 배열·재미 순서)** 전담 영역. 원고(대본) 작성과는 **분리해서 관리**한다. (분리 확정 2026-06-13)

## 왜 분리하나
- **대본기획**(`대본/_기획기준/`) = 원고를 **원칙대로 쓰는** 단계.
- **편집기획**(이 폴더) = 그 원고를 **재미 순으로 파괴·재배열하는** 단계.
- 두 단계는 태도·기준·순서가 정반대라(원칙주의 ↔ 재미지상주의) 룰북을 섞지 않고 독립 운영한다.
